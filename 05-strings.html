Strings and alignment

You’re given the strings axb and ayb. You may delete characters independently from each while keeping their order. Find the longest string both can produce. The diagram compares one prefix from each input at a time.

Start this topic in reading order → · See the whole reading path

  • Two prefixes and the last alignment columnYou have the strings ab and acb. In one step you can delete a letter, insert a letter, or replace one letter by another. Each step costs 1, and keeping an equal letter costs 0. Find the smallest cost of turning ab into acb.
  • Recover a shortest string containing both inputs as subsequencesYou have two strings, ab and ac. Write the shortest possible new string that contains each of them in order, allowing gaps. One written character may serve both strings, as the initial a can here. Return one shortest string.
  • Count a fixed pattern inside a streamYou’re given a text and a fixed pattern. Count the ways to choose positions in the text, in increasing order, that spell the pattern. For pattern aa and text aaa, track which two occurrences of a you chose.
  • Dictionary breaks, trie edges, and weighted parsingYou have the text aba and a dictionary containing a, ab and ba. Split the whole text into adjacent dictionary words, with no gaps. Count the different splits. A dictionary word may be used again if the text allows it.
  • Carry the longest relevant suffixBuild a binary word of length three from left to right. Count the words in which two 1s never appear next to each other. An appended bit is legal only if the word still avoids the forbidden pattern 11.
  • Count wildcard bracket strings by their open balanceReplace each of four question marks by an opening or a closing bracket. Count the replacements for which every closing bracket matches an earlier opening bracket and every opening bracket is eventually closed.
  • Jump over a balanced suffix to find its opening bracketYou’re given a string of parentheses. For each position find the length of the longest balanced substring ending exactly there. In ()(()), the last closing bracket completes the whole six-character string, including the earlier pair ().
  • Different subsequences, next occurrences, and rankingYou can delete any positions of the string aa, keeping the order of the remaining letters. Count different resulting strings, including the empty one. Deleting the first a or deleting the second a produces the same one-letter result.
  • Restrict edit distance to a diagonal band when only k edits matterGiven two strings and a limit k, decide whether at most k single-character insertions, deletions or substitutions can turn one into the other. For kitten and sitten let k=1. The strings in the larger version may be long even when the edit budget is small.
  • Only matching pairs can improve LCSGiven two strings, find the length of their longest common subsequence. You may skip letters in either string but must preserve their order. For ab and aab, the first a has two possible partners. In the larger version relatively few pairs of positions hold equal letters.
  • A witness from two thin rowsGiven axb and ayb, return an actual longest sequence of letters appearing in order in both strings. You can skip letters freely, but your memory budget holds only a few rows of the usual table. Knowing the optimum length alone will not identify the letters to print.
  • Rank distinct substrings by counting paths in a suffix automatonList every different nonempty contiguous substring of aba once and sort the list in dictionary order, with a shorter prefix first. Return the fourth entry. On a long string you need to find the requested entry without materializing the full list.
  • Palindrome boundaries, suffix links, and series linksSplit ababa into contiguous blocks, each of which must read the same forwards and backwards. Every letter belongs to exactly one block. Return the smallest possible number of blocks. To end at a particular position, the last block must be a palindrome ending there.

Test your recognition
A million identical letters make every suffix palindromic. Is one visit per palindromic suffix efficient?

It makes Θ(n²) visits over all prefixes. Group suffix lengths with equal successive differences using series links and aggregate their contribution.

The two strings are permutations of the same n symbols. How can you avoid n² LCS cells?

Replace symbols in the first sequence by their positions in the second. Their strict LIS is the LCS. With repeats, list all matching positions in descending order within each first-string position.
