Find the first integer missing from a subarray LCM

For each nonempty contiguous subarray, imagine computing its LCM and finding the first positive integer that does not divide that LCM. Return all distinct answers achievable across subarrays. The array entries are small compared with the LCM they can generate.

Work through the example

  1. With [2,3,4,1], an interval containing just 3 first misses 2. The interval [2,3] has LCM 6 and first misses 4. The first three elements give LCM 12 and first miss 5. A composite with two distinct prime factors cannot be first missing because its maximal prime-power factors are smaller.
  2. For a candidate prime power x, positions divisible by x are barriers. Between consecutive barriers take the whole gap. Extending inside the gap keeps x absent and can only add smaller powers. Just before each barrier i, test whether every smaller prime power has appeared strictly after the preceding barrier.
  3. Sweep once from left to right. Store the latest occurrence of a multiple of each prime power in a range-minimum tree ordered by the numerical powers. At a position, test all powers dividing its value before updating any latest indices. Add a final sentinel barrier for every candidate, including the first prime power above n. Use index 0 for unseen powers.

Why it works

An integer divides an LCM exactly when every prime power in its factorization divides at least one array element. The first failure is consequently a prime power. A single minimum over smaller powers certifies that they all have a witness in one and the same barrier gap.

When the conditions change

Inputs satisfy aᵢ≤n. Precompute prime powers and the powers dividing each input via smallest-prime factors. Each value has O(log n) such powers, giving O(n log² n) time. Check the gap is nonempty, particularly when x=2 has no smaller prime-power requirement.

Try one change

Would checking all smaller primes suffice?

Show the reasoning

No. An interval can include a multiple of 2 but no multiple of 4. The missing 4 must be detected before testing 5.

From idea to code

Index the minimum tree by numerically sorted prime powers. Query before updating the latest occurrence, so an obstacle never counts as a witness inside its own gap.
