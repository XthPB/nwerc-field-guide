Build a zero-sum witness by following indices

Each array entry at one-based index i obeys 1 ≤ i−aᵢ ≤ n. Find a nonempty subset with sum zero. What does this unusual bound let you build?

Work through the example

  1. For a = [−1,−1,2,0], draw the arrow from each i to i−aᵢ. The first three arrows are 1→2, 2→3 and 3→1.
  2. Follow arrows from any index, recording its first visit. Once an index repeats, take precisely the vertices from its first visit up to the repeat. Here the values on that cycle sum to −1−1+2=0.
  3. The method works even when the initial walk has a long tail. Discard the tail. A self-loop is also a valid one-element answer.

Why it works

On every arrow u→v the array value equals u−v. Around a cycle each index occurs once with a plus sign and once with a minus sign. The input bounds ensure that every arrow has an endpoint inside the array, so a repeat is inevitable.

∑i∈Cai=∑i∈C(i−next⁡(i))=0\sum_{i\in C}a_i=\sum_{i\in C}\bigl(i-\operatorname{next}(i)\bigr)=0i∈C∑​ai​=i∈C∑​(i−next(i))=0

C is the set of vertices on one directed cycle.

When the conditions change

O(n) time and space. Preserve one-based labels when computing i−aᵢ. The distinct vertices on the cycle are the subset to return.

Try one change

Could the same trick prove a weighted sum is zero?

Show the reasoning

Yes if the chosen edge labels have the form potential(u)−potential(v). Every directed cycle cancels those labels.

From idea to code

The function from one index to the next is the graph. Keep first-visit positions to slice the witness straight out of the walk.
