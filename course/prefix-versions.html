Range queries and sweeps · 14 of 19

Subtract two versions to descend to a range order statistic

You’re given a fixed array and many queries, each specifying an interval and a rank k. Return the kth-smallest occurrence inside that interval, counting duplicates. In [5,1,5,3], the example asks for the second-smallest value at positions 2 through 4.

Work through the example

  1. Build one frequency-tree version after every prefix, copying only nodes on the inserted value’s path. Query version 4 minus version 1 to represent [1,5,3].
  2. In the lower value half {1,3}, the difference count is two. The second item is in this half.
  3. Split {1,3}. Only one item is at 1, so skip it. The remaining first item is 3.

Why it works

Paired descent works because prefix frequencies subtract to nonnegative range frequencies. For branching historical updates use a version tree; subtracting unrelated versions no longer means an array interval. A wavelet tree or matrix answers static rank and kth by remapping index ranges by value bits.

When the conditions change

O(log σ) per insertion and kth query with O(n log σ) copied nodes. CF 840D descends only where the count can exceed a threshold; CF 813E encodes previous occurrences before querying historical counts. CSES Range Queries and Copies practices branching versions.

Try one change

Can the same two-root subtraction recover a range minimum from prefix minima?

Show the reasoning

No. Minimum has no inverse. Frequencies work because they are additive.
