Solve a random stopping game in XOR space

A token is repeatedly added at a uniformly chosen DAG vertex, with one extra equally likely choice to stop. At stopping time, two players move tokens until one loses. What is the first player's win probability from no tokens?

Work through the example

  1. A sink has Grundy value zero. A vertex with an edge only to that sink has value one. With these two vertices, the three equally likely actions are stop, toggle the token XOR, and leave it unchanged. Starting at zero gives p₀=(p₁+p₀)/3 and p₁=(1+p₀+p₁)/3, so p₀=1/3.
  2. Compute Grundy values in reverse topological order and count how many vertices have each value g. Let p[x] be the win probability starting at token XOR x. At stop, the win indicator is [x≠0]. Adding at a vertex sends x to x XOR g.
  3. The resulting linear system contains an XOR convolution of p with the counts c. Apply the Walsh–Hadamard transform. Each transformed coordinate becomes one division. Invert the transform and take p[0].

Why it works

The XOR of independent impartial positions determines the winner once stopped. Before stopping, the continuation probability is n/(n+1)<1, ensuring a unique real solution. The Walsh characters turn every XOR shift into multiplication by +1 or −1.

(n+1−c^[t]) p^[t]=[x≠0]^[t](n+1-\widehat c[t])\,\widehat p[t]=\widehat{[x\ne0]}[t](n+1−c[t])p​[t]=[x=0]​[t]

When the conditions change

(n+1)p[x] − Σg c[g]p[x XOR g] = [x≠0]. Each transformed denominator is between 1 and 2n+1 and below the contest modulus. Use a power-of-two transform length H exceeding the largest Grundy value, including H=1 when all are zero. With linear-time marked mex per adjacency list, O(n+m+H log H) time.

Try one change

What happens if every vertex is a sink?

Show the reasoning

Every token position has Grundy value zero and the player to move at stopping always loses. The probability is zero.

From idea to code

Call the XOR transform on the frequency vector and the stopping payoff. Divide coordinatewise, then apply the inverse transform with its normalization.
