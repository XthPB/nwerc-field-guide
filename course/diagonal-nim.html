Restore one XOR per diagonal after a grid move

A grid holds nonnegative integers. A turn reduces a chosen positive cell, then may change later cells along one right/down path by arbitrary amounts, keeping them nonnegative. Players alternate and a player with no move loses. Decide the winner from the initial grid.

Work through the example

  1. In the 2×2 grid [0 3; 3 0] every antidiagonal XOR is zero. Decreasing the upper-right 3 to 2 changes the middle diagonal XOR to 1. Any later cell on that path lies on another diagonal, so the mover cannot repair this first change.
  2. From a position with a nonzero diagonal XOR, take the earliest such diagonal. The Nim highest-bit argument gives a cell whose value can be decreased to make that diagonal's XOR zero.
  3. Extend a southeast path from that cell to the bottom-right corner. On each later diagonal the path contains exactly one cell. Set that cell to its old value XOR that diagonal's current XOR. This restores every later diagonal. Earlier ones were already zero.

Why it works

Every move from all-zero diagonal XORs leaves the first affected diagonal nonzero. From every other position there is a legal move back to all-zero diagonal XORs. The coordinate sequence in diagonal order decreases lexicographically at its earliest changed entry, providing termination for finite grids of nonnegative integers.

When the conditions change

O(nm) time, O(n+m) stored diagonal XORs, and less memory if counting diagonals during a suitable scan. The construction uses the freedom to increase a later cell on the path.

Try one change

Does XORing every cell in the whole board suffice?

Show the reasoning

Two nonzero diagonal XORs could cancel globally. The later path operations can change them separately.

From idea to code

For just the winner, XOR each cell into bucket row+column. A winning position has at least one nonzero bucket.
