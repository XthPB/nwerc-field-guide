Bound unfinished groups by an exchange argument

You own tiles with integer labels. A group uses either three tiles of one label or one tile of each of three consecutive labels. Each physical tile can appear in at most one group. Find the largest number of groups you can make from the given multiplicities.

Work through the example

  1. Three runs [4,5,6] consume exactly the same tiles as [4,4,4], [5,5,5], [6,6,6]. Replacing the runs preserves the number of groups. Some optimum therefore starts at most two runs at any label.
  2. At label x let a runs have started at x−2 and b at x−1. Each needs a tile now. Try starting c=0,1,2 new runs, provided a+b+c tiles are available.
  3. With counts [1,2,3,2,1] at labels 1…5, start a run at each of 1, 2, 3. They consume [1,2,3,2,1] exactly. A greedy triple of 3s would destroy all three runs.

Why it works

Score a run when it starts. Use all remaining current-label tiles in disjoint equal triples. Carry (b,c) to the next label. Start and finish in (0,0), padding two zero counts at the end to force every started run to finish.

When the conditions change

Reject negative leftovers. There are nine states and at most three choices in each, giving O(n+m) time including frequencies for m labels. This compression depends on the replacement preserving the score.

Try one change

Would the bound of two survive if a run earned two points and an equal triple earned one?

Show the reasoning

Three runs would earn six versus three points for their replacement. The exchange no longer certifies the bound.

From idea to code

Two-state DP with rolling layers

Read the executable Python reference

These functions illustrate the core algorithm. The fourteen references have differential checks against independent small-instance solvers.

def tile_triples(counts):
    states = {(0,0): 0}
    for available in [*counts, 0, 0]:
        following = {}
        for (a,b), score in states.items():
            for c in range(3):
                spare = available - a - b - c
                if spare >= 0:
                    key = b, c
                    following[key] = max(following.get(key, -1), score + c + spare//3)
        states = following
    return states[0,0]
