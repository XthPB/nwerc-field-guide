Choose a question that distinguishes hypotheses

Four hidden values remain: 6,10,15,21. A query asks whether one chosen integer divides the value. What makes a query informative?

Work through the example

  1. Asking divisibility by 2 splits {6,10} from {15,21}. In each branch one more permitted test distinguishes its pair, such as divisibility by 3 or 5.
  2. Asking divisibility by 1 leaves all four values and spends a query. Balanced splits are useful only when the available next queries can finish both branches.
  3. For asymmetric query costs or a bound depending on the current lower endpoint, work backwards from the remaining budget and store the distinguishable interval size.

Why it works

Each answer eliminates hypotheses incompatible with it. A decision tree certifies a worst-case budget by checking its deepest leaf. Reversing the DP from “how many questions for this range?” to “how large a range with this many questions?” can expose a monotone construction, as in CF 1028G.

When the conditions change

Every query must be legal for every still-possible hidden value. An entropy or leaf-count bound alone need not be attainable. CF 679A uses divisibility queries where squares distinguish otherwise ambiguous composites.
