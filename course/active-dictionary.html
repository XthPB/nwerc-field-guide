Strings and pattern matching · 7 of 17

Find the best active pattern on a failure-tree ancestor path

Every dictionary entry has a score that can be changed, even decreased. A text query asks for the highest current score of any dictionary word appearing as a contiguous substring of that text. Distinct entries may have identical spelling.

Work through the example

  1. For patterns “he” and “she” with scores 7 and 4, processing “she” ends at a state whose failure ancestor is “he”. Both match here and 7 wins. If “he” drops to 1 the same text now returns 4.
  2. Build the Aho–Corasick automaton, then make each non-root state's failure link its parent in a tree. A pattern ending at the current text position is exactly a terminal on the path from the current automaton state up to the root.
  3. Store the best current terminal score per state. Use heavy-light decomposition with point updates and path-maximum queries. Scan a text once and maximize the path answers. For repeated dictionary strings keep a multiset of scores at their shared terminal.

Why it works

The failure chain lists suffixes of the consumed prefix that also occur as trie prefixes. Every dictionary occurrence ends somewhere in the text. Checking exactly these ancestor paths includes all occurrences, including nested and overlapping ones.

When the conditions change

With S dictionary characters and T query characters, preprocessing is linear for a fixed alphabet, a score edit takes O(log S+log multiplicity), and a text query costs O(T log² S). Distinguish an empty terminal from a valid score and translate the final empty result into the source's sentinel.

Try one change

Why not cache a maximum along every failure link?

Show the reasoning

A decreasing update to a popular suffix would invalidate the cached maximum in many descendant states.

From idea to code

Give each terminal’s best live score to one HLD position. HLD handles the failure-tree path while Aho–Corasick handles the text advances.
