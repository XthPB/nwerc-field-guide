Count different outcomes under child swaps

You can swap either pair of siblings in a perfectly balanced labeled binary tree. Count different preorder strings. Several choices of swaps may write the same string.

Work through the example

  1. A root A with leaf children A and B gives AAB or ABA. A root A with two B leaves gives only ABB. The factor of two depends on the children’s possible outputs.
  2. Give each leaf its label as a type. For an internal node make an exact tuple from its label and the sorted pair of child type IDs. Intern equal tuples to the same integer.
  3. When the child types differ, both orders are distinguishable. When they agree, both orders describe the same family. Two identical child types with two possible strings each still give four ordered pairs, including both mixed orders.

Why it works

Multiply the numbers of ways in the two children. Double exactly when their type IDs differ. Equality of type IDs characterizes equivalence by induction. The equal-length child fields in the preorder string make its two substrings uniquely decodable.

W(v)=W(l)W(r) (1+[T(l)≠T(r)])W(v)=W(l)W(r)\,\bigl(1+[T(l)\ne T(r)]\bigr)W(v)=W(l)W(r)(1+[T(l)=T(r)])

When the conditions change

An ordered map interns O(n) tuples in O(n log n) time and O(n) memory. Reduce counts modulo the requested modulus, keeping type identity exact. For ambiguous variable-length encodings, add structure markers or prove unique decoding first.

Try one change

Two children each have the same count of strings. Is that enough to skip doubling?

Show the reasoning

No. A child spelling only A and a child spelling only B each have count one, yet swapping them produces a second string.

These functions illustrate the core algorithm. The fourteen references have differential checks against independent small-instance solvers.

def preorder_count(labels, mod=998244353):
    """labels in heap order on a perfect binary tree."""
    types, ways, dictionary = [0] * (len(labels)+1), [1] * (len(labels)+1), {}
    for i in range(len(labels), 0, -1):
        left = right = 0
        if 2*i <= len(labels):
            left, right = types[2*i], types[2*i+1]
            ways[i] = ways[2*i] * ways[2*i+1] * (1 + (left != right)) % mod
        code = (labels[i-1], min(left, right), max(left, right))
        types[i] = dictionary.setdefault(code, len(dictionary)+1)
    return ways[1]
