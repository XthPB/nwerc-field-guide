Count formulas by the entire function they compute

A Boolean expression has unknown leaves and operators. Some input rows prescribe its output. Count legal completions of the expression, including different completions which compute the same function.

Work through the example

  1. For two variables, order the input rows as 00,01,10,11. Then A has outputs 0011 and B has 0101. Their OR gives 0111. Their AND gives 0001.
  2. A child table stores how many completions yield each truth mask. Under OR, parent mask S receives all pairs with X OR Y = S. Enumerating every pair is too expensive with four variables and 65,536 possible functions.
  3. For each mask S, sum each child’s counts over submasks of S. Multiplying those sums counts all pairs whose OR lies inside S. Möbius inversion removes the smaller answers and recovers the count for exact S.

Why it works

For AND, use the same transform over supersets. For an unknown operator, add the two exact distributions. For an unknown leaf, add one for every allowed literal. At the root keep masks consistent with every prescribed truth-table row and add their counts modulo the problem modulus.

When the conditions change

With v variables there are b=2ᵛ input rows and M=2ᵇ masks. Each internal merge costs O(bM), rather than O(M²). A recursion retaining one completed child per level takes O(M × tree height) memory. Distinguish choices of operators even when both give the same truth table.

Try one change

With two independent unspecified positive literals drawn from {A,B}, how many ordered fillings give A OR B under a fixed OR?

Show the reasoning

Two, namely (A,B) and (B,A). Assignments (A,A) and (B,B) yield different masks.

From idea to code

Sum over submasks · Modular arithmetic

Read the executable Python reference

These functions illustrate the core algorithm. The fourteen references have differential checks against independent small-instance solvers.

def truth_merge(left, right, operators, mod=1000000007):
    """Combine distributions over truth masks using AND and/or OR."""
    size = len(left)
    def transform(arr, op, inverse):
        arr = arr.copy()
        bit = 1
        while bit < size:
            for mask in range(size):
                target = bool(mask & bit) if op == "|" else not (mask & bit)
                if target:
                    delta = arr[mask ^ bit]
                    arr[mask] = (arr[mask] + (-delta if inverse else delta)) % mod
            bit <<= 1
        return arr
    result = [0]*size
    for op in operators:
        a, b = transform(left,op,False), transform(right,op,False)
        exact = transform([x*y % mod for x,y in zip(a,b)], op, True)
        result = [(x+y)%mod for x,y in zip(result,exact)]
    return result
