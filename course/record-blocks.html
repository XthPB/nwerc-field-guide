Discover what counts as one knapsack item

A machine takes two lists and repeatedly outputs the smaller item currently at their fronts, or the remaining list when one is empty. The lists themselves need not be sorted. Given a permutation produced by the machine, decide whether it can come from two equal-length lists.

Work through the example

  1. For output [3,1,2,5,4,6], suppose 3 comes from the left queue. The right head is larger than 3, or that queue is empty. The following 1 and 2 must come from the same queue as 3.
  2. Cut immediately before each new prefix maximum. Here the indivisible blocks are [3,1,2], [5,4], [6], of lengths 3, 2, 1. A subset of size 3 fills the left queue.
  3. Put the first block on the left, the others on the right. Merge the resulting queues: 3 beats 5, then 1 beats 5, then 2 beats 5. The rest follows. The same argument works at each block boundary.

Why it works

Scan for record highs, then use descending 0/1 subset sum on block lengths. On first discovering a total, record the responsible block. Follow those parents from half the output length and concatenate each side’s chosen blocks in original order.

When the conditions change

A bitset answers existence quickly. A first-discovery parent table gives reconstruction in O(number of blocks × target) time and O(target + n) space. Distinct permutation values justify the strict comparison. Dropping the within-side order can change the output.

Try one change

Could the second block be split after 5?

Show the reasoning

While processing that block, the other exposed head exceeds 5 or its queue is empty. It cannot output the smaller 4.

These functions illustrate the core algorithm. The fourteen references have differential checks against independent small-instance solvers.

def unmerge(output):
    """Recover two equal-length queues for a permutation, or return None."""
    if len(output) % 2:
        return None
    target = len(output) // 2
    starts = []
    for i, value in enumerate(output):
        if not starts or value > output[starts[-1]]:
            starts.append(i)
    starts.append(len(output))
    parent = {0: None}
    for block, (left, right) in enumerate(zip(starts, starts[1:])):
        length = right - left
        for total in range(target, length - 1, -1):
            if total not in parent and total - length in parent:
                parent[total] = block, total - length
    if target not in parent:
        return None
    chosen = set()
    while target:
        block, target = parent[target]
        chosen.add(block)
    a, b = [], []
    for block, (left, right) in enumerate(zip(starts, starts[1:])):
        (a if block in chosen else b).extend(output[left:right])
    return a, b
