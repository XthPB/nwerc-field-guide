Choose the tallest point to separate overlapping penalties

Choose an integer height from 0 through H for every building in a row. A building of height h earns h². Each interval rule charges its fixed fee once if at least one building in that interval exceeds its threshold. Maximize total earnings after fees.

Work through the example

  1. With two sites capped at 2, take one rule covering both, with threshold 1 and fee 3. Heights (2,2) earn 8−3=5. Charging the fee independently at both sites would report 2.
  2. Let F(l,r,h) consider only rules completely contained in [l,r], with heights capped at h. Either every height is below h, or a position p attains h.
  3. If p attains h, every contained rule covering p is decided immediately. It charges exactly when h exceeds its threshold. Every other contained rule lies wholly on one side and belongs to that child.

Why it works

Try the smaller cap, or each pivot p with height exactly h. Combine the two child intervals with cap h and subtract the sum of newly decided fees. Give empty intervals and cap zero value zero. Fill by cap and interval length. Tied maxima can give multiple witnesses, which is harmless for a maximum.

When the conditions change

For each cap, bucket active fees by their two interval endpoints. A 2D prefix-sum rectangle query over starts in [l,p] and ends in [p,r] returns C in O(1). This gives O(H(n³+m)) time with m rules and O(n²) working space with two cap layers. A maximum-closure min-cut is another formulation.

These functions illustrate the core algorithm. The fourteen references have differential checks against independent small-instance solvers.

def zoning_profit(n, cap, rules):
    """Rules (l,r,threshold,fee) have zero-based inclusive endpoints."""
    old = [[0]*n for _ in range(n)]
    for h in range(1, cap+1):
        pref = [[0]*(n+1) for _ in range(n+1)]
        for l,r,threshold,fee in rules:
            if h > threshold:
                pref[l+1][r+1] += fee
        for i in range(1, n+1):
            for j in range(1, n+1):
                pref[i][j] += pref[i-1][j] + pref[i][j-1] - pref[i-1][j-1]
        cur = [row.copy() for row in old]
        for width in range(1, n+1):
            for l in range(n+1-width):
                r = l+width-1
                for p in range(l, r+1):
                    fee = pref[p+1][r+1]-pref[l][r+1]-pref[p+1][p]+pref[l][p]
                    left = cur[l][p-1] if l<p else 0
                    right = cur[p+1][r] if p<r else 0
                    cur[l][r] = max(cur[l][r], left+right+h*h-fee)
        old = cur
    return old[0][n-1]
