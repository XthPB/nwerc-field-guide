Count legal cuts when valid starts have holes

Split an array into nonempty consecutive pieces. In each piece, count the values appearing exactly once. That count must be at most k in every piece. Return the number of legal partitions, keeping different cut positions as distinct answers.

Work through the example

  1. For [a,b,b,a] ending at the last position, the singleton counts for starts 1,2,3,4 are 0,1,2,1. With k=1 the legal starts are 1,2,4. A single sliding-window boundary cannot encode them.
  2. When appending value x at r, let p and q be its most recent and second most recent previous occurrences, using zero when absent. Starts in (p,r] see x become a singleton. Starts in (q,p] lose their old singleton. Earlier starts change by zero.
  3. Give start l weight dp[l−1]. Before querying r activate its new start with weight dp[r−1]. Add one on (p,r], subtract one on (q,p], then sum weights at active starts with a count at most k.

Why it works

One implementation stores a difference marker +1 at the last occurrence and −1 at the penultimate occurrence of each value, all other markers zero. Suffix sums of these markers are the singleton counts. Updating a value changes at most three marker positions. In each block tabulate weights by local suffix sum and prefix-sum the bins. Sweep blocks from right to left, carrying the marker sum of blocks already passed.

When the conditions change

With block length B, local sums lie in [−B,B]. Rebuild changed blocks in O(B), query O(n/B) full blocks and scan the current partial block. Total O(n(B+n/B)) time and O(n) memory, using B near √n. Future starts must carry zero weight.

def isolated_partitions(values, k, mod=998244353):
    """Sqrt decomposition with local suffix histograms of ±1 markers."""
    n = len(values)
    width = isqrt(n) + 1
    blocks = (n+width-1)//width
    markers, weight = [0]*n, [0]*(n+1)
    weight[0] = 1
    sums = [0]*blocks
    prefix = [[0]*(2*width+1) for _ in range(blocks)]
    def rebuild(b):
        hist = [0]*(2*width+1)
        total = 0
        for j in reversed(range(b*width, min(n,(b+1)*width))):
            total += markers[j]
            hist[width+total] += weight[j]
        for j in range(1,len(hist)):
            hist[j] = (hist[j]+hist[j-1]) % mod
        sums[b], prefix[b] = total, hist
    last_two = {}
    for r,x in enumerate(values):
        last, previous = last_two.get(x, (-1,-1))
        touched = {r//width}
        for j, v in ((previous,0),(last,-1),(r,1)):
            if j>=0:
                markers[j] = v
                touched.add(j//width)
        for b in touched:
            rebuild(b)
        total = ways = 0
        for b in reversed(range(r//width+1)):
            bound = k - total
            if bound >= -width:
                ways += prefix[b][min(width,bound)+width]
            total += sums[b]
        weight[r+1] = ways % mod
        last_two[x] = r, last
    return weight[n]
