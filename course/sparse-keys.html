Range queries and sweeps · 12 of 19

Compress the boundaries where any answer can change

You assign, clear or flip integer intervals up to 10¹⁸ and query the smallest missing positive integer. Allocating one leaf for every integer is impossible.

Work through the example

  1. Start with operations [2,4] and [4,8]. Include the domain start 1 and every l and r+1 as breakpoints. The runs [2,4), [4,5) and [5,9) can each change as one unit.
  2. A segment-tree node stores how much of its span is present. Assignment overwrites a prior flip; a new flip complements coverage relative to the span length.
  3. Descend left if that child’s covered length is less than its physical length; otherwise go right. Include an uncovered tail sentinel after the last possible update.

Why it works

Every update has constant membership over each elementary interval. For a missing-value query, the first integer of the first nonfull elementary interval answers. If coordinates arrive online, an implicit segment tree allocates nodes along touched paths.

When the conditions change

Offline O(q log q) and O(q) nodes after compression. In CF 1119D sort gaps between points, then use prefix sums over small gaps for length-of-union queries. Be careful forming r+1 when the integer type may overflow.
