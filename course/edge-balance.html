Color edges by walking an Euler circuit

Color points red or blue so that on every horizontal or vertical line the counts differ by at most one. Treating each line independently can give one point two conflicting colors.

Work through the example

  1. Make a bipartite graph: each used x and each used y is a vertex. A point (x,y) becomes one edge. A balanced point coloring is a balanced incident-edge coloring.
  2. Pair odd-degree vertices through suitable auxiliary edges or pair incident edges locally into alternating chains. For the local method, at each vertex pair its incident original edges arbitrarily, leaving at most one unpaired.
  3. Regard original edges as new vertices and these pairings as links. They form paths or even cycles. Alternate colors along them. Every paired incidence now contributes one of each color.

Why it works

Cycles of pairings alternate which endpoint class supplies the pairing because the original graph is bipartite. They have even length. Only the possible unpaired incidence at each coordinate can introduce an imbalance.

When the conditions change

O(n log n) with coordinate compression, then O(n) traversal. CF 547D uses this balancing construction. CF 1368E is a separate constructive graph exercise using layer information to meet a deletion budget.
