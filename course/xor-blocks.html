Precompute every order the swaps can actually create

An array has 2ʰ entries. A request swaps adjacent aligned blocks of size 2ᵏ everywhere. After each request, find the largest subarray sum, allowing the empty subarray.

Work through the example

  1. For four entries [4,−6,3,2], the best sum is 5. Flipping bit 0 of every index exchanges neighbors, giving [−6,4,2,3] and best sum 9.
  2. Flip bit 1 next. The running mask becomes 3, and the array is [2,3,−6,4]. Its best sum is 5. Identical requests twice cancel each other.
  3. For each aligned segment store, for every mask on its local index bits, the total, best prefix, best suffix, and best internal sum. The highest mask bit chooses left-right or right-left. Apply the same lower mask inside both children.

Why it works

Combine the usual maximum-subarray summaries. The best crossing subarray takes the left suffix and the right prefix. Compute all masks once and answer each cumulative request by one XOR and one root-table lookup.

B(LR)=max⁡(BL,BR,SL+PR),m←mxor2kB(LR)=\max(B_L,B_R,S_L+P_R),\qquad m\gets m\mathbin{\mathrm{xor}}2^kB(LR)=max(BL​,BR​,SL​+PR​),m←mxor2k

When the conditions change

With N=2ʰ the construction takes O(Nh) time. Free child tables after merging for O(N) live storage; retaining all nodes uses O(Nh). In the empty-allowed version leaf prefix, suffix and best are max(0,value).

From idea to code

These functions illustrate the core algorithm. The fourteen references have differential checks against independent small-instance solvers.

def xor_block_bests(values):
    """Root maximum (allowing an empty subarray) for all global XOR permutations."""
    def combine(a, b):
        total_a, pre_a, suf_a, best_a = a
        total_b, pre_b, suf_b, best_b = b
        return (total_a+total_b, max(pre_a, total_a+pre_b),
                max(suf_b, total_b+suf_a), max(best_a, best_b, suf_a+pre_b))
    def build(lo, hi):
        if hi-lo == 1:
            x = values[lo]
            return [(x, max(0,x), max(0,x), max(0,x))]
        mid = (lo+hi)//2
        left, right = build(lo, mid), build(mid, hi)
        return ([combine(a,b) for a,b in zip(left,right)] +
                [combine(b,a) for a,b in zip(left,right)])
    assert values and len(values) & (len(values)-1) == 0
    return [summary[-1] for summary in build(0, len(values))]
