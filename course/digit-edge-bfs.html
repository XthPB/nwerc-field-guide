Explore equal digit prefixes together in a graph

Traveling along edge i appends the decimal digits of i. For every destination find the smallest integer that can be written on a route from the source. Sorting ordinary edge weights does not compare concatenations correctly.

Work through the example

  1. A route labeled 9 then 1 writes 91. A single edge labeled 12 wins with 12, even though its edge index is larger than 9. Replace a traversal labeled 12 by a chain labeled 1 then 2. Give the opposite traversal its own directed chain, again spelling 12.
  2. Process a queue of groups. Each group contains vertices first reached by the same minimum digit string. Starting from the source's empty string, gather outgoing edges of the whole group into digit buckets 0 through 9. Create one child group per nonempty bucket, in ascending order, marking a vertex when it is claimed.
  3. Groups of length d are processed in lexicographic order before length d+1. Extend the modular value for an output by multiplying by 10 and adding the new digit. The traversal order determines which answer wins.

Why it works

Positive edge indices have no leading zero. Numeric order is therefore length first and then lexicographic order. Children of one equal-prefix group with the same digit have equal labels. A smaller entire prefix wins against any larger prefix before the new digit even matters.

When the conditions change

Expansion has O(m log(m+1)) arcs and auxiliary vertices in decimal length. Grouped BFS is linear in that expanded graph for fixed alphabet size. Comparing residues modulo the output modulus would destroy numeric ordering.

Try one change

Why isn't sorting the adjacency list of each vertex enough?

Show the reasoning

Two vertices with the same written prefix can offer different next digits. Their outgoing edges must compete together.

From idea to code

Replace the individual BFS queue entry by a list of states sharing an equal prefix. Process the ten digit buckets for the entire list before moving to the next prefix.

from collections import deque

def shortest_digit_labels(n, edges, modulus):
    """Undirected edge i appends i+1. Return minimum route labels modulo modulus."""
    adj = [[] for _ in range(n)]
    for index,(a,b) in enumerate(edges,1):
        digits = [int(d) for d in str(index)]
        for source,target in [(a,b),(b,a)]:
            u = source
            for digit in digits[:-1]:
                v = len(adj)
                adj.append([])
                adj[u].append((digit,v))
                u = v
            adj[u].append((digits[-1],target))
    values = [None]*len(adj)
    values[0] = 0
    groups = deque([[0]])
    while groups:
        group = groups.popleft()
        prefix = values[group[0]]
        buckets = [[] for _ in range(10)]
        for u in group:
            for digit,v in adj[u]:
                if values[v] is None:
                    buckets[digit].append(v)
        for digit,bucket in enumerate(buckets):
            fresh = []
            for v in bucket:
                if values[v] is None:
                    values[v] = (prefix*10+digit)%modulus
                    fresh.append(v)
            if fresh:
                groups.append(fresh)
    return values[:n]
