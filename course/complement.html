Graphs, connectivity and flow · 7 of 27

Explore edges that are absent from the input

You’re given a vertex set and a list of forbidden unordered pairs. Every other pair is connected by an edge. Find the connected components of this implied graph. The list is short enough to read but the number of allowed edges can be quadratic.

Work through the example

  1. On four vertices forbid 1–2 and 1–3. Starting at 1, inspect unseen vertices. Only 4 is reachable directly, so remove 4 from unseen and queue it.
  2. From 4 the remaining 2 and 3 are both reachable. Each is removed from unseen exactly once.
  3. For the active vertex mark its forbidden neighbors, sweep the current unseen set, and extract every unmarked vertex as a neighbor in the complement.

Why it works

Charge a successful extraction to the newly discovered vertex. An unsuccessful inspection is charged to an explicitly stored forbidden edge. A linked unseen list and timestamp marks permit O(V+E) work without repeatedly clearing an array.

When the conditions change

An ordered-set implementation may add logarithmic factors. CF 1242B makes missing edges zero-cost and listed edges unit-cost, so connecting the complement’s components takes their count minus one paid edges. A graph and its complement are different search spaces in CF 601A.

Try one change

Why can scanning the entire original vertex array for each BFS pop still be quadratic?

Show the reasoning

Previously discovered vertices would keep being inspected. The charging argument needs a shrinking unseen collection.
