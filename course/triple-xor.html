Turn a parity invariant into an explicit sequence of operations

In one operation replace three selected values by their common XOR. Can you make an entire array equal, and can you print a short sequence that achieves it?

Work through the example

  1. On [1,2,4,8,16], apply the operation to positions (1,2,3). The first three values become 7. Apply it to (3,4,5). The last three become 31, while the first two still form an equal pair.
  2. Visit overlapping triples from left to right, advancing by two. The final triple contains the XOR of the whole odd-length array. Walk the earlier triples backward. Two equal old values cancel, so the new global value propagates left.
  3. Every operation preserves the array XOR, because x XOR x XOR x=x. For an even-length array an equal final array must have XOR zero. If total XOR is zero, leave its last element untouched and equalize the first n−1. Their XOR already equals that last value.

Why it works

After each forward step, a pair equal to the current prefix XOR is left behind. The backward pass combines each such pair with the desired value. This proves sufficiency as well as giving a linear sequence of legal operations.

x⊕x⊕y=yx\mathbin{\oplus}x\mathbin{\oplus}y=yx⊕x⊕y=y

When the conditions change

For odd n at least three the construction uses n−2 operations. Handle already-equal arrays and n≤2 directly. With even n and nonzero total XOR no legal sequence can work.
