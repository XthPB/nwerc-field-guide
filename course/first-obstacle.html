Count paths on a huge grid with few blocked cells

On a large rectangular board, start in the upper-left cell and move right or down toward the lower-right cell. Only a few listed cells are forbidden. Count routes that reach the destination without landing on a forbidden cell when there are too many cells for a full table.

Work through the example

  1. In a 3-by-3 grid there are six down/right paths from the upper-left to the lower-right. Four visit the center, since there are two ways to reach it and two to leave it. So two paths survive.
  2. In a bigger grid, sort blocked cells and then the destination in monotone coordinate order. At each special point p begin with the binomial count of unrestricted paths from start to p.
  3. For each earlier block q that can reach p, subtract the number of paths that first hit a block at q times the unrestricted number of paths from q to p. Store the remainder for p. The destination's remainder is the requested count.

Why it works

A path that touches any block has a unique first block. Sorting guarantees its count is known when p is processed. A suffix may hit more blocks freely, since the path has already been assigned to its first one.

C(q,p) counts unrestricted monotone paths between the two points. The relation q ≼ p means both coordinates can increase from q to p.

When the conditions change

With b blocked cells and factorials up to h+w, time is O(h+w+b²) and memory O(h+w+b). For modular factorial inverses, the prime modulus must exceed the largest factorial index or an appropriate alternative is needed. Deduplicate repeated blocks.

Try one change

Why would subtracting all unrestricted paths through each obstacle fail for two obstacles in a line?

Show the reasoning

A path visiting both would be subtracted twice. The first-block count at the second obstacle already excludes that path.
