Average a million squared distances with four sums

A grid cell has a numeric label. From your current cell, jump uniformly to a cell with a strictly smaller label, paying the squared Euclidean distance. Stop when there is no smaller label. Find the expected total charge from the specified starting cell.

Work through the example

  1. Consider three cells in a row at coordinates 0, 1, 2, with labels 1, 2, 3. Starting at 0 costs zero. From 1 the sole destination is 0, so E(1)=1.
  2. From 2 there are two choices. Jumping to 0 costs 4. Jumping to 1 costs 1 now and another 1 in expectation. Their average is 3.
  3. Expand (x−u)²+(y−v)². A query only needs the count k and the accumulated sums of u, v, u²+v², and E of all eligible destinations. Each previously solved cell contributes once to these totals.

Why it works

Sort by cell label. Compute the whole group of equal labels from the same old totals, then add the group. Minimum-label cells have no successor and receive zero. Use modular inverses in the contest’s prime field where the positive denominator is invertible.

E(x,y)=x2+y2+∑E+∑(u2+v2)−2x∑u−2y∑vkE(x,y)=x^2+y^2+\frac{\sum E+\sum(u^2+v^2)-2x\sum u-2y\sum v}{k}E(x,y)=x2+y2+k∑E+∑(u2+v2)−2x∑u−2y∑v​

When the conditions change

For N cells, sorting takes O(N log N) time and storage is O(N). Treat ties as a batch. A Manhattan cost has an absolute value and needs a split by coordinate before trying this expansion.

Show the reasoning

All cells are terminal. The group is empty of eligible predecessors and no division occurs.

These functions illustrate the core algorithm. The fourteen references have differential checks against independent small-instance solvers.

def expected_squared(cells, mod=998244353):
    """cells are (label,x,y). Return expectations in input order, in the prime field."""
    from itertools import groupby
    values = [0] * len(cells)
    count = sx = sy = squared = futures = 0
    order = sorted(range(len(cells)), key=lambda i: cells[i][0])
    for _, group in groupby(order, key=lambda i: cells[i][0]):
        indices = list(group)
        inv = pow(count, -1, mod) if count else 0
        for i in indices:
            _, x, y = cells[i]
            if count:
                values[i] = ((x*x+y*y) + (futures+squared-2*x*sx-2*y*sy)*inv) % mod
        for i in indices:
            _, x, y = cells[i]
            count += 1
            sx += x
            sy += y
            squared += x*x + y*y
            futures += values[i]
    return values
