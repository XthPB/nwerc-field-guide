Repair a non-bipartite graph by counting which cycles cross a cut

Which individual edges could you delete to leave a bipartite graph? Coloring once tells you there is a conflict, but it does not identify every possible repair.

Work through the example

  1. Color a DFS forest by depth parity. A non-tree edge joining equal colors is bad. Every other non-tree edge is good. On a triangle there is one bad edge and no good non-tree edge. Deleting any triangle edge works.
  2. Removing a tree edge lets you flip the colors in its child subtree. That fixes every bad non-tree edge crossing the cut, but it breaks every good one crossing the same cut.
  3. Count crossed bad and good edges on all forest edges at once. Add at each deeper endpoint, subtract at its ancestor and sum bottom-up. A tree edge works if it crosses every bad edge and no good edge. A non-tree edge works precisely when it is the sole bad edge, unless the graph was already bipartite.

Why it works

Keeping tree edges fixes the coloring of each tree up to a global flip. Deleting a tree edge creates exactly one extra flip choice. Checking its cut examines all constraints affected by that choice. Count bad edges globally across disconnected components.

Bₑ and Gₑ count bad and good non-tree edges crossing the cut at e. Bₐₗₗ counts all bad edges in the graph.

When the conditions change

O(V+E) time and space with a DFS forest. Identify the parent by edge ID if parallel edges are allowed. With zero bad edges every deletion preserves bipartiteness.

Try one change

What if two different connected components each contain an odd cycle?

Show the reasoning

A single deletion affects only one component. No cut crosses every bad edge.
