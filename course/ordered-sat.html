Encode an unknown shared integer as threshold literals

Choose stations satisfying pairwise coverage and exclusion constraints. All chosen stations must also accept one common frequency f. Trying 2-SAT once per possible frequency would repeat nearly the whole computation.

Work through the example

  1. Let station A allow frequencies 2..4 and B allow 4..5. If both are selected, f=4 works. Introduce Tⱼ meaning f≥j. Selecting A implies T₂ and ¬T₅, while B implies T₄. The overlap appears automatically.
  2. Add Tⱼ₊₁→Tⱼ for all j. Force T₁ true and a sentinel Tₘ₊₁ false. Selecting station i implies Tₗᵢ and ¬Tᵣᵢ₊₁. Add each coverage pair as (A∨B) and each exclusion pair as (¬A∨¬B).
  3. Convert the clauses, including each implication's contrapositive, into a 2-SAT graph. After solving, choose f as the largest true threshold and output the station booleans from the same satisfying assignment.

Why it works

Every integer in 1..M has exactly one monotone true-prefix encoding. Conversely any assignment on the threshold chain with the two sentinels has a last true threshold. The two endpoint implications are precisely the membership condition for a selected interval.

When the conditions change

O(M+stations+constraints) time and space with SCCs. For a very large integer domain compress sorted interval endpoints carefully so a threshold and its strict successor represent the appropriate different regions.

Try one change

Can an arbitrary allowed set of three disjoint intervals be expressed by these same two implications?

Show the reasoning

Those implications describe one contiguous interval. A union would require a separate logical encoding.

From idea to code

Use one variable per station and per threshold. Encode a⇒b as ¬a∨b through the ordinary 2-SAT clause helper so its contrapositive is inserted too.
