Solve a retry loop by conditioning on the next move

A trial succeeds with probability 1/4. Each trial costs one move and failure returns you to the initial state. What is the expected number of moves?

Work through the example

  1. On success the remaining cost is zero. On failure it is the original unknown E.
  2. Pay for the current move in both cases: E=1+(3/4)E. Hence E=4.
  3. With multiple states, write one equation per state with terminal values fixed. If every non-self transition goes to a previously solved state, isolate self-loops locally.

Why it works

First-step conditioning partitions outcomes into disjoint alternatives. In finite absorbing models with finite expected times, the resulting transient linear system has the required solution. Games with alternating turns may need the turn in the state.

When the conditions change

Acyclic transitions use DP; cycles may require elimination or structure such as a tridiagonal row. For CSES Moving Robots compute each robot’s location distribution first, then multiply the independent probabilities that a particular square is empty.

Try one change

If a reachable closed class never reaches the target, can the unconditional expected hitting time be finite?

Show the reasoning

No. A positive probability of never hitting gives infinite hitting time.
