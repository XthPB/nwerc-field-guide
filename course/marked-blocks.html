Count a weighted partition by marking a second element

You have n distinct objects, each with a weight. Partition them into exactly k nonempty groups without labeling the groups. Each group scores its number of objects times its total weight. Add the scores of all groups across all partitions.

Work through the example

  1. For three weights 2,3,5 and k=2, the pairs {2,3}, {2,5}, {3,5} can each form the two-element block. Their complete partition scores are 15,17,18, summing to 50.
  2. Fix an element i. Its weight contributes once for each j in i's block, including j=i. For j=i every partition qualifies, giving S(n,k) possibilities. For j≠i glue i and j into one labeled object. The resulting partitions are counted by S(n−1,k).
  3. Therefore each weight has the same coefficient S(n,k)+(n−1)S(n−1,k). Compute S(a,k), the Stirling number of the second kind, by counting onto maps to k labeled boxes with inclusion–exclusion, then divide by k!.

Why it works

Saying a block has size b is equivalent to choosing one of b possible marked elements inside it. Counting the mark turns an apparently nonlinear block statistic into an equality constraint on just two labels.

When the conditions change

The onto-map sum is Σⱼ(−1)ʲ C(k,j)(k−j)ᵃ. With factorials and modular powers the two Stirling values cost O(k log n) time and O(k) memory. The usual modular formula needs k! invertible. Use S(0,0)=1 and a consistent 0⁰ convention.

From idea to code

Use factorials for the binomial coefficients and exponentiation for (k−j)ⁿ. The argument of each Stirling number tells you which exponent to use.
