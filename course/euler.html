Use every edge by splicing closed walks

You receive three-letter fragments such as abc, bca and cab. Reorder and overlap all of them to form a single string. Each fragment must be used exactly once, and the last two letters of one fragment must match the first two of the next.

Work through the example

  1. Use each two-letter prefix or suffix as a vertex. Each triple becomes one directed edge: ab→bc, bc→ca, ca→ab.
  2. Walk until stuck and append a vertex when backing up. Reverse that output to recover the Euler walk.
  3. Start with ab and append each traversed edge’s last letter. The resulting abcab contains all three input triples.

Why it works

Every use of an input occurrence corresponds to exactly one edge. A directed trail needs all nonzero-degree vertices in one weak component and the required in/out imbalances. A prescribed start and finish must match those imbalances.

When the conditions change

O(V+E) with adjacency cursors. Parallel copies must remain separate edges. Check that the reconstructed trail used every edge, even when all degrees look right.

Try one change

What if all degrees balance but there are two disconnected cycles?

Show the reasoning

A single trail cannot cover both. Degree conditions alone do not join components.
