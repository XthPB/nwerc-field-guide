Separate cycles from single points of failure

A triangle 1–2–3–1 has a tail 3–4. Which single road disconnects the graph if it closes?

Work through the example

  1. Run DFS. Give each discovered vertex an entry time. The subtree reached through 2 can return to 1 via the triangle.
  2. Vertex 4 has no route to 3 or above except its parent edge. Its smallest reachable discovery time exceeds that of 3.
  3. Mark 3–4 as a bridge. Contract the remaining connected components and the bridges form a forest.

Why it works

For a DFS tree edge v→u, it is a bridge when low[u] > tin[v]. For a nonroot articulation vertex the corresponding test is ≥; equality still lets the child reach v but cannot bypass v. A DFS root needs at least two DFS children to be an articulation point.

low⁡(v)>tin⁡(u) ⟹ (u,v) is a bridge for DFS child v\operatorname{low}(v)>\operatorname{tin}(u)\ \Longrightarrow\ (u,v)\text{ is a bridge for DFS child }vlow(v)>tin(u) ⟹ (u,v) is a bridge for DFS child v

When the conditions change

O(V+E). Skip the incoming edge ID, not every edge to the parent, because parallel roads can save each other. Once bridges are contracted, diameter or path queries become tree problems.

Try one change

Add a second road from 3 to 4. Is either a bridge?

Show the reasoning

No. The second parallel edge provides a return route when the first is removed.
