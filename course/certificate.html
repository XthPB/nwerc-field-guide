Constructive proofs and implementation · 4 of 12

Give a lower bound and build a witness that attains it

You need a binary grid with exactly a requested number of isolated letter-regions. Drawing cells until the count looks right gives no guarantee that later changes preserve it.

Work through the example

  1. Start with broad connected monochrome bands. Reserve isolated positions inside a different letter’s band, separated by at least one background cell horizontally and vertically.
  2. Each isolated island adds exactly one component of its letter. Keep a connected backbone of the host band so the background does not split.
  3. Count the base components plus the islands and verify the board dimensions. CF 989C uses this pattern for several letters.

Why it works

Identify independently adjustable gadgets whose side effects are completely controlled. For an optimization witness, first bound what any solution can achieve and then realize that bound step by step. CF 911F uses diameter endpoints to build and certify a high-scoring tree-removal order.

When the conditions change

Construction constraints include output size as well as arithmetic feasibility. For small cases, run a flood fill, replay each operation, or verify every required pair as an independent oracle.

Try one change

Why must islands of a foreign letter be separated even if the host remains connected?

Show the reasoning

Adjacent foreign islands merge, so two intended contributions become one.
