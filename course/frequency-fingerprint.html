Test divisibility of every frequency with random subsets

Does every value occur a multiple of k times inside a queried range, while array entries change? The range length being divisible by k is necessary but insufficient.

Work through the example

  1. In [a,a,b,b] with k=4 the length is divisible by 4, but neither frequency is. Choose a random subset of values. If it contains only a, the range contains two marked elements and the trial detects failure.
  2. Assign one independent fair bit to each distinct value. Use a Fenwick tree over positions to count marked elements in the range. For each independent trial, reject if the count is nonzero modulo k. An edit changes the marker at one position.
  3. If every frequency is divisible by k, every subset count is divisible. Otherwise fix the random bits of all good and bad values except one offending v. Its two bit choices give totals differing by freq[v], which is nonzero modulo k. At most one choice can pass.

Why it works

For a fixed bad query, independent trials miss with probability at most 2⁻ᵗ, including composite k. Across Q fixed queries the union bound gives probability at most Q·2⁻ᵗ for any missed violation. Reuse one trial's bits across equal values and across updates.

Pr⁡[some bad query passes all t trials]≤Q 2−t\Pr[\text{some bad query passes all }t\text{ trials}]\le Q\,2^{-t}Pr[some bad query passes all t trials]≤Q2−t

Q is the number of fixed queries on input independent of the private random bits.

When the conditions change

O(t log n) per operation with t Fenwick trees, or replay stored operations once per trial to reduce memory to O(n+q). Use an independent seed for each trial and input independent of the private randomness. k must be positive.

Try one change

Why assign bits to values instead of positions?

Show the reasoning

Different positions holding one value must contribute the same bit. Otherwise even a valid frequency could yield a nonzero residue.

From idea to code

Replay operations in their original order for each independent set of random value bits. An ordinary Fenwick update is the new bit minus the old bit.
