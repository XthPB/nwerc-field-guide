Read from the end that determines the sign

A word contains symbols with increasing face values. A symbol adds its value unless a larger symbol appears anywhere to its right, in which case it subtracts its value. You may replace at most one symbol. Find the largest total value achievable.

Work through the example

  1. Use a tiny alphabet A=1, B=10, C=100. In ABA, the last A is +1. The B is +10. The first A sees B and contributes −1. Total 10.
  2. Replace the first A with C. Reading CBA backwards gives +1, +10, +100, for 111. At each step the sign only asks for the largest letter already seen.
  3. At a position try keeping the old letter, or each allowed replacement if the edit is unused. Combine partial solutions with the same suffix maximum and edit count by keeping their largest signed total.

Why it works

Start with an empty suffix of score zero and a maximum smaller than every symbol. Process one letter per layer. Read the best final score across the permitted edit counts. The real task has five denominations and at most one replacement.

When the conditions change

The sign is +1 on equality and −1 only when c is strictly smaller than m. With alphabet size A and budget b, time is O(n A²(b+1)) and rolling memory is O(A(b+1)). Unreachable entries start at negative infinity.

Try one change

Why can two suffixes with the same score still behave differently?

Show the reasoning

A maximum of B makes a new B positive, while a maximum of C makes it negative. The score does not reveal that difference.

From idea to code

Two-state DP with rolling layers

Read the executable Python reference

These functions illustrate the core algorithm. The fourteen references have differential checks against independent small-instance solvers.

def suffix_score(word, values=(1, 10, 100, 1000, 10000)):
    """word contains zero-based indices into strictly increasing positive values."""
    states = {(-1, 0): 0}
    for old in reversed(word):
        following = {}
        for (largest, used), score in states.items():
            for new, value in enumerate(values):
                changes = used + (new != old)
                if changes > 1:
                    continue
                key = max(largest, new), changes
                candidate = score + (value if new >= largest else -value)
                following[key] = max(following.get(key, -float("inf")), candidate)
        states = following
    return max(states.values())
