Recover hidden tree endpoints from a distance-sum oracle

A query on a set of tree vertices returns one minimizing the sum of its distances to two hidden endpoints, together with that sum. Can you recover both endpoints in eleven queries for n≤1000?

Work through the example

  1. Ask about all vertices. The answer gives a path vertex r and the hidden distance D. On a path with distances 2 and 5 from r to its ends, D=7. Among layers at depth 4,5,6 from r, exactly the first two touch the path.
  2. For a vertex v the sum equals D plus twice its distance to the hidden path. Query one whole depth layer at a time. The oracle returns D precisely when that layer touches the path. Binary-search the last good depth from ⌈D/2⌉ through min(D,tree height). Retain the actual returned good vertex.
  3. The last good layer contains a hidden endpoint e. Query the vertices exactly D edges from e. Only the other endpoint lies both on this sphere and on the hidden path, so it minimizes with sum D.

Why it works

Rooting at any hidden-path vertex splits that path into two arms. Its attained depths are a solid prefix ending at the longer arm's endpoint. Ties can choose either endpoint if both arms have equal length.

d(v,a)+d(v,b)=d(a,b)+2d(v,path(a,b))d(v,a)+d(v,b)=d(a,b)+2d\bigl(v,\mathrm{path}(a,b)\bigr)d(v,a)+d(v,b)=d(a,b)+2d(v,path(a,b))

Each off-path edge from v to its nearest path vertex is counted twice.

When the conditions change

For D≤999 the search range contains at most 500 candidate depths. An inclusive binary search needs at most nine queries, plus the first and last for eleven. Form the lists by BFS, skip nonexistent layers, flush requests and handle the judge's termination signal.

Try one change

Can an off-path vertex tie the true endpoint in the final query?

Show the reasoning

Its distance to the path is positive, so its distance sum exceeds D.

From idea to code

Use two ordinary distance traversals to build the layer lists. Retain a returned vertex at each successful binary-search probe so the last successful probe gives the endpoint.
