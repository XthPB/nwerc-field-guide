Repair the first impossible prefix at minimum extra cost

You’re given a string of opening brackets, closing brackets and question marks. For each question mark you know the separate prices of changing it to an opening or a closing bracket. Replace them all at minimum total cost so every closing bracket has an earlier unmatched opening and all openings are eventually closed.

Work through the example

  1. Start by paying the closing price at every unknown. Changing one of those closings into an opening now costs just the difference between its two prices. On “(??)” suppose those differences are 5 and 1. The initial balances are 1, 0, −1, −2.
  2. Scan left to right. Keep a min-heap of the differences for unknowns seen so far. When balance first falls below zero, flip the cheapest available position. At the third character the heap contains 5 and 1. Spending 1 raises the current balance from −1 to 1.
  3. The final closing brings the result to zero. With negative differences use the same rule. A valid word uses a fixed number of flips, and delaying the choice until it becomes compulsory gives you the largest eligible pool.

Why it works

A deficient prefix forces every feasible solution to flip an unchosen unknown in that prefix. Exchange its flip for the cheapest one. Earlier prefixes already feasible under the committed flips stay feasible. From the deficient position onward the two choices give the same balance.

When the conditions change

If the heap is empty at a deficit or the ending balance is nonzero, there is no solution. Store the original position alongside each heap key. O(n log n) time and O(n) space.

Try one change

Why can't we take the cheapest flips in the whole string first?

Show the reasoning

A cheap flip after a negative prefix never repairs that prefix.

From idea to code

Use a min-heap of (opening price minus closing price, index). An ordinary running balance is enough to detect the moment to pop.

def cheapest_brackets(pattern, costs):
    """Return a minimum-cost word, or None. Costs are (opening, closing) in '?' order."""
    from heapq import heappush, heappop
    offers = iter(costs)
    result = list(pattern)
    balance = total = 0
    heap = []
    for i, char in enumerate(pattern):
        if char == '?':
            opening, closing = next(offers)
            total += closing
            result[i] = ')'
            heappush(heap,(opening-closing,i))
        balance += 1 if result[i]=='(' else -1
        if balance < 0:
            if not heap:
                return None
            extra, pos = heappop(heap)
            total += extra
            result[pos] = '('
            balance += 2
    return (total,''.join(result)) if balance==0 else None
