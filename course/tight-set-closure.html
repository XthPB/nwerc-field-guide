Price Hall-tight sets by converting a matching into implications

Choose sets with minimum total signed price subject to their union having exactly as many elements as the number of chosen sets. The input guarantees that every group of sets has at least that many neighbors.

Work through the example

  1. Take sets A={1,2} costing −5, B={2} costing 3 and C={3} costing 1. Pair A with 1, B with 2, C with 3. Selecting A brings in B's matched element 2, so equality forces B to be selected as well. A and B together cost −2.
  2. Use bipartite matching to pair every set with its own distinct element. For each element of set i add an implication i→j to the set j that owns that element in the matching. A chosen family is valid precisely when it contains all implied sets.
  3. Build a cut network. A negative price −b gives source→i capacity b. A positive price a gives i→sink capacity a. Give each implication capacity greater than the sum of all finite capacities. The source side of a minimum cut is an optimum family, and minimum cost equals cut value minus the sum of all b.

Why it works

The matching accounts for exactly one distinct element per chosen set. Extra elements arise precisely from arcs to unchosen owners. The cut pays for positive prices taken and negative-price benefits forgone, giving a constant offset from the desired objective.

When the conditions change

The task has n sets and n possible elements, Hall's condition, and allows the empty selection. Run one matching and one max flow. A wide integer type must fit the total finite capacity plus one. With a different universe size some elements may lack a matched owner.
