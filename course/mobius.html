Count divisible objects first, then isolate an exact gcd

In [2,3,6], how many nonempty subsequences have gcd exactly 1? A table indexed by every possible subset is too large.

Work through the example

  1. For divisor d let c[d] count input values divisible by d. There are 2ᶜ⁽ᵈ⁾−1 nonempty subsets whose gcd is a multiple of d.
  2. At d=6 this is 1. At d=3 it is 3, of which one has gcd 6, leaving 2 exactly. Similarly two have gcd 2.
  3. At d=1 there are seven nonempty sets. Subtract 1+2+2, leaving 2: {2,3} and {2,3,6}.

Why it works

Sweep divisors downwards, subtracting all already-computed proper multiple buckets. Möbius inversion performs the same removal with signed coefficients. For pair queries replace the subset count by c[d] choose 2.

F counts objects with exact gcd and G counts objects whose gcd is divisible by the argument. The sums stop at the largest possible gcd.

When the conditions change

O(M log M+n) with frequencies and a multiples sieve. For dynamic coprime-pair toggles in CF 547C only square-free divisors matter. For weighted subset size in CF 839D change the statistic inside each bucket.

What if the array contains repeated 2s?

Show the reasoning

Count occurrences as distinct choices when selecting subsequences. The divisor sieve uses frequencies, not presence bits.
