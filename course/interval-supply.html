Greedy, sorting and search · 9 of 15

Give the next bridge to the gap that will expire first

Each gap between islands can be spanned by any bridge whose length lies in its own inclusive interval. The available bridges have fixed lengths and each can be used once. Find an assignment that fills every gap, or determine that none exists.

Work through the example

  1. Suppose the gaps accept [2,4] and [3,3], and the bridges have lengths 3 and 4. Both gaps accept 3. Giving it to the first gap strands the second.
  2. Sweep the bridges from shortest to longest. Sort gaps by their minimum length. Insert every gap that has opened into a min-heap keyed by maximum length. At 3, the heap returns [3,3].
  3. At 4, fill [2,4]. If the smallest waiting maximum is already below the current length, that gap has expired and no later bridge can repair it. Report success only if every gap was filled.

Why it works

In any feasible assignment, consider the waiting gap with the smallest deadline. If a different waiting gap used today's bridge, swap their assigned lengths. Both have opened, and the second gap's deadline is at least the first gap's deadline. Both assignments remain legal.

ℓmin⁡=c−b,ℓmax⁡=d−a\ell_{\min}=c-b,\qquad \ell_{\max}=d-aℓmin​=c−b,ℓmax​=d−a

When the conditions change

For adjacent islands [a,b] and [c,d], the allowable lengths are [c−b,d−a]. Preserve the original indices to output an assignment. Sorting n gaps and m bridges plus heap operations costs O((n+m) log(n+m)).

Try one change

Can demands still be put into a single min-heap if a gap accepts two disjoint length intervals?

Show the reasoning

The proof used continuous eligibility between the assigned lengths. A bridge inside the hole can invalidate the swap.
