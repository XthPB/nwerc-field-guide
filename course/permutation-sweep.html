Range queries and sweeps · 10 of 19

Count consecutive-value intervals by keeping the minimum slack

You’re given a permutation. Count contiguous intervals whose values form a set of consecutive integers, in any order. For instance [2,4,3] qualifies because its values are exactly 2,3,4. Every singleton also qualifies.

Work through the example

  1. Fix r and define slack(l)=max(l..r)−min(l..r)−(r−l). For [2,4] the slack is 1. Append 3 and [2,4,3] has slack zero. For the permutation [2,4,3,1] the contributions by right end are 1,1,3,2, giving 7 valid intervals.
  2. On extending r, subtract 1 from all previously active starts. Update their maxima using a decreasing stack of maxima and their left boundaries. A popped range with old maximum M gains new−M in slack. A second, increasing stack adds oldMin−new wherever the minimum falls.
  3. Activate start r at slack zero. A lazy segment tree stores the minimum slack and the number of leaves attaining it. The global minimum among active starts is zero, so add its multiplicity to the answer.

Why it works

An interval of t distinct integers spans at least t−1. Equality means every integer between its minimum and maximum occurs. Starts with the same old maximum or minimum form contiguous groups, and each group is pushed and popped at most once.

When the conditions change

O(n log n) time and O(n) space. Keep future starts inactive or query only the active prefix. In the chessboard formulation, order by row and use the column permutation. Duplicates break the nonnegative-slack proof.

Try one change

Why can't we keep only the leftmost valid start?

Show the reasoning

Valid starts need not be consecutive. With rightmost value 1 in [2,4,3,1], the full interval and the singleton qualify while both intermediate starts fail.

From idea to code

Change the lazy tree aggregate to (minimum, count). Merge tied minima by adding counts. A lazy addition changes only the minimum.
