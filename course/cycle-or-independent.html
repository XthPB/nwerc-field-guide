Build either a short cycle or many nonadjacent vertices

A graph promises you may output either a cycle of length at most k or an independent set of size ⌈k/2⌉. How does failure to find the first object help construct the second?

Work through the example

  1. First consider a forest. Color vertices by depth parity. The larger color class is independent and contains at least ⌈k/2⌉ vertices when k≤n.
  2. If a connected graph has a cycle, run DFS and use the back edge with the smallest difference in depth between ancestor and descendant. Together with the intervening tree path it forms a chordless cycle, since any chord would itself span fewer depths.
  3. If this cycle is short enough, output it. If its length exceeds k, take vertices 1,3,5,… among its first k vertices. No selected pair is consecutive, there is no closing edge between the first and last selected vertices, and no chord can join them.

Why it works

The second witness relies on induced structure, not just a list of vertices that happens to form a cycle. Minimizing the depth span of a DFS back edge produces that induced structure in linear time.

When the conditions change

Use an undirected simple graph as in the contest. Count cycle length in vertices. Global DFS bookkeeping must distinguish a parent tree edge from a back edge. Time and space are O(V+E).

Try one change

Would alternating vertices of an arbitrary long cycle always give an independent set?

Show the reasoning

A chord can join two alternating vertices. Choosing a chordless cycle supplies the missing guarantee.
