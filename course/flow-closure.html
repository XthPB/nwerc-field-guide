Pay a shared penalty only once with a cut

Accepting either of two projects requires buying the same machine for 7. Their profits are 6 and 5. How do you avoid charging the machine twice?

Work through the example

  1. Make a positive node per project with an arc from the source of capacity its profit. Make a negative machine node with an arc to the sink of capacity 7.
  2. A very large arc from each project to the machine says that choosing the project forces the purchase. Place selected nodes on the source side of a cut.
  3. Taking both yields 11−7=4. Taking neither gives zero. A cut pays the foregone positive profits plus all selected costs.

Why it works

Maximum closed-set weight equals the sum of positive weights minus the minimum cut capacity. Take an implication capacity greater than the sum of all positive weights; then an optimal cut never breaks an implication. CF 1082G maps an edge’s reward to selecting both endpoints.

When the conditions change

For CF 1146G create a node for each height increment and each one-time interval fine. Connect a height selection to the lower height and to every newly triggered fine. Check whether the threshold is strict. The flow complexity depends on the constructed network.

Try one change

Can you reverse a project→machine implication?

That would force buying a machine to select all associated projects. Buying it is allowed even if only one project uses it.
