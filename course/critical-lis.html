Would changing this one value break every longest chain?

You have a fixed array and many hypothetical edits. For each query replace just the named entry by the proposed value and report the length of the longest strictly increasing subsequence. The next query starts from the original array again.

Work through the example

  1. For [1,4,2,5], the longest length is 3. The middle layer has two candidates, 4 or 2. Changing 4 to 0 leaves the chain 1,2,5 intact.
  2. Compute L[i], the best length ending at i, and R[i], the best starting there. Position i belongs to some best chain precisely when L[i]+R[i]−1 equals the global length K. Any best chain uses one eligible position in each layer L.
  3. For an edit at i, a chain avoiding i has length K unless i is the only eligible member of its layer. In that case it has length K−1. Removing i from an old best chain attains that lower bound.

Why it works

Also compute the best chain using the replacement x. An offline left-to-right Fenwick maximum gives the best prefix strictly below x before i. A reverse pass gives the best suffix strictly above x after i. Query before inserting the original item at i. Take the better of using and avoiding the edit.

K′=max⁡ ⁣(K−[i mandatory],1+leftLess(i,x)+rightGreater(i,x))K'=\max\!\left(K-[i\ \mathrm{mandatory}],\quad 1+\mathrm{leftLess}(i,x)+\mathrm{rightGreater}(i,x)\right)K′=max(K−[i mandatory],1+leftLess(i,x)+rightGreater(i,x))

When the conditions change

Compress query values too. O((n+q) log(n+q)) time and O(n+q) space. A position on no best chain cannot be mandatory even if some other eligible position is alone in its layer. The precomputation assumes independent edits.

Try one change

In [1,4,2,5], replace the final 5 by 0. Which branch wins?

Show the reasoning

The final position was mandatory. Avoiding it gives length 2. Using the new final 0 gives only 1.

These functions illustrate the core algorithm. The fourteen references have differential checks against independent small-instance solvers.

def lis_edits(array, queries):
    """Each (zero-based position, replacement) refers to the original array."""
    groups = [[] for _ in array]
    for q, (i, x) in enumerate(queries):
        groups[i].append((q, x))
    def side(indices, direction):
        tails = []
        lengths, inserts = [0] * len(array), [0] * len(queries)
        for i in indices:
            for q, x in groups[i]:
                inserts[q] = bisect_left(tails, direction*x)
            value = direction * array[i]
            j = bisect_left(tails, value)
            lengths[i] = j + 1
            if j == len(tails):
                tails.append(value)
            else:
                tails[j] = value
        return lengths, inserts
    left, prefix = side(range(len(array)), 1)
    right, suffix = side(reversed(range(len(array))), -1)
    best = max(left)
    layers = [0] * (best+1)
    for l, r in zip(left, right):
        if l+r-1 == best:
            layers[l] += 1
    answers = []
    for q, (i, _) in enumerate(queries):
        mandatory = left[i]+right[i]-1 == best and layers[left[i]] == 1
        answers.append(max(best-mandatory, prefix[q]+1+suffix[q]))
    return answers
