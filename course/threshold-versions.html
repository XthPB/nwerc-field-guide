Range queries and sweeps · 15 of 19

Find the best minimum over a fixed-width run in any interval

Inside a query range, place a sign across w consecutive fence posts. Its height is the smallest post it covers. Which placement gives the largest height?

Work through the example

  1. For heights [5,2,4,4] and w=2, test height 5. The active pattern is 1000, so it fails. At height 4 the pattern is 1011. Its last two posts fit.
  2. Activate positions in decreasing height order. In a segment-tree node store the segment length, active prefix, active suffix and longest active run. A run crossing the midpoint has length left.suffix + right.prefix.
  3. Save a persistent root after each distinct height. For query [l,r], binary-search these roots for the first with longest run at least w inside that interval. Its threshold is the answer.

Why it works

Lowering the proposed sign makes more posts usable. The predicate is monotone, and the run summary preserves everything a neighbor needs at their shared boundary. Restricting the summary to the query interval prevents runs outside it from helping.

b=max⁡(bL,bR,sL+pR)b=\max\bigl(b_L,b_R,s_L+p_R\bigr)b=max(bL​,bR​,sL​+pR​)

Here b is the best run, s is the active suffix and p is the active prefix. L and R are the two children.

When the conditions change

Preprocessing uses O(n log n) nodes and time, including sorting. A query takes O(log² n). Equal heights may be activated together. Keep left and right query fragments in spatial order.
