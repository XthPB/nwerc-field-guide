Group substrings by their ending positions

“ababa” has several copies of “ba” and “a”. Which substring properties survive when you extend a substring by one letter?

Work through the example

  1. Each substring has a set of ending positions. Substrings with identical ending positions allow exactly the same following characters and have the same occurrence count.
  2. A suffix automaton state holds a range of lengths from len(link)+1 to len(state). Place one visit at each original prefix endpoint, and zero initial visits at clones.
  3. Propagate visits downwards in order of decreasing length to suffix links. All substrings represented by the same state now know their frequency.

Why it works

Each extension edge appends one character. Each suffix link moves to the longest suffix outside the present class. For a cyclic-pattern query such as CF 235C, scan the doubled pattern and count each distinct rotation’s class at the required length only once.

When the conditions change

Linear number of states and transitions for a fixed alphabet, with implementation-specific lookup costs. Distinguish counting distinct strings from counting all their occurrences. A clone splits a class but is not an original prefix endpoint.
