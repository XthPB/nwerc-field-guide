Range queries and sweeps · 8 of 19

Compose pending updates in the order they happened

You can edit an interval of an array by setting every entry to a number or by adding a number to every entry. After edits, answer interval-sum queries. For three entries totaling 12, setting them all to 5 and then adding 2 gives a different result from doing those edits in reverse.

Work through the example

  1. Represent an update by x↦ax+b. Assignment to 5 has (a,b)=(0,5), and adding 2 has (1,2).
  2. Composing the later action after the earlier one gives x↦7, so the new segment sum is 21. Reversing them would give 15.
  3. Apply a tag to a sum using a·sum+b·length. When descending, compose each child’s old tag with the parent’s newer one in this order.

Why it works

The update must act on the segment summary and compose with another update. CF 446C adds a Fibonacci sequence, so shifting a tag to the right child depends on its offset. CF 438D uses a maximum to prune modulo operations, whose effect on a sum has no fixed affine tag.

When the conditions change

O(log n) for the affine update family. Segment-tree beats handles range chmin with sum by storing the maximum, strict second maximum and multiplicity; it can stop only when the cap is strictly above the second maximum and below the maximum.

Try one change

Can a lazy “set to zero” flag be represented by the value zero meaning no pending operation?

Show the reasoning

No. Zero is a valid assignment. Use an explicit flag or the affine identity (1,0).
