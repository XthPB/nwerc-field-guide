Range queries and sweeps · 5 of 19

Move the right endpoint and maintain the latest valid witness

An array such as [a,b,a,c] is fixed, and many queries name inclusive intervals. For each interval, count the different values appearing inside it. Repeated occurrences contribute once. All queries are available before you have to print their answers.

Work through the example

  1. At r=1 mark position 1 for a. At r=2 mark position 2 for b.
  2. At r=3 erase a’s mark at 1 and put it at 3. Marks now stand at 2 and 3.
  3. A Fenwick sum over [2,3] counts b and a exactly once. At each r, every value has one live mark at its latest occurrence.

Why it works

A value occurs in [l,r] exactly when its last occurrence up to r is at least l. When frequency enters the objective, reconsider whether a single mark suffices. Mo’s algorithm instead maintains exact frequencies while moving both ends of a query window.

When the conditions change

Latest occurrences give O((n+q)log n). Mo’s technique costs about O((n+q)√n) single-element moves with standard block ordering. In CF 86D, adding x changes x·freq² by x·(2·freq+1).

Try one change

If a range query asks for the number of values occurring exactly twice, where can l start?

Show the reasoning

For each value the allowed starts lie between its third-last and second-last occurrence. That whole interval of possible starts needs a contribution.
