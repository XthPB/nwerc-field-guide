Count lattice points on intersecting segments exactly once

You’re given segments with integer-coordinate endpoints and no two on the same supporting line. Count the distinct integer-coordinate points lying on any segment, endpoints included. If several segments pass through the same lattice point it contributes only once.

Work through the example

  1. A segment from (0,0) to (6,4) has steps (3,2) and contains three lattice points. Add the vertical segment from (3,0) to (3,3), which contains four points. They share (3,2), giving 3+4−1=6.
  2. When inserting a segment, first add gcd(|dx|,|dy|)+1. Intersect it with each previous segment using exact determinants and segment parameters. Count an intersection only when it lies on both closed segments and its two coordinates are integers.
  3. Put the qualifying coordinates in a temporary set for the new segment and subtract its size. Use a fresh set for the next segment. If three segments meet at one lattice point, the third segment subtracts that point once.

Why it works

The gcd gives the largest common number of equal integer steps along the segment. Every already-covered point on the new segment must be an intersection with an earlier segment. Deduplicating by the coordinates removes exactly those previous contributions.

#{lattice points on AB}=gcd⁡(∣xB−xA∣,∣yB−yA∣)+1\#\{\text{lattice points on }AB\}=\gcd(|x_B-x_A|,|y_B-y_A|)+1#{lattice points on AB}=gcd(∣xB​−xA​∣,∣yB​−yA​∣)+1

This count includes both endpoints.

When the conditions change

The source excludes collinear pairs on the same supporting line. To admit overlapping segments, merge their intervals per normalized line before applying the crossing count. O(n² log n) time with ordered sets and O(n) temporary space. Widen intermediate products before multiplication.

Try one change

Should an intersection at (1/2,1/2) reduce the answer?

Show the reasoning

No. The individual segment counts contain only lattice points.

From idea to code

Use exact determinants and divisibility tests before dividing either coordinate. Normalize a denominator’s sign before making coordinates into set keys.
