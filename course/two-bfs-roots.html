Graphs, connectivity and flow · 3 of 27

Count trees preserving distances from two roots

Count spanning trees whose distances from both x and y equal the graph distances. The two roots impose different parent constraints. Where do those constraints meet?

Work through the example

  1. On the diamond x–a–y and x–b–y, both a and b lie on a shortest x-to-y path. A tree has only one x-to-y route. Both vertices would need to lie on that length-two route, which is impossible.
  2. Run BFS from each possible root. For one pair (x,y), find all v with dₓ(v)+dᵧ(v)=dₓ(y). Their count must equal dₓ(y)+1. If so, there is exactly one shortest spine, whose edges are forced.
  3. For each vertex outside the spine count neighbors that are one closer to both roots. Multiply those counts. Choosing such a parent at every off-spine vertex completes the tree. For x=y the spine contains just the root.

Why it works

In any valid tree every off-spine vertex heads toward both roots along the same first edge. Parent edges cannot form cycles because distance to x strictly decreases. Following them must enter the spine, so all independent choices form a valid connected tree.

When the conditions change

For n≤400 and m≤600 as in the contest, O(n²(n+m)) time and O(n²+m) space suffice. Store all BFS distances, and for each surviving root pair scan the adjacency lists once. In a dense variant the same direct bound can be quartic.

Try one change

If two routes from x meet at v, must that disqualify x as one of the roots?

Show the reasoning

Only a tie along the forced x-to-y spine disqualifies the whole pair. An off-spine vertex can have several legal parents. Each contributes a distinct tree.

From idea to code

Use one BFS per root to build the distance table. For the multiplication loop the only per-pair state is the forced spine and one count per off-spine vertex.
