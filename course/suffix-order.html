Sort suffixes to answer many substring comparisons

In “banana”, how can you compare two long substrings or find a repeated one without rescanning every character from both starts?

Work through the example

  1. Sort suffixes: a, ana, anana, banana, na, nana. Neighboring common-prefix lengths are 1,3,0,0,2.
  2. Every suffix starting with “ana” is consecutive. The first two such suffixes share three characters, so “ana” repeats.
  3. The common-prefix length of any two suffixes is the minimum neighboring LCP on the rank interval between them. Cap by the desired substring lengths.

Why it works

Lexicographic order puts every fixed prefix in one contiguous interval. This converts string equality and repetition questions into range and neighbor queries. For multiple texts insert unique separators and keep track of which text owns each suffix.

When the conditions change

A doubling suffix array with radix/counting sorting costs O(n log n), Kasai LCP O(n). Distinct substrings total n(n+1)/2 minus the adjacent LCP sum. CF 427D additionally requires uniqueness in both input strings.

Try one change

Could the largest adjacent LCP be zero if a nonempty substring repeats?

Show the reasoning

No. Suffixes with that repeated prefix form a block containing an adjacent pair sharing it.
