Undo unions in reverse time or across a time interval

Edges appear and disappear. At time 1 add AB, at 2 add BC, at 3 remove AB. How can an ordinary union structure answer connectivity at each time?

Work through the example

  1. An edge exists on an interval of time. AB covers [1,3); BC starts at 2. Put each lifetime into canonical nodes of a time segment tree.
  2. At each node save the union history length, add that node’s edges, then visit its children. At leaf 2 both edges are present.
  3. Undo to the saved history length before returning. Leaf 3 now sees BC alone, even though it follows a leaf that saw AB.

Why it works

The nodes on a leaf’s search path partition every lifetime containing that instant exactly once. Rollback only needs parent and size changes when union by size is used without path compression.

When the conditions change

For T operations and m lifetimes, O((m log T) log V + T) with union by size, plus output costs. Deletions-only can often run backwards with a normal DSU. Form separate lifetimes for repeated toggles and define multiplicities for parallel edges.
