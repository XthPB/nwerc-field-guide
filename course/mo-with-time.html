Range queries and sweeps · 18 of 19

Move a range query through positions and edit time

An array receives value replacements between queries. Inside a queried interval, compute how many times each distinct value occurs. Return the smallest positive integer that is absent from those occurrence counts. For example, frequencies 1 and 2 make the answer 3.

Work through the example

  1. In [a,a,b], positive frequencies are 2 and 1 and the answer is 3. Change b to a. The same range now has only frequency 3, so the answer becomes 1.
  2. Record (left,right,number of earlier edits) on each query. For every edit store both old and new values. Coordinate-compress all values, order queries in three-dimensional Mo order, and move the two endpoints plus the edit clock to each target.
  3. Keep freq[v] and howMany[f], the number of values having positive frequency f. Before and after changing a value adjust its two frequency buckets. Applying or undoing an edit inside the current range also changes those buckets. Scan positive f until howMany[f]=0.

Why it works

Moving one coordinate changes a known value's multiplicity by one or replaces a known entry. Maintaining both directions makes the counts exact at each query. If 1 through k all occur then the range has at least 1+⋯+k entries, so the first missing frequency is O(√n).

When the conditions change

For comparable array, query and edit counts N, use block size about N^(2/3) with left block, right block and time as keys. Endpoint and time movements total O(N^(5/3)), plus O(√N) per mex query. Handle repeated edits at one position using their chronological old values.
