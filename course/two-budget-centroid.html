Trees and paths · 12 of 14

Count tree pairs under two simultaneous distance limits

In an edge-weighted tree, each path has both a length in edges and a total weight. Count unordered pairs of distinct vertices whose connecting path uses at most L edges and has weight at most W. Both limits apply to the same pair.

Work through the example

  1. At a chosen centroid c, label each vertex by (h,d), the hop count and weighted distance to c. Suppose two vertices in different branches have labels (2,5) and (1,4). Their path uses 3 hops and weight 9.
  2. To count valid pairs in a label list, sort points by h. For each query point (hᵢ,dᵢ), count points with h≤L−hᵢ and d≤W−dᵢ. Sort these queries by hop threshold and insert eligible points into a Fenwick tree over compressed d. Subtract qualifying self pairs and divide ordered pairs by two.
  3. Run that count on the whole component including (0,0) for c, then subtract the same count on each individual branch. Recurse below c. Paths staying in one branch are handled lower down where their true distances split.

Why it works

The subtraction leaves precisely paths passing through c, for which both distances add. Every unordered pair first separates at exactly one centroid. Offline dominance counting intersects the two inequalities rather than accidentally satisfying them with two different endpoints.

hj≤L−hi,dj≤W−dih_j\le L-h_i,\qquad d_j\le W-d_ihj​≤L−hi​,dj​≤W−di​

L bounds hops and W bounds weight. Both inequalities must hold for the same partner.

When the conditions change

O(n log² n) time and O(n) working space when lists are released before recursion. Use wide weights. A point counts itself in the ordered tally exactly when 2h≤L and 2d≤W.

Try one change

Could a two-pointer scan on distances alone work?

Show the reasoning

A short weighted path can have too many edges. The data structure keeps the second ordering while the sweep enforces the first.

From idea to code

Collect (hop count, weight sum) during the centroid branch traversal. Each call to the dominance counter uses its own sorted threshold sweep.
