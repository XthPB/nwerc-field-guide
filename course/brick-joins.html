Choose compatible grid joins with bipartite matching

Some cells of a rectangular grid are marked. Cover exactly those cells with straight bricks of any positive length, laid horizontally or vertically. Bricks cannot overlap or turn a corner. Find the minimum number needed.

Work through the example

  1. Start with one brick per cell. A legal join between two adjacent marked cells saves one brick. In a three-cell L there are two possible joins, one horizontal and one vertical. They share the corner cell, so you can save just one brick.
  2. Make one vertex per candidate join. Connect a horizontal join to a vertical join whenever they touch the same cell. Parallel joins never conflict, even when consecutive. Select as many joins as possible without a conflict.
  3. The conflict graph is bipartite. Its maximum independent-set size is the number J of joins minus a maximum matching. The final brick count is the number of cells minus that independent-set size.

Why it works

Any compatible join set forms straight paths on the grid, with one fewer brick for every chosen edge. Conversely every brick defines exactly the joins along its length. König's theorem converts minimum vertex cover into maximum matching in the conflict graph.

minimum bricks=C−J+ν\text{minimum bricks}=C-J+\numinimum bricks=C−J+ν

C counts marked cells, J counts candidate joins, and ν is the conflict graph’s maximum matching size.

When the conditions change

The conflict graph has O(C) vertices and edges for C marked cells. Hopcroft–Karp takes O(C√C). A unit-capacity bipartite flow network also supports the matching reduction. To reconstruct joins take the complement of a minimum vertex cover.

Try one change

Would the same count hold on a row that wraps around?

Show the reasoning

A full ring of selected joins can contain a cycle. The identity bricks = cells − joins used the ordinary rectangular grid.

From idea to code

Give horizontal joins unit edges from the source, and vertical joins unit edges to the sink. Put a unit arc between each incompatible pair and read the matching as the resulting flow.
