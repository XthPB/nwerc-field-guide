Count distinct walk XORs with a cycle basis

Edges of an undirected graph carry integer labels. Fix start and finish vertices, and XOR all edge labels traversed along a walk, counting repeated traversals. Determine which XOR totals can occur as you choose different routes and detours.

Work through the example

  1. Use a spanning tree and record x[v], the XOR from its root to v. The tree route from u to v has value x[u] XOR x[v]. Each non-tree edge ab offers a cycle adjustment x[a] XOR weight(ab) XOR x[b].
  2. On a triangle with edge weights 1,2,7 the cycle adjustment is 4. If the direct tree route has XOR 3, detouring around the cycle changes it to 7. Taking that detour twice returns 3.
  3. Insert all cycle adjustments into a binary linear basis. Rank r gives 2ʳ distinct answers for every pair in the component. To sum answers, handle each bit separately. If the bit occurs in the span, exactly half the masks set it. Otherwise its value is fixed by the two endpoint labels.

Why it works

Adding a closed detour toggles its XOR, and walking to a remote cycle and back cancels the connector edges. Conversely the parity difference between any walk and the tree route decomposes into cycles. The reachable masks are therefore one translate of the cycle space's XOR image.

W(u,v)=(xu⊕xv)⊕span⁡(cycle XORs)\mathcal W(u,v)=(x_u\mathbin{\oplus}x_v)\mathbin{\oplus}\operatorname{span}(\text{cycle XORs})W(u,v)=(xu​⊕xv​)⊕span(cycle XORs)

When the conditions change

Build a separate basis per component. With B-bit weights, O((V+E)B) word operations suffice for traversal, basis insertion and bit totals. A simple-path requirement would invalidate the detour argument.

Try one change

If two cycles both change the XOR by 4, how many distinct adjustments do they provide?

Show the reasoning

Two, zero and four. Their vectors are dependent, so they increase the rank only once.
