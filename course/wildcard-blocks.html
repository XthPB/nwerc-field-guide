Spend a subset dimension only at the wildcards

A string contains fixed letters and a few question marks. Fill the question marks with distinct allowed letters. Dictionary entries have weights, and each occurrence contributes its weight, including overlaps. Choose the filling with maximum total score.

Work through the example

  1. Use alphabet {a,b}, patterns ab worth 3 and ba worth 2, and text ?a?. The filling aab scores 3. The filling baa scores 2. The two question marks consume distinct letters.
  2. An Aho–Corasick state remembers which dictionary prefixes currently match a suffix. Attach to each state the sum of terminal weights on its failure chain. Reading one character now pays for every pattern ending there.
  3. Split the text at question marks. For each fixed block and each entering automaton state, precompute its exit state and total gain. After a mask of used letters is known, its popcount tells you which block follows the next wildcard.

Why it works

Read the fixed prefix once. From each reachable (mask,state), try one unused letter, collect its transition gain, then jump through the next fixed block. Keep the highest total for the resulting mask and state. Stop when every wildcard has been filled, even if some letters remain unused.

When the conditions change

With alphabet A, S automaton states and text length n, direct block precomputation is O(Sn). The mask phase costs O(S A 2ᴬ) time and O(S 2ᴬ) space, plus the block summaries. Initialize unreachable scores to negative infinity because pattern weights may be negative.

def wildcard_score(text, patterns, alphabet):
    """Letters at '?' positions are distinct. patterns holds (word, weight) pairs."""
    size = len(alphabet)
    index = {letter:i for i,letter in enumerate(alphabet)}
    go, failure, gain = [[-1]*size], [0], [0]
    for word, weight in patterns:
        state = 0
        for letter in word:
            c = index[letter]
            if go[state][c] == -1:
                go[state][c] = len(go)
                go.append([-1]*size)
                failure.append(0)
                gain.append(0)
            state = go[state][c]
        gain[state] += weight
    queue = deque()
    for c in range(size):
        child = go[0][c]
        if child == -1:
            go[0][c] = 0
        else:
            queue.append(child)
    while queue:
        u = queue.popleft()
        gain[u] += gain[failure[u]]
        for c in range(size):
            v = go[u][c]
            if v == -1:
                go[u][c] = go[failure[u]][c]
            else:
                failure[v] = go[failure[u]][c]
                queue.append(v)
    def read(state, block):
        score = 0
        for letter in block:
            state = go[state][index[letter]]
            score += gain[state]
        return state, score
    prefix, *blocks = text.split("?")
    start, score = read(0, prefix)
    states = {(0,start): score}
    for block in blocks:
        jump = [read(u, block) for u in range(len(go))]
        following = {}
        for (mask, state), score in states.items():
            for c in range(size):
                if mask >> c & 1:
                    continue
                after = go[state][c]
                target, extra = jump[after]
                key = mask | 1 << c, target
                following[key] = max(following.get(key, -float("inf")), score+gain[after]+extra)
        states = following
    return max(states.values())
