Strings and pattern matching · 10 of 11

Turn substring-occurrence queries into tree path and range queries

How many times does one dictionary pattern occur inside the texts with indices l through r? Running every search separately repeats almost identical work.

Work through the example

  1. Build one Aho–Corasick machine. Every text character produces one visited state. A pattern ending at state p matches exactly when p is an ancestor of that state in the failure tree.
  2. Flatten the failure tree so p’s descendants form one interval. While adding a text, add a point at each visited state.
  3. Answer prefix-of-text-list queries by a subtree sum. Subtract the answers after texts r and l−1 for a closed interval.

Why it works

Failure links encode suffix containment and an Euler tour encodes ancestry as interval containment. CF 163E instead activates patterns over time: add or remove the pattern’s subtree contribution and read a point when scanning.

When the conditions change

O((total text length + queries) log states) after building the automaton, with a subtraction event per prefix endpoint. CF 1202E combines forward ending counts and reverse starting counts at each split.

Why count visits with multiplicity?

Show the reasoning

A text may reach the same state many times, yielding several occurrences of the same pattern.
