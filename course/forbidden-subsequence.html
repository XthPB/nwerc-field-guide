Build a common subsequence while forbidding one substring

Find a longest common subsequence of two strings, subject to a forbidden contiguous pattern in the chosen output. What does an ordinary LCS table forget?

Work through the example

  1. For inputs ABC and ABC with forbidden BC, the ordinary LCS is ABC, which is illegal. Both AB and AC have length two and are legal. If the chosen output currently ends in B, appending C is dangerous.
  2. Make a KMP automaton for the forbidden word. Its state is the length of the longest suffix of the chosen output that matches a prefix of that word. Skipping a character in either input leaves this state unchanged.
  3. At a matching input character you may append it and advance the automaton. Discard transitions reaching the full forbidden length. Store the best length for each pair of input-prefix lengths and automaton state, with parents to recover an actual subsequence.

Why it works

Two partial outputs at the same input positions and KMP state have the same legal futures. Keeping only the longer one preserves an optimal completion. The automaton must read characters that were chosen for the output.

When the conditions change

With input lengths n,m and forbidden length f, the DP costs O(nmf) after precomputing transitions. A predecessor table costs O(nmf). Two layers save space if only the length is required. A dictionary of forbidden patterns calls for Aho–Corasick.

Try one change

If C occurs in an input immediately after B but you skip it, does it complete the forbidden word?

Show the reasoning

No. Skipped characters never enter the output and never advance its automaton.
