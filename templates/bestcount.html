Merge optimal scores and counts

Extend the winning score, sum tied counts modulo the modulus and preserve one witness. Combine disjoint sources so a path never counts itself twice.

From the DP companion.

// Merge DISJOINT candidate sets. Use ways mod 1e9+7 at every stage.
// id == -1 is the empty identity. A count can be zero modulo the modulus.
struct Best {
    i64 score = 0;
    int ways = 0;
    int id = -1;
};
inline Best combine_best(Best a, Best b) {
    if (a.id == -1) return b;
    if (b.id == -1) return a;
    if (a.score != b.score) return a.score > b.score ? a : b;
    return {a.score, (a.ways + b.ways) % 1000000007, std::min(a.id, b.id)};
}
