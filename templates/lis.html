Strict longest increasing subsequence

The lower_bound version finds a strictly increasing chain. Equal values can extend a nondecreasing chain when you switch to upper_bound. The returned number is a length.

From the ICPC Code Templates cheat sheet.

// Longest strictly increasing subsequence, O(n log n).
// tails[k] = smallest end of an increasing subsequence of length k+1
int lis(const vector<ll> &a) {
    vector<ll> tails;
    for (ll x : a) {
        // non-decreasing subsequence: upper_bound instead
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) tails.push_back(x);
        else *it = x;
    }
    return tails.size();
}
// the sequence itself: also store, for each x, its length (index
// it - tails.begin()) and the previous element; walk back from the end
