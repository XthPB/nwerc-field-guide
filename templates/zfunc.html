Z-function

Choose a separator outside the input alphabet if using a pattern followed by its text.

From the ICPC Code Templates section “Z-Function”. Use the code with the types and conventions shown in the excerpt.

// Z-function. USE: pattern search (like KMP), periods, "how much
//   of the start of s matches at position i". TIME: O(n).
// z[i] = longest common prefix of s and s.substr(i), z[0] = 0
vector<int> zFunction(const string &s) {
    int n = s.size();
    vector<int> z(n, 0);
    // [l, r) = the match reaching farthest right so far
    for (int i = 1, l = 0, r = 0; i < n; i++) {
        if (i < r) z[i] = min(r - i, z[i - l]);
        while (i + z[i] < n && s[z[i]] == s[i + z[i]]) z[i]++;
        if (i + z[i] > r) { l = i; r = i + z[i]; }
    }
    return z;
}
// find p in t: z of p + '#' + t; z[i] == |p| -> match at i-|p|-1
// smallest period of s: first p >= 1 with p + z[p] == n, else n
