Convex breakpoints for nondecreasing fits

Use the maximum heap to repair the upper breakpoint when a new value undercuts it. The returned cost is for absolute error with a nondecreasing fitted sequence.

From the DP companion.

// Minimum sum of absolute corrections to make a sequence nondecreasing.
inline i64 isotonic_l1(const std::vector<int>& a) {
    std::priority_queue<int> breakpoint;
    i64 cost = 0;
    for (int value : a) {
        breakpoint.push(value);
        if (breakpoint.top() > value) {
            cost += static_cast<i64>(breakpoint.top()) - value;
            breakpoint.pop();
            breakpoint.push(value);
        }
    }
    return cost;
}
