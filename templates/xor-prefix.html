XOR prefixes and letter parities

prefix_xor returns n+1 values. prefix_xor(a)[r] XOR prefix_xor(a)[l] gives the XOR on [l,r). A one-hot letter mask lets the same arithmetic track odd frequencies. This guide companion also shows the three-value operation used in constructive proofs.

std::vector<unsigned> prefix_xor(const std::vector<unsigned>& a) {
    std::vector<unsigned> prefix(a.size() + 1);
    for (std::size_t i = 0; i < a.size(); ++i)
        prefix[i + 1] = prefix[i] ^ a[i];
    return prefix;
}
bool at_most_one_odd(unsigned parity) {
    return (parity & (parity - 1u)) == 0;
}
void equalize_triple(std::vector<unsigned>& a, int i, int j, int k) {
    unsigned value = a[i] ^ a[j] ^ a[k];
    a[i] = a[j] = a[k] = value;
}
