Look up a boundary in sorted values

The compression snippet locates the first value at least x with lower_bound. Use upper_bound for the first greater value. Searching a monotone feasibility predicate instead needs the binary-search-on-the-answer loop.

From the ICPC Code Templates cheat sheet.

// Coordinate compression: values -> 0..k-1, order kept. USE: big
//   values (1e9) as indices of a Fenwick / segment tree. O(n log n).
vector<ll> vals = a;
sort(vals.begin(), vals.end());
vals.erase(unique(vals.begin(), vals.end()), vals.end());
auto id = [&](ll x) {
    return int(lower_bound(vals.begin(), vals.end(), x) - vals.begin());
};

These are contest snippets. Bring the declarations they use into your file, including standard headers, the ll alias or the modulus where applicable.
