Grundy values on a finite game

Use mex for a finite impartial normal-play game and XOR for its independent disjoint components. Weighted score games need minimax, while cyclic games may also have draws.

From the ICPC Code Templates cheat sheet.

// Grundy values for a pile game: from n you may take any amount in
//   moves (e.g. {1, 3, 4}). TIME: O(N * |moves|).
vector<int> grundy(int N, const vector<int> &moves) {
    vector<int> g(N + 1, 0);
    for (int n = 0; n <= N; n++) {
        vector<bool> seen(moves.size() + 1, false);  // g <= #moves
        for (int m : moves)
            if (m <= n) seen[g[n - m]] = true;
        while (seen[g[n]]) g[n]++;       // mex
    }
    return g;
}
