Divide-and-conquer partition DP

Use the recursion once optimal cuts are proven monotone. For exactly k nonempty groups, compute only i ≥ k and permit j ≥ k−1. Use the reachable prefix range on each layer.

From the ICPC Code Templates cheat sheet.

// Divide & conquer DP. USE: split n items into K consecutive
//   groups: dp[k][i] = min over j < i of dp[k-1][j] + cost(j, i).
// NEEDS: best j for i never moves left as i grows (typical when
//   cost(j, i) is like (sum of group)^2 or #pairs in group).
// TIME: O(K n log n) cost calls instead of O(K n^2).
// cost(j, i) = cost of one group made of items j+1..i (1-based).
// INF from the template.
vector<ll> prevLayer, curLayer;
ll cost(int j, int i);
void computeLayer(int lo, int hi, int optLo, int optHi) {
    if (lo > hi) return;
    int mid = (lo + hi) / 2, bestJ = optLo;
    ll best = INF;
    for (int j = optLo; j <= min(mid - 1, optHi); j++) {
        if (prevLayer[j] >= INF) continue;
        ll val = prevLayer[j] + cost(j, mid);
        if (val < best) { best = val; bestJ = j; }
    }
    curLayer[mid] = best;
    computeLayer(lo, mid - 1, optLo, bestJ);
    computeLayer(mid + 1, hi, bestJ, optHi);
}
// prevLayer[i] = cost(0, i) (one group); then for k = 2..K:
// curLayer.assign(n + 1, INF); computeLayer(1, n, 0, n - 1);
// prevLayer = curLayer.  Answer: prevLayer[n]
