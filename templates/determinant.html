Determinant modulo a prime

Use modular elimination for an exact residue over a prime field. The determinant changes sign when swapping rows. Build a path-count matrix for nonintersecting families before applying this snippet.

From the ICPC Code Templates cheat sheet.

// Determinant mod a PRIME p (exact Gaussian elimination).
// USE: #spanning trees (Kirchhoff): L[i][i] = degree of i,
//   L[i][j] = -(#edges i-j); delete row r and column r (any r);
//   #spanning trees = det. DIRECTED, #spanning trees with all edges
//   pointing away from root r: L[i][i] = in-degree, L[i][j] =
//   -(#edges i->j); delete row r and column r.
// NEEDS: power(). TIME: O(n^3). Exact count: use a big prime + hope,
//   or two primes + CRT (counts can be astronomically large).
ll detMod(vector<vector<ll>> a, ll p) {
    int n = a.size();
    for (auto &row : a)
        for (ll &x : row) x = ((x % p) + p) % p;
    ll det = 1;
    for (int col = 0; col < n; col++) {
        int piv = col;
        while (piv < n && a[piv][col] == 0) piv++;
        if (piv == n) return 0;
        if (piv != col) { swap(a[piv], a[col]); det = (p - det) % p; }
        det = det * a[col][col] % p;
        ll inv = power(a[col][col], p - 2, p);
        for (int r = col + 1; r < n; r++) {
            ll factor = a[r][col] * inv % p;
            for (int c = col; c < n; c++)
                a[r][c] = ((a[r][c] - factor * a[col][c]) % p + p) % p;
        }
    }
    return det;
}
