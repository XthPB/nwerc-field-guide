Binary search on the answer

Supply a feasibility predicate and prove it changes truth value in only one direction. Check the feasible upper bound and the loop's inclusive endpoints.

From the ICPC Code Templates cheat sheet.

// Binary search on the answer. USE: "smallest x such that x works"
//   when ok() is monotone: false..false true..true. O(log range).
// returns hi + 1 if none. Largest x with ok: firstTrue(!ok) - 1
ll firstTrue(ll lo, ll hi, function<bool(ll)> ok) {
    hi++;
    while (lo < hi) {
        ll mid = lo + (hi - lo) / 2;
        if (ok(mid)) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}
