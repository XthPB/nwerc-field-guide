Interactive protocol and query budgets

Keep local simulation and the judge protocol separate. Flush each actual query and handle termination.

From the ICPC Code Templates section “Interactive Problems”. Use the code with the types and conventions shown in the excerpt.

// Interactive problems: FLUSH after every line (endl flushes, '\n'
//   does not). Read the judge's reply before the next question.
ll ask(ll x) {
    cout << "? " << x << endl;     // exact format of the problem
    ll reply;
    cin >> reply;
    if (reply == -1) exit(0);      // judge: wrong / too many queries
    return reply;
}
