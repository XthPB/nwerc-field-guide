Digit DP on a numerical bound

The sheet memoizes loose prefixes for a fixed digit sum. Replace sum with the required automaton and add a started flag when padded zeros have different meaning. The public copy removes a stray character after the negative-bound return.

From the ICPC Code Templates cheat sheet.

// Digit DP: count x in [0, N] with a property of its digits.
//   [L, R] = countUpTo(R) - countUpTo(L - 1).
// State: position, what we need to remember (here: digit sum), and
//   tight = "prefix still equal to N" (then digits only up to N's).
// TIME: O(#digits * #states * 10). Example: digit sum == S.
// If leading zeros matter (e.g. "no two equal adjacent digits"),
//   add a flag started = "a non-zero digit was placed".
string D;                    // digits of N
ll memo[20][200];            // memo for tight == false, -1 = unknown
ll go(int pos, int sum, bool tight, int S) {
    if (sum > S) return 0;
    if (pos == (int)D.size()) return sum == S;
    if (!tight && memo[pos][sum] != -1) return memo[pos][sum];
    int limit = tight ? D[pos] - '0' : 9;
    ll res = 0;
    for (int d = 0; d <= limit; d++)
        res += go(pos + 1, sum + d, tight && d == limit, S);
    if (!tight) memo[pos][sum] = res;
    return res;
}
ll countUpTo(ll N, int S) {  // #x in [0, N] with digit sum S (< 200)
    if (N < 0) return 0;
    D = to_string(N);
    memset(memo, -1, sizeof memo);
    return go(0, 0, true, S);
}
