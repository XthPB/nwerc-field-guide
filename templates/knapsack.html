0/1 knapsack

Use the descending capacity loop for one-use items. The initial zeros in this implementation mean “at most this capacity.” For exact weight, mark initially unreachable cells before the first update.

From the ICPC Code Templates cheat sheet.

// Knapsack: items (weight w, value v), capacity W. TIME: O(n W).
ll knapsack01(int W, const vector<pair<int, ll>> &items) {
    vector<ll> best(W + 1, 0);         // best value, weight <= c
    for (auto [w, v] : items)
        for (int c = W; c >= w; c--)   // DOWN: each item at most once
            best[c] = max(best[c], best[c - w] + v);
    return best[W];
}
// unbounded (items reusable): same line, but c = w .. W going UP.
// k copies of an item: split into 1, 2, 4, .., rest copies (0/1).
// weight EXACTLY c: start best[0] = 0, others -INF (skip -INF).
