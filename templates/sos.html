Sum over submasks

The per-bit sweep aggregates values from subsets. Choosing a representative or a maximum needs its own combining operation and identity.

From the ICPC Code Templates cheat sheet.

// SOS: f[mask] = sum of a[sub] over submasks of mask, O(n 2^n)
// start with f = a
for (int b = 0; b < n; b++)
    for (int mask = 0; mask < (1 << n); mask++)
        if (mask & (1 << b)) f[mask] += f[mask ^ (1 << b)];
// supersets: if (!(mask & (1<<b))) f[mask] += f[mask | (1<<b)];
