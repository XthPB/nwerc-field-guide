First-step expectation and probability

Use the first-step or indicator formulas to derive your equation. The sheet gives mathematical reference notes. Cyclic systems can use the linked Gaussian elimination code.

From the ICPC Code Templates cheat sheet.

  E[X + Y] = E[X] + E[Y] even if dependent: sum of indicators
  Try until success with probability p: 1/p tries expected
  Restart: a try costs a, fails w.p. p, a fail costs r more and you
    start over: E = (a + p r) / (1 - p). k steps, a fail at any step
    restarts all: E[k] = (E[k-1] + c + p r) / (1 - p), c = step cost
  Random order: expected #records (prefix maxima) = H(n) ~ ln n + 0.58
  Birthday: k random values in [0, M) all distinct w.p. ~exp(-k^2/2M)
  Coupon collector: n (1 + 1/2 + .. + 1/n), H(n) ~ ln n + 0.5772
  Integer X >= 0: E[X] = sum over k >= 1 of P(X >= k)
  States form a DAG: DP in topological order; cycles: Gauss
  Bayes: P(A|B) = P(B|A) P(A) / P(B)
