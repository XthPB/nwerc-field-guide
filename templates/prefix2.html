Prefix sums and difference arrays

A prefix answers a range sum by subtraction. A difference array reverses the operation by marking the two ends of an interval update. The sheet includes the two-dimensional inclusion–exclusion form.

From the ICPC Code Templates cheat sheet.

// 2D prefix sums, 1-based: P[i][j] = sum of grid[1..i][1..j]
for (int i = 1; i <= R; i++)
    for (int j = 1; j <= C; j++)
        P[i][j] = grid[i][j] + P[i-1][j] + P[i][j-1] - P[i-1][j-1];
// rectangle rows r1..r2, cols c1..c2:
// P[r2][c2] - P[r1-1][c2] - P[r2][c1-1] + P[r1-1][c1-1]
// add v to a[l..r] for many ranges: d[l] += v; d[r+1] -= v;
// at the end a = prefix sums of d (difference array)
