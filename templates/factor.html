Prime factorization

For a square-product mask keep exponents modulo two. Repeated occurrences with the same parity mask can be grouped only after accounting for the number of labeled selections.

From the ICPC Code Templates cheat sheet.

// Factorisation by trial division, O(sqrt n) (n = 1e12: 1e6 steps).
// MANY numbers <= 1e7: loop p only over the primes of the Sieve.
vector<pair<ll, int>> factorize(ll n) {     // {prime, exponent}
    vector<pair<ll, int>> f;
    for (ll p = 2; p * p <= n; p++) {
        if (n % p != 0) continue;
        int e = 0;
        while (n % p == 0) { n /= p; e++; }
        f.push_back({p, e});
    }
    if (n > 1) f.push_back({n, 1});
    return f;
}
