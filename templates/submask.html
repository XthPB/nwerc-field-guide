Enumerate submasks

The loop visits every nonempty submask. Add the empty option separately if it is legal. Enumerating submasks for every mask costs three to the power n across all masks.

From the ICPC Code Templates cheat sheet.

// USE: subsets of n <= 20 items. Iterating submasks of every mask
//   costs O(3^n) total (n <= 15..16).
// all non-empty submasks of mask:
for (int sub = mask; sub > 0; sub = (sub - 1) & mask) { /* use sub */ }
