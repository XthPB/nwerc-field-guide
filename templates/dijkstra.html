Dijkstra on an expanded graph

First define what constitutes a vertex of the state graph. Construct an edge for each legal transition. All weights used by Dijkstra must be nonnegative.

From the ICPC Code Templates cheat sheet.

// Dijkstra: shortest paths from src. NEEDS: weights >= 0; directed
//   (undirected: add both directions); adj[u] = list of {v, w}.
// TIME: O((V + E) log V). Unreachable: dist = INF (template).
vector<ll> dijkstra(int src,
                    const vector<vector<pair<int, ll>>> &adj) {
    vector<ll> dist(adj.size(), INF);
    // min-heap of {dist, node}
    priority_queue<pair<ll, int>, vector<pair<ll, int>>,
                   greater<pair<ll, int>>> pq;
    dist[src] = 0;
    pq.push({0, src});
    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();
        if (d > dist[u]) continue;     // outdated entry
        for (auto [v, w] : adj[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}
// path: parent[v] = u when relaxing. Many sources: all dist 0.
// extra state (direction, fuel, ...): id = vertex * STATES + state
// no U-turn (never u->v->u): state = arc, but O(n + m): keep only the
//   first 2 arrivals at v with DIFFERENT preds p1, p2. p1's relaxes
//   every edge but v->p1, p2's only v->p1. Ignore later arrivals.
