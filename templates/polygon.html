Signed polygon area

Keep doubled area for integer coordinates until final presentation.

From the ICPC Code Templates section “Geometry: Polygon Area”. Use the code with the types and conventions shown in the excerpt.

Include these supporting sections first · Exact integer geometry

// Polygon area (shoelace). NEEDS: vertices in order around the
//   polygon (clockwise or counter-clockwise), simple polygon.
// TIME: O(n). Integer points: twice the area = |sum cross(p[i],
//   p[i+1])| is an exact ll (use it for Pick's theorem).
long double polygonArea(long double Xc[], long double Yc[], ll n)
{
    long double area = 0.0;
    ll j = n - 1;
    for (ll i = 0; i < n; i++)
    {
        area += (Xc[j] + Xc[i]) * (Yc[j] - Yc[i]);
        j = i;
    }
    return abs(area / 2.0);
}
