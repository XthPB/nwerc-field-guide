Kruskal’s minimum spanning tree

For classifying edges of equal weight, postpone unions until the whole weight group has been examined.

// Kruskal MST. NEEDS: the dsu class above, UNDIRECTED edges
//   {w, u, v}. TIME: O(E log E). Max spanning tree: sort descending.
// Minimax path (smallest possible largest edge) lies on the MST.
ll kruskal(int n, vector<array<ll, 3>> edges) {
    sort(edges.begin(), edges.end());
    dsu d(n);
    ll total = 0;
    int used = 0;
    for (auto [w, u, v] : edges) {
        if (d.findpar(u) == d.findpar(v)) continue;
        d.join(u, v);
        total += w;
        used++;
    }
    return used == n - 1 ? total : -1;   // -1: not connected
}
