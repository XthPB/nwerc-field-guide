Lucas’s theorem

Lucas factors binomial coefficients by digits in a prime base.

From the ICPC Code Templates section “Lucas (nCr mod a small prime, huge n)”. Use the code with the types and conventions shown in the excerpt.

Include these supporting sections first · Modular arithmetic

// Lucas: C(n, k) mod a SMALL prime p (p <= ~1e6), n and k up to
//   1e18: multiply C(n_i, k_i) over the base-p digits of n and k.
// NEEDS: power(). TIME: O(p) per call (build f once for many calls).
ll lucas(ll n, ll k, ll p) {
    if (k < 0 || k > n) return 0;
    vector<ll> f(p, 1);                // factorials mod p
    for (int i = 1; i < p; i++) f[i] = f[i - 1] * i % p;
    ll res = 1;
    while (n > 0 || k > 0) {
        ll a = n % p, b = k % p;
        if (b > a) return 0;
        res = res * f[a] % p * power(f[b] * f[a - b] % p, p - 2, p) % p;
        n /= p;
        k /= p;
    }
    return res;
}
