Randomization and DP

You want a path through k different graph vertices. Temporarily color every vertex at random, then look for a path whose colors are all different. If a real path receives a repeated color, what does that particular trial tell you?

Start this topic in reading order → · See the whole reading path

  • Replace a random elimination order with random prioritiesTake a rooted tree and a uniformly random order of all its vertices. When a vertex’s turn arrives, if it is still present, remove it and all its remaining descendants. Find the expected number of vertices that get their own removal turn before an ancestor removes them.
  • Use completion counts to sample a valid answer uniformlyThere are three valid words, 001, 010 and 100. Generate one so each complete word has probability 1/3. You must write the word left to right. The first decision has two possible bits, but they do not lead to the same number of completed words.
  • Fix random decisions one at a time while preserving an expectationYou’re given an undirected graph. Put every vertex on one of two sides and output an assignment for which at least half the edges cross from one side to the other. The challenge is to construct a qualifying assignment even if you start from a random-choice argument.
  • Randomly colour vertices, then run an exact subset DPIn a large graph, decide whether there is a path visiting k distinct vertices. Vertices cannot be reused, and k is small compared with the total vertex count. You may use randomness to search, but any path you report must satisfy the original distinctness requirement.
  • Evaluate a counting polynomial when only identity mattersTwo constructions count combinatorial objects by size and encode their counts as polynomial coefficients. You want to know whether the two count sequences differ. The polynomials are too large to expand in full, so you are allowed a randomized equality test with a stated error bound.

A repeated colour blocks a real path

The original three-vertex path exists. The mask after the first two vertices contains red and blue, so a red endpoint cannot extend it.

A fresh colouring exposes it

The same graph now has a path whose mask grows {R} → {R,B} → {R,B,G}. The found path is a certificate.

Count the chances for this witness

There are 3³ = 27 assignments of three colours to these vertices. Exactly 3! = 6 are colourful. Repeating independent trials multiplies miss probabilities.

Test your recognition
A colourful path is found in the third trial. Does ignoring two failed trials change the validity of this path?

Every successful witness can be checked deterministically. The error is one-sided and concerns failing to find any witness when one exists.

Completion counts modulo 7 are 1 and 1. Can you use equal probabilities to sample uniform complete objects?

The true counts might be 1 and 8. Use exact counts, an exact sampler or a suitable provable alternative.
