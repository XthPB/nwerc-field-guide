Range queries inside DP

Begin with sums and moving minima. Then return an index, exclude one colour, or update a whole range of old choices. End with time and extra dimensions.

Start this topic in reading order → · See the whole reading path

  • Query an interval of previous valuesCount routes to square 4 when each jump may advance by 1, 2 or 3. What if there are thousands of allowed lengths in a consecutive range?
  • Count previous prefixes with the missing sumHow many nonempty stretches of the digits 1, 2, 0, 1 have a digit sum equal to their length? Trying every pair of endpoints would take quadratic time.
  • A moving predecessor window with a monotone dequeKeep the best score among the last two positions as you advance. What happens when yesterday's best leaves the window?
  • Search by one coordinate and return the best of anotherAmong pairs with first coordinate from 2 through 6, return the ID with smallest second coordinate. Which coordinate should the tree index?
  • Answer “best predecessor of a different colour” with two recordsFor every new colour c, a transition asks for the cheapest previous state whose colour differs from c. Must you scan all colours for every query?
  • Use higher barriers to bound possible jumpsA glider may leave a mountain for a shorter mountain if every intervening mountain is also lower than its starting point. Find the longest route.
  • Accumulate range rewards between the few times a state can changeYou gain skill points occasionally but face many checks between gains. How can you score all allocations without touching every state per check?
  • A new endpoint changes many split candidates by the same amountSplit a string into segments and earn the number of different letters in each segment. How do candidate cuts change when you append a letter?
  • Equal segment extrema form consecutive blocks of cutsFor every possible final cut, the new segment costs its maximum. How can appending one number update many cuts together?
  • Versions or time intervals preserve the correct DP layerA sequence branches into two versions. Updating one branch must leave the old prefix available to its sibling. How can both see the correct scores?
  • A third coordinate and earlier-to-later transitionsFind the longest chain when three different coordinates must all increase. How do you enforce all three without a cubic table?

Test your recognition
A sorted sweep implements strict x and strict y using a prefix max on y. Two equal-x records unexpectedly chain. How do you repair it?

Query all points of the same x against the previous groups, then insert their results. Use a y prefix ending one rank below the queried point.

A coin can appear and disappear. Can you undo a max-knapsack update by simply iterating upward and subtracting the item’s profit?

The displaced second-best states are gone. Use offline lifetimes plus a rollback/copying traversal. Counting with positive-weight polynomial factors is a special invertible case.
