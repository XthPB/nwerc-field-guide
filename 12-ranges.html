Range queries inside DP

Each record has an eligibility value a and a score b. With records (1,7), (3,2), (3,5) and (8,1), find the index with the lowest b among records satisfying 2 ≤ a ≤ 6. The lowest b in the whole list belongs to an ineligible record.

Start this topic in reading order → · See the whole reading path

  • Query an interval of previous valuesYou start on square 0 of a number line and want to land exactly on square 4. Each jump moves forward by 1, 2 or 3 squares. Count the different sequences of jumps. The same question can give a much larger destination and a whole interval of allowed lengths.
  • Count previous prefixes with the missing sumYou’re given a string of digits. Count the nonempty contiguous stretches whose digits add up to the number of positions in the stretch. In 1201, the stretch 20 qualifies because its sum and length are both 2. Count stretches by their positions.
  • A moving predecessor window with a monotone dequeWhile processing a sequence, each new position can extend only a recent predecessor. You need the largest score in the current window. With scores 5, 2, 4 and a window of width two, yesterday’s best value eventually stops being eligible. Return the best score for each window.
  • Search by one coordinate and return the best of anotherYou have records with an ID and two values (a,b). A query specifies an inclusive interval of a values, such as 2 through 6. Among just those records, return the ID with the smallest b. The coordinate that determines eligibility differs from the one you minimize.
  • Answer “best predecessor of a different colour” with two recordsYou have a best known cost for each color from the previous round. In the next round you must choose color c and may continue only from a different previous color. Find the cheapest eligible previous cost for every possible c, including when several colors tie.
  • Use higher barriers to bound possible jumpsMountains stand in a line. A glider may fly from one to a strictly shorter mountain if every mountain between them is lower than the starting mountain. Choose the start and later landings to visit as many mountains as possible. A tall intervening mountain can block an otherwise downhill flight.
  • Accumulate range rewards between the few times a state can changeYou occasionally receive a point to assign to one of two skills. Between awards, a series of checks tests whether the relevant skill reaches a specified threshold. Earlier assignments remain fixed. Choose the assignments that pass the most checks over the whole sequence.
  • A new endpoint changes many split candidates by the same amountSplit a sequence of letters into a prescribed number of nonempty contiguous pieces. Each piece earns its number of distinct letters, so repeated copies of a letter count once inside that piece. Maximize the sum of piece scores. The last cut determines which pieces gain from a new letter.
  • Equal segment extrema form consecutive blocks of cutsSplit an array into contiguous pieces. A piece’s cost is its largest entry. In a partitioning step you know the best cost up to each possible last cut. Find the least total cost as you move the final endpoint right and the last piece’s maximum changes.
  • Versions or time intervals preserve the correct DP layerA sequence has several versions. Two different extensions may both start from the same saved prefix, and each needs to query the best predecessor in that prefix. Compute the best scores as each version grows without letting a change in one branch affect its sibling.
  • A third coordinate and earlier-to-later transitionsYou’re given points with three coordinates. Make the longest chain in which all three coordinates increase strictly from one point to the next. Equal values in even one coordinate prevent that transition, regardless of the other two.

Test your recognition
A sorted sweep implements strict x and strict y using a prefix max on y. Two equal-x records unexpectedly chain. How do you repair it?

Query all points of the same x against the previous groups, then insert their results. Use a y prefix ending one rank below the queried point.

A coin can appear and disappear. Can you undo a max-knapsack update by simply iterating upward and subtracting the item’s profit?

The displaced second-best states are gone. Use offline lifetimes plus a rollback/copying traversal. Counting with positive-weight polynomial factors is a special invertible case.
