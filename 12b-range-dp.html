Advanced range queries inside DP

You receive substring queries on text that can change. For each queried piece, what is the fewest letters you can delete so that no two surviving a’s are adjacent? The letters before and after a cut affect whether two partial answers fit together.

Start this topic in reading order → · See the whole reading path

  • A forbidden gap can turn one predecessor query into twoYou’re given heights in a fixed order. Choose a subsequence in which consecutive chosen heights differ by at least 4 in absolute value. Find the longest such subsequence. A previous height can qualify by being either much lower or much higher than the new one.
  • Store a witness or the number of optimizers inside each range nodeMany earlier positions could lead to the same destination. Each has a best score, a number of ways to reach that score, and an index you can use to reconstruct a route. Among the eligible positions, return the best score, how many ways attain it, and one actual route.
  • Independent rectangle bounds require a second range dimensionEarlier points have (x,y) coordinates and scores. For a new point you may extend only a predecessor lying inside a given rectangle. With candidates (1,1,9), (2,3,5), (3,2,7), find the largest score in x=2..3 and y=2..3 simultaneously.
  • Find the k-th value between two array positionsThe array is 5, 1, 5, 2. A query gives a left endpoint, a right endpoint and a rank k. Return the kth value in sorted order within those positions, counting duplicate occurrences separately. Here the query asks for the second-smallest value at positions 2 through 4.
  • A range update can act linearly on each stored DP valueEach array position stores an integer index a and represents the Fibonacci number F(a). An update increases every index in a range by a given amount, such as 2. A query asks for the sum of the represented Fibonacci numbers over a range after the updates.
  • Represent a substring by its whole DP transitionA string receives single-character changes. After each change, find the minimum edit cost that makes the resulting string obey a fixed rule with only a few states, such as avoiding a forbidden adjacent pair. An edit at one position can affect legality across a segment boundary.
  • Replace a fan of interval transitions with segment-tree nodesA directed travel offer may let you leave one station and reach any station in a numbered interval for one fixed fare, such as 4. Other offers can have a range of starting stations. Find least-cost trips from a given source when listing every individual connection would be too expensive.

Test your recognition
A range-query structure returns (best score, count). Why can two overlapping sparse-table blocks give the wrong count?

A shared maximizing predecessor contributes twice. Query disjoint blocks or use an idempotent operation when overlap is unavoidable.

Why keep separate upward and downward segment trees for an interval-to-vertex graph?

A bidirectional zero-cost tree connects unrelated leaves for free. Separate directed trees make every permitted move pass through the intended weighted offer.
