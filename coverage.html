NWERC and other ICPC contests

The regional index explains 46 selections from NWERC, BAPC, SWERC, GCPC, North Central North America, Asia Yokohama and the World Finals. The NWERC survey spans 1995–2025. The 2022 and 2023 NWERC problem details stay private for practice.

See all regional problem-to-template mappings
  • NWERC 2004 · Minimax Triangulation

    Fix a boundary chord and the third vertex of its triangle. Combine the two remaining subpolygons by their worst triangle, minimizing over valid pivots. A nonconvex polygon also needs a validity test.

    Split on the final merge, pivot, or triangle · Interval DP in increasing length · Exact integer geometry
  • World Finals 2025 · Buggy Rover

    Only 24 direction priorities are possible. The authors’ alternative DP stores a priority and the fewest necessary changes for the observed prefix, competing with a direct greedy filter.

    A fixed number of recent decisions · Two-state DP with rolling layers
  • NWERC 2024 · Limited Library

    A book that fits a shelf also fits every taller shelf. For a proposed number of reduced-capacity shelves, reduce the shortest ones and match books greedily in sorted order. Binary search finds the largest feasible number. The separate range-query lesson shows what changes when eligibility is an arbitrary interval.

    Search by one coordinate and return the best of another · Binary search on the answer · Look up a boundary in sorted values
  • NWERC 2024 · Dutch Democracy

    Requiring every selected party to be necessary collapses to removing the smallest. Count exact prefix sums in the narrow window that crosses a strict majority when this party enters.

    Which voting groups need every member? · Count minimal winning coalitions · 0/1 knapsack
  • NWERC 2025 · Bisecting Bargain

    A bitset tests one proposed collection of notes. Enumerating all collections remains too slow. Exchange equivalent denominations first to reduce the outer search.

    Can the cashier make an unsplittable payout? · Find a payout that cannot be split · Bitset subset sum
  • BAPC 2023 · Jungle Job

    Count connected subsets once by their highest vertex and by size. Multiplying child options performs the size split automatically.

    Merge a child’s size or budget distribution · Rooted tree DP and rerooting · 0/1 knapsack
  • SWERC 2021–22 · Gastronomic Event

    At a candidate centroid, sizes of hanging subtrees become weights. The orientation objective prefers two near-equal totals. A direct bitset still repeats too many shifts until multiplicities are compressed.

    Repeated weights and the square-root bound · Centroid decomposition · Bitset subset sum
  • GCPC 2024 · Jigsaw Present

    Encode two disjoint chosen sets using signs −1,0,+1 and join signed vector sums across a split. A pigeonhole bound is also needed to limit how many input vectors the exponential search uses.

    When the two halves interact through conflicts · Meet in the middle for sums

AtCoder Educational DP Contest

26 of 26 tasks have a lesson, a template and an adaptation below. Official task list

  • A · Frog 1

    To land at stone i, compare the two legal preceding stones and add the absolute height difference. Stone zero is the only initial state.

    A fixed number of recent decisions · Two-state DP with rolling layers
  • B · Frog 2

    Take the minimum over the previous K stones, with a different absolute height charge for each predecessor. The small K allows a direct scan. A plain moving minimum of old scores would omit the height-dependent charge.

    A moving predecessor window with a monotone deque · Two-state DP with rolling layers
  • C · Vacation

    The activity of the preceding day is the only history that forbids an option today. Keep a separate best reward for each last activity.

    What must a state remember? · Two-state DP with rolling layers
  • D · Knapsack 1

    Index capacity and store maximum value. Scan capacities down for each one-use item so the new row cannot reuse it.

    Which sums can you make using each item once? · 0/1 knapsack
  • E · Knapsack 2

    The huge capacity makes the ordinary table too large. For each exact value store the lightest possible selection and read the largest affordable value.

    When the capacity is huge, index by profit · Knapsack by profit · 0/1 knapsack
  • F · LCS

    Store the best common length for each pair of prefixes. Follow a diagonal for a matched pair or a preserving neighbour to recover one common subsequence.

    Two prefixes and the last alignment column · Longest common subsequence and interval order · Edit distance
  • G · Longest Path

    Order vertices topologically and extend the longest length on every outgoing edge. Initialize all possible starting vertices at length zero.

    Find a quantity that always moves forward · Topological order and DAG DP
  • H · Grid 1

    Sum arrivals from up and left on open cells. A wall blocks both arrivals, and the open start contributes one empty prefix.

    Separate a monotone walk from a general shortest path · Two-state DP with rolling layers
  • I · Coins

    After each coin keep the distribution over head counts. Sum final probability mass on counts strictly larger than half of n.

    Follow probability through one trial at a time · First-step expectation and probability · Two-state DP with rolling layers
  • J · Sushi

    Count plates with one, two and three pieces. An empty-plate draw costs a step and returns to the same state. Isolate that self-loop algebraically before recursing.

    First-step analysis and self-loops · First-step expectation and probability · Two-state DP with rolling layers
  • K · Stones

    A remaining pile is winning if at least one allowed removal leaves a losing pile. A Boolean win/loss table suffices because the input has one pile.

    Winning positions, minimax, and sums of independent games · Grundy values on a finite game
  • L · Deque

    Keep the best lead of the player whose turn it is on an interval. Taking an end subtracts the opponent's lead on the remaining interval.

    Two ends, score difference, and forced turns · Interval DP in increasing length
  • M · Candies

    One child is one bounded type. Use a prefix window on the previous child's row to count indistinguishable candy allocations.

    Count bounded allocations with one sliding sum · Prefix sums and difference arrays · 0/1 knapsack
  • N · Slimes

    Try the final adjacent merge. Prefix sums price the merged interval. Nonnegative weights also permit the optimized Knuth implementation.

    Split on the final merge, pivot, or triangle · Interval DP in increasing length · Knuth-optimized adjacent merging
  • O · Matching

    A mask records used partners. Its bit count determines the next person. Add the counts of ways to assign one available compatible partner.

    An exact set can determine the step number · Enumerate submasks · Two-state DP with rolling layers
  • P · Independent Set

    At a black vertex every child must be white. At a white vertex a child may have either colour. Children combine independently once the parent colour is fixed.

    A tree edge is a one-vertex interface · Rooted tree DP and rerooting
  • Q · Flowers

    Sweep the input order. Query maximum beauty below the current height and publish the extended score at its height.

    Weights, counts, and two strict coordinates · Bottom-up segment tree · Coordinate compression
  • R · Walk

    Power the adjacency matrix to K. Ordinary modular matrix multiplication counts walks of exactly K edges and summing entries allows any two endpoints.

    Exponentiate a repeated stationary transition · Matrix multiplication and power
  • S · Digit Sum

    Keep the bound as a string and use a remainder and tight flag. Remove the padded representation of zero from the final remainder-zero count.

    Handle a bound with ten thousand decimal digits · Digit sums for a decimal-string bound
  • T · Permutation

    Insert the newest element by its relative rank. Each inequality admits a prefix or suffix of old ranks, so cumulative sums compute a layer.

    Count by rank instead of remembering actual labels · Prefix sums and difference arrays · Two-state DP with rolling layers
  • U · Grouping

    Precompute pair contributions for each group mask. Select a valid group containing one anchored person, then solve the complement.

    Partition a set into compatible groups · Enumerate submasks
  • V · Subtree

    Count connected choices on each side of a directed edge. Use leave-one-child-out products for the reverse pass, which is valid for composite moduli.

    Send each child the contribution of all its siblings · Connected sets by rerooting with prefix and suffix products · Rooted tree DP and rerooting
  • W · Intervals

    Sweep positions while storing candidates by the last selected position. An interval ending here contributes an additive reward to a consecutive range of candidate states.

    A new endpoint changes many split candidates by the same amount · Lazy range updates · Bottom-up segment tree
  • X · Tower

    Sort blocks by increasing weight plus strength. Add a new block underneath only when its strength covers all selected weight above it.

    Sort stackable blocks before doing knapsack · 0/1 knapsack
  • Y · Grid 2

    Count unrestricted monotone paths between special cells. Subtract paths by their first blocked cell, then evaluate the target.

    Sparse obstacles and a first-bad-event subtraction · Binomial coefficients and modular arithmetic
  • Z · Frog 3

    Expand the squared height difference. Each completed state supplies a line, queried at the height of the next stone before its new line is inserted.

    Turn each predecessor into a line · Li Chao tree

  • Dice Combinations

    A route to sum s ends with exactly one die value from 1 to 6. Add the previous six counts, seeded by one way to make zero.

    Query an interval of previous values · Prefix sums and difference arrays · Two-state DP with rolling layers
  • Minimizing Coins

    Track the fewest coins for each exact sum. Every denomination can be used repeatedly. Skip unreachable predecessors before adding one.

    Reuse, bounded stock, or one choice per group · 0/1 knapsack
  • Coin Combinations I

    Order matters, so choose the last coin of a sequence. Iterate total sum outside and possible last coin inside.

    Identical weights, distinguishable items, and multiplicity · 0/1 knapsack
  • Coin Combinations II

    Only the multiplicity of each denomination matters. Place denominations outside the ascending sum loop to count each multiset once.

    Identical weights, distinguishable items, and multiplicity · 0/1 knapsack
  • Removing Digits

    A move subtracts one positive decimal digit currently appearing in x. The new number is smaller, so evaluate states in increasing numerical order.

    Find a quantity that always moves forward · Two-state DP with rolling layers
  • Grid Paths I

    Blocked squares get zero and an open square receives the sum of its northern and western neighbours. Check a blocked start before seeding it.

    Separate a monotone walk from a general shortest path · Two-state DP with rolling layers
  • Book Shop

    One book is one item, its price is weight and its pages are value. Descending capacities ensure that a book is bought at most once.

    Which sums can you make using each item once? · 0/1 knapsack
  • Array Description

    What must a state remember? · Two-state DP with rolling layers
  • Counting Towers

    Count towers by the seam at their top · Matrix multiplication and power · Two-state DP with rolling layers
  • Edit Distance

  • Longest Common Subsequence

    Use the prefix-pair recurrence on the integer arrays, then trace a path backward to print a witness as required by this version.

    Two prefixes and the last alignment column · Longest common subsequence and interval order · Edit distance
  • Rectangle Cutting

    The rectangle has no internal marks, so dimensions alone determine the answer and location can be dropped. Try each horizontal or vertical cut. A square needs zero cuts.

    Four boundaries identify an arbitrary subrectangle · Interval DP in increasing length
  • Minimal Grid Path

    Sweep diagonals. Append the smallest reachable next letter and retain every position that spells the optimal prefix.

    Keep an entire diagonal of equally good prefixes · Two-state DP with rolling layers
  • Money Sums

    Shift the reachability row by each one-use coin and OR with the old row. Scan its positive set bits to list all attainable sums.

    Update many reachable sums with one shift · Bitset subset sum
  • Removal Game

    An optimal interval lead gives the first player's actual score by adding total and lead and dividing by two. Negative values remain valid.

    Two ends, score difference, and forced turns · Interval DP in increasing length
  • Two Sets II

    A subset of half the overall sum determines both groups. Force n into a designated group, or count subsets of the remaining numbers that form the other group, to break the exchange symmetry.

    Charge each object to a unique last choice · 0/1 knapsack
  • Mountain Range

    Nearest greater-or-equal barriers bound the landing interval. A range maximum over already processed lower mountains supplies the best remaining route.

    Use higher barriers to bound possible jumps · Monotone stack and sliding deque · Bottom-up segment tree
  • Increasing Subsequence

    Store the smallest ending value for each attainable length. Locate the first tail at least x to preserve the strict comparison.

    The cheapest tail for each length · Strict longest increasing subsequence
  • Projects

    Sort projects by end time. Here days are inclusive, so the previous project's end must be strictly less than the next start. Binary search that boundary before adding the reward.

    Sort by finish and jump to the last compatible predecessor · Look up a boundary in sorted values · Two-state DP with rolling layers
  • Elevator Rides

    For a used subset keep the fewest rides and then the lightest last ride. Try a final passenger to update the lexicographic pair.

    A lexicographic pair can replace enumeration of groups · Enumerate submasks
  • Counting Tilings

    Describe cells already occupied from the previous column with a mask. Enumerate legal ways to fill the column and finish with an empty protrusion mask.

    A narrow frontier remembers occupied cells · Enumerate submasks
  • Counting Numbers

    Keep the preceding real digit, a started flag and the bound status. A real equal adjacent digit is forbidden. The canonical number zero itself satisfies the rule.

    Make leading zeros and the actual number zero behave correctly · Digit DP on a numerical bound
  • Increasing Subsequence II

    Sum counts ending strictly below the current value, add one for the new singleton, then add the result to the compressed value's position.

    Count all increasing subsequences by their last value · Fenwick tree · Coordinate compression
