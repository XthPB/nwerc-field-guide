Games on graphs, minimax and Sprague–Grundy

“Random choice” can still mean worst case

If the output asks for an absolute guarantee, every permitted outcome must be covered, even when the story says a choice is random. Jail or Joyride therefore takes the maximum over tied escape destinations. Expected capture time would be a different problem with probability equations.

For a finite acyclic turn-based game, a state is winning if it has a move to a losing state; it is losing if every move goes to a winning state. The terminal convention depends on normal play (“no move loses”) versus misère play (“no move wins”).

Retrograde analysis handles cycles

Start from known losing terminal states. A predecessor of a losing state is winning because it can move there. A predecessor becomes losing once all of its outgoing moves are known winning. Track the number of unresolved outgoing moves and process a queue.

while(!q.empty()) {
    int v=q.front();q.pop();
    for(int u:reverse[v]) if(state[u]==UNKNOWN) {
        if(state[v]==LOSE) state[u]=WIN,q.push(u);
        else if(--remaining[u]==0) state[u]=LOSE,q.push(u);
    }
}
// Unresolved states may be draws under the specified infinite-play rules.

Time is O(V+E). A plain recursive minimax with memoisation can loop forever on cyclic games; a depth cutoff changes the game instead of solving it.

Minimax with costs

If one player chooses an action and an adversary chooses a response, the recurrence has a min outside and a max inside. Nonnegative costs and cycles require care: the adversary may force infinite cost. Structural reductions can remove one player's choices, as the shortest-approach proof does in Jail or Joyride.

Always specify whose turn a state represents. If a position looks identical but the player to move differs, those are different states.

Nim and the XOR invariant

In normal-play Nim, a move reduces one heap. The position is losing exactly when the XOR of heap sizes is zero. From zero XOR, changing one heap makes it nonzero. From nonzero XOR, choose the highest set bit and reduce a heap containing it to make the XOR zero. This gives both a proof and a winning move.

Sprague–Grundy values

For a finite impartial normal-play game, define g(state)=mex{g(next)}. Independent games combine by XOR of their Grundy values. The value is more informative than win/lose: two winning games can sum to a losing game.

int mex(const vector<int>& values) {
    vector<char> seen(values.size()+1,false);
    for(int x:values) if(x<(int)seen.size()) seen[x]=true;
    int g=0;while(g<(int)seen.size() && seen[g])++g;
    return g;
}

The theorem needs independent components, impartial moves and normal play. Do not apply it unchanged to partisan games, shared resources, or arbitrary cyclic games.

Alpha–beta and state-space search

For small adversarial search problems, minimax with alpha–beta pruning can reduce visited nodes, especially with good move ordering. Worst-case complexity remains exponential. Transposition tables reuse repeated states; symmetry reduction can shrink the state graph. These techniques are useful when constraints permit search, not a substitute for proving polynomial structure when n is large.

Checkpoint: why does XOR of two equal Nim heaps equal a losing position?

The equal values cancel. Any move changes one heap, and the opponent can mirror it in the other heap, restoring equality until the first player has no move.
