Graphs, connectivity and flow · Foundations

Matching, max flow and min-cost flow

A local choice can block a global assignment

Three people want tasks: A accepts {1,2}, B accepts {1}, C accepts {2,3}. Assigning A→1 greedily blocks B. An augmenting path repairs the mistake: move A→2 and give B→1, possibly moving C onward if needed.

A matching pairs vertices without reuse. In bipartite graphs, a matching is maximum exactly when no augmenting path exists. Flipping matched/unmatched edges along such a path increases its size by one.

Kuhn to Hopcroft–Karp

Kuhn's DFS tries to find an augmenting path from each left vertex, rerouting earlier assignments. A simple version costs O(VE).

bool augment(int u) {
    if(seen[u]) return false; seen[u]=true;
    for(int v:g[u])
        if(matchR[v]==-1 || augment(matchR[v])) {
            matchR[v]=u; return true;
        }
    return false;
}
// Reset seen before each new left-side augmentation attempt.

Hopcroft–Karp finds many shortest augmenting paths per phase using BFS layers and DFS. Its O(E√V) bound is useful for large sparse bipartite graphs. Do not use these bipartite algorithms on arbitrary graphs; general matching needs techniques such as Edmonds' blossom algorithm.

Max flow as a modelling language

Create source→left edges of capacity 1, left→right edges for allowed matches, and right→sink edges of capacity 1. Integral max flow is a matching. Larger capacities represent multiple identical resources without expanding them into many vertices.

Disgruntled Diner benefits from grouping identical ticket types. A small symbol/type flow network can replace a large graph of individual tickets. The compression must preserve every compatibility relation and each multiplicity.

Residual edges explain rerouting

For every edge of capacity c carrying f, the residual graph has forward capacity c−f and reverse capacity f. A reverse residual edge means “undo some earlier choice,” not a physical reverse road. Forgetting reverse edges destroys the ability to repair assignments.

Dinic repeatedly builds a BFS level graph and sends a blocking flow along increasing levels. The standard general bound is O(V²E), with stronger bounds for special unit-capacity networks. In contest code, store reverse-edge indices and use a current-edge pointer to avoid rescanning exhausted edges.

Min cut, vertex cover and lower bounds

After max flow, vertices reachable from the source in the residual graph define a minimum cut. This gives certificates and reductions: split a vertex into in/out with a capacity edge to limit vertex usage; model closure problems with large-capacity implication edges. “Infinity” must exceed every finite cut that could be optimal, without overflowing sums.

In bipartite graphs, Kőnig's theorem equates maximum matching and minimum vertex-cover size. Alternating reachability constructs the cover, useful when the output asks for a minimum set of items hitting all conflicts.

Min-cost flow and assignment

When each allocation has a cost, add edge costs and minimise cost for a specified flow amount. Successive shortest augmenting paths with potentials allow Dijkstra on nonnegative reduced costs after appropriate initialisation. Hungarian solves dense weighted bipartite assignment in O(n³). Prefer that specialised algorithm when the model is exactly a square assignment matrix.

Checkpoint: does maximum flow alone minimise the total assignment cost?

No. It optimises only the amount sent. Among maximum flows, costs may differ. Use min-cost flow or a weighted assignment algorithm when cost is part of the objective.
