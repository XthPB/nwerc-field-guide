DAG DP, SCCs, bridges and 2-SAT

A cycle tells you what information to compress

In a strongly connected component (SCC), every vertex reaches every other. Contract each SCC into one vertex; the resulting condensation graph is always a DAG. If it had a directed cycle, its components would mutually reach each other and should have been one SCC.

Kosaraju runs DFS for finish order, then DFS on reversed edges in reverse finish order. Tarjan uses one DFS with discovery indices, low links and an active stack. Both take O(V+E). Prefer an implementation you can explain and test; Tarjan's low-link update rules are easy to misremember.

Why sink components appear repeatedly

A sink SCC has no outgoing edge in the condensation graph. Every finite DAG vertex reaches a sink. In Locking Doors, one chosen exit in every sink SCC is necessary and sufficient. In Failing Factory, dependency closure leads to choosing among sink SCCs and evaluating their probability products.

Do not memorise “SCC problem → count sources.” Determine whether the arrows mean “can reach,” “requires,” or “must happen before.” Reversing the semantic direction changes sources into sinks.

DP after contraction

For a DAG, process vertices in topological order for forward transitions, or reverse order when a state depends on successors.

for(int u:reverseTopo) {
    best[u]=base[u];
    for(int v:dag[u]) best[u]=max(best[u],weight(u,v)+best[v]);
}

Contracting an SCC does not automatically make arbitrary optimisation easy. Longest simple path inside an SCC remains hard in general. You need a reason the component can be represented by a single weight, reachability flag, or other sufficient summary.

Bridges and articulation points

In undirected DFS, low[v] is the earliest discovery time reachable from v's subtree using tree edges and at most one back edge. A tree edge u→v is a bridge when low[v]>tin[u]. Removing it splits the graph. An articulation point separates child subtrees when low[v]≥tin[u]; the DFS root has its own child-count rule.

low[u]=tin[u]=timer++;
for(auto [v,id]:g[u]) {
    if(id==parentEdge) continue;
    if(tin[v]!=-1) low[u]=min(low[u],tin[v]);
    else {
        dfs(v,id); low[u]=min(low[u],low[v]);
        if(low[v]>tin[u]) bridges.push_back(id);
    }
}

Use edge IDs so a parallel edge back to the parent is not accidentally ignored.

2-SAT turns choices into implications

A clause (a OR b) means not a → b and not b → a. A formula is satisfiable exactly when no variable and its negation belong to the same SCC. Recovering an assignment depends on your component numbering convention; verify it on unit clauses rather than copying an unexplained comparison.

Pairwise conflicts can make the implication graph quadratic. House Numbering admits a stronger unicyclic structural solution, demonstrating why a generic reduction may be correct yet unnecessarily large.

Checkpoint: why is a reachable directed cycle fatal in Jail or Joyride?

The desired guarantee covers every tied escape choice. A cycle lets the teenagers keep choosing an escape along it indefinitely. This is an adversarial certainty criterion, not an expected-time calculation under a benign random tie-break.
