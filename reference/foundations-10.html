BFS, DFS and the graph you actually need

A road map gives intersections and legal roads, and you need a shortest route. Some turns are legal only if you arrived from a particular direction. Two visits to the same intersection may therefore have different next moves. Decide what one vertex in your search should represent.

Vertices need not be places

A road map suggests one vertex per intersection. But if legality depends on your incoming direction, remaining turn budget and indicator state, an intersection alone is not enough. The correct vertex is (intersection, incoming direction, budget used, indicator). Buggy Blinkers makes this state-expansion lesson concrete.

Two histories can merge only when they have the same possible futures with the same costs. Ask this before running BFS.

BFS explores distance layers

With every edge costing one, the queue processes distance 0, then 1, then 2. The first time a vertex is discovered is its shortest distance. Mark it when enqueuing, not when removing it, to avoid many duplicate queue entries.

vector<int> d(n,-1),parent(n,-1);
queue<int> q; d[source]=0; q.push(source);
while(!q.empty()) {
    int u=q.front(); q.pop();
    for(int v:g[u]) if(d[v]==-1) {
        d[v]=d[u]+1; parent[v]=u; q.push(v);
    }
}

Time and memory are O(V+E) for an adjacency list. Multi-source BFS puts every source in the queue at distance zero and computes distance to the nearest source.

Reverse the question

In Kiosk Construction, a guest's next move is fixed once the destination is fixed. For one target, every other vertex has one outgoing edge. Instead of simulating from every start, reverse the edges and BFS from the target. You discover every successful start and its forced walk length at once.

This “all sources to one target” reversal is broadly useful. In directed graphs, reverse edges before using a target as a source; traversing the original edges answers a different question.

DFS exposes structure

DFS records entry and exit events, ancestry, cycles and subtrees. In a directed graph, an edge to a currently active (grey) vertex reveals a cycle; an edge to a finished vertex does not. In an undirected graph, skip the parent edge ID, especially if parallel edges are allowed.

Recursive DFS can overflow on a chain of 200000 vertices. An explicit stack of frames stores the current vertex and next adjacency index, preserving real enter/exit order. A stack of vertices alone is enough for reachability but may not reproduce postorder.

Functional graphs

When every vertex has one successor, each component consists of a directed cycle with trees feeding into it. Useful tools include indegree peeling, DFS colours, Floyd’s tortoise-and-hare for one trajectory, and binary lifting for k-th successors. Choose based on whether you need all vertices, one start, or many long-jump queries.

A subtle shortest-walk example

Homesick forbids immediate reversal. State (previous,current) is the obvious exact model. The archive's more efficient method compresses how many incoming labels must be retained. The lesson is to begin with the correct expanded state, then prove compression; simply running vertex-only BFS discards information too early.

Checkpoint: is the BFS tree the same as the DFS tree?

No. Both span reachable vertices, but BFS preserves shortest unweighted distance from its root. DFS preserves ancestry and finishing structure. A proof that depends on one property cannot substitute the other traversal casually.
