Linear algebra, XOR bases and recurrences

Elimination is systematic substitution

To solve Ax=b, choose a nonzero pivot, normalise its row if appropriate, and eliminate that variable from other rows. A row of all-zero coefficients with nonzero right side means inconsistency; missing pivots mean free variables. Gaussian elimination costs O(n³) for a dense n×n system.

Over real numbers, partial pivoting improves numerical stability. Over a prime field, pivot division uses a modular inverse and has no rounding error. Over a composite modulus, nonzero does not imply invertible; ordinary field elimination may fail.

XOR is addition over F₂

Represent a bit vector as a machine word. XOR adds vectors modulo 2. A basis stores one vector for each highest set bit. Insert x by eliminating its highest bit with the corresponding basis vector; if none exists, x becomes a new pivot.

array<unsigned long long,64> basis{};
void insert(unsigned long long x) {
    for(int b=63;b>=0;b--) if(x>>b&1ULL) {
        if(!basis[b]) {basis[b]=x;return;}
        x^=basis[b];
    }
}

Each insertion costs O(word bits). A vector reduces to zero exactly when it lies in the span. With rank r, the span contains 2^r distinct XOR values. If n original vectors have rank r, each attainable XOR has 2^(n−r) subset representations, because the linear map's kernel has that size.

To maximise an unsigned XOR, scan basis vectors from high bit down and replace answer by max(answer,answer^basis[b]). Counting k-th XOR values needs a canonical reduced basis and careful ordering; the insertion form alone is not enough.

Matrix exponentiation accelerates repeated transitions

For a linear recurrence such as Fibonacci, store a vector state and a transition matrix. Applying it k times is matrix exponentiation by squaring: O(d³ log k) for a dense d×d matrix. This is useful when the number of steps is enormous but the state dimension is small.

Matrix power(Matrix a,long long k) {
    Matrix result=identity(a.size());
    while(k) {
        if(k&1) result=result*a;
        a=a*a;k>>=1;
    }
    return result;
}

Matrix multiplication can use other semirings: Boolean OR/AND for reachability of exactly k edges, or min/+ for minimum cost of exactly k edges. “Exactly k” is not the same as “at most k”; add appropriate self-loops or an augmented state only after checking the intended meaning.

Algebra can remove interactions

Lopsided Lineup seems to require optimising pair synergies. Symmetry makes cross-team terms cancel in the difference, leaving independent row weights. This is not Gaussian elimination, but it is the same habit of rewriting expressions until the true degrees of freedom become visible.

Further tools

For high-order linear recurrences, polynomial reduction can improve on cubic matrix multiplication. Berlekamp–Massey finds a shortest linear recurrence over a field from a sufficiently informative sequence; using it on a handful of terms without a justified model is pattern guessing. Kirchhoff's matrix-tree theorem counts spanning trees via a Laplacian minor determinant. Both deserve separate implementation practice before use under contest pressure.

Checkpoint: can a nonzero integer always be used as a pivot modulo 8?

No. For example, 2 is nonzero but has no inverse modulo 8. Field-based elimination assumes every nonzero pivot is invertible; a prime modulus provides that property.
