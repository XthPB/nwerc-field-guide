Shortest paths: BFS to potentials

Choose by edge weights

Structure Algorithm Typical bound
Unit weights BFS O(V+E)
Weights 0 or 1 0–1 BFS O(V+E)
Nonnegative weights Dijkstra with heap O((V+E) log V)
Negative edges Bellman–Ford O(VE)
DAG, any weights Topological relaxation O(V+E)
All pairs, small dense graph Floyd–Warshall O(V³)

These conditions are part of correctness. A negative edge can improve a vertex after Dijkstra has considered it final.

Dijkstra's invariant

At each step, extract the smallest tentative distance. Any alternative path to that vertex must cross from the settled set through an edge of nonnegative weight; it cannot arrive more cheaply than the current minimum. That is why the greedy settlement works.

0–1 BFS is a specialised priority queue

For an edge of cost zero, put the improved vertex at the front of a deque; for cost one, at the back. The deque maintains only two adjacent distance layers. This is ideal when a move either follows a preferred action for free or pays one to deviate.

Floyd–Warshall and the meaning of k

d[i][j] after layer k permits only vertices 0…k as internal vertices. Therefore k must be the outer loop. The recurrence either avoids k or goes through it: min(d[i][j],d[i][k]+d[k][j]). Guard infinity and use enough integer range.

Jail or Joyride uses original shortest-path distances even when a blocked road changes escape reachability. Mixing those two graphs gives a plausible but incorrect model.

Negative cycles and potentials

Bellman–Ford relaxes all edges V−1 times; a further reachable improvement detects a reachable negative cycle. It does not imply every target has unbounded distance: the cycle must also reach the target.

A potential h reweights an edge as w'(u,v)=w(u,v)+h[u]-h[v]. Every s→t path changes by the same amount h[s]-h[t], so path order is preserved. Johnson’s all-pairs algorithm and min-cost flow use potentials to obtain nonnegative reduced costs and run Dijkstra repeatedly. Derive the sign convention once and stick to it.

Checkpoint: can a graph DP have negative edge costs safely?

Yes, if the dependency graph is acyclic and you process topologically. There is no cycle to revisit and no need for Dijkstra's nonnegativity condition.
