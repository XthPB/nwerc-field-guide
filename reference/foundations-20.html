Strings: KMP, Z, tries and hashing

Borders explain repeated matching work

A border is a proper prefix that is also a suffix. When matching a pattern and the next character fails, the matched prefix already tells you which shorter prefix might still match. KMP's prefix function follows these border links instead of restarting from zero.

vector<int> pi(s.size());
for(int i=1;i<(int)s.size();i++) {
    int j=pi[i-1];
    while(j>0 && s[i]!=s[j]) j=pi[j-1];
    if(s[i]==s[j]) ++j;
    pi[i]=j;
}

The total number of backward link moves is O(n): j increases by at most one per outer iteration and never becomes negative. KMP matches a length-m pattern in a length-n text in O(n+m).

Z-function: match every suffix against the prefix

Z[i] is the longest common prefix of the whole string and the suffix starting at i. Maintain the rightmost known matching interval [l,r). Inside it, reuse Z[i-l] up to the boundary, then extend. KMP and Z solve overlapping tasks but expose different information; choose whichever makes the desired condition clearer.

For pattern matching, build pattern + separator + text, where the separator cannot appear in the alphabet. An index with Z≥pattern length is a match.

Tries share prefixes

A trie represents strings by paths of characters or tokens. Dictionary word-break DP can walk the trie from each reachable text position and mark endpoints at terminal nodes. Directory names in Compressing Commands form a trie of path components, turning string structure into a weighted tree rerooting problem.

If the alphabet is large, a map per node saves unused child slots but has overhead. If the alphabet is small and dense, fixed arrays are faster. Account for total characters, not just number of words.

Rolling hashes make equality cheap—but probabilistic

A polynomial prefix hash permits O(1) substring fingerprints after O(n) preprocessing. Equal strings always have equal hashes; equal hashes need not imply equal strings. Two independent moduli or a random 64-bit scheme reduce risk, while explicit comparison or suffix-array methods can restore determinism.

// h[i+1] = h[i]*base + code(s[i]) (mod M)
long long hash(int l,int r) {
    return (h[r]-h[l]*power[r-l]%M+M)%M;
}

Use a wide intermediate type when multiplication can overflow. Randomising a base helps against inputs crafted for a known base, but does not make collisions impossible. Never use a single small hash as a proof of equality across millions of substrings.

Equal-length occurrences: greedy selection

In Karaoke Compression, after fixing pattern length L, choose occurrences by increasing start and skip overlaps. Equal interval lengths mean the earliest start also finishes earliest, so the exchange proof applies. The challenge is grouping equal substrings efficiently across all patterns, not merely finding one pattern quickly.

Aho–Corasick

For many patterns against one text, a trie plus failure links acts like KMP over a dictionary. Each text character advances the automaton, following failure links as needed. Report terminal patterns through output links or aggregated counts. Complexity is O(total pattern length + text length + number of reported matches), with alphabet-dependent transition implementation costs.

Checkpoint: why can “the string has a valid dictionary segmentation” be insufficient to identify its random generator with certainty?

A random-character generator may accidentally produce a string that also has a valid segmentation. Membership can be checked exactly, but recovering which generator produced a shared possible output is inherently ambiguous.
