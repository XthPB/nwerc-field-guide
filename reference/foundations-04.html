Prefix sums, sweeps and monotonic structures

Pay once for repeated questions

For a=[3,-1,4,2], prefix sums are [0,3,2,6,8]. The sum of indices [1,4) is P[4]-P[1]=5. The empty prefix is a design feature: it makes intervals starting at zero obey the same formula.

vector<long long> pref(n+1);
for(int i=0;i<n;i++) pref[i+1]=pref[i]+a[i];
auto sum=[&](int l,int r){return pref[r]-pref[l];};

In two dimensions, four prefix values answer a rectangle sum by inclusion–exclusion. For range additions followed by one final readout, invert the idea: add x at l and −x at r in a difference array, then prefix-sum once. Updates become O(1), but intermediate online queries are not supported without more structure.

A queue can be a single number

If q people remain and a new group of size a arrives before a vehicle of capacity c departs, the next queue size is max(0,q+a-c). Tracking every individual is unnecessary if the output only needs group waiting time. The remaining count is a sufficient summary. Be precise about whether arrivals happen before or after departure; that changes the recurrence.

Sweeps turn geometry into events

Sort events by one coordinate or time. Maintain exactly the objects currently active. At equal coordinates, the order of “add”, “query” and “remove” encodes whether intervals are open or closed. State the tie rule explicitly; do not let the incidental sort order decide the mathematics.

Sliding minimum: discard dominated candidates

Suppose a DP asks for the minimum of prior values in a moving window whose left boundary never decreases. Candidate j dominates earlier i when value[j]≤value[i]: j is no worse and expires no earlier. Remove i permanently.

deque<int> q;
for(int i=0;i<n;i++) {
    while(!q.empty() && q.front()<left[i]) q.pop_front();
    // q.front() now gives the minimum over retained earlier candidates.
    while(!q.empty() && value[q.back()]>=value[i]) q.pop_back();
    q.push_back(i);
}

The order of query and insertion depends on whether i may use itself. Every index enters once and leaves at most once from each end, so the total is O(n), despite the nested while loops. Museum Visit is an excellent application after you derive its DP window.

Monotonic stacks and rectangles

For each histogram bar, a monotonic stack finds the nearest smaller bar on each side. Those boundaries describe where the bar is a minimum. Equal heights need a deliberate strict/non-strict convention to avoid double counting. In Horse Habitat, threshold activation and component lengths give another perspective on the same minimum-height structure.

Checkpoint: why does a monotonic minimum queue fail when the left endpoint can move backwards?

A discarded expired candidate may become eligible again. The algorithm relies on permanent expiry. Use a segment tree, an offline ordering, or another structure when query windows do not move monotonically.
