Sorting, two pointers and searching the answer

Sorting creates structure you can exploit

Without order, finding a partner near a target may require scanning everything. After sorting, increasing the left pointer increases the sum; decreasing the right pointer decreases it. A monotone boundary replaces repeated search.

For sorted a, the closest pair sum to T can be found with two pointers. If a[l]+a[r]<T, no pair with the same l and a smaller r is better on the high side, so discard l. The invariant explains which candidates become irrelevant.

int l=0, r=(int)a.size()-1;
while (l<r) {
    long long sum=a[l]+a[r];
    consider(l,r);
    if (sum<T) ++l;
    else --r;
}

The scan is O(n), because each pointer moves at most n times. Sorting costs O(n log n). This is amortised analysis, not “each loop iteration is constant so the total is constant.”

Binary search is a theorem about a predicate

To find the first feasible integer, you need false false … true true. Write the predicate and prove monotonicity before writing the loop.

// Invariant: lo is infeasible; hi is feasible.
while (hi-lo>1) {
    long long mid=lo+(hi-lo)/2;
    if (feasible(mid)) hi=mid;
    else lo=mid;
}
return hi;

A sentinel is useful only if its truth value is justified. If you do not know a feasible upper bound, double one until it becomes feasible, checking overflow.

Worked model: mills and travel time

By time T, a mill with productivity p and round-trip travel delay 2t contributes max(0,p(T-2t)). Sum this over mills. Every contribution is nondecreasing in T, so the total is too. To deliver quantity Q, search for the first T whose total reaches Q.

A numerical search with 80–100 fixed iterations has predictable precision, unlike a vague while(hi-lo>eps) whose meaning changes with scale. But the function is piecewise linear: after sorting mills by activation time, maintain P=Σp and B=Σ2pt. Within a segment, capacity is PT-B; solve T=(Q+B)/P and check whether T lies in that segment. This is a progression from feasibility to exploiting algebra.

Two pointers inside DP

In Interrail Pass, each pass covers a consecutive suffix of trips bounded by both dates and trip count. As the current trip advances, the earliest coverable trip cannot move backwards. Keep one moving pointer per pass type, turning repeated binary searches into O(nk) total pointer work.

When ternary search is appropriate

Ternary search needs a unimodal objective, not merely a monotone predicate. On a discrete domain, examine the final few positions exactly. Flat regions, multiple peaks, or numerical noise can invalidate an informal “looks like a hill” argument.

Checkpoint: can you binary-search a target sum in an unsorted array?

Not by comparing an arbitrary middle element. The required monotonicity is absent. You can sort, use a hash table, or binary-search an entirely different monotone feasibility predicate.
