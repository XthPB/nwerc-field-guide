Bitmask DP and meet in the middle

A subset is a compact state

For n labelled choices, bit i records whether choice i has been used. A mask is a representation; the DP state still needs a mathematical meaning. Assignment DP can use only mask, because the next person is popcount(mask). Travelling-salesman DP also needs the last vertex, because the next edge cost depends on it.

vector<long long> dp(1<<n,INF); dp[0]=0;
for(int mask=0;mask<(1<<n);mask++) {
    int person=__builtin_popcount((unsigned)mask);
    if(person==n) continue;
    for(int job=0;job<n;job++) if(!(mask>>job&1))
        dp[mask|(1<<job)]=min(dp[mask|(1<<job)],dp[mask]+cost[person][job]);
}

Assignment takes O(n2^n) time and O(2^n) space. TSP-style DP takes O(n²2^n) time and O(n2^n) space. For large bipartite assignment, matching or Hungarian is more appropriate.

Partition a set into groups

If a group is feasible when its subset sum is divisible by k, one recurrence chooses a feasible submask and recurses on the remainder. All (mask,submask) pairs total 3^n: each element is outside mask, inside submask, or inside mask but outside submask.

for(int sub=mask;sub;sub=(sub-1)&mask) {
    if(valid[sub]) dp[mask]=max(dp[mask],1+dp[mask^sub]);
}

Require a fixed bit of mask to lie in sub if the order of groups is irrelevant. This removes duplicate partitions, but does not change the exponential class.

SOS DP: aggregate every submask

If F[mask]=Σ A[sub] over all sub⊆mask, do not enumerate every submask separately. For each bit, transfer from masks without that bit to masks with it. O(n2^n) work replaces O(3^n).

F=A;
for(int b=0;b<n;b++) for(int mask=0;mask<(1<<n);mask++)
    if(mask>>b&1) F[mask]+=F[mask^(1<<b)];

The invariant after processing b bits is that all choices on those bits have been summed, while unprocessed bits remain fixed. Möbius inversion reverses the operation by subtraction.

Meet in the middle

For 40 items, 2^40 is too large but two lists of 2^20 sums are manageable. Enumerate each half, sort one, and binary-search complementary sums. Time is O(2^(n/2)·n) with ordinary sorting and memory O(2^(n/2)).

Adjusted Average has a different small parameter: at most four removals among many items. Split four into two plus two. Index disjointness is the hard part: sweeping an index boundary makes the two pairs automatically disjoint. Combining two arbitrary pair-sum lists without this condition is wrong.

Bitsets are parallel set operations

A machine word intersects 64 Boolean values at once. popcount(A&B) counts common elements; this is excellent for dense neighbourhoods or colour masks. A bitset is not automatically a subset DP: Hidden Art uses four-colour masks as a counting signature, while Gyrating Glyphs uses masks to enumerate operator codewords.

Checkpoint: when can labelled items be replaced by counts?

When items with the same type are interchangeable in every future transition and in the objective. Grinding Gravel depends on residues, so a vector of residue counts is sufficient. If identities create extra compatibility constraints, the compression may lose necessary information.
