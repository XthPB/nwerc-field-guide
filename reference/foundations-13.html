DSU, Kruskal and activation sweeps

Roads open one at a time between initially separate towns. After an opening, you need to know whether two particular towns now belong to the same connected group. Later versions ask which roads to buy at minimum cost or which groups exist at a price threshold.

Connectivity without keeping paths

A disjoint-set union stores a partition. find(x) identifies a representative; unite(a,b) merges two components. It does not tell you the path between vertices, and it does not by itself support deleting edges.

struct DSU {
    vector<int> p,sz;
    DSU(int n):p(n),sz(n,1){iota(p.begin(),p.end(),0);}
    int find(int x){return p[x]==x?x:p[x]=find(p[x]);}
    bool unite(int a,int b){
        a=find(a);b=find(b);if(a==b)return false;
        if(sz[a]<sz[b])swap(a,b);
        p[b]=a;sz[a]+=sz[b];return true;
    }
};

Union by size plus path compression gives amortised O(α(n)) operations. “Almost constant” is a practical description, not a literal O(1) worst-case theorem.

Kruskal's minimum spanning tree

Sort edges by weight and add an edge exactly when it joins different components. The cut property proves safety: a lightest edge crossing any cut can belong to some MST. The DSU tests whether an edge would form a cycle. Time is O(E log E); on a disconnected graph you obtain a minimum spanning forest.

An MST minimises total edge weight connecting all vertices. A shortest-path tree minimises distances from one root. They solve different objectives.

Turn thresholds into time

Suppose positions become usable when a threshold falls below their height. Activate positions in descending height, union active neighbours, and maintain component statistics. A contiguous component of length L contains L(L+1)/2 subintervals. When components of lengths a and b merge, new cross-boundary intervals number a·b.

This is a powerful bridge between histograms, DSU and rectangle counting. Equal-height activations should be grouped when the query asks for a strict threshold; otherwise intermediate states may represent a threshold that never actually exists.

Geometry needs a candidate generator

Coherency asks which spatial objects connect. DSU makes merging cheap, but testing all pairs is still quadratic. A grid hash or sweep generates nearby candidates. The distance bound and packing assumptions justify a bounded neighbourhood; DSU alone does not create that bound.

Separate the proof into two parts: every true edge is considered, and the number of considered candidates is small enough. A grid that is fast but misses a neighbour is not a valid optimisation.

Weighted and rollback DSU

Weighted DSU stores a relation from a node to its parent: a distance difference, parity, or multiplicative ratio. During path compression, compose those relations. Unit conversions are a clean example.

Rollback DSU supports undoing merges by saving changed fields. Use union by size without path compression, so each merge changes O(1) fields and find costs O(log n). Combine rollback with a segment tree over time for offline dynamic connectivity: place each edge in the time intervals where it exists, traverse the time tree, apply edges on entry and roll back on exit.

Checkpoint: can ordinary DSU answer whether deleting an edge disconnects two vertices?

No. A partition loses the information needed to split a component. Use offline reversal for deletion-only workloads, rollback over time, or a more advanced dynamic connectivity structure.
