Number theory, modular arithmetic and finite fields

Start with divisibility and invariants

Euclid's algorithm repeatedly replaces (a,b) by (b,a mod b), preserving the set of common divisors. It computes gcd in O(log min(a,b)). Extended Euclid additionally finds x,y with ax+by=gcd(a,b), giving inverses and linear Diophantine solutions.

Congruences describe an invariant under adding a modulus. In Hidden Art, gcd compresses compatibility between row and column periods. In Grinding Gravel, residues capture grouping feasibility while the original weights still determine the objective.

Modular inverses are conditional

An inverse of a modulo m exists exactly when gcd(a,m)=1. For prime p and nonzero a, Fermat gives a^(p−2) mod p. This does not justify division by zero or by a non-coprime value modulo a composite number.

long long modpow(long long a,long long e,long long mod) {
    long long r=1%mod;
    while(e) {
        if(e&1) r=(__int128)r*a%mod;
        a=(__int128)a*a%mod; e>>=1;
    }
    return r;
}

Normalise negative residues with (x%mod+mod)%mod. In C++, remainder can be negative. Use integer bit length for exact powers-of-two boundaries instead of floating log2 when off-by-one errors matter.

Chinese remainder theorem

For coprime moduli, a system of congruences has a unique solution modulo their product. With non-coprime moduli, residues must agree modulo the gcd; if compatible, the combined modulus is the lcm. Extended Euclid constructs the merge. Product overflow is often the real implementation limit.

Sieves and factorisation

The sieve of Eratosthenes marks prime multiples in O(N log log N) time and O(N) space. A smallest-prime-factor sieve also enables fast repeated factorisation. For 64-bit integers beyond sieve range, deterministic-base Miller–Rabin and Pollard rho are advanced tools; use a vetted implementation and overflow-safe modular multiplication. Trial division to √n can be far too slow near 10^18.

Finite-field lines as error-resistant encoding

Faulty Connection maps a message to a line y=ax+b over the prime field F₃₁. Two points with distinct x determine the line:

a=(y₂−y₁)/(x₂−x₁) mod 31
b=y₁−ax₁ mod 31

The denominator is invertible because x values differ and 31 is prime. Assign message k to (a=k mod 31,b=floor(k/31)); 600 messages fit within the 31² possible lines. This is a coding-theory use of elementary modular arithmetic.

Constructive identities

An identity can turn an existence theorem into a tiny output. For cubes, (r+1)³+(r−1)³−r³−r³=6r. Choose c so n−c³ is divisible by 6, then represent n using those four cubes plus c³. Checking the allowed root bounds is part of the proof; an algebraically correct identity may still violate output limits.

Checkpoint: does a^(m−2) always compute an inverse modulo m?

No. The Fermat exponent applies when m is prime and a is nonzero modulo m. For example, 2 has no inverse modulo 4 at all.
