One family of intervals contributes a ramp at every covered index

For each character position, count substrings through it that satisfy a subsequence rule. How can whole families of substring ends contribute together?

Work through the choice

Fix a left endpoint and find the interval of right endpoints that violate the rule. Count how many of those intervals cover each position. Across positions the contribution has a constant part and a descending ramp, which difference arrays can add together.

The rule you can reuse

Instead of counting independently at each queried position, fix the left endpoint. Next-occurrence jumps give the earliest right end completing each required subsequence. A present/absent condition leaves a contiguous range [A,B] of bad right ends.

For fixed left l and A≤B, positions i∈[l,A] belong to B−A+1 bad intervals; i∈[A+1,B] belong to B+1−i. Range-add coefficients of constant and linear functions using two difference arrays.

Check the boundary. If the required pattern never finishes, this l contributes nothing. If the forbidden one never finishes, B=n. Earliest completion at the same position leaves an empty bad range.

Cost O(n·(alphabet+total pattern length)) with a next-occurrence table for fixed patterns, O(n) after endpoints are known. CF 2276E, rated 1800.
