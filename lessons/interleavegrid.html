‹ Multidimensional states, from 2D to 4D

Two independently advancing strings make a 2D grid

Can you form acb by weaving ab and c together while respecting the order within each source?

Work through the choice

A move consumes the next letter of one source. After taking one letter from each, the next target position is already known. Store the two counts and try a move only if the next letter matches.

The rule you can reuse

To build a target by interleaving A and B in order, let i,j be the lengths already consumed. The target position equals i+j. Two histories ending at the same (i,j) leave the same suffixes available.

Fi,j=(Fi−1,j∧Ai=Ti+j)∨(Fi,j−1∧Bj=Ti+j)F_{i,j}=(F_{i-1,j}\land A_i=T_{i+j})\lor(F_{i,j-1}\land B_j=T_{i+j})Fi,j​=(Fi−1,j​∧Ai​=Ti+j​)∨(Fi,j−1​∧Bj​=Ti+j​)

F[0,0]=true. Reach (i,j) from (i−1,j) if A[i] matches target[i+j], or from (i,j−1) if B[j] matches. These formulas use 1-based characters.

Check the boundary. Check the total target length first. Replacing OR by addition counts interleavings of source positions. Counting distinct resulting strings requires a rule for merging equal outputs.

Cost O(|A||B|) time for nonempty strings or O((|A|+1)(|B|+1)) including boundaries. One row suffices for feasibility.
