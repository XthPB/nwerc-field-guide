Make geometry part of the state · Lesson 187 of 235

Replace strict geometric containment with a chain

Nest envelopes of sizes (2,3), (2,4) and (3,5). Both dimensions must grow strictly. What is the longest nesting?

1. Work one example

Sort by width. At one width process heights in decreasing order so an increasing-height sequence cannot use two envelopes of the same width. Then compute a strict LIS on heights.

2. What do we need to remember?

Sort points by one coordinate and express legal predecessors with the other. A geometric chain then becomes an ordered DP.

3. How do we get the next answer?

Ask whether containment is transitive and can be represented by ordered keys. Axis-aligned rectangles with fixed orientation fit strictly by width and height. Once sorted, every admissible nesting points forward.

Filter out envelopes unable to contain the starting card. Sort by width increasing and height decreasing on tied widths. A strictly increasing LIS on height then represents exactly a strictly nested chain.

Check the boundary. For a weighted chain, use a prefix maximum and batch equal widths before updating. For arbitrary shapes, rectangle side comparisons may cease to characterize containment. Ties on boundaries follow the statement’s strictness.

Cost O(n log n) for rectangles with a witness using tail parents or a Fenwick argmax. O(n²) explicit compatibility is often preferable when the geometric test is richer.

Try one change

Two rectangles have the same width but different heights. Can they form a strict nesting pair?

See the reasoning

No. When scanning by width, batch equal widths or sort their heights in an order that prevents them from extending each other.
