Count wildcard bracket strings by their open balance

Four question marks each become an opening or a closing bracket. How many distinct replacements form a balanced string?

Work through the choice

A prefix with two unmatched openings needs exactly two future closings more than openings. The positions of the unmatched openings have no effect when all brackets have one type. Count the prefixes with each possible number of unmatched openings. Dropping below zero would use a closing before its opening.

The rule you can reuse

fi+1(b+1)+=fi(b),fi+1(b−1)+=fi(b) (b>0)f_{i+1}(b+1)\mathrel{+}=f_i(b),\qquad f_{i+1}(b-1)\mathrel{+}=f_i(b)\ (b>0)fi+1​(b+1)+=fi​(b),fi+1​(b−1)+=fi​(b) (b>0)

Apply the first move if an opening is allowed and the second if a closing is allowed. Seed balance zero with one way and read only final balance zero. Discarding a balance larger than the number of remaining characters is safe.

Check the boundary. For the question “can this substring be balanced?”, feasible balances have one parity and fill every second integer between their minimum and maximum. This compresses existence to two endpoints. Those endpoints lose the number of assignments, as the two solutions for four question marks show.

Cost O(n²) time and O(n) memory for counts. For all substrings, fix the left endpoint and extend the two feasible-balance bounds in O(n²) total time and O(1) extra space.

From idea to code

  • Count bracket replacements or feasible intervals
    Choose bracket_completions for the number of fillings modulo a positive integer. Choose possible_bracket_intervals for the number of intervals admitting at least one filling. Both functions take a string over opening brackets, closing brackets and question marks.
See the idea in contest problems
  • CF 917A · The Monster 1800

    Fix a left endpoint. Feasible balances after each extension form a parity interval. A wildcard can move either way. Once even the largest balance is negative the start cannot recover. Count an endpoint once when zero is reachable, regardless of how many replacements achieve it.
