‹ Knapsack and subset sum

Split, merge, or temporarily omit · Lesson 208 of 235

Build the knapsack of everything except one item

You must report the best value at capacity 4 after leaving out each of (weight 2, value 3), (3,5) and (1,2). Can you share work across all three reports?

1. Work one example

For the left block containing only the first item, add both right items to an initially empty knapsack. They fit together and give 7. For the right block inherit the first item. To omit the second item add only the third, giving 5. To omit the third add only the second, giving 5.

2. What do we need to remember?

On entering a block of item indices, the table contains exactly the items outside that block. At a one-item block this is precisely the required answer.

3. How do we get the next answer?

Doutside(L)=insert(Doutside(L∪R),R).D_{\mathrm{outside}(L)}=\mathrm{insert}(D_{\mathrm{outside}(L\cup R)},R).Doutside(L)​=insert(Doutside(L∪R)​,R).

Before descending left insert every item of the right sibling into a copy. Before descending right insert the left sibling into a fresh copy of the parent table. At each depth every item is inserted at most once across the sibling updates. In CF 1442D, separately prove that an optimum needs at most one partially taken array. Nondecreasing marginal values let you move a selection between two partial arrays toward an endpoint without reducing the reward. Try that partial array at its leaf.

Check the boundary. A maximum-valued knapsack table loses the runner-up. Subtracting the value of a removed item cannot in general reconstruct the optimum without it.

Cost O(nB log n) time and O(B log n) working memory using depth-first traversal, for capacity B and n≥2. Saving every output table takes additional space.

Try one change

Four groups are A,B,C,D. While descending toward the leaves A and B, which complete groups must the carried knapsack already include?

See the reasoning

C and D. At the next split, add B when descending toward A, and A toward B. At each leaf the carried table contains all other groups.
