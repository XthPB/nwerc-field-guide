Describe a graph walk · Lesson 55 of 235

Index a shortest-path DP by the intermediates it allows

In a complete distance table, adding one allowed transfer city may improve many pairs at once. How do you update the table consistently?

1. Work one example

If the best route newly uses city k, split it at k. Each side uses only earlier allowed intermediates. Compare going through k with the old direct price for every ordered pair. Reversing a deletion order turns removals into these additions.

2. What do we need to remember?

First allow no intermediate vertices. Each new layer permits one additional vertex to be used between the endpoints.

3. How do we get the next answer?

Dk(i,j)=min⁡ ⁣(Dk−1(i,j),Dk−1(i,k)+Dk−1(k,j))D_k(i,j)=\min\!\left(D_{k-1}(i,j),D_{k-1}(i,k)+D_{k-1}(k,j)\right)Dk​(i,j)=min(Dk−1​(i,j),Dk−1​(i,k)+Dk−1​(k,j))

Keep k as the outer loop. During reverse additions relax all pairs, then sum distances for active endpoints only. Guard unreachable additions and use a sufficiently wide accumulator.

Check the boundary. A reachable negative cycle makes some shortest-path values unbounded below. The ordinary finite-path interpretation requires handling this separately.

Cost O(n³) time and O(n²) space.

Try one change

When vertex k becomes allowed, what are the two ways a best route from i to j can look?

See the reasoning

It already avoided k, or it goes from i to k and then k to j. Both smaller parts use only the previously allowed intermediate vertices.
