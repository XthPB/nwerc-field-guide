Choose a matrix parenthesization by the last multiplication

Multiply matrices of dimensions 10×30, 30×5 and 5×60. The result is fixed, but which grouping requires fewer scalar products?

Work through the choice

The last multiplication splits the ordered chain in two. The final dimensions of each subproduct depend only on its two endpoints, so the cost of joining them can be read without knowing either internal parenthesization.

Use D(i,i)=0 and increasing interval length. Keep the winning split if the question needs the parenthesization. The dimension vector for this example is [10,30,5,60].

Check the boundary. Matrix multiplication is associative but its input order must stay fixed. Arbitrary dimension products do not automatically satisfy the conditions for Knuth optimization.

Cost O(n³) time and O(n²) storage.
