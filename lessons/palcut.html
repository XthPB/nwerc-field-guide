Palindrome boundaries, suffix links, and series links

You want the fewest palindrome blocks that spell ababa. Which cuts can create its last block?

Work through the choice

Its palindromic endings have lengths 1, 3 and 5. Try the best known answer before each ending and add one block. On repetitive strings the candidate list grows long. A palindromic tree groups suffixes with repeated length differences.

The rule you can reuse

For a partition into palindromes, only palindromic suffixes of the current prefix are legal last blocks. Precompute isPal for moderate n. At large n, an eertree gives one node per distinct palindrome and links to smaller palindromic suffixes.

D(i)=1+min⁡palindromic suffix vD(i−len⁡(v))D(i)=1+\min_{\text{palindromic suffix }v}D(i-\operatorname{len}(v))D(i)=1+palindromic suffix vmin​D(i−len(v))

d[i]=1+min d[i−len(v)] over palindromic suffixes v. Nodes with common diff=len(v)−len(link(v)) form arithmetic progressions of candidate lengths.

Check the boundary. Series links skip a run of equal differences. Cache the run aggregate at the shifted predecessor index; skipping nodes without aggregating them drops valid cuts. Use parity flags when only even cuts are allowed.

Cost Dense O(n²); simple eertree enumeration still O(n²) worst case. Standard series-link factorization DP is O(n log n) with constant-time alphabet transitions.

From idea to code

  • Palindromic tree with series links
    This implementation solves mirrored block partitions after interleaving the two ends of the input. Its suffix links and series links are reusable. Adapt the per-node accumulated DP for other palindrome objectives.
Worked C++17 implementation
// Count splits into matching outer blocks (their total number must be even).
// Lowercase a-z, even length, result modulo 1e9+7. O(n log n).
inline int mirrored_block_splits(const std::string& s) {
    constexpr int mod = 1000000007;
    struct Node {
        int len=0, link=0, diff=0, series=0, subtotal=0;
        std::array<int,26> next{};
    };
    int n=static_cast<int>(s.size()), last=1;
    std::vector<Node> nodes(2);
    nodes.reserve(n+2);
    nodes[0].len=-1; // Imaginary root. Node 1 is the empty palindrome.
    std::string text(1,'#');
    std::vector<int> ways(n+1);
    ways[0]=1;
    for (int i=1; i<=n; ++i) {
        char ch=(i%2) ? s[(i-1)/2] : s[n-i/2];
        text.push_back(ch);
        int k=ch-'a';
        auto suffix = [&](int v) {
            while (text[i-1-nodes[v].len]!=ch) v=nodes[v].link;
            return v;
        };
        int parent=suffix(last);
        if (!nodes[parent].next[k]) {
            int id=static_cast<int>(nodes.size());
            nodes.emplace_back();
            nodes[parent].next[k]=id;
            auto& cur=nodes[id];
            cur.len=nodes[parent].len+2;
            cur.link=cur.len==1 ? 1 : nodes[suffix(nodes[parent].link)].next[k];
            const auto& link=nodes[cur.link];
            cur.diff=cur.len-link.len;
            cur.series=(cur.diff==link.diff) ? link.series : cur.link;
        }
        last=nodes[parent].next[k];
        for (int v=last; nodes[v].len>0; v=nodes[v].series) {
            auto& u=nodes[v];
            u.subtotal=ways[i-nodes[u.series].len-u.diff];
            if (u.diff==nodes[u.link].diff) {
                u.subtotal=(u.subtotal+nodes[u.link].subtotal)%mod;
            }
            if (i%2==0) ways[i]=(ways[i]+u.subtotal)%mod;
        }
    }
    return ways[n];
}
