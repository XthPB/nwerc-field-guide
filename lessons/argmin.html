Search by one coordinate and return the best of another

Among pairs with first coordinate from 2 through 6, return the ID with smallest second coordinate. Which coordinate should the tree index?

Work through the choice

Sort by the first coordinate. Two binary searches find the allowed slice. Store pairs of second coordinate and ID in a range-min tree over positions. The ID travels with the winning value and can reconstruct the predecessor.

NWERC Limited Library uses a monotone shelf-capacity test. Its eligibility sets are nested. The arbitrary coordinate-window query in this lesson needs a different operation.

The rule you can reuse

A data structure can store a compound answer. Sort pairs by a. Convert a range of a to index boundaries by binary search. Store (b,original index) in each leaf and merge lexicographically to return the smallest b with a witness.

j∗=arg⁡min⁡j: A≤aj≤B(bj,idj)j^*=\arg\min_{j:\,A\le a_j\le B}(b_j,\mathrm{id}_j)j∗=argj:A≤aj​≤Bmin​(bj​,idj​)

For inclusive A≤a≤B use [lower_bound(a,A),upper_bound(a,B)). Query the pair minimum on that interval. Reverse the value comparison for a maximum and specify tie-breaking.

Check the boundary. One sorted axis and a single stored payload is a one-dimensional range query. With independent lower/upper bounds on both coordinates, consider an offline sweep, range tree, or versioned structure.

Cost Static arbitrary ranges: sparse table O(n log n) build, O(1) idempotent query. Mutable values: segment tree O(log n) per update/query. Prefix-only monotone updates can use a Fenwick maximum.

From idea to code

  • Range minimum with the original index
    Sort entries by the query coordinate and keep original IDs. Binary-search a closed coordinate range to obtain a half-open slice. Query its lexicographically smallest (value, ID).
  • Bottom-up segment tree
    The original combine is addition over a half-open interval. For a min, max, witness or matrix payload, update the stored type, combine and empty identity together. Preserve combination order for matrices.
