Before, inside, and after an operation

Multiply one consecutive block of an array by −2 to make a subarray sum as large as possible. How do you stop yourself starting a second block?

Work through the choice

Remember whether multiplication is still available, is currently active, or has ended. Moving from one phase to the next spends that permission. Taking just the middle of 3, −2, 4 gives a profitable example.

The rule you can reuse

A single contiguous modification adds a phase to a scan. Let forward transitions enter or exit the modified interval. Combine with “currently inside a chosen subarray” if the output has its own interval.

Ii=max⁡{xai, Pi−1+xai, Ii−1+xai}I_i=\max\{xa_i,\ P_{i-1}+xa_i,\ I_{i-1}+xa_i\}Ii​=max{xai​, Pi−1​+xai​, Ii−1​+xai​}

With ending-at-i values for a maximum subarray and one optional multiplied segment, plain=max(a,plainOld+a), inside=max(xa,plainOld+xa,insideOld+xa), after=max(insideOld+a,afterOld+a).

Check the boundary. The answer includes plain, inside and after for an optional modification. Include 0 only if an empty answer is permitted. A multiplier extending outside the scored subarray can be clipped for this variant.

Cost O(n) time and O(1) space. For k disjoint segments, carry how many have started, typically O(nk).
