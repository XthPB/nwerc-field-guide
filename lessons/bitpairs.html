Follow tight bounds digit by digit · Lesson 111 of 235

Count bounded pairs whose binary addition has no carry

How many ordered pairs (a,b), each between 0 and 3, satisfy a+b = a XOR b?

1. Work one example

A carry occurs exactly where both bits are 1. On a two-bit full range, each position independently permits 00, 01 or 10, yielding nine ordered pairs. Upper bounds make only the two tight flags necessary across positions.

2. What do we need to remember?

Choose the bits of both numbers together. Each bound has its own tight flag, and each arithmetic rule restricts the allowed bit pairs.

3. How do we get the next answer?

F(A,B)=#{0≤a≤A, 0≤b≤B: a&b=0}F(A,B)=\#\{0\le a\le A,\ 0\le b\le B:\ a\mathbin{\&}b=0\}F(A,B)=#{0≤a≤A, 0≤b≤B: a&b=0}

For both numbers in [L,R], use F(R,R)−F(L−1,R)−F(R,L−1)+F(L−1,L−1). Return zero for any negative upper bound.

Check the boundary. The condition counts ordered pairs. Restricting to positive numbers or unordered pairs requires handling zero and symmetry deliberately.

Cost O(bits) time for constant many flag states. Choose an integer type or modulus that can hold the answer.

Try one change

If no binary carry is allowed, which of the four possible pairs of bits must be excluded?

See the reasoning

Exclude (1,1). It creates a carry. The other three bit pairs are allowed subject to the two numbers' bounds.

How to compare AND and XOR from the top bit
  1. For a one-bit array of two numbers, list the possibilities 00, 01, 10, 11. Their AND and XOR respectively tie, lose, lose and win. There is one tied column and one winning column.
  2. Append a lower bit. If the higher bits already won, every one of the four new columns works. If the higher bits tied, this column must tie or win. A loss at an earlier bit cannot be repaired.
  3. With two bits there is one tied high prefix and one winning high prefix. The low column gives 1 tied array and 4+1=5 winning arrays. Six of the sixteen ordered arrays satisfy AND at least XOR. For longer arrays, count columns of each type using the parity of their one-count.
