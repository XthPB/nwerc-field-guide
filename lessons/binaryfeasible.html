Binary search the answer with a DP feasibility test

The positive numbers 3, 2 and 4 must be split in order into at most two nonempty contiguous groups. Measure a split by the sum of its heaviest group. Find the smallest possible value of that maximum.

1. Work one example

Fix a proposed limit. A limit of 4 needs three groups, whereas 5 allows [3,2] and [4]. Any larger limit preserves those same cuts. Binary search this monotone answer and choose the simplest correct feasibility test for each limit.

2. What do we need to remember?

Replace the requested optimum by a yes/no threshold. Prove feasibility changes in only one direction before binary searching.

3. How do we get the next answer?

A minimum allowable threshold or maximum achievable separation may turn an objective into a monotone yes/no question. Design the cheapest DP that tests one threshold and prove monotonicity in that threshold.

For positive job lengths, fixed maximum load M and ≤k consecutive groups, g[i]=1+min g[j] over prefixSum[i]−prefixSum[j]≤M. Greedily taking the longest feasible group happens to implement this test.

Check the boundary. Binary searching a target count with an arbitrary nonmonotone predicate is invalid. This method tests feasibility at a bound; WQS instead optimizes a penalized objective and needs different hypotheses.

Cost O(T log range) for integer thresholds with test cost T. If few distinct threshold values are possible, search their sorted list.

  • NWERC 2024 · Limited Library

    Books have heights and shelves have height limits. Every shelf can hold either a larger or a smaller number of books. How many shelves can use the smaller capacity while all the books still fit?

    A book that fits a shelf also fits every taller shelf. For a proposed number of reduced-capacity shelves, reduce the shortest ones and match books greedily in sorted order.
