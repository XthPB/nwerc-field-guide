‹ Multidimensional states, from 2D to 4D

Build a state by asking which histories can have different futures

Can you make weight 5 using exactly two items from 2, 3 and 5?

Work through the choice

A mark at weight 5 mixes two different stories. Choosing 5 used one item. Choosing 2 and 3 used two. Store reachability for a pair of coordinates so the output can distinguish them.

The rule you can reuse

Start with a processed prefix i. Try merging two histories, then look for a future action that only one can take. Add the coordinate that distinguishes them. The number of axes describes the state, while the product of their ranges determines its price.

Fi(k,w)=max⁡{Fi−1(k,w), pi+Fi−1(k−1,w−wi)}F_i(k,w)=\max\{F_{i-1}(k,w),\,p_i+F_{i-1}(k-1,w-w_i)\}Fi​(k,w)=max{Fi−1​(k,w),pi​+Fi−1​(k−1,w−wi​)}

For capacity W and exactly K items define Fᵢ[k,w] as the best profit with exactly k selections of exact weight w. A take reads Fᵢ₋₁[k−1,w−weight]+profit. A skip reads Fᵢ₋₁[k,w].

Check the boundary. The prefix is a real third coordinate even when only two layers are stored. Separately decide what lives inside a cell. A pair (best,count achieving best) is one answer for one state.

Cost For n=100, K=20, W=5000 there are 10,607,121 conceptual cells including i=0. One layer needs 105,021 cells, about 0.80 MiB at eight bytes each. Count the work again if each transition loops over more choices.

From idea to code

  • 0/1 knapsack
    Use the descending capacity loop for one-use items. The initial zeros in this implementation mean “at most this capacity.” For exact weight, mark initially unreachable cells before the first update.
  • Bitset subset sum
    Set only bit zero at the start. A shifted copy represents taking one item. OR retains the outcomes of skipping it. Choose MAXS large enough for the actual largest queried sum.
See the idea in contest problems
  • CF 711C · Coloring Trees 1700

    Use prefix length, last colour and number of colour runs. Equal successive colours keep the run count, different colours add one. For a prepainted position allow only its fixed colour at cost zero.
