‹ Knapsack and subset sum

Solve a small geometric instance first, then knapsack its cost curve

On a 2 by 3 board, filling a whole row or column earns a point. What is the cheapest way to earn two points when a painted cell costs one?

Work through the choice

A row and a column share one cell, so their joint price is 4. Compute the cheapest price for each score on this board first. Across different boards costs add, so each board becomes one group of knapsack options.

The rule you can reuse

When independent regions each offer several possible scores, build the minimum price of obtaining each score inside one region. Treat that curve as one group in a min-plus knapsack. Each point has a marginal cost that can depend on the other points taken in that same group.

Completing r rows and c columns of an h×w rectangle uses rw+ch−rc distinct cells. Take a minimum over r,c for each r+c. For an at-least target, cap the global points at K and minimize total cells.

Check the boundary. A pattern that completes extra lines is still valid for an at-least objective. For exactly K, account for those extras. The table can use an option that guarantees at least t points: any optimal actual painting has a set of completed rows/columns whose union costs no more and is represented by an option.

Cost O(Σ(h+1)(w+1)) to enumerate local pairs, then O(nK²) for truncated cost curves, O(K) rolling space. Merge all t≥K into the K bucket. A more specialized marginal-cost computation can save local work.
