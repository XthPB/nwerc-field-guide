Describe a graph walk · Lesson 53 of 235

Use shortest distances to expose a DAG of optimal paths

Count shortest routes and find how many pass through one chosen vertex.

1. Work one example

Get distances first. Keep an edge only when it preserves a shortest distance. With positive weights these edges go from smaller to larger distance, so you can count prefixes forward and suffixes backward. Multiply counts at the chosen vertex.

2. What do we need to remember?

Keep only edges that can appear on a shortest route. Find an order for those remaining edges before counting paths.

3. How do we get the next answer?

In a positive-weight graph a shortest-path edge u→v satisfies d[u]+w=d[v], hence d[v]>d[u]. After finding distances, filter to tight edges. Increasing distance gives a valid order for counting shortest paths or aggregating a secondary reward.

d(u)+wuv=d(v),#shortest paths through v=F(v)G(v)d(u)+w_{uv}=d(v),\qquad \#\text{shortest paths through }v=F(v)G(v)d(u)+wuv​=d(v),#shortest paths through v=F(v)G(v)

Forward ways F[s]=1 and F[v]=Σ tight u→v F[u]. Reverse ways G[t]=1 and G[u]=Σ tight u→v G[v] for the chosen target. The number of shortest s→t paths through v equals F[v]G[v].

Check the boundary. Testing that every shortest path uses v requires exact counts, a proven exact alternative, or a documented probabilistic bound. A zero-weight equal-distance cycle invalidates this topological order and can create infinitely many shortest walks.

Cost O((V+E)log V) for heap Dijkstra followed by a linear pass once vertices are in increasing settled-distance order. Unit edges permit BFS layer order.

Try one change

A vertex has distance 5. Which outgoing edge belongs to the shortest-path structure: weight 2 to distance 7, or weight 2 to distance 6?

See the reasoning

Only the first satisfies 5+2=7. Positive weights make retained edges go toward strictly larger distance.

From idea to code

  • Dijkstra on an expanded graph
    First define what constitutes a vertex of the state graph. Construct an edge for each legal transition. All weights used by Dijkstra must be nonnegative.
  • Topological order and DAG DP
    Use a verified acyclic order. Process every outgoing transition after its source is final. Counting merges by addition and longest paths by maximum.
