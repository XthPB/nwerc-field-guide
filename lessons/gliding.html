Restrict the previous choices · Lesson 153 of 235

Use higher barriers to bound possible jumps

Mountains stand in a line. A glider may fly from one to a strictly shorter mountain if every mountain between them is lower than the starting mountain. Choose the start and later landings to visit as many mountains as possible. A tall intervening mountain can block an otherwise downhill flight.

1. Work one example

For a starting mountain, the nearest height at least as high on each side blocks every jump beyond it. Inside those barriers every other position is a valid shorter destination. Solve shorter mountains first, then query their best route in the interval.

2. What do we need to remember?

For each landing site, find the first barrier high enough to block a jump on each side. Query only already-solved lower sites between those barriers.

Find nearest greater-or-equal indices with a monotone stack. Query a range maximum for processed lower heights. Compute equal heights as a batch before inserting them.

Check the boundary. Strictness applies to both the landing and intervening heights. Treat missing barriers as outside the array and an empty range maximum as zero.

Cost O(n log n) time and O(n) storage.

Try one change

You can jump only over lower sites. What does the nearest blocking site to the right tell you?

See the reasoning

Every legal rightward landing lies strictly before that barrier. Query the lower sites already processed within that boundary, applying any jump-distance limit as well.
