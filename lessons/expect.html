First-step analysis and self-loops

A button succeeds with probability one quarter per press. On average how many presses will you need?

Work through the choice

Pay for the first press. On failure you return to exactly the state where you started. Put that unknown expectation on both sides of the equation and solve it, so a self-loop never causes an infinite recursive call.

The rule you can reuse

Expected time to absorption satisfies a weighted average of successor expectations plus the cost of the step. A self-loop can be isolated algebraically if the escape probability is positive.

E(s)=c(s)+∑t≠sp(s,t)E(t)1−p(s,s)E(s)=\frac{c(s)+\sum_{t\ne s}p(s,t)E(t)}{1-p(s,s)}E(s)=1−p(s,s)c(s)+∑t=s​p(s,t)E(t)​

E[s]=(cost+Σ_{t≠s} p(s,t)E[t])/(1−p(s,s)). For a terminal state use zero remaining cost.

Check the boundary. A reachable closed nonterminal class can make the expected hitting time infinite. Check termination and signs before dividing. In modular problems also check denominator invertibility.

Cost O(states × outgoing choices) when other transitions decrease rank. Compress symmetric items to counts of each type when identities do not matter.
