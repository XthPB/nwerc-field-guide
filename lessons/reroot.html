Ask the same tree question everywhere · Lesson 96 of 235

Send messages in both directions

For every vertex of the path 0–1–2–3, find the sum of distances to all vertices.

1. Work one example

Compute the sum at 0 once. Moving across 0–1 brings three vertices one step closer and puts 0 one step farther away. Each edge has a subtree size that tells you both counts for the next move.

2. What do we need to remember?

First learn what lies below every vertex. Then move the root across an edge, accounting for which distances or contributions change.

3. How do we get the next answer?

To obtain an answer at every root, moving across one edge changes whole components uniformly. For a generic associative merge, precompute prefix and suffix aggregates of neighbour messages so each outgoing message can omit its recipient.

A(v)=A(u)+wuv(n−2 size(v))A(v)=A(u)+w_{uv}\bigl(n-2\,\mathrm{size}(v)\bigr)A(v)=A(u)+wuv​(n−2size(v))

For all distance sums on an unweighted n-vertex tree, ans[v]=ans[u]+n−2·size[v] when moving parent u→child v. Each of size[v] vertices is one step closer; others one farther.

Check the boundary. Dividing a product to exclude one child fails on a zero or a noninvertible residue. Prefix/suffix products work for any modulus. For maxima maintain the best two contributions with their sources.

Cost O(n) for constant-size messages, since the sum of degrees is 2(n−1). Multiply by the cost of combining larger messages.

From idea to code

  • Rooted tree DP and rerooting
    Use reverse traversal for bottom-up child messages. Use forward traversal for the parent contribution. Derive a new message when the objective differs from distance or subtree size.
Worked C++17 implementation
// Adjacency list of a connected, unweighted, simple tree.
inline std::vector<i64> distance_sums(const std::vector<std::vector<int>>& graph) {
    int n = static_cast<int>(graph.size());
    if (n == 0) return {};
    std::vector<int> parent(n, -1), order{0}, size(n, 1);
    std::vector<i64> ans(n);
    for (std::size_t i = 0; i < order.size(); ++i) {
        int u = order[i];
        for (int v : graph[u]) {
            if (v == parent[u]) continue;
            parent[v] = u;
            order.push_back(v);
        }
    }
    for (int i = n-1; i > 0; --i) {
        int v = order[i];
        size[parent[v]] += size[v];
        ans[0] += size[v]; // Each root path pays once per edge.
    }
    for (int i = 1; i < n; ++i) {
        int v = order[i];
        ans[v] = ans[parent[v]] + n - 2LL * size[v];
    }
    return ans;
}
