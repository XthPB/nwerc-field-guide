‹ Probability, expectations and games

Choose while the future is uncertain · Lesson 129 of 235

Learn an unknown probability as you make decisions

A machine secretly chooses one failure probability uniformly between 0 and 1 and keeps that same probability for every trial. You see two failures in a row. Given those observations, what probability should you assign to a failure on the next trial?

1. Work one example

The first two observations tell you something about the machine. A high failure rate would produce those observations more often. The order of successes and failures adds no information once you know both counts. Use the number of trials and failures as the state, then take the best action after seeing the next outcome.

2. What do we need to remember?

Repeated observations teach you about one hidden rate. Store sufficient observations to predict the next outcome under the updated distribution.

3. How do we get the next answer?

q(c,u)=u+1c+2q(c,u)=\frac{u+1}{c+2}q(c,u)=c+2u+1​

Here c is the number observed and u the number of failures. In the BAPC card game, an observed bad card lets you correct it alone or flip all remaining cards. After flipping everything, the future uses the complementary rate. The equivalent history of c + 1 observations then contains c − u bad cards. The template prices both actions before combining the outcome probabilities.

Check the boundary. A fresh independent uniform rate on every trial would give a constant prediction of one half. For a shared Beta(α, β) prior the predictive probability is (α + u)/(α + β + c). The complementary-rate shortcut in the card example uses the symmetry of its uniform prior.

Cost O(n²) time across all pairs of observation counts and O(n) memory when each state reads only the following row.

Try one change

For an unknown coin, do three heads and no tails give the same forecast as three heads and seven tails?

See the reasoning

Generally no. Under a fixed Beta prior, both observed counts update the next-head probability. Today's information changes the value of tomorrow's decision.
