All submask aggregates by one sweep per bit

You know a value for each binary mask. How can you sum over every subset of each mask without listing all subset pairs?

1. Work one example

Process one bit at a time. A mask containing that bit receives contributions from the same mask with that bit cleared. Each pass doubles the choices accounted for along one dimension.

2. What do we need to remember?

After processing one bit, a mask can aggregate information from the mask obtained by removing that bit.

3. How do we get the next answer?

Every query asks for an aggregate of values of masks contained in M. Fix one bit direction at a time. After processing the first k bits, those k may have been cleared and the others are still fixed.

F(M)=∑S⊆MA(S)F(M)=\sum_{S\subseteq M} A(S)F(M)=S⊆M∑​A(S)

F=A. For each bit b, for each M containing b, F[M] ← F[M] + F[M without b]. For superset sums reverse the direction. Subtraction undoes a sum transform.

Check the boundary. OR, max and existence also permit forward associative aggregation with this partition. Recovering A by Möbius inversion needs an additive inverse. Restrict complement to the active bits.

Cost O(b2ᵇ) time, O(2ᵇ) storage. Replaces O(3ᵇ) for all submask aggregates.

From idea to code

  • Sum over submasks
    The per-bit sweep aggregates values from subsets. Choosing a representative or a maximum needs its own combining operation and identity.
Worked C++17 implementation
// Nonempty array of power-of-two length. Sums must fit i64.
inline std::vector<i64> subset_zeta(std::vector<i64> a) {
    for (std::size_t bit = 1; bit < a.size(); bit *= 2) {
        for (std::size_t mask = 0; mask < a.size(); ++mask) {
            if (mask & bit) a[mask] += a[mask ^ bit];
        }
    }
    return a;
}
