‹ Algebraic and counting DP

Count the complement using a canonical first violation

Count binary strings of length three where neither of the first two bits is 1.

Work through the choice

Subtract each forbidden event from the total. The strings with both bits set were removed twice, so add their intersection back once. An alternative DP can assign each bad object to its first violation.

The rule you can reuse

When constraints interact, count all choices then remove bad choices without losing overlap. Inclusion–exclusion iterates subsets of few bad events. A partial order sometimes allows a cheaper first-violation DP.

Check the boundary. A first bad event must be uniquely assignable, including ties. Using sums over all visited bad events as if they were disjoint creates the same overlap.

Cost O(2ᵏ × intersection cost) for k events. Compare to a 2ᵏ-state mask DP and to a first-event recurrence exploiting order.

From idea to code

  • Binomial coefficients and modular arithmetic
    Use modular binomial coefficients for independent choices and unrestricted grid paths. Check that the modulus and factorial range make the inverses used by the template valid.
  • Enumerate submasks
    The loop visits every nonempty submask. Add the empty option separately if it is legal. Enumerating submasks for every mask costs three to the power n across all masks.
