Handle a bound with ten thousand decimal digits

Count positive integers at most a huge decimal string K whose digit sum is divisible by D. How do you avoid parsing K into an integer?

Work through the choice

Read one character of K at a time. Store the current sum modulo D and whether the prefix still equals K. Each transition needs only the preceding row, so even a long string does not require deep recursion.

Loose prefixes represent 00 through 24. The one tight completion is 25, whose digit sum is 7 and whose remainder is 1. The remainder-zero column contains nine numbers, or eight after removing zero.

The rule you can reuse

r′=(r+d) mod D,t′=t∧(d=Ki)r'=(r+d)\bmod D,\qquad t'=t\land(d=K_i)r′=(r+d)modD,t′=t∧(d=Ki​)

Store the bound as text. For an interval [L,R], compute F(R)−F(L−1) using decimal-string subtraction or use two tight flags directly.

Check the boundary. The all-zero representation is included in a padded count. Subtract it exactly once if zero is excluded. A modular residue suffices for counts modulo M but cannot support ranking by true counts.

Cost O(10D·digits) time and O(D) working space.
