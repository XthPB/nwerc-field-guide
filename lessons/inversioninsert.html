Count permutations with exactly k inversions

How many permutations of three distinct elements have exactly one inversion?

1. Work one example

Insert the new largest value into a permutation of length n−1. Placing it before j existing entries creates exactly j inversions and leaves old ones alone. This partitions the answers by insertion position and gives a sliding sum.

2. What do we need to remember?

Inserting the largest element can create any permitted number of new inversions. Sum over its possible insertion positions.

3. How do we get the next answer?

F(n,k)=∑j=0min⁡(k,n−1)F(n−1,k−j)F(n,k)=\sum_{j=0}^{\min(k,n-1)}F(n-1,k-j)F(n,k)=j=0∑min(k,n−1)​F(n−1,k−j)

Use a running window over the previous row. As k increases, add the new right endpoint and remove the term that falls n places behind.

Check the boundary. For repeated input values insertion can overcount identical permutations. The recurrence assumes labeled distinct ranks.

Cost O(nk) time and O(k) space after the sliding-window optimization.

Try one change

Insert the largest of four labels into a permutation of the first three. How many new inversions can appear?

See the reasoning

Anywhere from zero to three, exactly once for each insertion slot. Its new inversions equal the number of smaller labels to its right.

From idea to code

  • Prefix sums and difference arrays
    A prefix answers a range sum by subtraction. A difference array reverses the operation by marking the two ends of an interval update. The sheet includes the two-dimensional inclusion–exclusion form.
  • Binomial coefficients and modular arithmetic
    Use modular binomial coefficients for independent choices and unrestricted grid paths. Check that the modulus and factorial range make the inverses used by the template valid.
