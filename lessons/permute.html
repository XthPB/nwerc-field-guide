‹ Digits, bounds and carries

Choose and order actual digits

Rearrange digits 1,1,2 into different valid numbers. How do you keep the identical copies from doubling the answer?

Work through the choice

Sort the digits. At each step use the first still-available copy of a value as its representative. A used-mask and a running remainder can then count distinct arrangements under divisibility constraints.

The rule you can reuse

If the digits are supplied and must be used once, a position index and a digit-sum state do not identify the remaining choices. Use a mask, or a mixed-radix vector of remaining multiplicities, together with the remainder.

(M,r)⟼(M∪{j},(10r+dj) mod m)(M,r)\longmapsto(M\cup\{j\},(10r+d_j)\bmod m)(M,r)⟼(M∪{j},(10r+dj​)modm)

From (M,r) append unused digit d and set r′=(10r+d) mod m. For equal sorted digits, allow index j only if its equal predecessor has already been used.

Check the boundary. Disallow a real leading zero where the statement requires it. If the target counts labeled digit selections, the duplicate-skip rule would throw away valid permutations.

Cost O(2ⁿ n m), O(2ⁿm) memory. A count vector has ∏(c_d+1) configurations, useful with many repeated digits.
