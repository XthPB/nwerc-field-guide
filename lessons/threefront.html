Fit three growing strings inside a host

Can you weave aa, b and c into the host abac as a subsequence?

Work through the choice

For fixed counts consumed from the three strings, two histories may end at different host positions. The earlier finish has access to every suffix available to the later finish. Store that earliest finish and try extending one source.

The rule you can reuse

In a host string, seek an interleaving of three source prefixes as a subsequence. A fourth coordinate for the current host position is tempting. For fixed prefix lengths, an earlier finish dominates every later finish because its available suffix contains theirs.

Di,j,k=min⁡ ⁣{next⁡(Di−1,j,k,Ai)next⁡(Di,j−1,k,Bj)next⁡(Di,j,k−1,Ck)D_{i,j,k}=\min\!\begin{cases}\operatorname{next}(D_{i-1,j,k},A_i)\\\operatorname{next}(D_{i,j-1,k},B_j)\\\operatorname{next}(D_{i,j,k-1},C_k)\end{cases}Di,j,k​=min⎩⎨⎧​next(Di−1,j,k​,Ai​)next(Di,j−1,k​,Bj​)next(Di,j,k−1​,Ck​)​

D[0,0,0]=0. D[i,j,k] is the minimum of next(D[i−1,j,k],A[i]), next(D[i,j−1,k],B[j]) and next(D[i,j,k−1],C[k]) over valid predecessors. next(p,c) is the first position strictly after p holding c. Failure returns ∞.

Check the boundary. When one source appends, recompute the whole newly exposed face of the 3D box in dependency order. Popping reveals valid old cells. After popping and appending a different character, overwrite the face, including formerly unreachable or stale cells.

Cost O(nσ) for the host next table, O((A+1)(B+1)(C+1)) DP cells, and O((B+1)(C+1)) time for an append to the first string. At lengths 250, a 251³ int32 array uses about 60.3 MiB.
