Enforce an XOR bound on every pair in a subset

From the labeled numbers 0,1,2,3, how many nonempty subsets have every pairwise XOR at most 2?

1. Work one example

In binary the limit is 10. Only the pairs (00,11) and (01,10) have XOR 11 and fail. Pick at most one member from each of these two forbidden pairs. Each pair has three choices, including neither, so the answer is 3×3−1=8.

2. What do we need to remember?

Split on the first undecided bit. Sometimes a whole pair of branches is safe immediately. For the remaining pairs, keep two trie nodes whose cross-pairs still need checking.

3. How do we get the next answer?

E(U,V)=2∣U∣+2∣V∣−1,T(U,V)=E(U,V)+B(U,V).E(U,V)=2^{|U|}+2^{|V|}-1,\qquad T(U,V)=E(U,V)+B(U,V).E(U,V)=2∣U∣+2∣V∣−1,T(U,V)=E(U,V)+B(U,V).

B(U,V) counts pairs of nonempty chosen subsets, one from each node, with all cross-XORs still legal. E counts choices with at least one side empty and T allows both conventions.

At a zero bound bit, both nonempty sides must lie in matching bit branches, so add B(U₀,V₀) and B(U₁,V₁).

At a one bit, equal-bit pairs are automatically safe. Multiply T(U₀,V₁) and T(U₁,V₀), then subtract E(U,V) to restore the nonempty convention.

After the last bit all cross choices are legal.

Check the boundary. For the outer one-node question, at a zero bit recurse inside either child. At a one bit count all nonempty subsets entirely in either child, then add B(left,right) for choices using both. Equal numerical values still represent distinct labeled positions. Applying a two-number digit DP independently to every pair counts incompatible subset choices.

Cost O(nW) construction and arithmetic for n labeled values of W bits, with precomputed powers of two. At a given depth the paired recursive calls use disjoint groups of inputs. The example code returns counts modulo 1,000,000,007.

Try one change

With numbers 00,01,10,11 and limit 10₂, can a valid subset contain both 01 and 10?

See the reasoning

No. Their XOR is 11₂. The highest differing bit ties the limit's high bit, so the lower bit still decides legality.
