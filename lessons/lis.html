The cheapest tail for each length

2. What do we need to remember?

For each length, keep the smallest possible last value of an increasing subsequence. It is the easiest one to extend.

3. How do we get the next answer?

For a strictly increasing subsequence, two histories with the same length differ only in their last value for future comparisons. The smaller last value can accept every successor that the larger one can.

T[ℓ]=min⁡{last value of an increasing subsequence of length ℓ}T[\ell]=\min\{\text{last value of an increasing subsequence of length }\ell\}T[ℓ]=min{last value of an increasing subsequence of length ℓ}

tails[ℓ−1] = minimum attainable tail of length ℓ. Replace the first tail ≥ x, or append if none exists.

Check the boundary. Use upper_bound (first > x) for nondecreasing subsequences. Tails alone loses counts, weights, and the actual witness after replacements.

Cost O(n log n), O(n) space. With both ends constrained, compute prefix and suffix lengths and combine at a shared pivot.

The best tails for lengths 1 and 2 are 2 and 8. A 5 arrives. What changes?

See the reasoning

Length 2 gets tail 5. Both tails allow a length-2 subsequence, but 5 can later accept a 6, while 8 cannot.

From idea to code

  • Strict longest increasing subsequence
    The lower_bound version finds a strictly increasing chain. Equal values can extend a nondecreasing chain when you switch to upper_bound. The returned number is a length.
Worked C++17 implementation
// A strict LIS, returning indices. For nondecreasing use upper_bound.
inline std::vector<int> lis_indices(const std::vector<i64>& a) {
    std::vector<i64> tails;
    std::vector<int> end, parent(a.size(), -1);
    for (int i = 0; i < static_cast<int>(a.size()); ++i) {
        int k = std::lower_bound(tails.begin(), tails.end(), a[i]) - tails.begin();
        if (k > 0) parent[i] = end[k-1];
        if (k == static_cast<int>(tails.size())) {
            tails.push_back(a[i]);
            end.push_back(i);
        } else {
            tails[k] = a[i];
            end[k] = i;
        }
    }
    std::vector<int> chain;
    for (int i = end.empty() ? -1 : end.back(); i != -1; i = parent[i]) {
        chain.push_back(i);
    }
    std::reverse(chain.begin(), chain.end());
    return chain;
}
