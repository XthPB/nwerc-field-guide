Finish with counting and optimization hybrids · Lesson 231 of 235

Count strings that contain every allowed subsequence

A target word is chosen one stage at a time, with a set of allowed letters at each stage. Count candidate words of the requested length that contain every possible target as a subsequence. For stages {a,b} then {c}, a candidate must contain both ac and bc in order.

1. Work one example

For one stage, the worst required choice is the one whose first occurrence comes last. Once every allowed letter has appeared, all choices can be matched by this position. Start the next stage from that boundary and avoid counting multiple decompositions of the same word.

2. What do we need to remember?

Finish a phase at the earliest point where every required letter has appeared. The remaining suffix must then serve every choice in the next phase.

3. How do we get the next answer?

To contain every choice of one symbol from each of several alphabets, greedily end the first phase at the earliest position by which every first-phase symbol has appeared. The last first occurrence is a possible adversarial choice, so the remaining suffix must handle all later phases. This also proves sufficiency.

Within a phase with h required symbols still missing and total alphabet m, h symbols advance and m−h loop. To complete this stage its length generating function is hz/(1−(m−h)z). Multiply over h from phase size down to 1 and over all phases; append 1/(1−mz) for the unconstrained tail.

Check the boundary. For phase sizes ≤5, collect equal denominators. After the numerator’s power of z is removed, write F=∏(1−aⱼz)^(−bⱼ). Set Q=∏(1−aⱼz), P=Σ bⱼaⱼ Q/(1−aⱼz); QF′=PF gives each next coefficient from at most six earlier ones. Start F[0]=1, multiply the result by the product of phase factorials. If the required numerator degree exceeds n, return zero.

Cost O(n·d+d²+total phase sizes) arithmetic for d≤6 distinct loop counts. Coefficient division by i is valid for i below the problem modulus. CF 2169F, rated 2800.

Try one change

Over alphabet {A,B}, after reading AAB, what has the first complete phase guaranteed?

See the reasoning

Either possible first target letter can be matched within that phase. From its boundary onward the suffix can supply the rest without relying on which letter was chosen.
