Combine two functions on disjoint subsets

For every guest set S, choose who sits at table A and who sits at B. Each table contributes a score depending on its entire set. How can you sum products of the two scores?

1. Work one example

A submask T determines exactly the complementary table S minus T. Trying all T for all S takes 3ⁿ operations. To accelerate, group values by their population count before the subset zeta transforms. Rank information lets you discard overlaps.

2. What do we need to remember?

Split subset contributions by cardinality. This extra rank distinguishes disjoint partitions from overlapping contributions.

3. How do we get the next answer?

h(S)=∑T⊆Sf(T) g(S∖T)h(S)=\sum_{T\subseteq S}f(T)\,g(S\setminus T)h(S)=T⊆S∑​f(T)g(S∖T)

Zeta-transform each rank layer. Multiply the rank polynomials pointwise for every mask. Möbius-invert each output rank, then read rank equal to the mask size so the two sets are disjoint and cover it.

Check the boundary. This fast version uses a ring admitting addition, multiplication and subtraction. Replacing sum by maximum does not preserve Möbius inversion.

Cost O(n²2ⁿ) time and O(n2ⁿ) stored coefficients. Direct submask enumeration is often simpler for small n.

Try one change

With sets A={1,2} and B={2}, why is union size 2 smaller than the two input sizes added together?

See the reasoning

The sets overlap at 2. Requiring the two input ranks to sum to the output size after union filters out overlapping decompositions.

From idea to code

  • Sum over submasks
    The per-bit sweep aggregates values from subsets. Choosing a representative or a maximum needs its own combining operation and identity.
  • Enumerate submasks
    The loop visits every nonempty submask. Add the empty option separately if it is legal. Enumerating submasks for every mask costs three to the power n across all masks.
