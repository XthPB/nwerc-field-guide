Choose a state in unfamiliar problems · Lesson 219 of 235

Undo an invertible decision chain

A point starts at 0 on a line and ends at 0 after a sequence of reflections. Reflecting x around center c sends it to 2c−x. The first center is missing and the remaining centers are 4, 1 and 3 in that order. Recover the missing center.

1. Work one example

Reflecting twice in the same centre returns to the starting point. Undo every known reflection in reverse order. The position you recover immediately after the unknown reflection determines that first centre.

2. What do we need to remember?

When the final value is fixed and each update has a unique inverse, undo the operations in reverse order to recover the starting value.

3. How do we get the next answer?

If a final state is fixed and every operation is invertible, trace the single possible history backward. A large DP table becomes one scalar. For a reflection about a, inverse and forward maps coincide.

xprevious=2a−xcurrent,p=xafter first/2x_{\rm previous}=2a-x_{\rm current},\qquad p=x_{\rm after\ first}/2xprevious​=2a−xcurrent​,p=xafter first​/2

Reverse known centres with x ← 2a−x starting from final x=0. The unknown first reflection from 0 produced 2p, so p=x/2.

Check the boundary. If an operation rounds or takes an absolute value, the inverse may contain several states. Track a set or interval only after proving that it stays representable.

Cost O(n) time and O(1) extra space with the input available in reverse. CF 2274A, rated 800.

Try one change

A value is doubled and then increased by 3, finishing at 17. How do you recover its starting value?

See the reasoning

Undo in reverse order: subtract 3 to get 14, divide by 2 to get 7. Check integrality and domain restrictions before accepting an inverse.
