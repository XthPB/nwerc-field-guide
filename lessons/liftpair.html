Choose a set and its endpoint · Lesson 75 of 235

A lexicographic pair can replace enumeration of groups

Three riders weigh 4, 4 and 2. A lift carries total weight at most 6 per ride, and each rider must travel once. You can choose who rides together and in what order to load them. Find the fewest rides.

1. Work one example

First prefer fewer rides. Among equally many rides, prefer the one with a lighter last ride because the next passenger has more space. Try every possible last passenger to recover the best pair for each subset.

2. What do we need to remember?

For each set of passengers keep the best pair consisting of rides already opened and load on the current ride.

3. How do we get the next answer?

When items share identical bin capacity C and the only open bin is the last one, keep (number of rides,load of last ride). A lighter final load dominates at equal ride count. A prefix with one fewer ride can always start a fresh ride.

D(M)=min⁡j∈Mlexappend⁡(D(M∖{j}),wj)D(M)=\min_{j\in M}^{\rm lex}\operatorname{append}\bigl(D(M\setminus\{j\}),w_j\bigr)D(M)=j∈Mminlex​append(D(M∖{j}),wj​)

D[M]=min lex over choices of last item j of append(D[M without j],wⱼ). Append fills the last ride if it fits, otherwise starts one.

Check the boundary. Use a consistent empty-state convention, such as (0,0) then explicitly start the first ride. Item weights must fit an empty ride. Multiple simultaneously open bins change the dominance proof.

Cost O(n2ⁿ) time and O(2ⁿ) memory. Directly trying every last bin would cost O(3ⁿ).

Try one change

Two packings use two rides; their current rides carry 4 and 7 with capacity 10. Which state can you keep?

See the reasoning

Keep load 4. It can take any next passenger the other current ride can take, and sometimes one the load-7 ride cannot.
