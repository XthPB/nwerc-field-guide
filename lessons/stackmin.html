Equal segment extrema form consecutive blocks of cuts

For every possible final cut, the new segment costs its maximum. How can appending one number update many cuts together?

Work through the choice

Suffix maxima form consecutive blocks of equal values. A new value replaces every smaller suffix maximum up to the first larger one. A monotone stack locates exactly the blocks that merge.

The rule you can reuse

For a fixed right endpoint, segment maxima as the left cut moves right form a monotone step function. A new x merges the suffix of blocks whose old maximum ≤x. Preserve the required aggregate of old[j] in each block.

D(i)=min⁡j<i(P(j)+max⁡j<t≤iat)D(i)=\min_{j<i}\bigl(P(j)+\max_{j<t\le i}a_t\bigr)D(i)=j<imin​(P(j)+j<t≤imax​at​)

For Dᵢ=minⱼ(old[j]+max(a[j+1…i])), keep blocks of cuts with a common maximum. Each block contributes minOld+blockMax; maintain the minimum across current blocks.

Check the boundary. A stack controls how block boundaries move. You still need a way to query the aggregate across surviving blocks. If cost depends on length×maximum, a single minOld value may be insufficient.

Cost For the additive maximum example, each block pushes/pops once per layer and stack-prefix minima give O(n) per layer.
