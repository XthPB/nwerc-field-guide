‹ Bitmasks and subset transforms

Choose a set and its endpoint · Lesson 80 of 235

Track prime parity, used primes, or small-feature coverage

Choose a nonempty subset of the numbers 2, 8 and 3. Its product must be a perfect square, such as 16. Determine which selections qualify. The larger counting version asks how many different selections make every prime exponent even.

1. Work one example

A square has even exponent for every prime. Represent each odd exponent by one bit. Multiplication flips those bits, so identical masks cancel under XOR. The empty subset also cancels and has to be handled in the answer.

2. What do we need to remember?

A square has only even prime exponents. Represent their parities by bits and combine choices with XOR.

3. How do we get the next answer?

Replace a large arithmetic value by the features the next decision can inspect. For a square product, only odd exponent parities matter, so selection XORs masks. Pairwise coprimality needs disjoint used-prime masks instead.

F′(m)=F(m)+F(m⊕p)F'(m)=F(m)+F(m\oplus p)F′(m)=F(m)+F(m⊕p)

Square products: f′[m]=f[m]+f[m XOR p] for a one-use item with parity p. Coprimality requires (m AND p)=0 and advances to m OR p.

Check the boundary. For zero numbers, parity vectors do not encode the zero product. Specify its treatment separately. Distinguish “used at least once” from “used an odd number of times.”

Cost O(n2ᵇ); grouping equal masks can reduce n. For unrestricted counting of XOR-zero subsets use a binary linear basis and kernel dimension instead.

Try one change

Multiplying two numbers each containing a single factor of 3 gives what parity for the exponent of 3?

See the reasoning

Even. The two set bits cancel under XOR. For a square product, every prime's final parity must be zero.

From idea to code

  • Prime factorization
    For a square-product mask keep exponents modulo two. Repeated occurrences with the same parity mask can be grouped only after accounting for the number of labeled selections.
  • Enumerate submasks
    The loop visits every nonempty submask. Add the empty option separately if it is legal. Enumerating submasks for every mask costs three to the power n across all masks.
