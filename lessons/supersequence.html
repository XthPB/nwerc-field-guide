Read two strings together · Lesson 38 of 235

Recover a shortest string containing both inputs as subsequences

Construct a shortest common supersequence for ab and ac. How can one matched letter count for both strings?

1. Work one example

A common a can serve both inputs. Among possible alignments use one with the most such shared letters. An LCS provides exactly that. Weave the unmatched runs from both inputs around the LCS, keeping each source order.

2. What do we need to remember?

A printed character can serve both strings when their next needed symbols agree. Track both consumed prefixes.

3. How do we get the next answer?

LSCS=∣A∣+∣B∣−LLCSL_{\mathrm{SCS}}=\lvert A\rvert+\lvert B\rvert-L_{\mathrm{LCS}}LSCS​=∣A∣+∣B∣−LLCS​

Use an LCS length table with parent choices or direct SCS parents. When last characters match they can occupy the same final position. Otherwise try appending one input's last character.

Check the boundary. The identity is for two inputs. Three strings require more state, and a greedy pairwise merge can lose a global optimum.

Cost O(nm) time, O(nm) simple witness storage. Hirschberg can save memory for the common subsequence.
