‹ Knapsack and subset sum

Reuse, bounded stock, or one choice per group

A shop lets you choose one of two upgrades from the same group. Can you take both to get a higher profit?

Work through the choice

Each option must start from the table before entering the shop. If the second option reads values already produced by the first, it buys two upgrades. Unlimited items deliberately read today's values to allow reuse.

The rule you can reuse

An unlimited positive-weight item can read the current layer at a smaller sum. A group with mutually exclusive options must read the entire previous group. A stock bound sits between these cases.

D(s)←max⁡{D(s),D(s−w)+v}(s=w,w+1,…,W)D(s)\gets\max\{D(s),D(s-w)+v\}\qquad(s=w,w+1,\ldots,W)D(s)←max{D(s),D(s−w)+v}(s=w,w+1,…,W)

Unlimited max: d[s]=max(d[s],d[s−w]+v), ascending. Group: new[s]=max over options o of old[s−wₒ]+vₒ; include a zero option if skipping is allowed.

Check the boundary. For bounded optimization or existence, subdivide c copies into 1,2,4,… and a final remainder. For c=6 the bundles 1,2,3 represent 3 twice, so this transformation can overcount.

Cost Grouped O(W × total options). Binary bundles O(W Σ log(c+1)). An unlimited zero-weight positive-profit item makes the optimum unbounded.
