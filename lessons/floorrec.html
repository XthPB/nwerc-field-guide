Memoize only the quotients you can actually visit

Evaluate f(n)=f(⌊n/2⌋)+f(⌊n/3⌋) with f(0)=1 for an enormous n. Allocating a table up to n is impossible.

Work through the choice

Recursive divisions commute after flooring for positive divisors. Every reachable positive argument is ⌊n/(2ᵃ3ᵇ)⌋. The exponent pair has only logarithmically many choices per coordinate. Memoize by the resulting argument to merge even more calls.

The rule you can reuse

F(0)=1,F(x)=F(⌊x/2⌋)+F(⌊x/3⌋)F(0)=1,\qquad F(x)=F(\lfloor x/2\rfloor)+F(\lfloor x/3\rfloor)F(0)=1,F(x)=F(⌊x/2⌋)+F(⌊x/3⌋)

Check zero before recursing, then consult a hash map. Returning a cached value replaces an entire previously evaluated recursive tree.

Check the boundary. A recurrence containing x−1 can reach linearly many arguments. Shrinking some of the children does not by itself guarantee a small reachable set.

Cost O(log² n) distinct positive arguments as an upper bound, expected constant-time memo access, O(log n) call depth.
