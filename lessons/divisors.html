Count each object once · Lesson 115 of 235

A divisor lattice is another DP order

Among 2,4,6, how many pairs have gcd exactly 2?

1. Work one example

Start with all pairs whose numbers are multiples of 2. Every such pair has gcd equal to 2 or a larger multiple. Compute exact answers in decreasing divisor order, subtracting proper multiples already counted.

2. What do we need to remember?

First count objects divisible by d. Work downward so counts for larger exact gcds can be subtracted.

3. How do we get the next answer?

If objects extend by divisibility, iterate multiples instead of every pair. If all valid gcds divide a known divisor, invert “gcd divisible by d” counts from larger multiples to smaller d.

E(d)=(mult(d)k)−∑j≥2E(jd)E(d)=\binom{\mathrm{mult}(d)}{k}-\sum_{j\ge2}E(jd)E(d)=(kmult(d)​)−j≥2∑​E(jd)

For subsequences of k values with gcd exactly d, let mult[d] count inputs divisible by d. exact[d]=choose(mult[d],k)−Σ_{j≥2}exact[jd].

Check the boundary. Zero is divisible by every positive d, so handle it explicitly if admitted. For divisor-chain DP update from a previous length layer if a chain must contain exactly k positions.

Cost O(A log A) divisor/multiple visits up to maximum A plus binomial queries. Factor and enumerate only actual divisors when A is huge.

Try one change

Six choices have gcd divisible by 2, and two of them have gcd 4. Can all six be reported as gcd exactly 2?

See the reasoning

No. Subtract counts of all proper multiples of 2, each already made exact by processing larger gcds first.

How a tree turns gcd into a component count
  1. Take a three-vertex path labeled 6, 10, 15. To count paths with gcd divisible by 2, keep only vertices divisible by 2. The first two remain connected.
  2. A connected group of two vertices supplies three undirected paths, including the two one-vertex paths. More generally a group of s vertices gives s(s+1)/2. The original graph is a tree, so each endpoint pair has one path.
  3. Those three paths have gcds 6, 10 and 2. To obtain the count for exactly 2, subtract the already-known counts for proper multiples of 2. This leaves the single path 6–10. Compute larger gcds first.
