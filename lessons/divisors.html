‹ Algebraic and counting DP

A divisor lattice is another DP order

Among 2,4,6, how many pairs have gcd exactly 2?

Work through the choice

Start with all pairs whose numbers are multiples of 2. Every such pair has gcd equal to 2 or a larger multiple. Compute exact answers in decreasing divisor order, subtracting proper multiples already counted.

The rule you can reuse

If objects extend by divisibility, iterate multiples instead of every pair. If all valid gcds divide a known divisor, invert “gcd divisible by d” counts from larger multiples to smaller d.

E(d)=(mult(d)k)−∑j≥2E(jd)E(d)=\binom{\mathrm{mult}(d)}{k}-\sum_{j\ge2}E(jd)E(d)=(kmult(d)​)−j≥2∑​E(jd)

For subsequences of k values with gcd exactly d, let mult[d] count inputs divisible by d. exact[d]=choose(mult[d],k)−Σ_{j≥2}exact[jd].

Check the boundary. Zero is divisible by every positive d, so handle it explicitly if admitted. For divisor-chain DP update from a previous length layer if a chain must contain exactly k positions.

Cost O(A log A) divisor/multiple visits up to maximum A plus binomial queries. Factor and enumerate only actual divisors when A is huge.

From idea to code

  • Factorization and divisors
    Enumerate divisors to index a small state space. Exact gcd counts require subtracting proper multiples from all-multiples counts. Use overflow-safe multiplication when growing an LCM.
  • Binomial coefficients and modular arithmetic
    Use modular binomial coefficients for independent choices and unrestricted grid paths. Check that the modulus and factorial range make the inverses used by the template valid.
