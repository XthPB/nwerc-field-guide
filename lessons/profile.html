Cross a narrow boundary · Lesson 143 of 235

A narrow frontier remembers occupied cells

Fill every cell of a 2 × 3 board using dominoes that each cover two neighboring cells. A domino may be horizontal or vertical, and tiles cannot overlap. Count distinct complete tilings. A horizontal tile can extend into the next column while you are still filling this one.

1. Work one example

A horizontal domino placed here occupies a square in the next column. Record those protrusions as bits. Fully filling a column produces a new mask, and the last column must leave the empty mask.

2. What do we need to remember?

Once a column is finished, its only effect on the future is the mask of cells already occupied in the next column.

3. How do we get the next answer?

Sweep a long thin board. Once a column is fully covered, the future sees only which cells in the next column already belong to horizontal dominoes. Generate the next mask by filling the first empty cell.

For incoming mask m, either place a vertical domino on two adjacent free rows, or cover one row horizontally and set that bit in outgoing mask. Add ways[m] to every resulting mask.

Check the boundary. Account for blocked cells on both sides of a crossing. Two placements producing the same next mask must retain their multiplicity in counting variants.

Cost Let E be the number of valid mask transitions, width L and height h. O(LE) after preprocessing, O(2ʰ) DP cells, plus stored transitions.

Try one change

A horizontal domino protrudes from the previous column into the current column's top cell. What bit must the incoming mask carry?

See the reasoning

The top-cell bit is set. Treat it as already occupied so the next tiling move cannot cover that cell again.

  • Enumerate submasks
    The loop visits every nonempty submask. Add the empty option separately if it is legal. Enumerating submasks for every mask costs three to the power n across all masks.

    Color every cell of a two-row grid black or white. Side-sharing cells of the same color belong to the same connected region. How many colorings produce exactly k regions?

    Expose two cells per column. The old and new two-bit colour profiles determine how many connected components the new column creates or joins. Index the second axis by the current component count.

    You have an 8-by-8 board and a given stock of five tetromino shapes. Find a way to cover the board using the pieces, allowing rotations and reflections and forbidding overlaps.

    Statement-derived modelling exercise. Filling the first uncovered square canonically avoids generating all placement orders. A memoized frontier also needs the remaining stock of each shape.
