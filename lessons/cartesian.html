‹ Combining and compressing techniques

Make a range minimum or maximum the root

Paint boards of heights 2,1,2 with horizontal or vertical strokes. Which subproblems appear after a shared horizontal stroke?

Work through the choice

Paint to the shortest board. That board ends here and splits the remaining work into independent pieces. A Cartesian tree stores this repeated choice of range minimum so you can solve each resulting region once.

The rule you can reuse

If an operation on an interval is determined by the position of its extreme value, fixing that extreme splits it into left and right ranges. A Cartesian tree makes all such recursive splits available in one structure.

For fence painting, compare painting every board vertically against adding minHeight−base horizontal strokes and recursively painting both residual sides above minHeight.

Check the boundary. Fix ties consistently when constructing the tree. A recursive linear scan for the minimum at each call is quadratic on a sorted array. Equal-height nodes should not charge an extra height difference.

Cost O(n) construction by monotone stack and O(n) postorder combination for this recurrence. RMQ yields an alternative O(n log n) construction.
