Carry a convex piecewise-linear cost function

Adjust 5,1,2 to a nondecreasing sequence at minimum total absolute change. How can you avoid a table indexed by all possible adjusted values?

Work through the choice

Think of the best prefix cost as a function of its final value. Its slopes change only at a few breakpoints. A heap maintains these breakpoints and records the price of correcting a downward jump.

The rule you can reuse

If a numeric state ranges up to 10⁹, try representing its entire convex DP function by its slope-change points. Adding an absolute-value penalty inserts kinks. Prefix minima flatten the increasing side.

For L¹ nondecreasing fitting, Fᵢ(x)=|x−aᵢ|+min_{y≤x}Fᵢ₋₁(y). A max-heap specialization pushes aᵢ, then if its top exceeds aᵢ add top−aᵢ to cost, replace the top by aᵢ.

Check the boundary. A heap holds breakpoints; its values need not be the fitted sequence. Generic slope trick often needs two heaps and lazy shifts. Arbitrary nonconvex penalties invalidate the representation.

Cost O(n log n) time and O(n) space for L¹ isotonic fitting. Bounded step sizes move whole breakpoint ranges and need the appropriate lazy shifts.

From idea to code

  • Convex breakpoints for nondecreasing fits
    Use the maximum heap to repair the upper breakpoint when a new value undercuts it. The returned cost is for absolute error with a nondecreasing fitted sequence.

    Each new observation bends the convex cost of fitting a nondecreasing prefix in absolute distance. A max-heap retains the breakpoints, and reducing a too-high breakpoint adds exactly its displacement to the cost.
