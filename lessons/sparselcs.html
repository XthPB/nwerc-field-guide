‹ Strings and alignment

Only matching pairs can improve LCS

Find the common subsequence length of ab and aab. Can you visit only pairs of matching letters?

Work through the choice

For each letter in the first string list its matching positions in the second. A strictly increasing chain of positions spells a valid subsequence. List positions for one source letter backwards so that a chain can use it just once.

The rule you can reuse

If equal-character pairs are sparse, turn each potential match (i,j) into a point. A common subsequence is exactly a chain increasing in both coordinates. This turns a dense alignment into a sparse LIS problem.

LCS⁡(A,B)=LIS⁡(concatenated descending match lists)\operatorname{LCS}(A,B)=\operatorname{LIS}(\text{concatenated descending match lists})LCS(A,B)=LIS(concatenated descending match lists)

For each character in A, list its positions in B from largest to smallest and concatenate the lists. Find strict LIS on the resulting positions.

Check the boundary. A repeated letter in both strings can produce Θ(nm) matches. For small alphabets and dense matches, a packed bit-vector LCS or a dense row may win.

Cost O((n+m)+r log m) for r matches with position lists. For two permutations, r=n and the reduction is especially clean.

From idea to code

  • Strict longest increasing subsequence
    The lower_bound version finds a strictly increasing chain. Equal values can extend a nondecreasing chain when you switch to upper_bound. The returned number is a length.
  • Longest common subsequence and interval order
    The sheet gives the LCS recurrence and interval iteration order as notes. For an LCS witness store a parent choice or compute forward and backward rows for a recursive split.
