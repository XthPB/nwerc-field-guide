Follow a prefix · Lesson 6 of 235

Kadane’s algorithm and the best subarray ending here

Choose one nonempty stretch of −3, 4, −1, 2, −5 to earn as many points as possible. When you reach 2, which earlier choice still matters?

1. Work one example

Any stretch ending at today’s element either starts today or extends a stretch that ended yesterday. Every possible extension gains the same new value, so only yesterday’s best ending score matters. Separately remember the best ending score seen anywhere. It can remain the answer after a bad final element.

2. What do we need to remember?

Ask for the best nonempty stretch ending exactly here. Either it starts here or it extends yesterday’s stretch.

3. How do we get the next answer?

Ei=ai+max⁡(0,Ei−1)E_i=a_i+\max(0,E_{i-1})Ei​=ai​+max(0,Ei−1​)

E is the best nonempty sum ending exactly here. Initialize it to the first value. When a problem requires changing one segment, score each element by the gain from changing it and add the best segment gain to the original score.

Check the boundary. An all-negative input still needs a winner. On −4, −2 the answer is −2. When an empty operation is explicitly legal, taking zero overall gain is an additional option. Length bounds change the valid start points and call for a restricted prefix minimum.

Cost O(n) time and O(1) extra space. Save the restart index and the winning endpoints when you need a witness.

From idea to code

  • Kadane’s algorithm for one nonempty subarray
    Pass the gain at each position. The largest nonempty sum still works when every entry is negative. To allow an empty choice, compare the final return value with zero.
  • Prefix sums with an empty prefix
    Use the difference of two boundaries for an interval sum. For counts up to a price, first build a histogram that retains duplicates, then use this same prefix function.
See the idea in contest problems
  • CF 327A · Flipping Game 1200

    Represent flipping a zero as gain +1 and a one as gain −1. Add the best nonempty segment gain to the initial number of ones. A mandatory move on all ones loses one, so a zero-initialized global maximum gives the wrong answer.
