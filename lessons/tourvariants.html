A route can stop, return, visit only terminals, or respect prerequisites

A courier may need to return to the depot, stop at the last delivery, or deliver A before B. Which parts of a tour DP change?

Work through the choice

Fix what counts as a complete route before coding. A closed tour adds a final edge. A fixed destination filters endpoints. A prerequisite filters the move into B. The same visited-set and endpoint table supports all three.

The rule you can reuse

For the traveling salesman problem (TSP), start from the required output. For a fixed start s and required set R, a Held–Karp state (M,v) fixes both the visited required objects and the current location. How the walk ends and what can happen between required objects determine the base graph and final readout.

open=min⁡vD(R,v),closed=min⁡v(D(R,v)+w(v,s))\mathrm{open}=\min_v D(R,v),\qquad \mathrm{closed}=\min_v(D(R,v)+w(v,s))open=vmin​D(R,v),closed=vmin​(D(R,v)+w(v,s))

For an open path take minᵥD[R,v]. For a tour take minᵥ(D[R,v]+w(v,s)). To add j with prerequisite mask Pⱼ, require Pⱼ⊆M. For a small set of stops in a larger nonnegative graph, compute shortest distances between those stops first if arbitrary travel through intermediate vertices is legal.

Check the boundary. Metric closure permits the path between two stops to pass through others. It is sound for an unrestricted walk visiting each required vertex at least once. If encounters consume resources, prerequisites apply on physical first arrival, or every original vertex is usable at most once, the closure can destroy feasibility.

Cost For k stops, O(k²2ᵏ) DP time, O(k2ᵏ) cells. Add the cost of k shortest-path runs for metric closure. Save the preceding stop and underlying route for a full witness.

From idea to code

  • Held–Karp path or closed tour
    Set the start city to zero. The two switches in the calling convention are the distance matrix and whether the last edge must return to the depot. For a fixed finishing city read that one endpoint.
  • Dijkstra on an expanded graph
    First define what constitutes a vertex of the state graph. Construct an edge for each legal transition. All weights used by Dijkstra must be nonnegative.
