Measure a random process · Lesson 125 of 235

A random walk can have an acyclic direction and a cyclic row

A walker can move sideways within a row or down to an already solved row. How can you find its expected remaining time?

1. Work one example

Solve rows bottom-up. Sideways moves still couple neighbours in the same row, so write a small linear system for that row. Each equation touches at most two adjacent unknowns, which allows tridiagonal elimination.

2. What do we need to remember?

Horizontal moves may return to a neighboring cell in the same row. Solve that coupled row before passing values upward.

3. How do we get the next answer?

Suppose the allowed moves are stay, left, right and down when available, chosen equiprobably. The bottom row absorbs. A row depends on the row below and on its horizontal neighbours, so each row is one small linear system.

(k+1)Ej−∑h∼jhorizontalEh=k+2+Ebelow,j(k+1)E_j-\sum_{h\sim j}^{\text{horizontal}}E_h=k+2+E_{{\rm below},j}(k+1)Ej​−h∼j∑horizontal​Eh​=k+2+Ebelow,j​

Let j have k horizontal neighbours. Multiplying its first-step equation by k+2 and moving the stay term gives (k+1)Eⱼ−Σ horizontal Eₕ=(k+2)+Ebelow,ⱼ. The system is tridiagonal and strictly diagonally dominant.

Check the boundary. Boundary columns have fewer legal choices. Defining an impossible move as a stay instead would change the probabilities. Evaluate rows bottom-up and eliminate across each row in both directions to recover all unknowns.

Cost O(HW) arithmetic with a tridiagonal solve per row and O(W) working memory. For arbitrary transition graphs, solve the appropriate communicating classes or system.
