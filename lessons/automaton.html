Carry the longest relevant suffix

Count length-three binary strings that never contain 11.

Work through the choice

When appending a bit, only one piece of the past can forbid it. Did the current word end in 1? Keep two counters. A zero extends either counter and a one extends only words that ended in zero or were empty.

The rule you can reuse

A forbidden substring can begin before the current step and end after it. Store the KMP matched-prefix length or an Aho–Corasick trie state for several patterns. For each appended symbol the next machine state summarizes all future matching behaviour.

Fi+1(δ(q,c))+=Fi(q)F_{i+1}(\delta(q,c))\mathrel{+}=F_i(q)Fi+1​(δ(q,c))+=Fi​(q)

f[pos+1,δ(q,c)] += f[pos,q] when δ(q,c) is allowed. Mark terminal states inherited along failure links. Add a hit flag or count to require occurrences.

Check the boundary. Resetting to 0 after a match loses overlapping occurrences. Build the failure transition first. If rotations are considered identical, this automaton counts linear words.

Cost O(n·states·alphabet) after transition preprocessing. For huge n and stationary transitions, exponentiate the transfer matrix.

From idea to code

  • Aho–Corasick automaton
    Use automaton nodes as suffix states. Propagate forbidden or matching outputs through failure links before the DP. For a single short pattern a prefix-function automaton often suffices.
  • Two-state DP with rolling layers
    Track the best score when the preceding house was skipped or taken. Each step reads the old pair. Adapt it by naming the histories a future move can distinguish.
