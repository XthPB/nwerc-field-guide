Measure a random process · Lesson 124 of 235

Change the objective by tracking its incremental expected reward

Score each run of successes by its squared length. How do you find the average score as trials arrive?

1. Work one example

Extending a run from length L to L+1 raises its score by 2L+1. Track the expected length of the current trailing run and add the expected increment on each success. A failure resets the trailing length.

2. What do we need to remember?

The next success can extend a run already in progress. Track the run-length moments that occur when its reward is expanded.

3. How do we get the next answer?

When each maximal success run of length L scores L², appending a success to the current run of length X adds 2X+1. A failed attempt starts a fresh run. The expected incremental score needs only the mean current run length.

Ai=Ai−1+pi(2mi−1+1),mi=pi(mi−1+1)A_i=A_{i-1}+p_i(2m_{i-1}+1),\qquad m_i=p_i(m_{i-1}+1)Ai​=Ai−1​+pi​(2mi−1​+1),mi​=pi​(mi−1​+1)

For independent success probability pᵢ use score←score+pᵢ(2m+1), then m←pᵢ(m+1). Initialize score=m=0 and use the old m for both updates.

Check the boundary. E[X_final²] only scores the last run and is a different output. A polynomial score of degree d generally needs moments through degree d−1 for the incremental update. If p depends on X, conditioning changes the required statistics.

Cost O(n) time and O(1) memory for square scoring. The method generalizes to expected changes in inversions, completed groups, and additive events.
