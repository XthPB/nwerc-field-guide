‹ Bitmasks and subset transforms

Choose a set and its endpoint · Lesson 74 of 235

An exact set can determine the step number

There are as many jobs as workers. Each worker must get one job they can do, and no two workers may share a job. If the first worker can do x or y and the second can do only y, how many complete assignments are possible?

1. Work one example

Once the used jobs are known, their number tells you which worker acts next. Taking y first leaves no legal job for the second worker. The set of job identities is what makes that dead end visible.

2. What do we need to remember?

The used-job mask tells you how many workers have already been assigned, so the next worker is known.

3. How do we get the next answer?

If exactly one new job is assigned per worker, the used-job mask determines which worker comes next. Keep only the mask. Sum over the last job for counting, minimize for cost.

F(M∪{j})+=F(M),i=∣M∣F(M\cup\{j\})\mathrel{+}=F(M),\qquad i=\lvert M\rvertF(M∪{j})+=F(M),i=∣M∣

F[0]=1. For mask M and next worker i=popcount(M), add F[M] to F[M∪{j}] for every compatible unused job j.

Check the boundary. If workers can be skipped, popcount no longer determines i. Counting perfect matchings is exponential here, while finding one feasible assignment in a bipartite graph has polynomial algorithms.

Cost O(n2ⁿ) time and O(2ⁿ) memory.

Try one change

Three jobs are marked used in a mask. Workers are assigned in fixed order. How do you know who goes next?

See the reasoning

The fourth worker goes next. Every transition assigns exactly one worker and adds one job, so the mask's number of set bits determines the stage.
