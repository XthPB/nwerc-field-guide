Follow tight bounds digit by digit · Lesson 108 of 235

Count bounded numbers avoiding a digit pattern

Count integers between 10 and 25 inclusive whose decimal writing does not contain 12 as consecutive digits. A number can be inside the allowed range yet fail the pattern condition, so the construction must enforce both.

1. Work one example

After a real digit 1, appending 2 would complete the forbidden pattern. In a longer pattern, store the longest suffix that is also a prefix of a forbidden word. The automaton accounts for overlaps automatically.

2. What do we need to remember?

A digit can obey the numerical bound yet complete a forbidden pattern. Carry the pattern state alongside the tight flags.

3. How do we get the next answer?

D[i+1,t′,q′]+=D[i,t,q],q′=δ(q,d)D[i+1,t',q']\mathrel{+}=D[i,t,q],\qquad q'=\delta(q,d)D[i+1,t′,q′]+=D[i,t,q],q′=δ(q,d)

Build transitions for every automaton state and digit. Skip forbidden destination states. Cross the automaton state with tight and started flags if ordinary numerical representations are required.

Check the boundary. Leading padding should not feed a pattern automaton unless it is part of the alphabetic object. For several patterns, a failure link may also identify a forbidden suffix.

Cost O(10·digits·states) after constructing the automaton.

Try one change

Under a numeric bound, a prefix ends in 1 and pattern 13 is forbidden. What must happen if you try digit 3?

See the reasoning

Reject that transition even if 3 fits the bound. The numerical constraint and the suffix-pattern constraint must both allow the digit.

From idea to code

  • Aho–Corasick automaton
    Use automaton nodes as suffix states. Propagate forbidden or matching outputs through failure links before the DP. For a single short pattern a prefix-function automaton often suffices.
  • Digit DP on a numerical bound
    The sheet memoizes loose prefixes for a fixed digit sum. Replace sum with the required automaton and add a started flag when padded zeros have different meaning. The public copy removes a stray character after the negative-bound return.
