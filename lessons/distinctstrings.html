Track more than the last character · Lesson 136 of 235

Different subsequences, next occurrences, and ranking

You can delete any positions of the string aa, keeping the order of the remaining letters. Count different resulting strings, including the empty one. Deleting the first a or deleting the second a produces the same one-letter result.

1. Work one example

Choosing the first a or the second a creates the same one-letter word. To build each answer once, represent its next letter by its earliest available occurrence. The remaining suffix is then determined.

2. What do we need to remember?

When two choices start with the same character, use its earliest possible occurrence. It leaves room for every continuation of the later choice.

3. How do we get the next answer?

Counting embeddings and counting distinct strings are different tasks. For a distinct subsequence, assign its first character to the earliest possible occurrence after the current position. The resulting branches have disjoint first characters.

Check the boundary. For total count in a streaming recurrence use Tᵢ=2Tᵢ₋₁−T[last(c)−1] if c appeared before, with 1-based positions and T₀=1. Avoid negative modular results.

Cost O(n·alphabet) with a next table for unrestricted length; exact-length states add a factor K. Subtract the empty answer only at the end.

Try one change

In AAB, why is it safe to use the first A when constructing distinct subsequence strings starting with A?

See the reasoning

The suffix after the first A includes every continuation possible after the second. Choosing earliest avoids counting the same spelling through different embeddings.
