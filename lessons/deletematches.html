‹ Interval and partition DP

Split, merge, or temporarily omit · Lesson 201 of 235

Count deletion orders by interleaving independent regions

In one move delete two adjacent equal letters and close the gap. Starting with aaaa, count different complete move sequences that erase the entire string. Two sequences differ if they remove different original position pairs or remove the pairs in a different order.

1. Work one example

Fix which original position pairs with the first letter. Everything between those two must disappear before that pair can be removed. The suffix can act before, between or after the moves on the left, preserving the internal order of each region.

2. What do we need to remember?

A matching pair can disappear only after the material between it has gone. Counting deletion orders also requires interleaving independent moves.

3. How do we get the next answer?

Use only k for which both remaining intervals have even length. The block through k contains (k−l+1)/2 moves, with the boundary pair last inside this block. Choose its time slots among all moves. An empty interval contributes one.

Check the boundary. The combinatorial factor counts orderings of moves. If the task asks only which pairs were formed, the extra binomial factor overcounts.

Cost O(n³) time and O(n²) interval and binomial tables.

Try one change

Two independent regions need two moves and one move, respectively. How many ways interleave those moves while preserving both orders?

See the reasoning

Three. Choose which of the three slots holds the single move. Multiplying the two internal counts alone would miss these interleavings.
