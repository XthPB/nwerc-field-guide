Find the k-th value between two array positions

Find the second-smallest value in positions 2 through 4 of 5,1,5,2.

Work through the choice

Build a frequency tree for every prefix, sharing unchanged nodes. Subtract the two prefix counts in the left value half to decide where the requested rank lies. Continue in that half with the adjusted rank.

An old version

Only the original prefix exists. Its two children contain the counts for low and high ranks. Both counts are zero.

Insert a high-ranked item

Create a new root and a new high-rank child. The unchanged low-rank child is shared. The old root still points at the old high count of zero.

Read the difference

In the high half, the new count is 1 and the old count is 0. Their difference says this insertion contributes one high-ranked value. For k-th queries, repeat the same count comparison down the tree.

The rule you can reuse

Maintain a persistent frequency tree on compressed values. Version r contains exactly the first r events. When DP asks for a median, rank, or count inside an index interval, descend simultaneously in the two roots bracketing the interval.

L=cnt(left(rootr))−cnt(left(rootl−1))L=\mathrm{cnt}(\mathrm{left}(\mathrm{root}_r))-\mathrm{cnt}(\mathrm{left}(\mathrm{root}_{l-1}))L=cnt(left(rootr​))−cnt(left(rootl−1​))

For a 1-based slice [l,r] take roots r and l−1. At each node the left count difference is the number in the slice going left. For a 1-based k-th, descend left if k≤that difference, otherwise subtract it and descend right.

Check the boundary. Frequency differences are valid because the earlier prefix multiset is contained in the later one. Subtracting prefix minima or two unrelated branches has no analogous meaning. For a sum of absolute deviations also store subtree sums and split at the median.

Cost Build O(n log U) copied nodes on U value ranks. Queries cost O(log U). Multiply by the number of DP transitions using that interval-cost oracle before accepting the total.
