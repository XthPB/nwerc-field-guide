‹ Knapsack and subset sum

Choose objects once or many times · Lesson 16 of 235

Retrieve the selected items from a compressed sum table

A bag must weigh exactly 5 and the items weigh 2, 3 and 3. Each can be used once. You must return the indices of one valid selection, so you need to recover which physical items made the total after computing reachability.

1. Work one example

When a sum first appears, save which item created it and its preceding sum. Each parent leads back to an earlier item. Reading this chain backwards supplies real indices even when two weights are equal.

2. What do we need to remember?

When a sum becomes reachable, save the actual item and the earlier sum that made it happen.

3. How do we get the next answer?

For Boolean one-use sums, record an immutable parent only the first time a sum appears. Its predecessor was reachable using earlier items. For optimal weighted knapsack use per-layer decisions, divide-and-recompute, or immutable history nodes.

fresh=(B≪w)AND(NOTB)\mathrm{fresh}=(B\ll w)\mathbin{\mathrm{AND}}(\mathop{\mathrm{NOT}}B)fresh=(B≪w)AND(NOTB)

fresh = (old ≪ w) AND NOT old. For each newly set sum s, save parent[s]=(s−w,item). Stop tracing at 0.

Check the boundary. A flat mutable parent on every value improvement can point into a newer layer and reuse the same item. Parent-at-first-discovery is for monotone reachability.

Cost O(W) parent records. Efficient enumeration of fresh set bits costs O(W) individual discoveries over all items, plus bitset scans.

Save that item's identity and previous total 3. Following the predecessor for 3 continues the reconstruction down to zero.

From idea to code

  • Bitset subset sum
    Set only bit zero at the start. A shifted copy represents taking one item. OR retains the outcomes of skipping it. Choose MAXS large enough for the actual largest queried sum.
  • 0/1 knapsack
    Use the descending capacity loop for one-use items. The initial zeros in this implementation mean “at most this capacity.” For exact weight, mark initially unreachable cells before the first update.
