Keep only reachable descriptions · Lesson 196 of 235

Index by moves when the answer is smaller than the search space

Two test eggs and three drops are available. What is the largest building in which you can identify the highest safe floor?

1. Work one example

Choose a test floor. If the egg breaks, the remaining lower floors must be searchable with one fewer egg and one fewer move. If it survives, the upper floors allow the same eggs and one fewer move. Add both coverages and the tested floor.

2. What do we need to remember?

For a given number of moves and eggs, ask how many floors you can distinguish. The answer splits at the floor of your next drop.

3. How do we get the next answer?

F[m,e]=1+F[m−1,e−1]+F[m−1,e]F[m,e]=1+F[m-1,e-1]+F[m-1,e]F[m,e]=1+F[m−1,e−1]+F[m−1,e]

Start with zero coverage for zero moves or zero eggs. Increase moves until the coverage reaches the building height. Capping coverage at the target also keeps addition safe when implemented with overflow checks.

Check the boundary. When using one row, update eggs in descending order so both predecessors still represent the previous move count.

Cost O(eggs × answer) time and O(eggs) space.

Try one change

With one egg and three drops, how many floors can be distinguished as safe or unsafe by threshold?

See the reasoning

Three floors can be tested in order. With more eggs the first drop splits the remaining work into break and survive cases.
