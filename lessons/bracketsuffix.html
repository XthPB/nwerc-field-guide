Track more than the last character · Lesson 135 of 235

Jump over a balanced suffix to find its opening bracket

You’re given a string of parentheses. For each position find the length of the longest balanced substring ending exactly there. In ()(()), the last closing bracket completes the whole six-character string, including the earlier pair ().

1. Work one example

At a closing bracket, jump left over the longest balanced suffix ending one position earlier. Its brackets already match each other. The character immediately before that suffix is the only one that can open a longer block ending here. If it is an opening bracket, wrap the suffix in the new pair and attach any balanced suffix immediately to its left.

2. What do we need to remember?

A balanced suffix can be jumped over in one step to test whether an earlier opening matches the current close.

3. How do we get the next answer?

Use one-based positions and L₀ = 0. The displayed update applies only when position i closes, j ≥ 1 and position j opens. Otherwise Lᵢ is zero. Each endpoint with the global positive maximum identifies one occurrence.

Check the boundary. A suffix ending at an opening bracket has length zero. Check j before accessing it. Codeforces 5C asks for 0 1 when there is no positive-length match. A length by itself cannot record the types of several different unmatched opening brackets.

Cost O(n) time and O(n) memory. A stack of positions gives another linear solution and can return matching pairs directly.
