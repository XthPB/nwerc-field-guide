Only four witnesses determine a geometric score

Pick points to retain while balancing bounding-box perimeter against the price of retaining each point. How many points actually determine the perimeter?

Work through the choice

The four sides need witnesses for minimum and maximum x and y. A point may witness several sides, and you pay for that point only once. A mask of the four assigned roles keeps this distinction while other points are processed.

The rule you can reuse

The bounding-box perimeter is 2(max x−min x+max y−min y). If retaining a point forfeits a nonnegative removal reward, some optimum retains only witnesses for these four extrema. A point can witness several roles and its forfeited reward is charged once.

perimeter⁡=2(max⁡x−min⁡x+max⁡y−min⁡y)\operatorname{perimeter}=2(\max x-\min x+\max y-\min y)perimeter=2(maxx−minx+maxy−miny)

Start with all removal rewards. For each point, assign it a nonempty subset of unfilled roles. Add their signed coordinate contributions (+2x,−2x,+2y,−2y) and subtract its removal reward once. Maximize over full masks.

Check the boundary. Arbitrary role labels need not be true extrema, but their signed score never exceeds the actual retained perimeter. Some assignment chooses the true extrema, proving equality at the maximum. Negative removal rewards would allow profitable extra nonwitness points.

Cost O(n·3⁴) transitions and 16 cells per layer. CF 2169E, rated 2400.

From idea to code

  • Enumerate submasks
    The loop visits every nonempty submask. Add the empty option separately if it is legal. Enumerating submasks for every mask costs three to the power n across all masks.
  • Exact integer geometry
    Use dot and cross products for structural tests. For route costs use the distance definition required by the problem and a sufficiently wide type. Exact squared distance and Euclidean length may give different optima.
