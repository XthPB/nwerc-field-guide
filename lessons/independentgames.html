Choose while the future is uncertain · Lesson 132 of 235

When one move splits a game in two

On a turn a player chooses one pile and splits it into two unequal, nonempty piles. All resulting piles stay in play, and a player unable to split any pile loses. Starting with a pile of five, determine whether the first player has a winning move.

1. Work one example

After a split either remaining pile can be played independently. XOR their Grundy values to get the successor's value. The pile before choosing a split receives the mex of all those successor values.

2. What do we need to remember?

When one move splits a game into independent components, combine their Grundy values with XOR before taking the smallest missing value.

3. How do we get the next answer?

g(n)=mex⁡{g(a)⊕g(n−a):1≤a<n−a}g(n)=\operatorname{mex}\{g(a)\mathbin{\oplus}g(n-a):1\le a<n-a\}g(n)=mex{g(a)⊕g(n−a):1≤a<n−a}

Process n in increasing order. Compute successor XORs before taking mex. If the whole input already contains multiple independent piles, XOR their finished values.

Check the boundary. This calculation requires finite impartial normal play. If a rule couples the two child piles, their Grundy numbers no longer combine independently.

Cost O(n²) elementary precomputation up to n. For enormous n a new proof or a verified stronger property is needed.

Try one change

A move leaves two independent normal-play games with Grundy values 3 and 3. What is the combined value?

See the reasoning

Zero, because 3 XOR 3 is zero. Apply this only when a move acts on exactly one independent component.

A losing Nim position becomes a subset problem
  1. Take four piles of sizes 1, 2, 3, 3. A nonempty collection is losing for the next player precisely when its XOR is zero. Removing as many piles as possible now means keeping as few as possible with XOR zero.
  2. Among the first three piles, 1 XOR 2 XOR 3 = 0 requires all three. Once the second 3 arrives, the two 3s alone work. A yes/no flag for XOR zero cannot distinguish these costs.
  3. For a small alphabet keep a minimum nonempty size and its number of witnesses for each XOR. Read the old row, add the singleton separately, and compare skipping with extending a previous nonempty choice. The contest also has many interval queries, so their frequencies must be recovered efficiently.

From idea to code

  • Grundy values on a finite game
    Use mex for a finite impartial normal-play game and XOR for its independent disjoint components. Weighted score games need minimax, while cyclic games may also have draws.
