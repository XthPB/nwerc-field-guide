Ask the same tree question everywhere · Lesson 99 of 235

Answer a subtree query after changing the root

Each vertex has a value. The tree is stored with root 1, but a query names a temporary root r and a vertex u. Return the sum of the values below u, including u, when parent and child relationships are interpreted from r.

1. Work one example

If r is outside u's ordinary subtree, the subtree of u stays the same. If r is inside it, one neighbour of u becomes its new parent. Remove that neighbour's whole ordinary subtree from the tree total. When r equals u, the answer is the entire tree.

2. What do we need to remember?

Changing the root can turn a requested subtree into the complement of one branch. Use ancestry and one jump to identify that branch.

Flatten the tree using entry and exit times. Binary lifting from r finds the child c immediately below u. A Fenwick or segment tree stores ordinary subtree sums and supports point updates.

Check the boundary. Subtraction requires an invertible aggregate such as sum. For a maximum over a subtree complement, query up to two disjoint Euler intervals and combine their maxima.

Cost O(n log n) preprocessing, O(log n) per query with updates.

Try one change

The new root is inside the old subtree of v, below child c. What becomes v's new subtree?

See the reasoning

Everything except the old subtree of c. Removing edge v–c shows which side of v now points toward the root.

From idea to code

  • Lowest common ancestors
    Use the common ancestor to compute tree distances or compress marked paths. A virtual tree also needs traversal order and ancestor tests.
  • Fenwick tree
    The original update sets a value and corrects the old contribution. For monotone prefix maxima implement point chmax and prefix max. A prefix maximum cannot be subtracted from another maximum.
  • Bottom-up segment tree
    The original combine is addition over a half-open interval. For a min, max, witness or matrix payload, update the stored type, combine and empty identity together. Preserve combination order for matrices.

    A rooted tree supports changing the root, adding to the smallest rooted subtree containing two specified vertices, and asking for the sum in a rooted subtree. Answer the queries under the current root.

    Under the current root, the common ancestor of two vertices is the deepest of the three pairwise fixed-root LCAs involving those vertices and the current root. Use that vertex for the subtree addition. Ordinary subtrees and their complements map to one or two Euler ranges.
