Cross a narrow boundary · Lesson 146 of 235

Replace a narrow strip by a small separator

Choose a maximum independent set in a graph built from small overlapping bags of vertices.

1. Work one example

Once two regions meet only at a small bag, the rest of one region cannot see individual choices deep inside the other. Remember which bag vertices were selected and combine only consistent boundary assignments.

2. What do we need to remember?

A bag is the small interface between the processed graph and the rest. Cover every legal assignment on that interface.

3. How do we get the next answer?

On a graph with a supplied tree decomposition, a bag separates processed vertices from the rest. Store the choice at each bag vertex and whatever connectivity information crosses it. Introduce, forget and join bags change the interface locally.

Fjoin(S)=FL(S)FR(S)F_{\rm join}(S)=F_L(S)F_R(S)Fjoin​(S)=FL​(S)FR​(S)

For independent-set counting, a bag state S must be independent. At a forget(v) node add child counts for v absent/present. At a join multiply counts for the same boundary assignment.

Check the boundary. At joins avoid double-charging a selected bag vertex’s weight. Connectivity problems need partitions as well as subsets. Finding a good decomposition may itself be difficult.

Cost For independent sets on a given nice decomposition with bag size w+1, O(number of bags × 2^(w+1) × poly(w)).

Try one change

After a graph vertex is forgotten by a decomposition bag, may a future edge still depend on its unrecorded assignment?

See the reasoning

Only if that influence has already been accounted for. Process all constraints involving the vertex before forgetting it.

From idea to code

  • Enumerate submasks
    The loop visits every nonempty submask. Add the empty option separately if it is legal. Enumerating submasks for every mask costs three to the power n across all masks.
  • Rooted tree DP and rerooting
    Use reverse traversal for bottom-up child messages. Use forward traversal for the parent contribution. Derive a new message when the objective differs from distance or subtree size.
