Track more than the last character · Lesson 140 of 235

Rank distinct substrings by counting paths in a suffix automaton

List every different nonempty contiguous substring of aba once and sort the list in dictionary order, with a shorter prefix first. Return the fourth entry. On a long string you need to find the requested entry without materializing the full list.

1. Work one example

From the initial state of a suffix automaton, each path spells a different substring. Count all continuations from each state in reverse maximum-length order. Each outgoing character owns a contiguous block of answers in sorted order.

2. What do we need to remember?

Count how many strings each suffix-automaton state can generate. Ordered outgoing letters then let you skip entire blocks.

The one counts stopping at this state. Exclude the empty path at the root for nonempty queries. Sort outgoing labels. Skip their block sizes or consume one rank when you choose a label.

Check the boundary. When repeated occurrences of a substring count separately, the terminal contribution needs occurrence counts. A suffix link is different from a character transition.

Cost O(states+edges) counting after construction. Reconstruction depends on the alphabet representation and output length.

Try one change

Three distinct continuations start with A and five with B. Why can a rank query skip all three A continuations at once?

See the reasoning

They form a contiguous lexicographic block. Follow ordered transitions and subtract whole block sizes, accounting for stopping at the current nonempty substring.

From idea to code

  • Suffix automaton for distinct substrings
    Append lowercase letters to build the automaton. Compute continuation counts in decreasing state length for rank queries or count distinct substrings from suffix-link lengths.
  • Topological order and DAG DP
    Use a verified acyclic order. Process every outgoing transition after its source is final. Counting merges by addition and longest paths by maximum.
