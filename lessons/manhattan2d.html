Make geometry part of the state · Lesson 189 of 235

Compute the cheapest Manhattan delivery to every grid cell

Several cells of an unobstructed rectangular grid offer a product at different prices. Delivery costs 1 per horizontal or vertical step. For every cell, find the smallest purchase price plus delivery cost among all sources. The cheapest source can differ from cell to cell.

1. Work one example

Manhattan distance is a horizontal distance plus a vertical distance. First run left-to-right and right-to-left minima within every source row. Then propagate the resulting prices up and down each column. These two one-dimensional minimizations compose exactly.

2. What do we need to remember?

A step to an adjacent cell costs one. Sweeps along rows and columns spread the cheapest source cost through a clear Manhattan grid.

3. How do we get the next answer?

G(r,c)=min⁡i(∣r−i∣+min⁡j(f(i,j)+∣c−j∣))G(r,c)=\min_i\left(\lvert r-i\rvert+\min_j(f(i,j)+\lvert c-j\rvert)\right)G(r,c)=imin​(∣r−i∣+jmin​(f(i,j)+∣c−j∣))

Initialize nonsources to infinity. During a sweep compare the current value with the preceding processed cell plus one. For distinct horizontal and vertical costs, use the corresponding cost for each sweep.

Check the boundary. Obstacles can invalidate the direct Manhattan path. With blocked cells and nonnegative edge costs use the appropriate graph shortest-path algorithm.

Cost O(HW) time and O(HW) for all output values.

Try one change

Six: base 2 plus Manhattan distance 4. A blocked route or nonuniform movement cost would invalidate this simple distance rule.

From idea to code

  • Two-state DP with rolling layers
    Track the best score when the preceding house was skipped or taken. Each step reads the old pair. Adapt it by naming the histories a future move can distinguish.
  • Dijkstra on an expanded graph
    First define what constitutes a vertex of the state graph. Construct an edge for each legal transition. All weights used by Dijkstra must be nonnegative.
