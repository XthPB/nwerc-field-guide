OR, AND, XOR, and subset convolution are different joins

Two independent choices each produce a small binary label. You know how many ways each side can produce each label. Count ordered pairs of choices by the XOR of their labels. In particular, how many pairs produce zero?

1. Work one example

For one-bit labels, zero comes from 0 with 0 or 1 with 1. The Walsh transform diagonalizes this combination, so long repeated updates become independent multiplications. Use a transform matching the actual bit operation.

2. What do we need to remember?

When two choices combine by XOR, use the XOR transform to multiply their distributions and then invert the transform.

3. How do we get the next answer?

Identify how indices combine. XOR convolution mixes all pairs with i XOR j=k. Walsh–Hadamard transforms diagonalize it. OR/AND convolution use subset/superset zeta and Möbius transforms. Disjoint union needs extra rank information.

(A∗⊕B)(s)=∑xA(x)B(s⊕x)(A*_{\oplus}B)(s)=\sum_x A(x)B(s\oplus x)(A∗⊕​B)(s)=x∑​A(x)B(s⊕x)

XOR butterfly (u,v)→(u+v,u−v). Transform both arrays, multiply pointwise, transform again and divide by N=2ᵇ when the arithmetic permits it.

Check the boundary. Division by N can fail modulo an even number. One exact remedy for products/powers of integer arrays is to work modulo N·p until the last transform, then divide the canonical residues by N to obtain answers mod p.

Cost O(b2ᵇ) per transform. Ranked subset convolution handles disjoint subset sums in O(b²2ᵇ) ring operations; min-plus does not inherit the same inversion.

Two masks are both 01. What do their union and their XOR produce?

From idea to code

  • Repeated XOR convolution
    The Walsh transform gives one scalar per frequency. The multiply-and-power part supports repeated updates with the same kernel. The inverse here uses a scaled modulus for exact integer division.
Worked C++17 implementation
// Length N is a power of two. Initial/kernel entries are in [0,p).
// Requires 2*N*p to fit signed 64 bits; uses GCC/Clang __int128 for products.
inline std::vector<i64> xor_steps(std::vector<i64> initial,
                                  std::vector<i64> kernel,
                                  std::uint64_t steps, i64 p) {
    const i64 n = static_cast<i64>(initial.size()), mod = n*p;
    auto transform = [=](std::vector<i64>& a) {
        for (i64 h=1; h<n; h*=2) {
            for (i64 block=0; block<n; block+=2*h) {
                for (i64 j=block; j<block+h; ++j) {
                    i64 u=a[j], v=a[j+h];
                    a[j]=(u+v)%mod;
                    a[j+h]=(u-v+mod)%mod;
                }
            }
        }
    };
    auto mul = [=](i64 x,i64 y) -> i64 {
        return static_cast<i64>(static_cast<__int128>(x)*y%mod);
    };
    transform(initial);
    transform(kernel);
    for (i64 i=0; i<n; ++i) {
        i64 base=kernel[i], power=1%mod;
        for (auto t=steps; t>0; t>>=1) {
            if (t&1) power=mul(power,base);
            base=mul(base,base);
        }
        initial[i]=mul(initial[i],power);
    }
    transform(initial);
    for (auto& value:initial) value/=n;
    return initial;
}
