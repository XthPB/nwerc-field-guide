Count a fixed pattern inside a stream

How many pairs of positions spell aa inside aaa?

Work through the choice

Keep counts of ways to match zero, one or two letters of the target. Each new a can finish a pair using an earlier single a. Update longer matched prefixes first so the same text letter cannot play both roles.

The rule you can reuse

Small target length lets you store how many embeddings have matched each prefix. Reading a matching symbol may advance one position or be ignored. Keeping the old counts handles the skip implicitly.

F(j)+=F(j−1)(j=m,m−1,…,1; Pj=x)F(j)\mathrel{+}=F(j-1)\qquad(j=m,m-1,\ldots,1;\ P_j=x)F(j)+=F(j−1)(j=m,m−1,…,1; Pj​=x)

ways[0]=1. On symbol x, for j=m down to 1 with pattern[j−1]=x, add ways[j−1] to ways[j].

Check the boundary. This counts distinct index sequences. To count distinct resulting strings use canonical next occurrences. For an alphabet of wildcards, account separately for the number of choices that skip.

Cost O(nm), O(m). If only a few target positions carry each letter, update their precomputed descending lists.
