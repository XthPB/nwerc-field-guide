One witness, all optima, and lexicographic rank

Produce the third binary word of length three containing exactly one 1, in dictionary order.

1. Work one example

Try 0 first. Two completions begin with it, so rank three skips that entire group. The answer begins with 1 and has only one completion. Counting suffixes lets you construct a witness without storing every word.

2. What do we need to remember?

Store the move that attained a value. Following saved moves backward turns that value into an actual answer.

3. How do we get the next answer?

If a question asks for actual decisions, record the predecessor when a cell improves. For a lexicographically smallest answer, suffix feasibility often gives a simpler tie proof. For a k-th answer, store completion counts.

At a prefix, try symbols in order. If k exceeds a branch count c, skip it and set k ← k−c; otherwise take it.

Check the boundary. A predecessor pointer into an overwritten knapsack row can describe an impossible chain. Store layer indices, immutable first-discovery parents for Boolean sums, or recompute.

Cost Traceback is one step per decision after preprocessing. Saturate counts at the requested rank if exact totals exceed machine integers.
