‹ Designing the state

Can I, how many, how good, and how many best?

Two different routes arrive with the same score of 4. How should your program describe that result?

Work through the choice

First decide what the judge asks you to print. For the highest score keep 4. For the number of best routes keep both a score and a count. A tied candidate adds a way, while a new record replaces the old ways.

The rule you can reuse

Write the meaning of a cell before choosing its type. Combining alternative paths uses OR, addition, minimum or maximum. Extending a path uses AND, multiplication or adding a cost. Independent child choices generally multiply counts.

(v,c1)⊕(v,c2)=(v,c1+c2)(v,c_1)\oplus(v,c_2)=(v,c_1+c_2)(v,c1​)⊕(v,c2​)=(v,c1​+c2​)

Best-with-count merge: keep the larger score; on equal scores add counts. Extension by reward w maps (v,c) to (v+w,c).

Check the boundary. Counting paths counts objects only if each object has one derivation. Two orderings of the same chosen set are often the same answer.

Cost Typically identical transition count across these objectives. A min-plus operation or a count with big integers has a different per-operation cost.

From idea to code

  • Merge optimal scores and counts
    Extend the winning score, sum tied counts modulo the modulus and preserve one witness. Combine disjoint sources so a path never counts itself twice.
