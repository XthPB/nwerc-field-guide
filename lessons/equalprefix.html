Follow a prefix · Lesson 9 of 235

Count previous prefixes with the missing sum

How many nonempty stretches of the digits 1, 2, 0, 1 have a digit sum equal to their length? Trying every pair of endpoints would take quadratic time.

1. Work one example

Subtract 1 from each digit. A good stretch now has sum zero, so the running total is the same at both of its boundaries. For each new right boundary, every earlier occurrence of its total supplies a different left boundary. A frequency table counts them in one lookup.

2. What do we need to remember?

Write the desired segment sum as the difference of two running totals. Count how many earlier totals supply the missing value.

3. How do we get the next answer?

Pr−Pl=T  ⟺  Pl=Pr−TP_r-P_l=T\iff P_l=P_r-TPr​−Pl​=T⟺Pl​=Pr​−T

Store frequencies to count intervals, the earliest index to maximize length, or the latest index to minimize positive length. To count partitions into valid pieces, store the sum of ways to reach earlier boundaries with each prefix total. Seed the empty prefix with one way.

Check the boundary. Look up before inserting the current prefix. When the target is zero, inserting first would count an empty stretch at every endpoint. Negative entries work because the test uses equality of prefix totals.

Cost O(n) expected time and O(n) space with hashing. Sorting and coordinate compression or an ordered map give deterministic O(n log n) time.

Try one change

The running sum is 11 and you want segments summing to 4. What do you look up?

See the reasoning

Look for earlier running sums equal to 7. Each occurrence gives a different starting boundary, since 11 minus 7 is 4.

From idea to code

  • Count subarrays of a given sum
    The frequency table starts with the empty prefix. Query before updating. For an average of one, first subtract one from every element and use target zero.
  • Prefix sums with an empty prefix
    Use the difference of two boundaries for an interval sum. For counts up to a price, first build a histogram that retains duplicates, then use this same prefix function.
