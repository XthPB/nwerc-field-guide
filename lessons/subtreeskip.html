Pass one message up a tree · Lesson 95 of 235

A prerequisite tree can become a linear jump DP

Items form a rooted tree of prerequisites. An item has a cost and a value, and taking it requires taking every ancestor on its path to the root. Under a fixed budget, choose a legal collection with maximum total value.

1. Work one example

List vertices in preorder. When you reject a vertex, every descendant becomes unavailable, and all of them sit in one consecutive block. Jump directly to the position after that subtree. Taking the vertex moves one place forward.

2. What do we need to remember?

A preorder listing makes a subtree consecutive. Skipping a node can become a single jump past all its descendants.

3. How do we get the next answer?

Every selected vertex requires all its ancestors. In a preorder listing, skipping a vertex forbids one contiguous subtree. Taking it unlocks the very next vertex in the listing. This structure can remove expensive budget convolutions.

F(i,b)=max⁡{F(end(i),b), vi+F(i+1,b−ci)}F(i,b)=\max\{F(\mathrm{end}(i),b),\,v_i+F(i+1,b-c_i)\}F(i,b)=max{F(end(i),b),vi​+F(i+1,b−ci​)}

Let end[i] be the first preorder index after i’s subtree. With b budget remaining, F[i,b]=max(F[end[i],b], value[i]+F[i+1,b−cost[i]]) whenever taking is affordable. Set the row after the listing to zero.

Check the boundary. All ancestors of the current vertex that belong to its active branch must already be selected. This follows from entering a subtree only through a take. A prerequisite DAG with two parents or a sibling-dependent discount needs more boundary information.

Cost O(nB) time and O(nB) space for this form, or a dummy zero-cost root to handle a forest. An arbitrary future jump prevents simple two-row rolling.

Try one change

A project requires its parent project. If you skip the parent in preorder, what index can you visit next?

See the reasoning

The first index after the parent's entire subtree. Every descendant requires the skipped project too.

From idea to code

  • Rooted tree DP and rerooting
    Use reverse traversal for bottom-up child messages. Use forward traversal for the parent contribution. Derive a new message when the objective differs from distance or subtree size.
  • 0/1 knapsack
    Use the descending capacity loop for one-use items. The initial zeros in this implementation mean “at most this capacity.” For exact weight, mark initially unreachable cells before the first update.
