Move a tree-cut DP into the XOR span of allowed totals

Cut a labeled tree so every component's XOR belongs to a small allowed set. Can you avoid a table over every raw label?

Work through the choice

Completed components have XORs in the linear span of the allowed values. Express those combinations in basis coordinates. A transformed tree DP can then work in a space exponential in the rank of that span, even when the original labels contain many bits.

The rule you can reuse

When every finished component must have an XOR from a short list B, its actual 30-bit value has only rank(B) independent bits. Track the XOR s of all closed components, expressed in a basis of B. The open component at v then has value Xᵥ XOR s, where Xᵥ is its fixed original subtree XOR.

αv=2−r∑zF^v(z) 1B^(z) (−1)⟨z,enc(Xv)⟩\alpha_v=2^{-r}\sum_z\widehat F_v(z)\,\widehat{\mathbf1_B}(z)\,(-1)^{\langle z,\mathrm{enc}(X_v)\rangle}αv​=2−rz∑​Fv​(z)1B​​(z)(−1)⟨z,enc(Xv​)⟩

Let Fᵥ[s] count partial cut sets before deciding the parent edge. Keeping that edge sends Fᵥ to the parent. Cutting it adds αᵥ=Σ_{b∈B}Fᵥ[Xᵥ XOR b] to the single state Xᵥ if Xᵥ is in the span. Child contributions combine by XOR convolution.

Check the boundary. Work in the Walsh basis so child merges are pointwise products. With N=2ʳ, αᵥ=(1/N)Σ_z H(Fᵥ)[z]·H(1_B)[z]·(−1)^popcount(z AND enc(Xᵥ)) when Xᵥ is encodable, and 0 otherwise. The transformed point mass added on a cut is αᵥ times the same sign vector. At the root return α_root.

Cost O(n2ʳ) transformed arithmetic after basis construction and XOR encoding, r≤|B|≤10. Process the largest subtree first and adopt its returned vector as the parent accumulator. An already-live ancestor accumulator occurs only across a light-child descent, giving O(2ʳ log n+n) space with released vectors and the traversal stack. The odd prime modulus permits division by 2ʳ. CF 2194F2, rated 3000.

From idea to code

  • Linear XOR basis
    Basis insertion tests independence. For a compressed XOR DP, also encode allowed values in coordinates of the independent basis. Rank controls the transformed table size.
  • Repeated XOR convolution
    The Walsh transform gives one scalar per frequency. The multiply-and-power part supports repeated updates with the same kernel. The inverse here uses a scaled modulus for exact integer division.
  • Rooted tree DP and rerooting
    Use reverse traversal for bottom-up child messages. Use forward traversal for the parent contribution. Derive a new message when the objective differs from distance or subtree size.
