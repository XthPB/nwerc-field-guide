Common order in two sequences plus increasing values

Find a subsequence appearing in two arrays that also strictly increases.

Work through the choice

While processing one value of the first array, sweep through the second array. Keep the best match ending at a strictly smaller value seen earlier. Use it only when the two current values are equal.

The rule you can reuse

LCS on two sequences does not guarantee value order. Fix an element x of A and scan positions j of B left to right. Maintain the best old subsequence ending at an earlier B value strictly below x.

D(j)←max⁡ ⁣(D(j),1+max⁡t<j, Bt<xD(t))(Bj=x)D(j)\gets\max\!\left(D(j),1+\max_{t<j,\ B_t<x}D(t)\right)\qquad(B_j=x)D(j)←max(D(j),1+t<j, Bt​<xmax​D(t))(Bj​=x)

D[j]=best LCIS ending at B[j] after the processed A prefix. If B[j]<x, accumulate best=max(best,D[j]); if B[j]=x, update D[j]=max(D[j],best+1).

Check the boundary. For a witness, a mutable per-position parent can be changed by a later row. Store per-layer choices or immutable parent records for improvements, then follow the chain from the chosen final state.

Cost O(nm) time and O(m) length memory. Traceback can require more storage.

From idea to code

  • Longest common subsequence and interval order
    The sheet gives the LCS recurrence and interval iteration order as notes. For an LCS witness store a parent choice or compute forward and backward rows for a recursive split.
  • Strict longest increasing subsequence
    The lower_bound version finds a strictly increasing chain. Equal values can extend a nondecreasing chain when you switch to upper_bound. The returned number is a length.
See the idea in contest problems
  • CF 10D · LCIS 2800

    Scan the second sequence for each first-sequence value. A running best among earlier smaller values gives a quadratic LCIS.
