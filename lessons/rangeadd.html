Maintain the split candidates · Lesson 156 of 235

A new endpoint changes many split candidates by the same amount

Split a sequence of letters into a prescribed number of nonempty contiguous pieces. Each piece earns its number of distinct letters, so repeated copies of a letter count once inside that piece. Maximize the sum of piece scores. The last cut determines which pieces gain from a new letter.

1. Work one example

Find the last earlier copy of the new letter. Cuts before it already counted the letter. Later cuts gain one together. Add one over that whole interval of candidates and query their maximum.

2. What do we need to remember?

Treat each possible last cut as one maintained score. Identify which cut scores receive the same change when a new item arrives.

3. How do we get the next answer?

For partition DP, view each possible prior cut j as a leaf holding old[j]+C(j+1,i). Advance the right endpoint i. Group the cuts whose value changes together. A lazy tree can update a whole interval and report the best cut.

Dg(i)=max⁡g−1≤j<i{Dg−1(j)+distinct⁡(aj+1:i)}D_g(i)=\max_{g-1\le j<i}\{D_{g-1}(j)+\operatorname{distinct}(a_{j+1:i})\}Dg​(i)=g−1≤j<imax​{Dg−1​(j)+distinct(aj+1:i​)}

For distinct-count reward and previous occurrence p of current symbol (1-based, p=0 when absent), add 1 to cuts j∈[p,i−1]. Then query the maximum over valid j.

Check the boundary. If solving exactly g nonempty groups, query only j∈[g−1,i−1] and use −∞ for invalid previous-layer leaves. Old-layer leaves must not be contaminated by new DP values.

Cost O(Kn log n) over K layers, O(n) per tree. Other costs give different update intervals based on last occurrences or a monotone stack.

Try one change

Adding a new distinct label raises the score of every candidate last segment containing it for the first time. Which starts change?

See the reasoning

Those after its previous occurrence and at or before its new position. They form one range of cut positions you can increment together.

Which cuts change when a value repeats?
  1. Give a value inside a segment the cost of its last position minus its first. In 1,2,1, the second 1 arrives at position 3. The segment starting at 1 gains 2; the segments starting at 2 or 3 see their first 1 and gain zero.
  2. Append a third 1 at position 4. Every segment starting at or before position 3 already contains a 1. Its old last occurrence was 3 and its new one is 4, so each gains exactly 1.
  3. If the last piece starts just after cut j and the previous occurrence is at p, update all j less than p by the new distance. A range-add tree updates those candidate cut scores together. Its minimum gives the cheapest last cut on this partition layer.
