Paint column runs with a minimum and maximum width

Repaint marked and blank pixels so equal-colour vertical stripes have widths from x to y. What part of the two-dimensional picture still affects the cost?

Work through the choice

A monochromatic column has only two possible repaint costs. Sum each colour's costs by prefix. Once the final stripe's colour and width are fixed, the earlier prefix must end in the opposite colour.

The rule you can reuse

D[i,c]=min⁡x≤k≤y, k≤i(D[i−k,1−c]+Pc[i]−Pc[i−k])D[i,c]=\min_{x\le k\le y,\ k\le i}\left(D[i-k,1-c]+P_c[i]-P_c[i-k]\right)D[i,c]=x≤k≤y, k≤imin​(D[i−k,1−c]+Pc​[i]−Pc​[i−k])

Set both empty-prefix colour states to zero. Query only feasible previous stripes. A deque over the translated prefix minima can speed up a large moving width interval.

Check the boundary. The width bound applies to complete maximal runs. Two adjacent stripes declared the same colour would secretly create a longer run.

Cost O(HW+W(y−x+1)) with direct candidates, or O(HW+W) with deques.

From idea to code

  • Prefix sums and difference arrays
    A prefix answers a range sum by subtraction. A difference array reverses the operation by marking the two ends of an interval update. The sheet includes the two-dimensional inclusion–exclusion form.
  • Monotone stack and sliding deque
    The sheet includes nearest-smaller and sliding minimum examples. Reverse comparisons for maximum. Track indices so expiration still works for equal scores.
