Join two lists of subset sums

With weights 2, 2, 3 and 5, how many subsets total 5? What if forty weights are far too large for a sum table?

Work through the choice

Split into two independent halves. For each left sum ask how many times its missing complement appears on the right. The two ways to select a single 2 are separate choices, so retain duplicate sums.

The rule you can reuse

When n is about 36–44 and magnitudes rule out a sum table, split labeled items into two disjoint halves. Every full subset corresponds to exactly one ordered pair of half-subsets. The task becomes a join on their summaries.

N(T)=∑x∈Lfreq⁡R(T−x)N(T)=\sum_{x\in L}\operatorname{freq}_R(T-x)N(T)=x∈L∑​freqR​(T−x)

For exact target T, answer = Σ over left sums x of freqRight[T−x]. With sorted lists use equal_range or match runs with two pointers.

Check the boundary. Build half-sums by doubling the current list, appending x+item for each old x, or by a low-bit recurrence. Deduplicating is safe for existence only. Negative numbers work with sorted signed sums.

Cost For halves of size h≈n/2, enumeration O(2ʰ), sort and binary joins O(2ʰ log 2ʰ). Two arrays of 2²⁰ signed 64-bit sums cost 16 MiB.

From idea to code

  • Meet in the middle for sums
    Keep both lists including the empty subset. For an exact match use equal_range so repeated sums retain their multiplicity. For a closest partner inspect both neighbours of lower_bound.
Worked C++17 implementation
// Includes the empty subset. All sums, complements, and the result must fit i64.
inline std::vector<i64> half_sums(const std::vector<i64>& a, int lo, int hi) {
    std::vector<i64> sums{0};
    for (int i = lo; i < hi; ++i) {
        auto old_size = sums.size();
        sums.resize(2 * old_size);
        for (std::size_t j = 0; j < old_size; ++j) {
            sums[old_size + j] = sums[j] + a[i];
        }
    }
    return sums;
}
inline i64 count_subset_sum(const std::vector<i64>& a, i64 target) {
    int mid = static_cast<int>(a.size()) / 2;
    auto left = half_sums(a, 0, mid);
    auto right = half_sums(a, mid, static_cast<int>(a.size()));
    std::sort(right.begin(), right.end());
    i64 count = 0;
    for (i64 sum : left) {
        auto bounds = std::equal_range(right.begin(), right.end(), target - sum);
        count += bounds.second - bounds.first;
    }
    return count;
}
