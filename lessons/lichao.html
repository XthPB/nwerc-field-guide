An envelope with arbitrary insertions or query order

Lines arrive in arbitrary slope order and x queries may move backwards. Which line is cheapest at each query?

Work through the choice

Two straight lines change relative order at most once. Store the line that wins at the midpoint and recurse with the loser on the only side where it might still win. Query the lines on one root-to-leaf path.

The rule you can reuse

On a fixed x interval, two affine lines exchange relative order at most once. At each Li Chao node keep the better line at its midpoint. The displaced line can still win on at most one side, so recurse only there.

D(x)=min⁡L on query path(mLx+bL)D(x)=\min_{L\ \mathrm{on\ query\ path}}(m_Lx+b_L)D(x)=L on query pathmin​(mL​x+bL​)

After the midpoint comparison, if the loser wins at the left endpoint, insert it left; else if it wins at the right endpoint, insert it right. Query the minimum over the root-to-leaf path at x.

Check the boundary. Compress actual sorted x coordinates, but evaluate at their original values. Segment-limited lines need interval insertion. Mixing max/min conventions silently reverses the envelope.

Cost O(log U) per global line insertion and query for U discrete x values; typical segment-limited insertion O(log² U).
