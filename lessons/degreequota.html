‹ Dynamic programming on trees

Pass one message up a tree · Lesson 92 of 235

Choose tree edges with a different degree quota at each vertex

Each tree edge has a profit, and each vertex has a limit on how many incident edges you can keep. Choose edges to maximize total profit within all vertex limits. At a center with profits 7, 4 and 2 and a limit of two, only two slots are available.

1. Work one example

If the parent edge is used, one unit of the child's quota has already been spent. Compute two answers per vertex. Start with every child edge absent, then calculate the net gain from adding each edge including how the child's own budget changes.

2. What do we need to remember?

Count how many child edges can still be retained. Selecting the parent edge may consume one of those slots.

3. How do we get the next answer?

gv=wuv+Dv(1)−Dv(0)g_v=w_{uv}+D_v(1)-D_v(0)gv​=wuv​+Dv​(1)−Dv​(0)

At u with parent-edge flag p, start from the sum of child values D_v(0) and add up to d_u−p of the largest positive feasible gains. At the global root use p=0.

Check the boundary. The quota is an upper bound, so a negative gain can be skipped. A parent-used state is impossible when d_u=0. Taking absolute weights would change the objective.

Cost O(n log n) by sorting gains at vertices, O(n) storage.

Try one change

A vertex can use two edges total. Its parent edge is selected and child gains are 6, 4 and −1. Which gains may you take?

See the reasoning

Only 6. The parent used one slot, leaving one. If the parent edge were absent, both 6 and 4 could fit.

From idea to code

  • Rooted tree DP and rerooting
    Use reverse traversal for bottom-up child messages. Use forward traversal for the parent contribution. Derive a new message when the objective differs from distance or subtree size.
