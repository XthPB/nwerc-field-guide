Pass one message up a tree · Lesson 93 of 235

Keep a path open for the parent or close it through this vertex

Find the heaviest simple path in a weighted tree. What can a child send upward?

1. Work one example

A path that will use the parent edge can extend through only one child. A completed path whose highest vertex is here can use two child branches. Store an open arm and consider joining the two strongest arms locally.

2. What do we need to remember?

A path passed to the parent can use only one downward arm. A path finishing here may join two different arms.

3. How do we get the next answer?

Root a tree. A path can enter the parent through only one child edge, but a path whose highest vertex is u can use two distinct child directions. Compute the best continuing arm and the best completed path separately.

Du=wu+g1,Cu=wu+g1+g2D_u=w_u+g_1,\qquad C_u=w_u+g_1+g_2Du​=wu​+g1​,Cu​=wu​+g1​+g2​

With vertex weights let gain(v)=max(0,down[v]). Then down[u]=wᵤ+largest gain. Charge the closed candidate wᵤ+largest gain+second-largest distinct-child gain to u.

Check the boundary. Pad missing gains with zero. If the path must be nonempty and all vertex weights are negative, the global answer is the best single vertex. For an edge-count constraint or prescribed endpoint colours, keep the matching boundary property of each arm.

Cost O(n) for a fixed number of arm types. Scan child gains once and keep their origins so that the same child cannot be used twice.

Try one change

A vertex has downward branches of lengths 5 and 3. What length can pass upward, and what can finish here?

See the reasoning

A single descending arm sent upward can have length 5. A path joining the two distinct branches through the vertex has length 8.

From idea to code
