Reason about random choices · Lesson 215 of 235

Use completion counts to sample a valid answer uniformly

There are three valid words, 001, 010 and 100. Generate one so each complete word has probability 1/3. You must write the word left to right. The first decision has two possible bits, but they do not lead to the same number of completed words.

1. Work one example

Two valid completions begin with 0 and only one begins with 1. Draw a uniform rank among the completions, or choose each branch in proportion to its completion count. Apply the same rule at the next letter.

2. What do we need to remember?

Count completions below every possible next move. Choose a move in proportion to that count to sample a complete solution uniformly.

3. How do we get the next answer?

If each answer has one construction path, compute the exact number C(s) of completions at each state. Choose a successor in proportion to its completion count. The conditional probabilities along a path telescope to 1/C(start).

Pr⁡[s→t]=C(s→t)C(s),Pr⁡[one object]=1C(start)\Pr[s\to t]=\frac{C(s\to t)}{C(s)},\qquad \Pr[\text{one object}]=\frac1{C(\mathrm{start})}Pr[s→t]=C(s)C(s→t)​,Pr[one object]=C(start)1​

Draw an integer U uniformly from 0…C(s)−1. Partition that range into adjacent bins of lengths C(s→t), choose the containing bin and continue. One initial integer can also be unranked by carrying the offset inside each selected bin.

Check the boundary. Counts modulo a prime lose branch ratios. Use exact integers or a suitable exact sampler. Uniform bounded integers can be obtained by rejecting out-of-range bit patterns. If multiple histories encode one output, this procedure is uniform over histories.

Cost Cost is the counting DP plus one descent per sample. A node with many children can use binary search on cumulative counts. For sampling optimal solutions, keep only transitions achieving the optimum.
