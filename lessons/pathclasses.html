Classify vertices by the complete paths that contain them

In a directed acyclic grid, which cells occur on exactly the same family of complete start-to-finish paths?

Work through the choice

In a diamond, the start and finish occur together on every path, while either branch can be bypassed. For ordered internal vertices, require both that every prefix to the later one uses the earlier one and every suffix from the earlier one uses the later one. This gives two domination tests.

The rule you can reuse

A universal co-occurrence condition is equality of path sets. For active vertices u before v in a DAG, those sets coincide exactly when every source-to-v path passes u and every u-to-sink path passes v. These are dominance and postdominance.

Build the dominator tree in topological order: the immediate dominator of v is the LCA of its active predecessors. Reverse the DAG to get the postdominator tree. For v count dominator ancestors inside its postdominator subtree.

Check the boundary. During DFS of the dominator tree activate strict ancestors in a Fenwick tree by postdominator Euler entry; query the postdominator subtree of v before inserting v. If the count is h, charge 2ʰ subsets to latest vertex v. All U inactive cells form one separate class contributing 2ᵁ−1, even when there are no complete paths.

Cost O((V+E)log V) with binary-lifting LCA, and O(V log V) memory. Compute active cells by reachability from both ends. CF 2247F, rated 2900.

From idea to code

  • Topological order and DAG DP
    Use a verified acyclic order. Process every outgoing transition after its source is final. Counting merges by addition and longest paths by maximum.
  • Lowest common ancestors
    Use the common ancestor to compute tree distances or compress marked paths. A virtual tree also needs traversal order and ancestor tests.
See the idea in contest problems
