Count each object once · Lesson 113 of 235

Charge each object to a unique last choice

Count the ways to split a, b and c into two nonempty groups when exchanging the two groups means the same split.

1. Work one example

Give a a fixed home in the first group. Choosing a neighbour to join it now defines each split exactly once. The first group can contain a alone, a with b, or a with c.

2. What do we need to remember?

Name a unique witness for every object you count. Summing over witnesses then counts each object exactly once.

3. How do we get the next answer?

A count often looks exponential because the same answer can be built in several orders. Fix its smallest indexed member, last cut, first failure or highest vertex. Prove exactly one of these events exists for every counted object.

#A=∑p#{A∈A:pivot⁡(A)=p}\#\mathcal A=\sum_{p}\#\{A\in\mathcal A:\operatorname{pivot}(A)=p\}#A=p∑​#{A∈A:pivot(A)=p}

Count(all objects) = Σ over pivots p of count(objects whose canonical pivot is p).

Check the boundary. Equal weights do not identify equal items. Use original index as a tie-break for labeled objects. Division by 2 fails in modular arithmetic when 2 has no inverse.

Cost The pivot may add a loop or may disappear into a sorted sweep. Check both versions.

Try one change

A nonempty subsequence ends at position j. How many distinct positions can be its final position?

See the reasoning

Exactly one. Count all objects ending at each j and sum. If the objects are distinct strings rather than index choices, an extra canonicalization rule is needed.

From idea to code

  • Enumerate submasks
    The loop visits every nonempty submask. Add the empty option separately if it is legal. Enumerating submasks for every mask costs three to the power n across all masks.
See the idea in contest problems
  • CSES · Two Sets II

    A subset of half the overall sum determines both groups. Force n into a designated group, or count subsets of the remaining numbers that form the other group, to break the exchange symmetry.
