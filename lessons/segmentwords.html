Dictionary breaks, trie edges, and weighted parsing

In how many ways can you split aba into words from a, ab and ba?

Work through the choice

Draw a vertex between successive characters. A dictionary match is an edge from its start to its end. Counting routes from the start to the end counts splits. A trie finds these edges without testing every dictionary word.

The rule you can reuse

A segmentation has a unique final cut once the final token is fixed. Make positions vertices and each matching dictionary word an edge. Then use Boolean reachability, shortest cost, or number of paths as the cell algebra.

F(j)=∑w∈Dw ends at jF(j−∣w∣)F(j)=\sum_{\substack{w\in\mathcal D\\w\ \mathrm{ends\ at}\ j}}F(j-\lvert w\rvert)F(j)=w∈Dw ends at j​∑​F(j−∣w∣)

ways[0]=1. For each word ending at j with length ℓ, add ways[j−ℓ] to ways[j].

Check the boundary. If a word has multiple dictionary entries, decide if those are different choices. An empty token creates a cycle and can make the number of segmentations infinite.

Cost Trie scanning O(nL) for largest word length L; Aho–Corasick O(text + number of emitted matches) after building the automaton, for constant-time transitions.

From idea to code

  • Trie of strings
    Starting from a reachable split position, traverse matching dictionary prefixes, and relax the end position at every terminal. Preserve word multiplicity if separately labeled dictionary entries matter.
  • Topological order and DAG DP
    Use a verified acyclic order. Process every outgoing transition after its source is final. Counting merges by addition and longest paths by maximum.
