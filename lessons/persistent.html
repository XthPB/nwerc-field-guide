‹ Range queries inside DP

Versions or time intervals preserve the correct DP layer

A sequence branches into two versions. Updating one branch must leave the old prefix available to its sibling. How can both see the correct scores?

Work through the choice

Copy only the nodes on the root-to-leaf path you change. All other nodes can be shared, and each version keeps its own root. A depth-first traversal with reversible updates is another option when the traversal order allows it.

Watch two roots share unchanged data

1 / 3

An old version

Only the original prefix exists. Its two children contain the counts for low and high ranks. Both counts are zero.

Insert a high-ranked item

Create a new root and a new high-rank child. The unchanged low-rank child is shared. The old root still points at the old high count of zero.

Read the difference

In the high half, the new count is 1 and the old count is 0. Their difference says this insertion contributes one high-ranked value. For k-th queries, repeat the same count comparison down the tree.

The rule you can reuse

For branch-dependent histories, a DFS can inherit an immutable parent version of a range structure. For arbitrary insertions and deletions of 0/1 items known offline, put each item on a segment tree over its active time interval and carry a restorable knapsack DP down the traversal.

rootv=update⁡(rootparent(v),k,x)\mathrm{root}_v=\operatorname{update}(\mathrm{root}_{\mathrm{parent}(v)},k,x)rootv​=update(rootparent(v)​,k,x)

Version(child)=pointUpdate(version(parent),key,value). For time DFS, checkpoint, apply items covering the node, answer descendants, then rollback or discard the branch copy.

Check the boundary. Subtracting version counts gives range frequencies; subtracting minima does not give a range minimum. Deleting a knapsack item by undoing its forward loop is generally invalid.

Cost Path-copy segment tree O(log U) nodes per point update. Offline knapsack with I lifetimes and cap W costs O(IW log Q) transition work plus queries and restoration/copy costs.
