Choose a set and its endpoint · Lesson 76 of 235

Visit every city with a set and a last stop

Visit every city at minimum cost. If two routes have visited exactly the same cities, when may you discard one?

1. Work one example

The price of the next leg depends on where the route ends. Keep the cheapest prefix separately for each pair of visited set and last city. Extend to an unused city and add a return edge only if the tour must close.

Why does the last city need its own state?

Choose an endpoint

Start at S. Visit A and B in either order, then end at T. The numbers on the links are travel costs. All links shown are usable in both directions.

Cheaper so far, ending at A

S → B → A costs 2 + 1 = 3. Keeping only the cheapest route for the visited set would leave you here.

Another route, ending at B

S → A → B costs 5 + 1 = 6. It is more expensive so far, but B sits just one unit from T.

Compare completed routes

Ending at A costs 3 + 8 = 11 in total. Ending at B costs 6 + 1 = 7. Keeping both endpoint states saves the better route.

2. What do we need to remember?

Knowing the visited set leaves one more question: where does the route currently end? Both affect the price of the next leg.

3. How do we get the next answer?

For a route or a sequence with adjacent bonuses, the visited mask does not determine the last vertex. Append one unused vertex, charging its transition from the current end.

D(M,v)=min⁡u∈M∖{v}{D(M∖{v},u)+wuv}D(M,v)=\min_{u\in M\setminus\{v\}}\{D(M\setminus\{v\},u)+w_{uv}\}D(M,v)=u∈M∖{v}min​{D(M∖{v},u)+wuv​}

D[M,v]=min over u∈M without v of D[M without v,u]+w[u,v]. Initialize {start},start to 0. Add the return edge only for a round trip.

Check the boundary. Enumerating both orientations counts undirected cycles twice. Pin the start to avoid rotation duplicates. A path that may repeat vertices requires a different model.

Cost O(n²2ⁿ) time, O(n2ⁿ) memory, reducible for sparse edges. At n=20 the 8-byte endpoint table alone is 160 MiB.
