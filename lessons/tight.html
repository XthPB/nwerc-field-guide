‹ Digit DP, binary bounds and carries

Translate an enormous numeric interval into a short string

Count integers from 10 to 25 with at most one nonzero digit, without looping over every integer in a large interval.

Work through the choice

Build the number from left to right. While its prefix equals the upper bound, the next digit is capped by the matching bound digit. Once smaller, any next digit is allowed. Subtract the count up to 9 to discard the short prefix of the range.

The rule you can reuse

For counting integers in [L,R], write F(N) for values from 0 to N. Process the digits of N from left to right. Only a prefix equal to N constrains the next digit. A smaller prefix is free thereafter.

#{L≤x≤R}=F(R)−F(L−1)\#\{L\le x\le R\}=F(R)-F(L-1)#{L≤x≤R}=F(R)−F(L−1)

dp(i,tight,started,s): for d=0…(tight?digit[i]:9), advance with tight′=tight AND d=digit[i]. F(R)−F(L−1), with F(N)=0 for N<0.

Check the boundary. Define whether the all-padding path represents the number zero. Leading zeros do not normally count as repeated digits, real zero digits, or a forbidden prefix.

Cost O(D·base·states) time for D digits. Memoizing only non-tight states is convenient if bounds change; include remaining length and all properties in a reused key.

Worked C++17 implementation
// Counts integers in [0,n] with at most three nonzero decimal digits.
inline i64 classy(i64 n) {
    if (n < 0) return 0;
    std::array<std::array<i64,4>,2> cur{};
    cur[1][0] = 1;
    for (char digit : std::to_string(n)) {
        decltype(cur) next{};
        for (int tight = 0; tight <= 1; ++tight) {
            int limit = tight ? digit - '0' : 9;
            for (int used = 0; used <= 3; ++used) {
                for (int d = 0; d <= limit; ++d) {
                    int count = used + (d != 0);
                    if (count <= 3) {
                        next[tight && d == limit][count] += cur[tight][used];
                    }
                }
            }
        }
        cur = next;
    }
    i64 result = 0;
    for (const auto& row : cur) result += std::accumulate(row.begin(), row.end(), i64{0});
    return result;
}
