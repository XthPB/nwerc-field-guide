Represent a substring by its whole DP transition

Letters of a string change online. How can you recompute the cheapest edits satisfying a small automaton after each change?

1. Work one example

A substring may be entered in several machine states. Store its cheapest cost for every entrance and exit state. Joining neighbouring substrings tries each intermediate state. A segment tree recomputes only the joins on the updated path.

2. What do we need to remember?

Represent a short interval by its action on a state vector. Adjacent interval actions compose in the same order as the underlying sequence.

3. How do we get the next answer?

If each character updates a finite-state DP, store the transition from every possible entry state to every exit state for an interval. A query may start from a fixed automaton state, but a middle segment needs answers for arbitrary boundary states.

Txy(p,q)=min⁡r{Tx(p,r)+Ty(r,q)}T_{xy}(p,q)=\min_r\{T_x(p,r)+T_y(r,q)\}Txy​(p,q)=rmin​{Tx​(p,r)+Ty​(r,q)}

Let Tₓ[p,q] be minimum deletions to enter in p and exit in q across block x. For x followed by y, Tₓᵧ[p,q]=minᵣ(Tₓ[p,r]+Tᵧ[r,q]). Use zero on the identity diagonal and ∞ elsewhere.

Check the boundary. Composition is associative and ordered. Keep separate left and right accumulators in iterative range queries. For the Codeforces problem, automaton states also encode progress toward one required subsequence and prevention of another.

Cost For s states, a dense product costs O(s³). A segment tree costs O(ns³) to build, O(s³ log n) per update/query and O(ns²) storage. Short triangular automata can reduce constants.

From idea to code

  • Matrix multiplication and power
    The sheet multiplies with ordinary modular addition and multiplication. For minimum-cost transitions replace those by min and plus, use an infinite unreachable value, and skip unreachable additions.
  • Bottom-up segment tree
    The original combine is addition over a half-open interval. For a min, max, witness or matrix payload, update the stored type, combine and empty identity together. Preserve combination order for matrices.
