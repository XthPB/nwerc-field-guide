Find a quantity that always moves forward

Find the cheapest route from A to C when a stop at B can reduce the price.

Work through the choice

Before pricing C, finish every vertex that can feed it. In a graph with no directed cycle, a topological order guarantees this happens once. A negative edge still works because its source already has its final cost.

The rule you can reuse

Prefix length, number of bits chosen, interval length, tree depth, and elapsed moves are candidate ranks. Proving every dependency has smaller rank gives both evaluation order and an induction proof. Pull from predecessors or push to successors.

D(v)=min⁡u→v{D(u)+w(u,v)}D(v)=\min_{u\to v}\{D(u)+w(u,v)\}D(v)=u→vmin​{D(u)+w(u,v)}

D[v] = min over u→v of D[u]+w(u,v), with D[source]=0.

Check the boundary. A zero-length transition can keep the same rank. Topologically order those transitions, solve simultaneous equations, or switch to a graph algorithm as appropriate.

Cost O(V+E) for an explicit DAG. Acyclicity of the expanded state graph is what matters.
