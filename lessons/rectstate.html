Cross a narrow boundary · Lesson 147 of 235

Four boundaries identify an arbitrary subrectangle

Two opposite corners of a 3 by 3 board are marked. What is the cheapest way to cover them when painting a rectangle costs its longer side?

1. Work one example

Painting everything at once costs 3. A horizontal or vertical cut creates independent rectangles. An empty piece costs zero, so isolating the two marked cells costs 2. Keep the four borders so you know which marks belong to each piece.

2. What do we need to remember?

Identify the four boundaries of the remaining rectangle. An allowed cut must leave one or more strictly smaller rectangles.

3. How do we get the next answer?

When a child can be any subrectangle, height and width lose location-dependent information. Keep top, bottom, left and right. For a guillotine split, a first full horizontal or vertical cut yields independent child rectangles.

For a model allowing either painting the whole rectangle for max(height,width) or a straight cut, start F[R] at that painting cost. An unmarked rectangle costs zero. Minimize over sums of the two children for each horizontal and vertical cut.

Check the boundary. An unrestricted geometric covering problem needs a proof that some optimum admits such a split. For the Codeforces painting rule a cover cheaper than max(h,w) leaves an untouched row or column along the longer dimension, since the sum of the painted spans there is below that length. It supplies a separating cut. Clip outside rectangles to the subproblem first.

Cost There are H(H+1)W(W+1)/4 valid rectangles. Two-dimensional prefix sums test emptiness in O(1). Trying every cut gives O(H²W²(H+W)) time and O(H²W²) space.

Try one change

If you remove the left column of rectangle [top,bottom] by [left,right], which boundary changes?

See the reasoning

Only left moves one step inward. The remaining four-boundary state is smaller and can be looked up.
