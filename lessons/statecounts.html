Keep only reachable descriptions · Lesson 197 of 235

Count inputs that produce the same DP state

Write every two-letter word over A and B. Compare each word with AB using the length of their longest common subsequence, where skipped letters are allowed. Count the words for which that length is exactly one. The goal is to count possible inputs producing a specified DP result.

1. Work one example

For target AB, the LCS row of prefix A is (0,1,1). For B it is (0,0,1). Appending another character can distinguish these rows even though their final entry is the same. After two letters, AA, BA and BB all finish with LCS length one. AB alone finishes with two.

2. What do we need to remember?

Run an inner algorithm on one candidate prefix. In an outer table, count how many different prefixes produce each complete inner state.

3. How do we get the next answer?

Ci+1[T(r,c)]+=Ci[r](c∈Σ).C_{i+1}[T(r,c)]\mathrel{+}=C_i[r]\quad(c\in\Sigma).Ci+1​[T(r,c)]+=Ci​[r](c∈Σ).

T(r,c) is the deterministic next inner state after appending letter c. Prefixes reaching the same row have identical future behavior, so add their counts. The row’s adjacent LCS entries differ by zero or one. A binary signature can therefore encode a row of length m. Near-perfect LCS allows a narrower band. The same idea can count trees by the matching scores their subtrees produce, provided the tree construction itself counts each allowed tree correctly.

Check the boundary. Do not group by the final LCS length alone. For prefixes A and B both scores are one, but appending B produces scores two and one.

Cost With S reachable rows, target length m, alphabet size a and n steps, explicit row transitions use O(nSam) arithmetic plus map overhead. The supplied ordered-map code may spend O(m log S) per lookup. Full rows can grow exponentially in m.

Try one change

Against target AB, prefixes A and B each have LCS length one. Do they remain equivalent after appending B?

See the reasoning

No. AB reaches length two and BB stays at one. Keep the complete relevant LCS row before counting how many prefixes share it.
