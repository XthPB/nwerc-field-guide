‹ Dynamic programming on graphs

Fix the number of moves to make a cyclic graph acyclic in time

Find the cheapest walk of exactly two edges when a cycle contains a negative edge.

Work through the choice

Time supplies the missing order. A state after the second edge reads the table after exactly one edge. Each step spends one of the allowed moves, so repeatedly traversing the cycle cannot affect an earlier layer.

The rule you can reuse

If a walk must take exactly k edges, time gives a strict rank even when the original graph has cycles or negative weights. Distinguish exact from at-most horizons at the recurrence.

Dt(v)=min⁡u→v{Dt−1(u)+wuv}D_t(v)=\min_{u\to v}\{D_{t-1}(u)+w_{uv}\}Dt​(v)=u→vmin​{Dt−1​(u)+wuv​}

F₀[s]=0 with all other entries ∞. Fₜ[v]=min over u→v of Fₜ₋₁[u]+w(u,v). For at most t moves also allow carrying Fₜ₋₁[v].

Check the boundary. A negative cycle cannot be repeated beyond a fixed finite horizon. For huge k and a small stationary transition, min-plus matrix powering applies. Time-varying availability needs phase or event handling.

Cost O(kE) edge relaxations plus row initialization, or O(k(V+E)) total in a dense-cleared implementation. Rolling rows use O(V).

From idea to code

  • Bellman–Ford and edge-count layers
    For exactly t edges use a fresh layer after each pass. An in-place shortest-path relaxation can traverse several edges in a single pass and changes that meaning.
  • Matrix multiplication and power
    The sheet multiplies with ordinary modular addition and multiplication. For minimum-cost transitions replace those by min and plus, use an infinite unreachable value, and skip unreachable additions.
