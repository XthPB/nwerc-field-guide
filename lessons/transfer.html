Compose transitions · Lesson 176 of 235

Exponentiate a repeated stationary transition

Count very long binary strings avoiding 11 when the rule at each position is identical.

1. Work one example

A step changes the counts ending in zero and one by the same linear rule each time. Write that rule as a small matrix. Squaring it represents two, four and then exponentially many steps.

2. What do we need to remember?

One matrix describes one repeated step. Squaring it describes twice as many steps without filling the intermediate layers.

3. How do we get the next answer?

A huge number of steps with a small fixed state set suggests powering the one-step transition. Matrix multiplication composes transitions. Ordinary arithmetic counts walks; min-plus uses min and + for shortest walks of exactly t edges.

vt=Mtv0v_t=M^t v_0vt​=Mtv0​

With column vectors vₜ₊₁=Mvₜ, vₜ=Mᵗv₀. Compose a period of nonidentical transitions in time order, exponentiate full periods, then apply the leftover prefix.

Check the boundary. Use the correct identity for the algebra: min-plus has diagonal 0 and off-diagonal ∞. Exponentiating by t counts exactly t steps. Time-dependent transitions require a period or other structure.

Cost Dense O(s³ log t) time, O(s²) memory. Sparse multiplication can become dense after squaring.

Try one change

One fixed matrix advances a state by one day. What advances it 13 days?

See the reasoning

Use its powers for 8, 4 and 1 days. Matrix powers apply only if the transition repeats unchanged or a complete repeated block is used.

How geometry determines a transition probability
  1. Put A=(0,0), B=(1,0), C=(2,0) and D=(0,1). From A there are two eligible lines: horizontal ABC and vertical AD. Choosing a line uniformly gives each one probability one half.
  2. On the horizontal line, each destination then has probability one third. On the vertical line it has probability one half. The next-position row in A,B,C,D order is (5/12, 1/6, 1/6, 1/4). The first entry includes both ways of staying at A.
  3. The entries add to one. Build the other rows the same way, grouping collinear points once per line. Repeated moves on these points use matrix powers. The contest also permits choosing a starting point off this set; its first move is a separate calculation.
