‹ Knapsack and subset sum

Shrink the knapsack axis · Lesson 66 of 235

Which voting groups need every member?

Three parties have 4, 3 and 2 seats. A group needs 5 of the 9 seats to win. How many winning groups need every one of their members?

Who is essential?

There are 9 seats. A majority needs 5. Select parties to form a group.

7 seats win. Removing the 3-seat party leaves 4. Every member is essential.

1. Work one example

Try removing each party from a winning group. Removing its smallest party leaves the most seats behind. If even that remainder loses, removing any bigger party also loses. This single test replaces checking every member.

Count each group once

Read parties from largest to smallest. When the 3-seat party arrives, only the 4-seat party is already available. Together they win, and without the 3 they lose. When the 2-seat party arrives it can join the 4 or the 3. Joining both would leave 7 seats after it departs, so that group fails the test.

4 seatsNone0
3 seats{4}1
2 seats{4} or {3}2

There are three groups. For many parties, store how many earlier selections have each seat total. Writing s for that earlier total, w for the arriving party and H for half the seats rounded down gives the test below.

2. What do we need to remember?

Give each winning group one designated weakest party. Check whether removing it makes the whole group lose.

3. How do we get the next answer?

s+w>H,s≤H⟺H−w<s≤Hs+w>H,\quad s\le H\quad\Longleftrightarrow\quad H-w<s\le Hs+w>H,s≤H⟺H−w<s≤H

Sort items decreasingly with an index tie-break. Before inserting weight w, add Σ f[s] for H−w<s≤H. Then insert w once into the sum-count DP.

Check the boundary. Strict inequalities matter. If H=floor(total/2), a total exactly H loses. Insert w after querying or an item can count itself twice. Repeated weights are independent labeled parties.

Cost O(nH+n log n) time with a scalar loop per item, O(H) memory. With n≤60 the total number of labeled subsets fits signed 64 bits.

Try one change

Seats are 4, 3 and 2. A group needs 5 seats. Why is {4,3,2} excluded even though it wins?

See the reasoning

Remove its smallest member, 2. The remaining 7 still win, so that member was unnecessary. Removing the smallest always leaves the biggest remainder.

From idea to code

  • Count minimal winning coalitions
    Pass positive seat counts for labeled parties. The threshold is half the votes rounded down. The function queries old subset counts before adding the current smallest member.
Worked C++17 implementation
// Positive weights, n <= 60 and total weight fitting an int.
inline i64 minimal_majorities(std::vector<int> weights) {
    int half = std::accumulate(weights.begin(), weights.end(), 0) / 2;
    std::sort(weights.rbegin(), weights.rend());
    std::vector<i64> ways(half + 1);
    ways[0] = 1;
    i64 result = 0;
    for (int weight : weights) {
        for (int s = std::max(0, half - weight + 1); s <= half; ++s) {
            result += ways[s];
        }
        for (int s = half; s >= weight; --s) {
            ways[s] += ways[s - weight];
        }
    }
    return result;
}
