‹ Randomization and DP

Randomly colour vertices, then run an exact subset DP

Look for a path on k distinct vertices in a large graph. How can random labels shrink what the DP must remember?

Work through the choice

Assign each vertex one of k colours at random. Search exactly for a path using every colour once. A colourful path necessarily uses distinct vertices. Repeating independent colourings gives an explicit chance of missing a fixed real witness.

A repeated colour blocks a real path

The original three-vertex path exists. The mask after the first two vertices contains red and blue, so a red endpoint cannot extend it.

A fresh colouring exposes it

The same graph now has a path whose mask grows {R} → {R,B} → {R,B,G}. The found path is a certificate.

Count the chances for this witness

There are 3³ = 27 assignments of three colours to these vertices. Exactly 3! = 6 are colourful. Repeating independent trials multiplies miss probabilities.

The rule you can reuse

A graph has many vertices, but the sought simple path uses exactly k of them. Colour every vertex independently and uniformly with one of k colours. A path containing each colour once is automatically simple, so one trial only needs states (colour mask, endpoint).

pk=k!kk,Pr⁡[miss a fixed witness in R trials]=(1−pk)Rp_k=\frac{k!}{k^k},\qquad \Pr[\text{miss a fixed witness in }R\text{ trials}]=(1-p_k)^Rpk​=kkk!​,Pr[miss a fixed witness in R trials]=(1−pk​)R

Seed ({colour(v)},v). From (M,u) follow an edge u→v if colour(v) is absent from M. Reaching a full mask certifies a k-vertex path. Use parent pointers to produce a verifiable witness.

Check the boundary. A failed trial proves absence only for that colouring. With an exact-output requirement, enumerate a proven k-perfect hash family or use a deterministic small-instance method. Distinguish k vertices from k edges.

Cost Each trial costs O(2ᵏ(V+E)) time and O(2ᵏV) cells. After R independent trials the one-sided failure bound is (1−k!/kᵏ)ᴿ whenever a witness exists.

From idea to code

  • Enumerate submasks
    The loop visits every nonempty submask. Add the empty option separately if it is legal. Enumerating submasks for every mask costs three to the power n across all masks.
  • Held–Karp path or closed tour
    Set the start city to zero. The two switches in the calling convention are the distance matrix and whether the last edge must return to the depot. For a fixed finishing city read that one endpoint.
