‹ Dynamic programming on graphs

Compose a score while jumping through a functional graph

Each vertex has one successor. After exactly k jumps, report both the final vertex and the accumulated reward, including when the walk circles many times.

Work through the choice

Store where a jump of length 2ʲ ends and what it earns. To double it, take one jump, look up the equally long jump beginning at its endpoint, and combine their rewards in travel order.

Precompute destination and aggregate tables together. Read the set bits of k, updating the current vertex after taking each jump. The score operation must be associative and have an identity for zero steps.

Check the boundary. Specify whether a reward belongs to the departure or arrival vertex. For noncommutative operations such as function composition, preserve traversal order.

Cost O(n log K) preprocessing and O(log K) per query.

From idea to code

  • Functional graph distances and cycles
    Reuse the tree and cycle decomposition. For a cycle DP enforce consistency between the first and last decisions on the cycle.
  • Lowest common ancestors
    Use the common ancestor to compute tree distances or compress marked paths. A virtual tree also needs traversal order and ancestor tests.
