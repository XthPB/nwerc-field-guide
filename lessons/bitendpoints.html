‹ Bitmasks and subset transforms

Pack all possible Hamiltonian endpoints into one mask

For each small set of cities, can any path visit all of them and end at a particular city?

Work through the choice

When you need only existence, store possible last cities as bits of one word. To end at v, remove v from the set and check whether any previously possible endpoint has an edge into v.

The rule you can reuse

For existence only, let E[M] be a vertex bitset whose 1s are the endpoints of paths visiting exactly M. For candidate v, an endpoint u of a path on M without v must also have an edge u→v. That predecessor test is one bitwise intersection.

v∈E(M)  ⟺  E(M∖{v})∩N−(v)≠∅v\in E(M)\iff E(M\setminus\{v\})\cap N^-(v)\ne\varnothingv∈E(M)⟺E(M∖{v})∩N−(v)=∅

For a fixed start s initialize E[{s}] to bit s. For each larger eligible mask and each v≠s in M, set bit v in E[M] iff E[M without v] AND incoming[v] is nonempty. For a cycle test the full endpoints against vertices with an edge to s.

Check the boundary. The mask inside a cell represents reachable endpoints. Its table index represents the visited set. This removes the inner predecessor scan for Boolean reachability. It discards counts and costs. Recover a path by choosing a valid predecessor bit at each smaller mask.

Cost O(n2ⁿ) word operations and O(2ⁿ) words when n fits in a word. A multiword intersection adds a factor ⌈n/word⌉. Counts and weighted routes need the scalar endpoint table.

From idea to code

  • Held–Karp path or closed tour
    Set the start city to zero. The two switches in the calling convention are the distance matrix and whether the last edge must return to the depot. For a fixed finishing city read that one endpoint.
  • Enumerate submasks
    The loop visits every nonempty submask. Add the empty option separately if it is legal. Enumerating submasks for every mask costs three to the power n across all masks.
