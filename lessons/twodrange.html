‹ Advanced range queries inside DP

Independent rectangle bounds require a second range dimension

Find the best predecessor inside a rectangle bounded on both x and y. Can four prefix maxima answer the query?

Work through the choice

An excluded point with score 9 can dominate all four prefix answers, hiding the best included point of score 7. Decompose the rectangle into disjoint stored ranges. For changing points use a tree over x with a second structure on y, or sweep if the order permits.

The rule you can reuse

If each DP predecessor is a point (x,y), interpret inequalities geometrically. For offline counting by two upper bounds, sweep x and ask a Fenwick prefix sum on y. For fully interleaved rectangle-max queries among earlier points, use a 2D range structure.

S([a,b]×[c,d])=P(b,d)−P(a−1,d)−P(b,c−1)+P(a−1,c−1)S([a,b]\times[c,d])=P(b,d)-P(a-1,d)-P(b,c-1)+P(a-1,c-1)S([a,b]×[c,d])=P(b,d)−P(a−1,d)−P(b,c−1)+P(a−1,c−1)

A rectangle sum is four signed prefix sums. For max, a 2D segment or range tree decomposes the x interval into disjoint canonical nodes and queries their y ranges. A prefix max has no subtraction operation.

Check the boundary. A static offline reorder is valid only if it respects DP dependencies. If input time is an independent constraint, preserve it with an online structure or a left-before-right CDQ recursion. Batch strict ties before modifications.

Cost Offline prefix counting can take O((n+q)log n). With known update coordinates, each outer segment node can contain compressed y coordinates, giving O(n log n) storage and O(log² n) point updates/rectangle maxima.

From idea to code

  • Bottom-up segment tree
    The original combine is addition over a half-open interval. For a min, max, witness or matrix payload, update the stored type, combine and empty identity together. Preserve combination order for matrices.
  • Coordinate compression
    Compression preserves order and equality. Convert open and closed query bounds with lower_bound and upper_bound. Original distances must still use the uncompressed coordinates.
