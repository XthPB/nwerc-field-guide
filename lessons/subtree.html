‹ Dynamic programming on trees

Pass one message up a tree · Lesson 89 of 235

A tree edge is a one-vertex interface

A tree must be colored black or white, with no edge joining two black vertices. Count all valid colorings. On a three-vertex path, coloring the middle black immediately restricts both endpoints.

1. Work one example

Fix the middle colour. A black middle forces both neighbours white. A white middle makes the two neighbour choices independent. Given the parent colour, multiply child counts and then sum over alternatives.

2. What do we need to remember?

Cut the edge to a node’s parent. Ask what single answer that node must send about the entire detached subtree.

3. How do we get the next answer?

Root a tree. Given a choice at the parent, child subtrees are independent if the only constraint is on adjacent vertices. Compute both parent states in postorder. Replace product by sum or max to change the objective as appropriate.

Wu=∏v∈child(u)(Wv+Bv),Bu=∏v∈child(u)WvW_u=\prod_{v\in\mathrm{child}(u)}(W_v+B_v),\qquad B_u=\prod_{v\in\mathrm{child}(u)}W_vWu​=v∈child(u)∏​(Wv​+Bv​),Bu​=v∈child(u)∏​Wv​

Independent sets: white[u]=∏(white[v]+black[v]); black[u]=∏white[v]. A leaf has white=black=1. Return their sum at the root.

Check the boundary. For maximum-weight independent sets, black=wᵤ+ΣwhiteChild, white=Σmax(whiteChild,blackChild). Counts and weights have different merge algebra.

Cost O(n) time, O(n) memory. Build an explicit parent order and process it in reverse for a long chain.

Try one change

A vertex is selected in an independent set. What must each child know before it can choose?

See the reasoning

Its parent was selected, so the child itself must stay out. Given that one boundary condition, the different child subtrees can optimize independently.
