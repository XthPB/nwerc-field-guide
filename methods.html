What must a state remember?

You play a game in rounds. Each choice earns points and leaves you holding a colored card. In the next round a red card earns a 10-point bonus and a blue card earns nothing. If you can finish this round with 7 points and red or 9 points and blue, which possibilities should you keep to maximize your final score?

Can I, how many, how good, and how many best?

You travel through a directed graph and collect a score along each route. Two different routes to the same vertex each earn 4 points. A judge might ask whether you can get there, for the highest score, or for the number of routes attaining it. What would you keep for each question?

Find a quantity that always moves forward

You’re given a road map. Each road goes one way, and following the arrows can never take you back to a city you’ve left. You want the cheapest trip from A to C. The direct road costs 8. The road from A to B costs 4, and the road from B to C gives you a rebate of 3. Add the fares along the trip, counting the rebate as −3.

Keep a frontier when one score per position fails

You may select items up to a weight limit of 6, with the goal of maximizing profit. Two partial selections have (weight, profit) equal to (2,5) and (4,4), and both have the same items still available. Which partial selections can you safely discard?

Dense tabulation, sparse memoization, and rolling layers

You’re given two strings. In one edit you can insert, delete or replace one character. Find the fewest edits that turn the first string into the second. You have space for a few rows of numbers, so you need to know when an earlier result can be overwritten.

One witness, all optima, and lexicographic rank

Someone has sorted all length-three binary words containing exactly one 1 into dictionary order, with 0 before 1. Produce the third word. For longer words you need a way to skip whole groups while constructing the requested answer.

Charge each object to a unique last choice

Split the labeled objects a, b and c into exactly two nonempty groups. There is no first or second group, so {a} with {b,c} and {b,c} with {a} describe the same answer. Count each partition once.

Estimate the actual array before choosing a technique

You want a cheapest tour through 20 cities. One possible table stores the best cost for every visited set and possible last city. Before implementing it, estimate how many bytes those entries alone would take if a cost occupies eight bytes.

Build a state by asking which histories can have different futures

You’re given items of weights 2, 3 and 5. Choose exactly two distinct items whose total weight is exactly 5. A single item of weight 5 satisfies only one of the two requirements. Decide if any selection satisfies both.

Two independently advancing strings make a 2D grid

You have source strings ab and c and a target acb. Build the target one letter at a time by taking the next unused letter from either source. Each source must retain its internal order and both must be used up. Decide whether the target can be built.

Fit three growing strings inside a host

You have a fixed host string abac and three strings aa, b and c. You can interleave the three strings while preserving the order within each. Decide whether some interleaving appears in the host in order, allowing skipped host letters.

Three independently depleted piles give three prefix indices

You have three piles of positive numbers, one for each color. A move removes two numbers of different colors and earns their product. Each number can be used once. Find the largest score, starting with red {7,3}, blue {5} and green {4}.

Delete a coordinate using a conservation law

You must put every item into one of three bags. Each item has a known weight and cannot be split. You want to know which final loads are achievable. After placing weights 2 and 3, for instance, what can you infer if the first two bags contain 2 and 0?

Four boundaries identify an arbitrary subrectangle

Some cells of a board are marked. You may paint an axis-aligned rectangle for a cost equal to its longer side, and every marked cell must be covered. On a 3 × 3 board with opposite corners marked, compare covering both together with covering them separately.

Saturate, sparsify or pack a large product of dimensions

Each bundle contains a known number of red and blue tokens. You may take each bundle once. What is the fewest bundles that give you at least 3 red and 2 blue tokens? One available bundle contains 9 red and 1 blue, so going over a target is possible.

Which sums can you make using each item once?

You have a list of item weights and a target weight. You may use each physical item once, and you want to know whether some selection totals the target exactly. If the only item weighs 3 and the target is 6, using the same item twice would give a wrong answer.

When the capacity is huge, index by profit

Your bag holds weight 7. The available items have (weight, profit) equal to (8,3), (3,2) and (4,2), and each may be taken once. Find the largest profit that fits. In the larger version the capacity can be huge even when the total profit is small.

Identical weights, distinguishable items, and multiplicity

You have three labeled tickets A, B and C, each worth 2. Count the selections totaling 4 when each ticket can be used once. Then consider how the answer changes if a selection records only how many identical coins you took.

Update many reachable sums with one shift

You have three items weighing 2, 3 and 3. Each can be chosen at most once, and choosing nothing is allowed. Find every reachable total weight. Two different selections reaching the same weight light up just one answer.

Reuse, bounded stock, or one choice per group

You have a budget and a shop lists the cost and benefit of each upgrade. Find the largest total benefit you can afford. In the worked shop two alternatives belong to the same group, so you may buy at most one of them. Other shops allow repeated purchases or give a stock limit.

Remove a large multiplicity with a residue-class deque

A shop sells an item of weight 2 and a given value, with stock limited to two copies. For each bag capacity, improve the best profit you already had from earlier items. You may buy zero, one or two copies and must respect the same stock limit at every capacity.

Cardinality, two budgets, and resource coupling

You have items weighing 2, 3 and 5. Can you reach weight 5 using exactly two items? Then consider a version with a separate money budget as well as a weight limit. Each condition must hold for the same selection.

Negative weights, balance, residues, and nonempty subsets

Each listed transaction can be accepted or skipped once. Accepting it adds its signed amount to your balance, initially zero. Can you accept at least one transaction from +5, −3 and −2 and finish back at zero? Doing nothing does not qualify.

Which voting groups need every member?

In a council, the three parties hold 4, 3 and 2 seats. A coalition wins if its members hold at least 5 seats together. Count the winning coalitions in which losing any one member would also lose the majority. Parties, even those with equal seat counts, are distinct.

Partition, complements, gcd, and smallest missing sum

A wallet contains positive coins of values 1, 2, 2 and 7. Any subset may be spent once. Find the first positive amount that cannot be paid exactly, and decide whether this particular question requires storing every reachable sum.

Retrieve the selected items from a compressed sum table

A bag must weigh exactly 5 and the items weigh 2, 3 and 3. Each can be used once. You must return the indices of one valid selection, so you need to recover which physical items made the total after computing reachability.

Can the cashier make an unsplittable payout?

A cashier must pay 12 cents and can choose the denominations used for the payout. Two people will then try to divide those exact coins into two piles worth 6 cents each. Can the cashier choose a payout that makes an equal split impossible? Compare paying with 5,5,1,1 and paying with 10,1,1.

Solve a small geometric instance first, then knapsack its cost curve

Painting a cell costs one. A completed row or a completed column earns a point, and their intersection needs painting only once. On an empty 2 × 3 board, find the minimum cost of earning two points. Later you can distribute a points target across several boards.

Join two lists of subset sums

Choose any subset of the four labeled items weighing 2, 2, 3 and 5. Count how many subsets weigh exactly 5, keeping the two copies of weight 2 distinct. In the larger version there are around forty items and the target is too large for a sum-indexed table.

Closest, at most, or inside an interval

Choose a subset whose total is closest to a target of 6. Suppose you have split the items into two groups. One choice on the left weighs 2, and the possible right totals are 0, 3, 5 and 8. Which combinations come closest, including from above the target?

Profit under capacity, several resources, and exact size

Each item has a weight and a profit, and can be taken at most once. You split the collection into two halves to maximize profit under a weight limit. One left-hand choice leaves 3 units free. Find which right-hand choice gives the most profit that still fits.

Meet on a grid, a hash, or a boundary state

The board contains integers. Walk from the upper-left cell to the lower-right using right or down steps. XOR all values along each path, including both endpoints, and count paths matching a given target. The example has rows [1,2] and [4,8].

When the two halves interact through conflicts

You’re organizing a gathering. You know which pairs of guests refuse to attend together, and you want the largest invitation list containing no such pair. After selecting people from the first half, you must still enforce their conflicts with people in the second half.

Choose the parameter before you split

You’re given item weights and a target, and each item can be used once. Decide whether a subset hits the target exactly. One instance has 42 items with enormous weights. Another has 200 items but a target of only 60,000. The better search depends on which dimension is small.

A fixed number of recent decisions

A street has houses in a line, each holding a known number of coins. You may take coins from any houses you choose, but taking from two neighbors triggers an alarm. With 4, 5 and 4 coins in order, find the largest total you can take.

Before, inside, and after an operation

An array contains positive and negative numbers. You may multiply one contiguous block by −2. After this operation choose a contiguous subarray with the largest possible sum. The multiplied block and the subarray you score need not have the same endpoints.

The cheapest tail for each length

You’re given 4, 1, 3, 2, 5 in that order. You may skip entries but must keep the order of the entries you take. Find the largest number you can take so that each chosen value is strictly larger than the previous one.

Weights, counts, and two strict coordinates

You’re given points with coordinates (x,y) and a reward at each point. You may visit a sequence of points only if both coordinates strictly increase at every step. Find the greatest total reward. A point with the same x as the previous one cannot extend the chain.

Sort by finish and jump to the last compatible predecessor

Three jobs occupy the time intervals [0,3), [1,4) and [3,5) and pay 5, 8 and 6. You can do only one job at a time, and may start a new job exactly when another finishes. Choose compatible jobs for the greatest total pay.

Sort events and count open groups

Divide labeled people with given heights into groups. Each group costs its tallest height minus its shortest. Count groupings that fit a stated total budget. Processing the sorted heights encounters the first and last members of a group at different times.

Equivalent suffixes under gcd, AND, or OR

You’re given a sequence of positive integers. For each right endpoint r, consider every contiguous subarray ending at r. Find its possible gcd values and how many starting positions yield each one. Numerous starts can share the same gcd.

Find an order that is safe for every chosen subset

Your phone has limited free storage. Each app needs some temporary space to install and then occupies a possibly different amount permanently. You may choose apps and their installation order. Which order lets you test which selections fit without trying every permutation?

Two prefixes and the last alignment column

You have the strings ab and acb. In one step you can delete a letter, insert a letter, or replace one letter by another. Each step costs 1, and keeping an equal letter costs 0. Find the smallest cost of turning ab into acb.

A witness from two thin rows

Given axb and ayb, return an actual longest sequence of letters appearing in order in both strings. You can skip letters freely, but your memory budget holds only a few rows of the usual table. Knowing the optimum length alone will not identify the letters to print.

Only matching pairs can improve LCS

Given two strings, find the length of their longest common subsequence. You may skip letters in either string but must preserve their order. For ab and aab, the first a has two possible partners. In the larger version relatively few pairs of positions hold equal letters.

Different subsequences, next occurrences, and ranking

You can delete any positions of the string aa, keeping the order of the remaining letters. Count different resulting strings, including the empty one. Deleting the first a or deleting the second a produces the same one-letter result.

Carry the longest relevant suffix

Build a binary word of length three from left to right. Count the words in which two 1s never appear next to each other. An appended bit is legal only if the word still avoids the forbidden pattern 11.

Dictionary breaks, trie edges, and weighted parsing

You have the text aba and a dictionary containing a, ab and ba. Split the whole text into adjacent dictionary words, with no gaps. Count the different splits. A dictionary word may be used again if the text allows it.

Palindrome boundaries, suffix links, and series links

Split ababa into contiguous blocks, each of which must read the same forwards and backwards. Every letter belongs to exactly one block. Return the smallest possible number of blocks. To end at a particular position, the last block must be a palindrome ending there.

Count a fixed pattern inside a stream

You’re given a text and a fixed pattern. Count the ways to choose positions in the text, in increasing order, that spell the pattern. For pattern aa and text aaa, track which two occurrences of a you chose.

Split on the final merge, pivot, or triangle

Piles of weights 3, 1 and 2 stand in a row. A move replaces two neighboring piles by one pile whose weight is their sum. You pay that sum on every move. Find the smallest total payment needed to leave one pile.

Two ends, score difference, and forced turns

The numbers 8, 15, 3 and 7 lie in a row. Two players take turns removing either end and adding it to their own score until the row is empty. Both play optimally. How many points can the first player guarantee?

Delete, paint, or merge matching endpoints

A string shrinks as you erase letters. One move erases a contiguous run of equal letters, after which the remaining sides join. Find the fewest moves that erase aba. Initially its two occurrences of a are separated.

Noncrossing pairs, parsing, and interleaving

Place four ordered points on a line. Pair all points and draw one arc above the line for each pair. Arcs may nest but may never cross. Count the possible complete pairings. Pairing the first point creates separate obligations inside and outside its arc.

Cut a circular instance at a justified boundary

Pile weights lie around a circular necklace. You may merge neighboring piles, paying their combined weight, until only one remains. Find the minimum total cost. In the circle 5,1,4 the piles 4 and 5 are neighbors even though they sit at opposite ends of the written list.

Exactly k consecutive pieces

You’re given the array 1, 2, 1. Cut it into exactly two consecutive nonempty pieces, so each element belongs to one piece. Each piece costs the square of its sum. Choose the cut that minimizes the combined cost.

An exact set can determine the step number

There are as many jobs as workers. Each worker must get one job they can do, and no two workers may share a job. If the first worker can do x or y and the second can do only y, how many complete assignments are possible?

Visit every city with a set and a last stop

You have a small set of cities, a starting city and a travel cost for each available leg. Build a route that visits every city exactly once at minimum total cost. If the task requires a round trip, add the leg back to the start after the last visit.

Partition a set into compatible groups

Seat four guests at tables. You know which pairs can share a table, and every pair at the same table must be compatible. Guests a and b refuse to sit together. Use the fewest tables that allow everyone to sit.

All submask aggregates by one sweep per bit

Each binary mask represents a subset of a small universe and has an assigned value. For every mask M, return the sum of values of all subsets contained in M. The empty subset and M itself both contribute.

A lexicographic pair can replace enumeration of groups

Three riders weigh 4, 4 and 2. A lift carries total weight at most 6 per ride, and each rider must travel once. You can choose who rides together and in what order to load them. Find the fewest rides.

Track prime parity, used primes, or small-feature coverage

Choose a nonempty subset of the numbers 2, 8 and 3. Its product must be a perfect square, such as 16. Determine which selections qualify. The larger counting version asks how many different selections make every prime exponent even.

Charge a pair whenever a growing cut separates it

You’re given symbols and a weight for each related pair. Place the symbols in distinct positions on a line. A pair pays its weight times the number of positions separating it. Find an ordering that minimizes the total payment.

A route can stop, return, visit only terminals, or respect prerequisites

A courier starts at a depot and must visit all delivery locations. Travel prices are given. Find the cheapest trip when the courier may finish anywhere. Then change the rules so the courier must return to the depot, or must visit A before B. How do those requirements change the answer?

Pack all possible Hamiltonian endpoints into one mask

A small graph tells you which pairs of cities can be traveled between. For each subset of cities, determine which of its cities can be the endpoint of a path visiting precisely that subset, each city once. The answer for a subset can contain several endpoints.

Separate a monotone walk from a general shortest path

A board has two rows and three columns. You start in the upper-left corner and want to reach the lower-right corner. You may step one cell right or down, and the top middle cell is blocked. Count the different routes that avoid it.

Sparse obstacles and a first-bad-event subtraction

You must cross a very large grid from its upper-left corner to its lower-right corner, moving one cell right or down each time. Only a short list of cells is blocked. Count valid paths when the full grid is too large to store.

Synchronize two paths by elapsed moves

Two walkers start in the top-left corner of a reward grid and both finish at the opposite corner. On each tick each walker moves right or down. A cell pays its reward only once even if both walkers visit it. Maximize the total reward they collect.

A narrow frontier remembers occupied cells

Fill every cell of a 2 × 3 board using dominoes that each cover two neighboring cells. A domino may be horizontal or vertical, and tiles cannot overlap. Count distinct complete tilings. A horizontal tile can extend into the next column while you are still filling this one.

Occupancy fails when the frontier must remain connected

On a narrow grid, select grid connections so the final drawing is one connected loop satisfying the cell rules. Two partial drawings can cross the boundary to the next column in exactly the same places yet connect those loose ends differently. Which ones can finish as a single loop?

Replace a narrow strip by a small separator

You’re given a graph together with a tree of small overlapping vertex sets, called bags. Choose as many vertices as possible without choosing both ends of an edge. Parts of the graph processed separately must agree on the vertices they share.

Expand a graph by the small missing state

You’re given a road network with nonnegative fares and one coupon that makes any single road free. Find the cheapest trip from your source to your destination. On a route costing 4 followed by 9, you may decide which of those fares to waive.

Solve cycles locally and connect the components

You travel through a directed network and may revisit vertices. In one version each vertex offers a reward you may collect only once, and you want the greatest collectible reward. What can you safely treat as one place when the network lets you go back and forth between several vertices?

Strip trees, then close each cycle

Each vertex has a weight and points to exactly one successor. Choose vertices of maximum total weight subject to the rule that the endpoints of an arrow cannot both be chosen. Chains may feed into a directed cycle, so choices at the two ends of the cycle must agree.

Few terminals, many ordinary graph vertices

In a weighted undirected graph, a small set of vertices must all be connected. You may use other vertices and pay for each chosen edge only once, even when several routes share it. Find the minimum total edge cost of a network connecting every required vertex.

Use shortest distances to expose a DAG of optimal paths

You’re given a graph with positive edge lengths and two vertices s and t. A route’s length is the sum of its edge lengths. Count shortest routes from s to t and determine how many of those pass through a specified vertex.

Fix the number of moves to make a cyclic graph acyclic in time

In a directed graph you start at s and must use exactly two edges, ending back at s. The edge s → a costs 2 and a → s costs −3. Vertices may be revisited. Find the cheapest walk satisfying the exact move count.

A pairwise edge price needs a pending first edge

A traveler pays for consecutive edges in pairs. Traversing weights a and b together costs (a+b)². Starting at a given vertex, find the minimum fare to each destination using complete pairs. A route with one unpaid edge still needs a partner.

A transitive closure can make the entire SCC collectible

In a directed graph you may jump from u to v whenever v is reachable from u. Construct a route visiting distinct vertices. First maximize the number visited, then minimize their total vertex weight among routes of that length. A strongly connected group lets you choose the order in which you collect its vertices.

A tree edge is a one-vertex interface

A tree must be colored black or white, with no edge joining two black vertices. Count all valid colorings. On a three-vertex path, coloring the middle black immediately restricts both endpoints.

At most one child can take a special edge

You’re given a tree. You may mark an edge if neither of its endpoints touches any other marked edge. Find the maximum number of edges you can mark. At a branch, several children can compete for the same parent.

Merge a child’s size or budget distribution

A tree is rooted at a specified vertex. Choose a set of vertices that includes that root and stays connected by edges entirely inside the set. For each possible set size, count the choices. Taking a descendant can force its connecting ancestors into the set.

Send messages in both directions

You’re given an unweighted tree. Treat each vertex in turn as a meeting point and add the distances from it to every vertex. Return one sum per possible meeting point. Start with the path 0–1–2–3, where distance is the number of edges traveled.

Sparse marked vertices and virtual-tree DP

You’re given a large fixed tree with distances on its edges. Each query marks a small set of vertices. Find the total length of the smallest connected subtree containing the marked vertices, counting a shared portion of a path only once.

Collapse an interval of allowed labels to its endpoints

Each tree vertex receives one value from its given interval. An edge earns the absolute difference between its endpoints’ values. Choose the values to maximize the sum over all edges, remembering that one vertex’s value affects every incident edge.

Keep a path open for the parent or close it through this vertex

Each vertex of a tree has a weight, which may be negative. Choose a nonempty path that visits no vertex twice. Its score is the sum of the weights of the vertices it visits, including both ends. Find the largest possible score.

A prerequisite tree can become a linear jump DP

Items form a rooted tree of prerequisites. An item has a cost and a value, and taking it requires taking every ancestor on its path to the root. Under a fixed budget, choose a legal collection with maximum total value.

Replace strict geometric containment with a chain

Envelopes have (width,height) pairs (2,3), (2,4) and (3,5). One may be placed inside another only if both dimensions grow strictly, with no rotation. Find the greatest number that can form one nested chain.

Geometry can determine the price of a combinatorial move

A courier starts at a depot. On each trip they visit one or two uncollected points, then return to the depot. Traveling between two locations costs their squared Euclidean distance. Collect every point with the smallest total travel cost.

Absolute distance can turn all predecessors into two sweeps

Suppliers occupy positions along a straight road. A supplier at j charges its starting price plus the distance |i−j| to deliver to position i. For every position i, find the cheapest delivered price, including the option to buy from a supplier at i.

Turn a reachability cone into coordinate inequalities

Events occur at specified times and positions on a line. One walker can move at most one unit of distance per unit of time and may skip events. Choose the largest feasible sequence of events without claiming two locations that are too far apart in time.

Choose the triangle incident to a boundary chord

You’re given the vertices of a convex polygon in boundary order. Split it into triangles using noncrossing diagonals. A triangulation’s score is the area of its largest triangle. Find the smallest possible score over all triangulations.

Two monotone chains replace a visited set

You’re given points with distinct x coordinates. A tour must go from the leftmost point to the rightmost along one chain of increasing x, then return along another, visiting every point once before closing. Find the shortest tour obeying those restrictions.

Four directional path tables can meet around a crossing

Two travelers cross a rectangular grid from different corners, each restricted to moves toward their own opposite corner. Cells have rewards. The two routes must meet once, and the meeting cell earns no reward. Maximize the total collected on the two routes.

Translate an enormous numeric interval into a short string

You’re given an inclusive range of nonnegative integers. Count those whose decimal representation has at most one nonzero digit. For 10 through 25 you can check by hand, but in a large range you cannot visit every integer.

Attach a residue, digit mask, position, or automaton

Count the positive integers in a range that are divisible by every nonzero digit appearing in their own decimal representation. For instance, a number containing both 2 and 3 must pass both divisibility tests. A digit 0 adds no divisibility requirement.

Change direction for arithmetic carries

Choose an ordered pair (a,b) of nonnegative two-bit integers, so each lies between 0 and 3. Count pairs with ordinary sum equal to binary 10, which is decimal 2. Align their bits by position just as in written addition.

Choose and order actual digits

You have digit tiles 1, 1 and 2. Use every tile exactly once to write a number and count distinct results. Exchanging the identical 1 tiles does not produce a different number. In variants that allow a zero tile, the first digit may need a separate rule.

Sum digits, sum values, or compute moments without a sum axis

You’re generating decimal numbers one digit at a time. Instead of listing every valid number, you must return the sum of their numerical values. If the prefixes 1 and 3 are both allowed and each acquires the final digit 5, what should happen to the sum you store?

Follow probability through one trial at a time

Two independent coins show heads with probabilities 1/2 and 3/4. Flip each once. Find the probability of seeing exactly one head, counting either order of heads and tails. With many coins you may need the complete distribution of head counts.

First-step analysis and self-loops

Each press of a button succeeds independently with probability 1/4. Keep pressing until the first success. Find the expected total number of presses, including the press that eventually succeeds.

Several mutually dependent expectations

You start at A. A move from A always reaches B. At B, a fair coin sends you home or back to A. Home ends the trip. Find the expected number of moves before you arrive home, including moves on repeated visits.

Track only the moments a nonlinear reward reads

In a sequence of independent trials a success extends the current run and a failure resets it to zero. Your reward depends on the square of the current run length. Find its expected value. Two fair trials give a small distribution you can enumerate.

Winning positions, minimax, and sums of independent games

Two players share two heaps of stones. On a turn a player removes one or two stones from exactly one heap. A player with no legal move loses. Given the starting sizes, decide who can force a win if both choose their moves well.

Cycles in adversarial games need retrograde analysis

You’re given a directed graph of game positions. Players alternate moving along one outgoing edge. A player stuck with no move loses, and a play that continues forever is a draw. Classify each starting position, including a pair of positions that lead only to each other.

Choose before or after observing a random outcome

A coin shows heads or tails with equal probability. Guess correctly and earn 1, otherwise earn 0. Compare a game where you must commit before the toss with one where you can choose after seeing it. Find the best expected reward under each information rule.

Count interchangeable species and condition on a real change

Three species compete. Rock beats scissors, scissors beats paper, and paper beats rock. Each turn a random pair meets and, if the species differ, the loser is removed. Given the starting populations, find the probability that each species eventually survives alone.

A random walk can have an acyclic direction and a cyclic row

A robot starts in a given grid cell and stops when it reaches the bottom row. Each step it chooses uniformly from staying put, going down, and going left or right where a neighboring cell exists. Find its expected number of steps before it stops.

Change the objective by tracking its incremental expected reward

Trials succeed or fail independently with known probabilities. Every maximal consecutive run of successes of length L scores L². Find the expected total score of the entire sequence, including a run that continues through its final trial.

Replace a random elimination order with random priorities

Take a rooted tree and a uniformly random order of all its vertices. When a vertex’s turn arrives, if it is still present, remove it and all its remaining descendants. Find the expected number of vertices that get their own removal turn before an ancestor removes them.

Use completion counts to sample a valid answer uniformly

There are three valid words, 001, 010 and 100. Generate one so each complete word has probability 1/3. You must write the word left to right. The first decision has two possible bits, but they do not lead to the same number of completed words.

Randomly colour vertices, then run an exact subset DP

In a large graph, decide whether there is a path visiting k distinct vertices. Vertices cannot be reused, and k is small compared with the total vertex count. You may use randomness to search, but any path you report must satisfy the original distinctness requirement.

Evaluate a counting polynomial when only identity matters

Two constructions count combinatorial objects by size and encode their counts as polynomial coefficients. You want to know whether the two count sequences differ. The polynomials are too large to expand in full, so you are allowed a randomized equality test with a stated error bound.

Fix random decisions one at a time while preserving an expectation

You’re given an undirected graph. Put every vertex on one of two sides and output an assignment for which at least half the edges cross from one side to the other. The challenge is to construct a qualifying assignment even if you start from a random-choice argument.

Query an interval of previous values

You start on square 0 of a number line and want to land exactly on square 4. Each jump moves forward by 1, 2 or 3 squares. Count the different sequences of jumps. The same question can give a much larger destination and a whole interval of allowed lengths.

A moving predecessor window with a monotone deque

While processing a sequence, each new position can extend only a recent predecessor. You need the largest score in the current window. With scores 5, 2, 4 and a window of width two, yesterday’s best value eventually stops being eligible. Return the best score for each window.

Search by one coordinate and return the best of another

You have records with an ID and two values (a,b). A query specifies an inclusive interval of a values, such as 2 through 6. Among just those records, return the ID with the smallest b. The coordinate that determines eligibility differs from the one you minimize.

A new endpoint changes many split candidates by the same amount

Split a sequence of letters into a prescribed number of nonempty contiguous pieces. Each piece earns its number of distinct letters, so repeated copies of a letter count once inside that piece. Maximize the sum of piece scores. The last cut determines which pieces gain from a new letter.

A third coordinate and earlier-to-later transitions

You’re given points with three coordinates. Make the longest chain in which all three coordinates increase strictly from one point to the next. Equal values in even one coordinate prevent that transition, regardless of the other two.

Versions or time intervals preserve the correct DP layer

A sequence has several versions. Two different extensions may both start from the same saved prefix, and each needs to query the best predecessor in that prefix. Compute the best scores as each version grows without letting a change in one branch affect its sibling.

Equal segment extrema form consecutive blocks of cuts

Split an array into contiguous pieces. A piece’s cost is its largest entry. In a partitioning step you know the best cost up to each possible last cut. Find the least total cost as you move the final endpoint right and the last piece’s maximum changes.

Accumulate range rewards between the few times a state can change

You occasionally receive a point to assign to one of two skills. Between awards, a series of checks tests whether the relevant skill reaches a specified threshold. Earlier assignments remain fixed. Choose the assignments that pass the most checks over the whole sequence.

A forbidden gap can turn one predecessor query into two

You’re given heights in a fixed order. Choose a subsequence in which consecutive chosen heights differ by at least 4 in absolute value. Find the longest such subsequence. A previous height can qualify by being either much lower or much higher than the new one.

Store a witness or the number of optimizers inside each range node
