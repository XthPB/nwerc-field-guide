Designing the state

A program gets shorter when two different histories lead to the same future. Start with a two-colour counterexample, then learn which kind of information a table can safely forget.

Test your recognition
Two partial schedules end at the same time. One has used the single cancellation coupon and the other has not. Is the cheaper prefix always safe to keep?

Keep one minimum per coupon state. An expensive prefix with the unused coupon can save more later. Merge only after fixing future eligibility.

There are 2²⁰ masks and 20 possible last vertices. Can a full 64-bit table and a second full 64-bit parent table fit a 256 MiB limit?

The score table alone is 160 MiB. Two such tables cost 320 MiB. Compact the parent, store only reachable endpoints, roll compatible layers, or reconstruct in another pass.
