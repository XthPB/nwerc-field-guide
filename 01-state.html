Designing the state

Two roads take you from s through a to t. Their fares are 4 and 9, and you have a coupon that makes one road free. Where should you spend it to pay the least? At a, two travelers can stand in the same place with very different options left.

Start this topic in reading order → · See the whole reading path

  • What must a state remember?You play a game in rounds. Each choice earns points and leaves you holding a colored card. In the next round a red card earns a 10-point bonus and a blue card earns nothing. If you can finish this round with 7 points and red or 9 points and blue, which possibilities should you keep to maximize your final score?
  • Can I, how many, how good, and how many best?You travel through a directed graph and collect a score along each route. Two different routes to the same vertex each earn 4 points. A judge might ask whether you can get there, for the highest score, or for the number of routes attaining it. What would you keep for each question?
  • Find a quantity that always moves forwardYou’re given a road map. Each road goes one way, and following the arrows can never take you back to a city you’ve left. You want the cheapest trip from A to C. The direct road costs 8. The road from A to B costs 4, and the road from B to C gives you a rebate of 3. Add the fares along the trip, counting the rebate as −3.
  • Dense tabulation, sparse memoization, and rolling layersYou’re given two strings. In one edit you can insert, delete or replace one character. Find the fewest edits that turn the first string into the second. You have space for a few rows of numbers, so you need to know when an earlier result can be overwritten.
  • Estimate the actual array before choosing a techniqueYou want a cheapest tour through 20 cities. One possible table stores the best cost for every visited set and possible last city. Before implementing it, estimate how many bytes those entries alone would take if a cost occupies eight bytes.
  • One witness, all optima, and lexicographic rankSomeone has sorted all length-three binary words containing exactly one 1 into dictionary order, with 0 before 1. Produce the third word. For longer words you need a way to skip whole groups while constructing the requested answer.
  • Keep a frontier when one score per position failsYou may select items up to a weight limit of 6, with the goal of maximizing profit. Two partial selections have (weight, profit) equal to (2,5) and (4,4), and both have the same items still available. Which partial selections can you safely discard?
  • Charge each object to a unique last choiceSplit the labeled objects a, b and c into exactly two nonempty groups. There is no first or second group, so {a} with {b,c} and {b,c} with {a} describe the same answer. Count each partition once.
  • Memoize only the quotients you can actually visitA sequence begins at f(0)=1. For n>0 it satisfies f(n)=f(⌊n/2⌋)+f(⌊n/3⌋). Compute f(n) for one enormous n when an array containing all entries up to n would not fit in memory.
  • Index by moves when the answer is smaller than the search spaceA building has an unknown highest floor from which an egg survives a drop. It survives from every lower floor and breaks from every higher floor. A broken egg cannot be reused. With two eggs and at most three drops, find the largest number of floors for which you can always identify the threshold.

Try the upper continuation

The upper state spends its coupon on a→t, normally priced 9. The final cost is 4.

Compare both continuations

The lower state already spent the coupon, so its final cost is 9. Merging the two arrivals at a solely by paid cost would discard the winner.

Test your recognition
Two partial schedules end at the same time. One has used the single cancellation coupon and the other has not. Is the cheaper prefix always safe to keep?

Keep one minimum per coupon state. An expensive prefix with the unused coupon can save more later. Merge only after fixing future eligibility.

There are 2²⁰ masks and 20 possible last vertices. Can a full 64-bit table and a second full 64-bit parent table fit a 256 MiB limit?

The score table alone is 160 MiB. Two such tables cost 320 MiB. Compact the parent, store only reachable endpoints, roll compatible layers, or reconstruct in another pass.
