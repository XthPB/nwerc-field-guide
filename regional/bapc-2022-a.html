Adjusted Average

Remove at most k ≤ 4 entries from n ≤ 1500 numbers so the average of those left is as close as possible to x.

The observation

For exactly l removals, minimise |S − removedSum − (n−l)x|/(n−l). The target removed sum is S−(n−l)x. Meet in the middle becomes safe when the left pair is entirely before the right pair in index order.

Why it works

Every four-element set has a unique split into its first two and last two indices. When the right pair starts at j, store only pairs with both indices below j. A lower_bound and its predecessor give the closest feasible complementary sum. Compare all l separately because their denominators differ.

From a small instance to the contest constraints

Enumerate removal sets

Try every subset of size at most k. This is the clearest exact definition and a valuable differential-test oracle.

Small-instance oracle · O(n^k) time · O(k) space

One or two removals

For l = 1 or 2 inspect each candidate directly; no data structure is needed. Keep these cases in the final solution too.

Accepted for k ≤ 2 · O(n²) time · O(1) space

Sort and use two pointers

For three removals, fix one sorted entry and move two pointers to approach the target. Distinct positions are automatic. Four removals would still need O(n³).

Subproblem for k ≤ 3 · O(n²) time · O(n) space

Ordered pair sums with an index boundary

Sweep the first index j of the right pair. Insert all newly available left pairs (i,j−1). Query target−a[j]−a[t] for t>j. A corresponding set of earlier single values handles l=3.

Recommended · O(n² log n) time · O(n²) space

Offline coordinate compression

Compress every pair sum. A Fenwick tree marks which sums have appeared to the left of the boundary. Prefix counts and order-statistic search recover predecessor/successor. This trades tree-node allocation for contiguous memory; it does not improve the asymptotic bound.

Alternative data structure · O(n² log n) time · O(n²) space

Boundary checks

Do not query an unrestricted pair-sum list and accidentally reuse an index. Include zero removals, require n−l > 0, and use 64-bit sums. One editorial slide has an inconsistent target: derive it from the remaining mean.
