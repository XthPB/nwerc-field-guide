Boggle Sort

Rotate 16 fixed six-sided letter dice so their upward letters, read in order, form a nondecreasing sequence. Keeping a face costs 0, turning to a side costs 1, and turning to the bottom costs 2. Q represents the two-letter face Qu.

The observation

The future only needs the final letter of the previous expanded face. For Q, that letter is U. Positions never change, so the state graph is layered and acyclic.

Why it works

Every valid choice of one face per die corresponds to a path through the layers. Its edge/vertex costs sum to the number of rotations. Conversely every compatible path produces a sorted string. A shortest path or a DP over these layers therefore gives the optimum. Keeping only the cheapest prefix for a given terminal letter is safe because all such prefixes permit exactly the same continuations.

From a small instance to the contest constraints

All face assignments

Try all six faces on c dice, then check the expanded string. Use this to validate DP on two to six dice.

Small inputs only · O(6^c·c) time · O(c) space

Three-way branch-and-bound

For the current lower letter bound, only the smallest feasible side face matters: all side faces cost 1 and a smaller terminal letter cannot hurt the future. Branch on keep, that side, and bottom. Prune when spent cost already exceeds the best complete solution.

Exponential baseline · O(3^c·c) time · O(c) space

Shortest path in the layered graph

Make one node per face and connect compatible faces on consecutive dice, with the destination rotation cost. Dijkstra is correct because all costs are nonnegative; it is more machinery than necessary but a useful modelling bridge.

Efficient alternative · O(cr² log(cr)) time · O(cr²) space

Face-to-face dynamic programming

Process the DAG directly: try each previous face and current face. Here r=6 and c=16, so the straightforward transition is tiny. This also avoids any heap.

Recommended · O(cr²) time · O(r) space

Prefix-minimum alphabet DP

Index states by the terminal letter. A prefix minimum over the alphabet answers the best previous terminal letter ≤ the current first letter in constant time. Useful when the number of faces or allowed symbols grows.

Generalization · O(c(σ+r)) time · O(σ) space

Boundary checks

Do not sort the dice. Q may follow a letter ≤Q, but its successor must be ≥U. A greedy choice of smallest available letter can pay more rotations than necessary. The printed DP slide should use min and add the face cost.
