Graphs, connectivity and flow · BAPC 2025-H

Homesick

In an undirected unweighted simple graph, find a shortest nonempty closed walk starting at vertex 1 with no immediate edge reversal. Vertices and edges may reappear later; a valid walk need not be a simple cycle through 1.

The observation

A vertex alone is not a sufficient state: the next edge cannot return to the previous vertex. Yet only the two best arrivals from different predecessors are needed.

Why it works

An exact state is (previous,current). For any outgoing neighbour w, the best arrival into current must exclude predecessor w. Among arrivals with distinct predecessors, either the shortest is allowed, or the second-shortest is. Every later arrival is dominated for all future moves. Therefore keep two shortest labels per vertex, with distinct incoming neighbours, and run BFS. The first positive-distance label returning to the start yields an optimal walk; preserve label parents to reconstruct it.

From a small instance to the contest constraints

Enumerate walks by increasing length

BFS entire sequences, rejecting immediate reversals. Useful for graphs of a handful of vertices, but the number of histories is enormous.

Tiny graphs only · Exponential in walk length time · O(search frontier) space

BFS on directed-edge states

Store one state for each oriented edge. Each state may continue along every edge except its reverse. This is correct but a high-degree vertex causes many transitions.

Exact baseline · O(Σ deg(v)²) time · O(n+m) space

Find a cycle and attach a stem

A DFS can find a reachable cycle. A path from the start to it, a full lap, and the reversed stem gives a valid candidate. The first cycle found is not necessarily optimal; use it as an upper bound and a structural explanation.

Valid upper bound only · O(n+m) time · O(n+m) space

BFS with two predecessor labels

Admit at most two arrivals with different incoming neighbours at each vertex, in BFS order. Expand each admitted label once, excluding its incoming edge. This is exact dominance compression of the directed-edge state graph.

Recommended · O(n+m) time · O(n+m) space

Two-label Dijkstra

If roads have nonnegative unequal lengths, the same domination proof applies but BFS order does not. Finalize the first two distinct-predecessor arrivals using a priority queue. This is enrichment beyond the unweighted task.

Weighted-graph generalization · O((n+m) log n) time · O(n+m) space

Boundary checks

A tree has no valid walk. A cycle reachable through a stem may yield a valid lollipop walk; searching only simple cycles containing the start is wrong. The incoming-neighbour labels must be distinct. Reconstruction should follow label IDs, not just one parent per vertex.
