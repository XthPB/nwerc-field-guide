Range queries and sweeps · BAPC 2024-M

Museum Visit

Choose visit days with minimum total discomfort so every exhibition interval contains at least one chosen day. Up to 200,000 days and exhibitions.

The observation

After choosing today i, the previous chosen day must lie to the right of the latest start among intervals that already ended. This turns interval hitting into a sliding range-minimum DP.

Why it works

Let dp[i] be the cheapest valid prefix schedule whose last visit is i and which hits all intervals ending before i. Set a dummy visit dp[0]=0, and add day n+1 with zero cost. Define k_i=max{start: end<i}, or 0 if none. A previous last visit j is feasible exactly when k_i≤j<i: any interval ending since j then contains j or i, and any interval strictly before j was already hit. Thus dp[i]=cost[i]+min dp[j] over that range. k_i never decreases, enabling a deque.

From a small instance to the contest constraints

Enumerate visit subsets

For each subset, test that it intersects every interval and sum costs. This is a useful independent oracle for optimized methods.

Tiny n only · O(2^n·(n+m)) time · O(n) space

Scan the DP transition range

Compute k_i using buckets of interval ends, then scan dp[k_i..i−1]. The recurrence is the hard part; the range data structure is a separate optimization.

Exact baseline · O(n²+m+n) time · O(n+m) space

Segment tree for range minima

Store completed dp values in a min segment tree. Query [k_i,i), then point-update dp[i]. This works even if lower bounds did not move monotonically.

Recommended first implementation · O((n+m) log n) time · O(n+m) space

Min-heap with expired-index removal

A heap stores (dp value,index). Remove top entries whose index is below k_i; expired entries buried below the top can be left until they surface.

Alternative · O((n+m) log n) time · O(n+m) space

Monotonic deque

A newer index with no larger dp dominates an older one: it is cheaper and expires later. Remove dominated entries from the back and expired indices from the front. Each index enters and leaves once.

Advanced optimal method · O(n+m) time · O(n+m) space

Boundary checks

Intervals are inclusive: only end<i determines the lower bound at step i. Add the final zero-cost sentinel to force every exhibition to be hit. Costs can total about 2·10^14. The zero dummy day must disappear once a real interval has ended.
