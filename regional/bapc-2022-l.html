Geometry and numerical methods · BAPC 2022-L

Lowest Latency

Find the closest pair among 100000 three-dimensional points drawn independently and uniformly in a cube. The random-input promise is part of the problem.

The observation

Spatial bucketing is effective because random points are spread out. A cell-side s search of neighbouring cells is complete once the best distance found is ≤s: a closer pair cannot differ by two or more cell indices in any coordinate.

Why it works

For the certified grid variant, inspect all pairs in the same or adjacent cells. If the best distance d≤s, every omitted pair has a coordinate gap at least s and cannot improve d. If no certificate appears, enlarge the cells and repeat until it does. This makes correctness unconditional while expected efficiency uses the distribution.

From a small instance to the contest constraints

All pairs

Compute every squared Euclidean distance, then take one square root. This gives exact ground truth for small random tests.

Small-instance oracle · O(n²) time · O(1) space

Sort by x and prune by current distance

Only stop a forward scan when dx²≥best. This is safe; limiting the scan to a fixed number of neighbours is not.

Exact alternative · O(n²) worst case; faster on random data time · O(n) space

Fixed spatial grid

Choose about 100 cells per coordinate and inspect neighbouring cells. The random-input promise makes the closest pair overwhelmingly likely to lie within one cell width. Without a certificate, this is a probability argument.

Jury-style probabilistic approach · Expected near O(n+B); O(n²) worst case time · O(n+B) space

Add a correctness certificate and fallback

After the neighbour scan, check best≤s². Otherwise double s and rebuild. Eventually one large cell includes every point, so the process cannot silently miss the closest pair.

Recommended robust variant · Distribution-sensitive; O(n² log U) crude worst bound time · O(n) space

Randomised incremental closest-pair grid

Maintain cell width proportional to the current closest distance. When a new point improves it, rebuild the grid. Packing bounds limit work between rebuilds; random insertion order bounds rebuild probability by 2/i. This requires a careful grid convention and duplicate-point handling.

Advanced generalisation · Expected O(n) under standard random-order analysis time · O(n) space

Boundary checks

A fixed number of x-sorted neighbours is not a proof in 3D. The published fast grid exploits the random distribution; distinguish that from a worst-case closest-pair guarantee. Squared distance is at most 3·10^18 and fits signed 64-bit, but cast before multiplication.
