Range queries and sweeps · BAPC 2025-D

Duo Detection

You’re given many sets of distinct integers. Find two different sets that share at least two elements. Report the two sets and two values they have in common, or determine that no such pair exists.

The observation

Two obvious quadratic algorithms fail on opposite shapes of input. Split sets by size and let each algorithm handle the shape where it is cheap.

Why it works

Call a set heavy if its size is at least B. There are at most M/B heavy sets. Mark each heavy set and scan all sets, costing O(M²/B). For light sets, enumerate value pairs: sum |S|² ≤ BM. A repeated value pair proves the desired intersection. Balance these terms with B≈sqrt(M). The equivalent bipartite incidence graph asks for a 4-cycle.

From a small instance to the contest constraints

Intersect every pair of sets

For every pair, scan the smaller set and test membership in the larger. Stop after two hits. Many similarly sized sets make this too slow.

Small inputs only · O(NM) with membership sets time · O(M) space

Remember every co-occurring pair

Map each unordered pair of symbols to a set that contains it. A repeated pair gives a witness immediately. One enormous set makes pair enumeration prohibitive.

Good for small sets; bad worst case · O(Σ|S|²) expected time · O(Σ|S|²) space

Bitset intersections

After coordinate compression to U symbols, AND pairs of bitsets and look for two set bits. This makes the quadratic search word-parallel, but the dense representation may exceed memory. Use it only after calculating N·U.

Exact alternative; distribution dependent · O(N²U/w) time · O(NU/w) space

Heavy/light decomposition

Mark and scan heavy sets; use pair hashing only for light sets. This is the standard square-root balancing pattern: one part costs M²/B, the other MB.

Recommended · Expected O(M√M) time · O(M+B M) worst-case pair storage space

Remove hashing from the light case

Group pair processing by its first symbol. For each fixed symbol x, visit light sets containing x and timestamp the other symbols. Seeing y twice in different sets finds x,y. The timestamps replace a large pair hash map.

Advanced optimization · O(M√M+M log M) time · O(M+U) space

Boundary checks

Compress values before using marking arrays. Each input set has no duplicates, but different sets may be identical. Return two distinct values and two distinct set IDs. Heavy/light bounds must use total M, not the largest value or just the number of sets.
