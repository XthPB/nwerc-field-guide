Strings and pattern matching · BAPC 2024-K

Karaoke Compression

A song is a string. Store one repeated phrase separately and replace nonoverlapping copies of it in the song by a one-character reference. You pay for both the compressed song and the stored phrase. What is the minimum combined length?

The observation

For a fixed pattern of length L, taking its occurrences from left to right greedily maximizes the number of non-overlapping replacements. Then total length is n−count·(L−1)+L.

Why it works

All occurrences of a fixed substring have equal length. Choosing the leftmost available occurrence leaves at least as much remaining suffix as any other first choice, so induction proves greedy counting optimal. Enumerate pattern lengths and identify equal substrings efficiently. The goal is to share work between many patterns, not just to accelerate one pattern search.

From a small instance to the contest constraints

Try each substring with naïve matching

There are O(n²) patterns; testing one at every position with O(n) string comparison gives the loose quartic bound.

Small inputs only · O(n⁴) time · O(n) space

KMP for every candidate pattern

Linear-time pattern matching removes one factor. Filter matched start positions greedily by the last selected end.

Exact baseline · O(n³) time · O(n) space

Rolling hashes grouped by length

For each length L, scan starts in order and keep last selected end plus count per substring hash. Each occurrence contributes O(1) expected work. Strong hashing is probabilistic unless equality is checked.

Recommended practical alternative · Expected O(n²) time · O(n) working space per length space

Z-function per suffix

For each suffix, Z-values tell how long later positions match its prefix. These values support counting occurrences of each candidate length. A plain extra loop over all lengths and positions still gives O(n³); the preprocessing alone does not prove a quadratic solution.

Exact string-matching route · O(n²) Z preprocessing; counting strategy matters time · O(n²) if stored space

Suffix array plus LCP groups

For a fixed L, adjacent suffixes with LCP≥L form equal-pattern groups. Gather each group’s start positions, sort numerically, and greedily select non-overlapping occurrences. Repeating lengths is exact; sophisticated ordered-set variants reduce constants or reuse work.

Deterministic advanced alternative · O(n² log n) straightforward grouped counting time · O(n) space

Boundary checks

Occurrences must not overlap. Include dictionary storage cost L. Exactly one nonempty substring must be chosen: initialise the answer to n+1, not n (choosing the whole string always gives n+1). Single small-modulus hashes are collision-prone with millions of substrings; use verified equality, two strong hashes, or an exact suffix method.
