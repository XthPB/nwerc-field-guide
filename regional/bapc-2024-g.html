Greedy, sorting and search · BAPC 2024-G

Grocery Greed

Partition purchases into groups. Each group may be paid exactly or rounded to the nearest 5 cents. Minimize the total paid.

The observation

Only residues modulo 5 affect savings. Separate 0,1,2 cheaply, then optimize the remaining 3s and 4s.

Why it works

Adding a multiple of 5 to any price shifts every relevant rounded/exact total by that amount, so it can be separated. Residues 1 and 2 can be rounded down individually; 0 changes nothing. Among 3s and 4s, pair 3+4 to save 2, then pair remaining 3s to save 1 or group three remaining 4s to save 2. An exchange argument replaces larger groups by these patterns without increasing cost. Any leftover 3, 4, or two 4s can be paid exactly.

From a small instance to the contest constraints

Enumerate set partitions

Generate every grouping, paying min(exact sum, rounded sum) for each group. This is an excellent oracle for checking the residue rule.

Tiny inputs only · O(Bell(n)·n) time · O(n) space

Subset partition DP

For each mask, choose a nonempty submask as one payment group. Fix one distinguished item in the group to avoid redundant orderings.

Small inputs only · O(3^n) time · O(2^n) space

DP on counts of residue 3 and 4

After handling 0,1,2, try the useful patterns (3,4), (3,3), and (4,4,4), or pay one item exactly. This validates the greedy grouping on reduced states.

Exact reduced model · O(c3·c4) time · O(c3·c4) space

Residue-count greedy

Pair opposite difficult residues first, then process the remaining homogeneous residue. All reasoning happens on counts, so sorting is unnecessary.

Recommended · O(n) time · O(1) space

Compute savings directly and verify exchanges

Start from the exact sum and subtract savings: c1+2c2, then 2 per mixed pair, 1 per 3-pair, and 2 per 4-triple. This independently checks the direct-cost implementation.

Alternative formulation · O(n) time · O(1) space

Boundary checks

Rounding is optional. Parse money as integer cents; truncating a floating-point product can lose a cent. The order of purchases is unrestricted; this is not contiguous partition DP.
