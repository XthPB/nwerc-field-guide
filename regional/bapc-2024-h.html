Range queries and sweeps · BAPC 2024-H

Horse Habitat

For every height h and width w, count all h×w axis-aligned rectangles containing only empty cells in a grid.

The observation

Convert the grid into vertical empty-run heights. Then process height thresholds from high to low: active cells form horizontal intervals, whose lengths determine every width count.

Why it works

At a fixed height h, a rectangle with bottom row i is valid exactly when its w consecutive histogram bars are all ≥h. An active horizontal component of length L contributes max(0,L−w+1) rectangles of width w. Maintain the number I[L] of components of each length while activating cells. A cell is activated once and merges with at most two neighbours. Two suffix sums convert I into all width counts: C[w]=I[w]+C[w+1], R[w]=C[w]+R[w+1]. There are rc outputs, so O(rc) is output-optimal.

From a small instance to the contest constraints

Enumerate and inspect every rectangle

Choose both row and column boundaries, then scan every enclosed cell. This follows the definition and tests small random cases.

Tiny grid oracle · O(r³c³) time · O(1) space

2D prefix sums of blocked cells

An inclusion-exclusion query tells whether a rectangle contains any blocked cells in O(1). Enumeration remains quartic.

Small-grid improvement · O(r²c²) time · O(rc) space

Histogram minimum for every interval

For every bottom row and left boundary, extend the right boundary while maintaining the minimum height. Report the interval width at that maximum height; a suffix sum over heights accounts for all smaller heights.

Intermediate baseline · O(rc²), transpose if useful time · O(rc) space

Threshold activation with DSU

Bucket cells by height and activate in decreasing order. Union active left/right neighbours in the same row, maintaining a global length histogram. Compute width answers with two suffix sums at each height.

Efficient alternative · O(rc·α(rc)) plus O(rc) output time · O(rc) space

Merge interval boundaries directly

Because components are intervals on independent rows, generic DSU is unnecessary. Store each component’s length at its endpoints; activation reads adjacent endpoint lengths and writes the new two endpoints. Every cell costs constant time.

Recommended advanced method · O(rc) time · O(rc) space

Boundary checks

Histogram heights count consecutive empty cells above and including a cell. Components never connect vertically in the threshold structure. On a merge, remove the old component counts before adding the merged length. Store totals in 64-bit.
