Trees and paths · BAPC 2023-C

Compressing Commands

Choose a working directory minimizing the total number of components in relative paths to a list of files. A parent step .. counts as one component; duplicate requested files count repeatedly.

The observation

File paths form a trie/tree. Moving the working directory across one edge makes every file on one side one step closer and every file on the other side one step farther.

Why it works

Let cnt[v] count requested files in v’s subtree, with multiplicity, and let N be the number of requests. Moving from directory u to child directory v changes total distance by (N−cnt[v])−cnt[v]=N−2cnt[v]. Compute the root cost and subtree counts once, then reroot in linear time in the trie size. File nodes are destinations, not valid choices of working directory.

From a small instance to the contest constraints

Try every directory and construct all relative paths

For each candidate directory, find common prefixes with every file path and count up/down components. D is maximum depth.

Small inputs only · O(V·N·D) time · O(V+N·D) space

All-source tree distances

Run BFS from each directory and weight file distances by request counts. Easier than path-string manipulation but repeats work.

Exact baseline · O(V²) time · O(V) space

Two-pass rerooting DP

Build the trie, compute subtree request counts and root distance sum, then push costs along directory edges.

Recommended · O(total input characters) time · O(V) space

Weighted tree median descent

If a directory child contains more than half the file weight, moving into it strictly improves the answer. Follow such a child until none exists. If the heavy child is a file, stop at its parent because files are forbidden roots.

Alternative · O(V) after trie construction time · O(V) space

Weighted-edge rerooting

If traversing components has unequal weights, crossing an edge of weight w changes the cost by w(N−2cnt[v]). This generalizes the same proof to weighted tree facility-location problems.

Advanced generalization · O(V) time · O(V) space

Boundary checks

Duplicate paths must increase multiplicity. Count components, not characters. A file name cannot be selected as the working directory. Distinguish the root’s empty prefix from an ordinary component.
