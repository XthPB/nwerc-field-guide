Extraterrestrial Exploration

Query a sorted hidden integer list and choose three distinct indices maximizing the sum of square roots of their pairwise value differences. Queries are tightly limited.

The observation

Use the extreme values as the two outside points. The middle point should be as close as possible in value, not index, to their midpoint.

Why it works

For sorted values a≤b≤c, moving a left or c right cannot decrease any distance term, so the outer values can be the global extremes. With fixed extremes the varying part is sqrt(b−a)+sqrt(c−b), a concave function symmetric around (a+c)/2. It increases up to the midpoint and decreases afterwards. Binary-search the first interior value at least the midpoint and compare it with its predecessor.

From a small instance to the contest constraints

Read everything and test every triple

This directly evaluates the objective and is useful only in an offline tiny oracle.

Baseline; query budget fails · O(n³) work and n queries time · O(n) space

Fix endpoints and scan middle values

The endpoint proof removes two loops. A linear scan still violates the interactive budget for large n.

Correct offline, too many queries · O(n) time · O(1) space

Discrete ternary search

The objective is unimodal over sorted values. Ternary search can find its maximum, but needs careful equality handling and more queries than the midpoint approach.

Alternative; budget-sensitive · O(log n) rounds, about 2 new queries/round time · O(log n) cache space

Binary search the midpoint

Find lower_bound of the exact doubled midpoint among interior indices. Only the boundary candidate and its predecessor can be optimal.

Recommended · O(log n) queries time · O(log n) cache space

Binary search the derivative sign

For x inside the endpoints, the derivative has the sign of (a+c−2x). Thus the same search is a root-finding problem for a monotone sign, illustrating how calculus can yield an exact discrete algorithm without numerical derivatives.

Alternative derivation · O(log n) queries time · O(log n) cache space

Boundary checks

Query caching prevents repeated requests. Return distinct indices, even when values repeat. Compare |2b−a−c| with integer arithmetic instead of evaluating nearly equal square roots.
