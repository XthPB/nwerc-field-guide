Cangaroo

Cover marked grid cells with the minimum number of non-overlapping 2×2 cans, each supported by the floor or a can below it; width is at most 10.

The observation

Process horizontal bands of height two from the floor upward. A state is the set of columns where cans start. Adjacent starting columns are forbidden, and a can in the next band needs at least one column of overlap with support below.

Why it works

By induction from the floor, every can starts on an even-height band: support comes from a can of height two. Given the placement in the current band, all constraints involving lower bands are already decided. Thus dp[row][mask] is a sufficient state. Transition only from a supporting lower mask, and add the number of cans in the upper mask.

From a small instance to the contest constraints

Enumerate all cans in the grid

Choose candidate 2×2 placements, then check overlap, coverage and support. Useful only for tiny boards.

Exponential oracle · Exponential in grid area time · O(nm) space

Enumerate band configurations

Generate all independent sets of starts on a path of m−1 positions. The number of valid placements is Fibonacci-sized, much smaller than all cell subsets.

State-model step · O(2^m·m) time · O(2^m) space

Optimise each band independently

Minimum coverage in one band may leave the next band unsupported. This is the counterexample to discarding the boundary state: a cheap empty lower band can make a required upper can impossible.

Incorrect tempting shortcut · O(nS) time · O(S) space

Profile DP with support transitions

For every pair of placements, check support and coverage. Each upper start j requires occupied(lower)&(3<<j) to be nonzero.

Recommended · O(nS²), S=F_(m+1) time · O(S) space

Precompute compatibility lists

Support does not depend on the row. Build the list of legal predecessor masks once, then each band only filters coverage and performs minimum transitions.

Implementation refinement · O(mS²+nE), E≤S² time · O(E+S) space

Boundary checks

Occupancy masks and can-start masks are different. A start at j covers bits j and j+1. Include marks in both rows of a band. The bottom band is supported by the floor; an empty lower band cannot support a nonempty upper one.
