Graphs, connectivity and flow · BAPC 2022-K

Kiosk Construction

Choose a kiosk in a numbered grid so every guest reaches their destination under a prescribed greedy neighbour rule, minimising the worst walking distance.

The observation

Fix the destination first. Every other plot then has exactly one outgoing edge, chosen by (distance of neighbour label to target, distance of neighbour label to current label). Reverse these edges and BFS from the destination.

Why it works

A vertex reaches the target under the rule exactly when it is reachable from the target in the reversed graph. Its reverse-BFS distance is the number of forced moves, because each original vertex has one successor. Across all destinations, keep each starting plot’s maximum distance and reject it if any destination is unreachable.

From a small instance to the contest constraints

Simulate every start/target pair

Trace the forced walk until it reaches the target or repeats a vertex. There are N² pairs and each walk may take O(N).

Baseline · O(N³), N=h·w time · O(N) space

Memoised functional-graph DFS

For each destination, memoise distances from all vertices. Three colours distinguish unvisited, active, and finished; entering an active vertex identifies a cycle.

Accepted alternative · O(N²) time · O(N²), or O(N) per target space

Reverse BFS for each destination

Build O(N) reverse edges and traverse only the vertices that can reach the destination. This avoids recursion and cycle bookkeeping.

Recommended · O(N²) time · O(N) space

Store all distances for repeated kiosk queries

Save the target-by-start distance matrix if later queries change which destinations matter. For one kiosk decision, stream maxima instead; unnecessary storage is not an improvement.

Space/time trade-off · O(N²) preprocessing time · O(N²) space

Weighted walking costs

If every forced move has a positive cost, the successor structure still gives a unique route. Accumulate edge costs during reverse traversal; Dijkstra is unnecessary unless the guest has multiple allowed next moves.

Advanced extension · O(N²) on the reversed rooted components time · O(N) space

Boundary checks

Guests do not choose the geographically closest neighbour, and they must move even if the current label is numerically closer. Apply the stated second tie-break. Cycles not containing the destination represent failure, not a large finite distance.
