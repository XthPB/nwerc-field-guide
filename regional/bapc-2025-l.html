Geometry and numerical methods · BAPC 2025-L

Linguistic Labyrinth

In an n×n×n letter grid, n≤22, count ordered B,A,P,C quadruples with right angles at A and P. The two outer segments are perpendicular to the middle segment AP.

The observation

Fix the middle pair first. Choices for B and C become independent, and perpendicularity turns into equality of dot products.

Why it works

Let v=P−A. A valid B satisfies v·(B−A)=0, so v·B=v·A; a valid C satisfies v·C=v·P. For fixed A,P, multiply the two counts. Precompute a histogram of v·B and v·C for every possible displacement vector v. There are O(n³) vectors and O(n³) points, so preprocessing is O(n⁶), after which all AP pairs cost O(n⁶). Dot products range over O(n²) values, yielding O(n⁵) dense storage.

From a small instance to the contest constraints

Enumerate all quadruples

Test the two dot products for every B,A,P,C. This is the most transparent correctness oracle on very small grids.

Tiny n only · O(n^12) time · O(n³) space

Fix A,P and count each endpoint

For each middle pair, scan B and C independently instead of enumerating endpoint pairs. Multiplying independent counts removes one cubic factor.

Still too slow · O(n^9) time · O(n³) space

Cache sparse dot-product histograms

For every direction encountered, group endpoints by their projection. A hash table is a useful implementation prototype, but the contest limits make its overhead risky.

Exact prototype; high constants · Expected O(n⁶) time · O(n⁵) worst case space

Dense histograms for every displacement

Use the bounded displacement and dot-product ranges to replace hashes with direct arrays. Then each AP pair makes just two array lookups.

Recommended · O(n⁶) time · O(n⁵) space

Group queries by direction and stream histograms

Bucket AP queries by their displacement, then build and discard that direction’s histograms after answering its bucket. This trades a full direction-by-projection table for stored AP queries. Compare actual byte counts before choosing it; for some colour distributions the query list is still large.

Advanced memory alternative · O(n⁶+|A||P|) plus grouping time · O(|A||P|+n²) space

Boundary checks

Use 64-bit for the final count. Dot products can be negative, so index with an offset. Normalizing v and −v is optional but must also negate the dot-product key. Dense storage is large: compute bytes, not just asymptotic notation. Do not replace a deterministic dense histogram with slow nested hash maps without profiling.
