Trees and paths · BAPC 2023-J

Jungle Job

For every size k, count connected vertex subsets of a tree, modulo 10^9+7.

The observation

Root the tree. Every connected subset has a unique highest vertex, so count subsets containing that vertex and lying entirely in its rooted subtree.

Why it works

Let F_v[k] count connected k-vertex sets contained in v’s subtree and including v. Start with F_v[1]=1. For each child u, either take nothing from its subtree or take a connected set counted by F_u that includes u; no other choice can remain connected to v. Merge one child at a time by convolution. Every connected subset is counted once at its highest vertex, so sum F_v[k] over v. Size-bounded merges total O(n²): cross-child pairs are charged to their unique lowest common ancestor, with the single-root contributions bounded similarly.

From a small instance to the contest constraints

Enumerate subsets and test connectivity

For each nonempty subset, traverse induced edges from one selected vertex and count it if every selected vertex is reached.

Tiny trees only · O(2^n·n) time · O(n) space

Enumerate allocations across all children

For each desired size, enumerate how many vertices come from every child. This describes the correct combinatorics but repeats partial allocations.

Exponential-degree baseline · Exponential in child count time · O(n²) space

Tree knapsack with full-size arrays

Merge children sequentially but loop over all n possible sizes even when most entries are impossible. This establishes the recurrence before trimming loops.

Correct but wasteful · O(n³) loose implementation bound time · O(n²) space

Size-bounded child merges

Use vectors only as long as actual subtree sizes. Add every completed F_v into the answer and retain it until its parent has merged it.

Recommended · O(n²) time · O(n²), reducible with careful lifetime management space

Generating-function formulation

Write P_v(x)=x·Π_children(1+P_u(x)). Coefficients are exactly the DP. This connects tree knapsack to polynomial multiplication; FFT/NTT is an advanced extension, but simply swapping in convolution does not automatically prove an overall near-linear tree algorithm, especially modulo 10^9+7.

Advanced viewpoint · O(n²) with ordinary convolution time · O(n²) space

Boundary checks

The empty choice is a merge convenience, not an extra empty connected set in the output. Restrict loops to actual subtree sizes. Multiply in 64-bit before reducing modulo. Do not claim O(n³) merely because code has nested loops; analyze how subtree sizes share work.
