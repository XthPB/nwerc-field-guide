King of the Hill

Query heights in an n×n grid with distinct values. The only local maximum under four-neighbour adjacency is the global maximum. Find its height using at most 10n+100 queries.

The observation

A separator of known low cells traps an increasing path on one side. Query a middle cross, then retain the quadrant containing a higher neighbour while preserving the best point already known.

Why it works

From any nonmaximum cell, a strictly increasing path exists and must terminate at the unique maximum. Query the middle row and column and keep the greatest value among them and the previous witness. If that witness has no higher neighbour, it is the maximum. Otherwise its higher neighbour lies in a quadrant. An increasing path from it cannot cross the separator, whose queried values are lower, so the global peak lies in that quadrant. Repeating halves both dimensions; separator costs form a geometric sum O(n).

From a small instance to the contest constraints

Query the entire grid

The global maximum is easy after reading every cell, but the task is about query complexity rather than CPU time.

Budget-violating baseline · n² queries time · O(1) space

Hill climbing from an arbitrary cell

Repeatedly move to a higher neighbour. Uniqueness guarantees eventual success, but an adversarial increasing path can visit nearly every cell.

Correct result; budget can fail · O(n²) queries worst case time · O(queried cells) space

Random sampling then hill climbing

Sample about 3n positions and climb from the best. Hitting the top 2n values leaves at most 2n improving steps. The miss probability is at most e^-6 under fixed nonadaptive heights, so this is not a deterministic guarantee.

Probabilistic alternative · O(n) queries with a probability bound time · O(n) space

Middle-cross divide and conquer

Query both middle lines, inspect neighbours of the best witness, and shrink to the appropriate quadrant. Preserve the boundary invariant at every step.

Recommended deterministic method · O(n) queries time · O(n) queried-value cache space

Reusable separator-and-witness search

Abstract the method as a region, a low separating boundary, and a witness above that boundary. This proof pattern extends beyond peak finding to divide-and-conquer searches where an improving path cannot cross a certified barrier.

Advanced generalization · O(n) for balanced square-grid separators time · O(n) space

Boundary checks

Ordinary binary search on values or coordinates has no monotonic predicate here. Keep the previous best witness when shrinking the region; discarding it breaks the separator invariant. Cache queries and flush outputs. A long increasing snake defeats naïve hill climbing.
