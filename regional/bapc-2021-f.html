Strings and pattern matching · BAPC 2021-F

Fair Play

Every player has two numerical skills. Put all players into pairs so that every pair has the same total in the first skill and the same total in the second. Decide whether such a pairing is possible.

The observation

The common pair sum is forced: T=(sum of all vectors)/(n/2). Every vector v must be matched with T−v. Lexicographic sorting makes these complementary vectors appear in opposite order.

Why it works

Complementation reverses lexicographic order: if a<b, then T−a>T−b. Thus a feasible multiset pairs its smallest vector with its largest, then the next smallest with the next largest. Alternatively check equal multiplicities of each complement pair, and even multiplicity when v=T−v.

From a small instance to the contest constraints

Enumerate perfect matchings

Take the first unpaired vector, try all partners, and recurse. Useful for checking the forced-target insight.

Small-instance oracle · O((n−1)!!) time · O(n) space

Repeated linear complement search

Once T is known, every partner value is forced. Scan the unused list for it.

Exact baseline · O(n²) time · O(n) space

Frequency hash map

Count vectors. Complementary values must have equal counts; self-complementary vectors need an even count. Use a robust pair hash.

Expected linear solution · Expected O(n) time · O(n) space

Lexicographic opposite pairs

Sorting avoids custom hashing and target divisibility arithmetic. Compute the target from the first and last vectors, then verify every symmetric pair.

Recommended · O(n log n) time · O(n) space

Ordered multiset cancellation

Repeatedly remove a vector and its complement from an ordered multiset. This generalises cleanly when pairs must be output and identities must be retained.

Deterministic alternative · O(n log n) time · O(n) space

Boundary checks

Reject odd n. It is the pair sum, twice the average, that must be integral—not the average itself. For example, (0,0) and (1,1) form a valid pair despite a half-integer average. Keep vector coordinates coupled; sorting each coordinate separately is incorrect.
