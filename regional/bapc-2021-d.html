Advanced DP across subjects · BAPC 2021-D

Decelerating Jump

Choose an increasing sequence of positions from the first to the last, maximising collected values while jump lengths never increase.

The observation

Process allowed jump lengths from large to small. dp[i] stores the best score ending at i using only jumps at least the current length. At a fixed length s, update positions from left to right so multiple equal-length jumps are allowed.

Why it works

Before processing s, dp represents paths whose jumps are greater than s. Adding edges of length s in increasing destination order extends them by any number of s-jumps. Such extensions preserve nonincreasing lengths. Every valid path is created when its final, shortest jump length is processed.

From a small instance to the contest constraints

Enumerate intermediate stops

Every subset of intermediate positions defines a possible path; check its jump lengths and score.

Small-instance oracle · O(n·2^n) time · O(n) space

Position and last-jump DP

If the final jump to i has length s, the previous state is at i−s with last jump at least s. Scan all such previous lengths.

Direct baseline · O(n³) time · O(n²) space

Suffix maxima over jump lengths

Store best[i][s]=max score at i with final jump at least s. A suffix maximum answers each predecessor query in O(1).

Accepted alternative · O(n²) time · O(n²) space

Roll the speed dimension

Use the topological order described in the invariant. No n×n table is needed.

Recommended · O(n²) time · O(n) space

Recover an optimal path safely

A single mutable parent per position is unsafe: its predecessor may later change at a different speed. Retain the 2D decision table, or immutable predecessor nodes for successful updates, then reconstruct a consistent history.

Advanced reconstruction · O(n²) time · O(n²) straightforward space

Boundary checks

Initialise only dp[0]=p[0]; all other states are negative infinity, because values can be negative. Left-to-right order within a speed is essential. Do not accidentally allow a later larger jump by processing speeds upward.
