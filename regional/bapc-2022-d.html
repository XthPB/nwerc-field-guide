Games and interactive reasoning · BAPC 2022-D

Dividing DNA

Query whether a DNA interval occurs in a collection, and find as many disjoint absent intervals as possible using at most 2n queries.

The observation

Presence is closed under taking substrings. Therefore, if an interval is absent, every superinterval is absent. Starting after the previous chosen interval, take the shortest prefix that is absent.

Why it works

Let the first interval in an optimum end at e. Its enclosing prefix from our current start is also absent, so our earliest absent prefix ends no later than e. Replace the optimum’s first interval with ours without disturbing later intervals. Induct on the remaining suffix.

From a small instance to the contest constraints

Ask about every interval

Knowing all intervals reduces the problem to interval scheduling, but acquiring this information violates the limit.

Query-budget failure · O(n²) queries time · O(n²) space

Interval DP with a known oracle table

Choose the last absent interval or leave a character unused. This is a useful small-instance checker for the greedy rule.

Offline baseline · O(n²) time · O(n) space

Binary-search the first absent endpoint

For a fixed start, absence is monotone in the endpoint. Find its first true position, select it, and repeat. Correct mathematically, but g log n can exceed the query budget.

Conditional alternative · O(g log n) queries time · O(g) space

One forward scan

Extend the current interval one character at a time. Once absent, select it and restart at its end. Every endpoint is queried at most once.

Recommended · At most n queries time · O(g) space

Earliest-finish scheduling as a reusable theorem

The interactive scan implicitly generates only the first useful finish time. For arbitrary known candidate intervals, sort by finishing time and apply the same exchange proof. Here monotonicity saves the need to list them.

Generalisation · O(m log m) for m known intervals time · O(m) space

Boundary checks

Read the interval endpoint convention in the protocol. An unfinished final present suffix need not be chosen. Flush after queries and stop on protocol errors. Binary search per segment is not automatically within 2n queries.
