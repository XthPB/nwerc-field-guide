Probability, expectation and randomization · BAPC 2022-C

Crashing Competition Computer

Type c characters on a crash-prone computer; decide where to save, paying save time t and crash recovery time r. Minimise expected completion time.

The observation

Let E[k] be the expected time to complete an unsaved block of k characters. Conditioning on the last typing attempt gives E[k]=(E[k−1]+1+p r)/(1−p). A block also costs t to save.

Why it works

After a save the system restarts from the same clean state, so block costs add. The partition DP follows by choosing the final block. More strongly, E[k] is discretely convex: its successive differences grow by 1/(1−p). For a fixed number b of blocks, moving a character from a block at least two longer than another strictly improves the cost; balanced blocks are optimal.

From a small instance to the contest constraints

Enumerate save positions

There are 2^(c−1) partitions of the text into nonempty blocks. Evaluate each with the expected block-cost recurrence.

Exact baseline · O(c·2^c) time · O(c) space

Simulate crashes

Monte Carlo makes the cost of losing an unsaved block tangible. It cannot certify the requested numerical precision and may be extremely noisy for long blocks.

Intuition, not a precision solution · O(trials × random runtime) time · O(1) space

Expected-cost partition DP

Compute E, then dp[i]=min_{1≤j≤i}(dp[i−j]+E[j]+t). With c≤2000 this is comfortably small.

Recommended straightforward solution · O(c²) time · O(c) space

Balance blocks for each save count

For each b=1…c, let q=c/b and z=c%b. Use z blocks of length q+1 and b−z of length q. This is an original consequence of the convexity proof, not a claim that the slides present it.

Derived advanced optimisation · O(c) time · O(c) space

Recover the actual saving policy

Remember the best block count and output its balanced block lengths. This converts an expected-value optimum into a concrete policy and gives a second way to verify the DP’s value.

Constructive extension · O(c) time · O(c) output space

Boundary checks

The final save is required. The recurrence includes the lost work after a crash; using k/(1−p) ignores it. E[k] can overflow even long double: cap costs above the feasible all-single-character solution, since such a block cannot be optimal.
