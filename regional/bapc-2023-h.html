Number theory and algebra · BAPC 2023-H

Hidden Art

A rectangular tile of four colors repeats forever in both directions. You may choose an axis-aligned square whose edges follow pixel boundaries, even across copies of the tile. Can its four corner pixels all have different colors?

The observation

Periodicity turns geometry into congruences. Two row and column offsets can be extended into equal side offsets exactly when they agree modulo gcd(h,w).

Why it works

If corner offsets are Δrow and Δcol, repetitions permit Δrow+kh and Δcol+ℓw. They can be equal iff gcd(h,w) divides Δrow−Δcol, by Bézout. For each ordered pair of columns, a row contributes a two-colour bitmask and a row residue modulo g. A compatible row with the complementary two-colour mask gives all four colours and the required congruence. Use ordered columns or check both signs of the column difference.

From a small instance to the contest constraints

Expand a large finite wallpaper

A guessed finite expansion can miss a large valid square. It is useful for pictures and tests but not a completeness proof.

Unreliable baseline · O(expansion area squared) time · O(expansion area) space

Enumerate all tile rectangles with congruence

Try row pairs and ordered column pairs, test four colours and the gcd condition. This removes the infinite search but remains too slow.

Exact small-input oracle · O(h²w²) time · O(1) space

Group rows by residue for fixed columns

Fix columns first, bucket rows by residue, then compare only congruent-compatible buckets. This exposes the dimension that can be replaced by a tiny colour state.

Intermediate exact baseline · O(w²(h²/g+h)) time · O(h) space

Residue × colour-mask table

For each ordered column pair, record which two-colour masks appear at each residue. Query the complementary mask in the compatible residue. Only 16 masks exist.

Recommended · O(hw²) time · O(g·16) space

Bitset colour-state transitions

Store the possible masks for each residue in one machine word. The transition becomes a shift and bit test. The asymptotic gain already came from the gcd and colour compression.

Constant-factor refinement · O(hw²) time · O(g) space

Boundary checks

A rectangle in one tile does not automatically lift to a square. The condition concerns corner-pixel offsets; adding one to both dimensions for the cut does not change equality. Reject colour pairs with only one distinct colour. Normalize negative residues.
