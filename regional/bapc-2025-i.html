Greedy, sorting and search · BAPC 2025-I

Intermill Logistics

A shipment of wheat can be split among mills that work in parallel. Each mill has its own processing speed and travel time each way. Choose how much to send to each mill to minimize the time until all the processed wheat has returned.

The observation

Ask the decision question first: how much can be processed and returned by a deadline T? Each mill contributes max(0,p_i(T−2t_i)).

Why it works

The total capacity C(T) is continuous and nondecreasing. A deadline is feasible exactly when C(T)≥w, because wheat can be split continuously. Binary search therefore converges to the smallest feasible deadline. Alternatively, between successive activation times 2t_i, C(T)=P·T−B is linear, where P sums active speeds and B sums 2t_i p_i; solve the equation exactly within the correct interval.

From a small instance to the contest constraints

Assign all wheat to one mill

Choose min_i(2t_i+w/p_i). Two identical mills show why this can be suboptimal: splitting work halves the processing part.

Upper bound; not optimal generally · O(n) time · O(1) space

Enumerate the active subset

For each nonempty subset, solve T=(w+Σ2t_i p_i)/Σp_i and check it is consistent with the mills being active. This is an exact conceptual route but ignores the ordered structure of activation.

Small inputs only · O(2^n·n) time · O(n) space

Binary search a deadline

Evaluate capacity in O(n), keeping lo infeasible and hi feasible. Eighty iterations are more than enough for the contest precision over its bounds.

Recommended · O(n·I), I≈80 time · O(1) beyond input space

Sort breakpoints and solve each prefix

An active set is a prefix sorted by 2t_i. For every prefix, recompute its P and B, solve (w+B)/P, and keep the solution if it lies between the current and next breakpoint.

Exact alternative · O(n²+n log n) time · O(n) space

Sweep breakpoints with cumulative sums

Maintain P and B incrementally after sorting. Each mill is inserted once and the correct segment is detected in constant time. Unlike binary search, this computes the relevant linear equation directly.

Advanced efficient alternative · O(n log n) time · O(n) space

Boundary checks

Include the return trip. Do not binary-search only integer times; the answer is fractional. Use long double for capacity and bound the initial upper endpoint by sending everything to one mill. Complexity of real binary search depends on iterations/precision.
