Constructive proofs and implementation · BAPC 2024-J

Jumbled Scoreboards

For each list of football scoreboards, decide whether the snapshots could appear in that order during a single match.

The observation

A team’s score never decreases. The two coordinates must each be nondecreasing independently.

Why it works

Necessity follows because goals only add to a score. For sufficiency, between consecutive nondecreasing score pairs, schedule exactly the required additional goals in any order. Doing this for every adjacent pair constructs a valid match history.

From a small instance to the contest constraints

Simulate missing goals

Between snapshots, increment each team’s score until the next target is reached. A target below the current score is impossible.

Valid but unnecessarily value-dependent · O(n+total score increase) time · O(1) space

Check every pair of snapshots

Any earlier snapshot must be coordinatewise ≤ any later snapshot. This works but repeats implications already enforced by neighbours.

Valid baseline · O(n²) time · O(1) space

Check adjacent pairs

Transitivity makes adjacent checks sufficient. Stream the input while retaining just the previous score.

Recommended · O(n) time · O(1) beyond input space

Difference-array view

Compute score changes; all coordinate differences must be nonnegative. This connects feasibility to invariants on increments.

Alternative derivation · O(n) time · O(n), or O(1) streamed space

Dynamic validity with a segment tree

If snapshots can be edited online, only the two adjacent comparisons around an edit change. Maintain the number of bad boundaries in a segment tree or Fenwick tree and report valid iff it is zero.

Advanced variant, not needed here · O(n) build; O(log n) update time · O(n) space

Boundary checks

Do not compare total goals alone or sort the snapshots. Equal scoreboards are allowed. The two teams remain in fixed coordinate order.
