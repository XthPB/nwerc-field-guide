Probability, expectation and randomization · BAPC 2025-G

Garbage In, Garbage Out

You know a dictionary and receive a text from one of two sources. One concatenates dictionary words without spaces. The other generates letters uniformly at random. Decide which source produced the text, using the promised generation rules.

The observation

The robust semantic test is word segmentation: can the whole string be written as dictionary words? Randomness also permits cheaper statistical classifiers, but their guarantees are different.

Why it works

Let reachable[i] mean the prefix ending at i can be segmented. reachable[0] is true. For each reachable i and each possible word length, extend to i+length if that substring is in the dictionary. Induction on the number of words proves this accepts exactly dictionary concatenations. A random string could itself be a dictionary concatenation, so even this semantic test is not logically identical to recovering the hidden generator; under the stated distribution that ambiguity is negligible.

From a small instance to the contest constraints

Recursive segmentation

Try all five possible word lengths at each position. Ambiguous prefixes repeat the same suffix subproblem; crafted dictionaries cause exponential branching.

Exponential baseline · O(5^(L/6)) worst case time · O(L) space

Memoized word break

Cache the answer for each starting position. This is the first major optimization: histories leading to the same index have identical future options.

Exact membership test · O(L·5·10) expected time · O(L+dictionary size) space

Bottom-up word break

Use a boolean prefix array to avoid deep recursion. Word length is at most 10, so constructing short substrings is inexpensive and exact string equality resolves hash collisions inside unordered_set.

Recommended · O(L·5·10) expected time · O(L+dictionary size) space

Trie traversal from reachable positions

Store words in a trie and follow at most W=10 characters from each reachable position. Mark a destination whenever a terminal trie node is reached. This generalizes naturally to longer dictionaries.

Exact alternative · O(L·W+dictionary characters) time · O(L+dictionary characters) space

Prefix or repeated-6-gram classifier

A human text starts with a dictionary word. A uniformly random prefix matches one of D length≥6 words with probability at most D/26^6 by a union bound. Repeated six-grams give another signal for sufficiently long texts. These are contest-specific classifiers, not adversarial word-break algorithms.

Distribution-dependent alternative · O(L+dictionary size) time · O(L+dictionary size) space

Boundary checks

Do not present a randomized-input heuristic as correct on arbitrary text. Dictionary size and string length are different parameters. Hashing a substring is not collision-free unless verified. The provided accepted sources include both exact segmentation and probabilistic classifiers.
