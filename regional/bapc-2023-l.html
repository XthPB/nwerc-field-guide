Graphs, connectivity and flow · BAPC 2023-L

Locking Doors

Doors can be locked from only one side. Determine the minimum number of exterior exits needed so all doors can eventually be locked while people can leave.

The observation

Cycles of mutually reachable rooms behave as one region. Every sink region in the directed condensation graph needs its own exit.

Why it works

Orient b→a when the door can be closed from side a. An exit in a permits closing doors along paths directed toward a. Collapse strongly connected components: the result is a DAG. A sink component cannot lead to an exit elsewhere, so each sink needs at least one exit. Conversely every component in a finite DAG reaches a sink; placing one exit in each sink supports an ordering that closes all doors. The lower bound and construction match.

From a small instance to the contest constraints

Enumerate exit subsets

For each chosen exit set, check that every room can reach one through the directed closing relation. Minimize set size.

Tiny graphs only · O(2^n·(n+m)) time · O(n+m) space

Reachability matrix and equivalence classes

Compute transitive closure. Two vertices share a component if each reaches the other. Count components that reach no other component directly.

Small-graph baseline · O(n³) time · O(n²) space

Kosaraju SCC decomposition

Use finish order on the original graph, then traverse the reverse graph in descending finish order. Mark components with outgoing cross-edges.

Recommended · O(n+m) time · O(n+m) space

Tarjan low-link SCCs

Use one DFS with an active stack. This teaches the important distinction between a back edge into the active SCC search and an edge into an already completed component.

Advanced alternative · O(n+m) time · O(n+m) space

Produce an exit certificate and verify it

Choose one representative per sink SCC, then reverse-BFS from those exits. Every vertex must be reached. This checks the sufficiency part and gives a concrete plan for placing exits.

Constructive extension · O(n+m) time · O(n+m) space

Boundary checks

Count sinks, not sources, under the stated edge convention. An isolated room is a sink SCC. Deduplicating condensation edges is unnecessary if you only mark whether outgoing edges exist.
