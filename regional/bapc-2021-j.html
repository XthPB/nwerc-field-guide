Games and interactive reasoning · BAPC 2021-J

Jail or Joyride

Find the minimum police travel distance guaranteeing capture of fleeing teenagers, who choose a farthest reachable junction whenever approached. Ties are adversarial for a certainty guarantee.

The observation

After the first approach, every non-leaf teenager position allows escape to the whole graph. Build a directed graph from each non-leaf to all its globally farthest vertices, using original shortest-path distances. A reachable cycle means no finite capture guarantee; otherwise compute a longest weighted path.

Why it works

If an approach edge is not a bridge, removing it does not restrict escape. If it is a bridge, a non-leaf destination beyond it has a neighbour even farther from the previous teenager position; this contradicts having selected a farthest destination. Thus after the initial escape, a bridge approach can occur only at a leaf, where capture succeeds. The police always takes a shortest approach because choosing a longer route cannot improve the escape set. Handle the initial restricted component separately.

From a small instance to the contest constraints

Full pursuit-game states

A state records police and teenager positions; an action chooses an approach, followed by all possible escape choices. Retrograde minimax can model the problem, but proving the structural reduction is far simpler than implementing this graph.

Conceptual baseline · Polynomial but large state/action graph time · At least O(n²) space

All-pairs shortest paths

With n≤300, Floyd–Warshall supplies all original-graph distances. Repeated Dijkstra is an alternative for sparse graphs.

Necessary subproblem · O(n³) time · O(n²) space

Simulate the first escape, then DFS

Choose an edge entering t along a shortest p→t path. Temporarily remove it for reachability only. The first escape targets maximise d[t][v] within the remaining component. Then use the farthest-vertex graph and three-colour DFS.

Recommended · O(n³+n+m) time · O(n²+m) space

SCCs followed by DAG DP

Restrict to states reachable after the first escape. A nontrivial SCC or self-loop gives an adversarial cycle. Otherwise topologically sort and compute longest paths to leaf states.

Alternative · O(n³) time · O(n²+m) space

Repeated Dijkstra and iterative graph processing

On sparse graphs, replace Floyd–Warshall with Dijkstra from each source. Use iterative cycle detection or SCC decomposition to avoid recursion. This changes implementation costs, not the crucial pursuit proof.

Engineering alternative · O(n(m+n) log n+n²) time · O(n²+m) space

Boundary checks

Satnav distances use the original graph even when the police blocks an edge; reachability uses the blocked graph. Keep every tied farthest destination. A cycle outside the reachable escape region is irrelevant. Use 64-bit path lengths and a safe infinity.
