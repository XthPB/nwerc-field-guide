Geometry and numerical methods · BAPC 2025-C

Coherency

Up to 200,000 non-overlapping circular bases lie on a huge board. Two models are adjacent when their boundary distance is at most 50.8 mm. Decide connectivity, and when there are at least seven models, require every model to have at least two neighbours.

The observation

This is an implicit proximity graph. Connectivity is easy after finding the edges; the real problem is finding nearby pairs without checking all pairs.

Why it works

The largest allowed diameter is 160 mm, so adjacent centres are at most 160+50.8=210.8 mm apart. With 211 mm square cells, adjacent centres lie in the same or one of eight neighbouring cells. Minimum base diameter and non-overlap bound the number of centres in each cell. Thus the candidate loop is linear in n up to a packing constant. Union every adjacent pair and separately count degrees.

From a small instance to the contest constraints

Build the entire graph

Check every pair and run BFS. This separates the geometric predicate from connectivity and serves as a clean oracle.

Small inputs only · O(n²) time · O(n²) space

Quadratic DSU without storing edges

You need components and degrees, not the full graph. Union and count as each pair is found. The pair search is still the bottleneck.

Memory improvement only · O(n² α(n)) time · O(n) space

Sweep by x coordinate

Sort centres by x. Stop a forward scan when x-distance exceeds 211. Add a y filter before the exact predicate. This is often fast but a narrow vertical strip can still contain many candidates.

Exact; worst-case quadratic · O(n log n+n²) worst case time · O(n) space

Spatial buckets plus DSU

P bounds nearby packed models. Hash cell coordinates; compare each incoming model against earlier models in nine cells. This covers all pairs exactly once.

Recommended · Expected O(n·P α(n)) time · O(n) space

Ordered spatial buckets

Replace the hash table with a map or sort points by cell and build ranges. The packing proof is unchanged; lookup gets a logarithmic bound. This trades some speed for predictable behaviour and avoids hash tuning.

Deterministic lookup alternative · O(n log n+n·P α(n)) time · O(n) space

Boundary checks

Compare circle boundaries, not centres alone. Both connectivity and the extra degree requirement matter. Test adjacency exactly with 100·(dx²+dy²) ≤ [5(d1+d2)+508]²; promote products to __int128. Packing guarantees are essential to the complexity claim.
