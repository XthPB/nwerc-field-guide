Bitmasks and subset transforms

First let a bit mean one used job. Then add an endpoint when the next move has a price, partition the mask when groups act together, and finally aggregate many masks in one transform.

  • An exact set can determine the step numberTwo workers can do jobs {x,y} and {y}. How many assignments give each worker a distinct job?
  • Visit every city with a set and a last stopVisit every city at minimum cost. If two routes have visited exactly the same cities, when may you discard one?
  • A route can stop, return, visit only terminals, or respect prerequisitesA courier may need to return to the depot, stop at the last delivery, or deliver A before B. Which parts of a tour DP change?
  • Pack all possible Hamiltonian endpoints into one maskFor each small set of cities, can any path visit all of them and end at a particular city?
  • A lexicographic pair can replace enumeration of groupsFit riders of weights 4, 4 and 2 into lifts of capacity 6. How can a subset DP compare two partial packings?
  • Track prime parity, used primes, or small-feature coverageWhich nonempty subset of 2, 8 and 3 has a square product?
  • Partition a set into compatible groupsSeat four guests in as few compatible groups as possible. Guests a and b refuse to sit together.
  • Charge a pair whenever a growing cut separates itPlace symbols in a line so that heavily related pairs sit close. How can you price a partially chosen ordering?
  • All submask aggregates by one sweep per bitYou know a value for each binary mask. How can you sum over every subset of each mask without listing all subset pairs?

Test your recognition
Every subset of a 20-element set needs a sum over its submasks. When is a 20-pass transform valid?

When each answer aggregates a value belonging to the submask itself. If a transition instead combines arbitrary DP values for both the submask and its complement inside M, the plain SOS transform does not supply it.

Can a TSP state remember just the vertices visited if all distances are nonnegative?

No. Two orders of that set can end in different cities whose next-edge costs differ. Nonnegativity leaves that dependence intact.
