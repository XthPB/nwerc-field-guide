Bitmasks and subset transforms

Two optional features give four possible sets of features. Each exact set has a value. For every allowed set, find the sum of values for choices using only features inside it. Can the four requests share work?

Start this topic in reading order → · See the whole reading path

  • An exact set can determine the step numberThere are as many jobs as workers. Each worker must get one job they can do, and no two workers may share a job. If the first worker can do x or y and the second can do only y, how many complete assignments are possible?
  • A lexicographic pair can replace enumeration of groupsThree riders weigh 4, 4 and 2. A lift carries total weight at most 6 per ride, and each rider must travel once. You can choose who rides together and in what order to load them. Find the fewest rides.
  • Visit every city with a set and a last stopYou have a small set of cities, a starting city and a travel cost for each available leg. Build a route that visits every city exactly once at minimum total cost. If the task requires a round trip, add the leg back to the start after the last visit.
  • A route can stop, return, visit only terminals, or respect prerequisitesA courier starts at a depot and must visit all delivery locations. Travel prices are given. Find the cheapest trip when the courier may finish anywhere. Then change the rules so the courier must return to the depot, or must visit A before B. How do those requirements change the answer?
  • Pack all possible Hamiltonian endpoints into one maskA small graph tells you which pairs of cities can be traveled between. For each subset of cities, determine which of its cities can be the endpoint of a path visiting precisely that subset, each city once. The answer for a subset can contain several endpoints.
  • Track prime parity, used primes, or small-feature coverageChoose a nonempty subset of the numbers 2, 8 and 3. Its product must be a perfect square, such as 16. Determine which selections qualify. The larger counting version asks how many different selections make every prime exponent even.
  • Partition a set into compatible groupsSeat four guests at tables. You know which pairs can share a table, and every pair at the same table must be compatible. Guests a and b refuse to sit together. Use the fewest tables that allow everyone to sit.
  • Charge a pair whenever a growing cut separates itYou’re given symbols and a weight for each related pair. Place the symbols in distinct positions on a line. A pair pays its weight times the number of positions separating it. Find an ordering that minimizes the total payment.
  • All submask aggregates by one sweep per bitEach binary mask represents a subset of a small universe and has an assigned value. For every mask M, return the sum of values of all subsets contained in M. The empty subset and M itself both contribute.

Test your recognition
Every subset of a 20-element set needs a sum over its submasks. When is a 20-pass transform valid?

When each answer aggregates a value belonging to the submask itself. If a transition instead combines arbitrary DP values for both the submask and its complement inside M, the plain SOS transform does not supply it.

Can a TSP state remember just the vertices visited if all distances are nonnegative?

No. Two orders of that set can end in different cities whose next-edge costs differ. Nonnegativity leaves that dependence intact.
