Algebraic and counting DP

Two independent parts of a construction can each contribute size zero or one. The first has 1 and 2 ways to do so, and the second has 3 and 4 ways. Count complete constructions of each combined size.

Start this topic in reading order → · See the whole reading path

  • Count the complement using a canonical first violationConsider all length-three binary strings. Count the ones where neither the first nor the second position holds a 1. Strings that violate both restrictions belong to both forbidden groups, so any counting argument must account for their overlap.
  • A divisor lattice is another DP orderChoose two different positions in the array 2, 4, 6. Count the unordered pairs whose greatest common divisor is exactly 2. Divisibility of both entries by 2 is necessary, but for general inputs their gcd can still be larger.
  • Close a fixed divisor target under harmless additionsYou’re given positive integers and may select a subsequence. Its least common multiple must be a value absent from the entire input. Find the greatest possible subsequence length. In [1,2,3,12], the values 1,2,3 have LCM 6, which is absent.
  • Count by rank instead of remembering actual labelsFill three positions with the distinct numbers 1, 2 and 3. The first value must be smaller than the second, and the second larger than the third. Count the valid permutations. A longer input supplies a whole sequence of required rises and falls.
  • Count permutations with exactly k inversionsAn inversion is a pair of positions where the earlier number is larger. Arrange the numbers 1, 2 and 3 in every possible order and count how many orders have exactly one inversion. The larger version gives the length and required inversion count.
  • Maintain a composition when positions changeHouses stand in a line and each has a reward. You may take rewards from any houses except two adjacent ones. After an update changes the reward at one house, report the maximum possible total across the whole street.
  • Exponentiate a repeated stationary transitionCount binary strings of length n that never contain two consecutive 1s. The same local rule applies at every position, and n can be enormous. You need the answer without advancing through all n positions one at a time.
  • Jump to the n-th term of a short linear recurrenceYou know the first few terms of a sequence and a fixed formula expressing each later term as a linear combination of recent terms. Find a very distant term, such as the trillionth, under the specified arithmetic. Computing all earlier terms one by one is too slow.
  • Convolve independent count distributionsTwo labeled items weigh 2 and a third weighs 3. Each item can be taken or left once. Count the selections weighing exactly 5. More generally, you may want a count for every possible total weight at once.
  • OR, AND, XOR, and subset convolution are different joinsTwo independent choices each produce a small binary label. You know how many ways each side can produce each label. Count ordered pairs of choices by the XOR of their labels. In particular, how many pairs produce zero?
  • Combine two functions on disjoint subsetsFor each guest set S, distribute all its guests between two labeled tables A and B. Each table earns a value determined by its entire guest set. Sum the product of the two table values over disjoint assignments whose union is S.
  • Count inputs that produce the same DP stateWrite every two-letter word over A and B. Compare each word with AB using the length of their longest common subsequence, where skipped letters are allowed. Count the words for which that length is exactly one. The goal is to count possible inputs producing a specified DP result.

Test your recognition
A 2ᵇ-point inverse XOR transform normally divides by 2ᵇ. Your modulus is even. What information would let you divide exactly?

For integer forward convolutions/powers, lift the whole computation to modulus 2ᵇp. The canonical residue after the second transform is divisible by 2ᵇ, yielding the desired residue modulo p.

Exactly t edges are allowed, and edges have signed costs. What algebra and identity do you use in matrix powering?

Use min-plus multiplication, zero diagonal and ∞ off-diagonal for identity. Finite-length walks are well defined even if some edge costs are negative.
